# 확장 월드 설정 출처

`expanded-191-v1.json`은 D-069에서 승인한 기존 레포용 선택형 설정이다. 도시 키와 이름은 `resources/map/integration.json`을 대조했다. 특산 거점과 생산량은 게임 밸런스용이며 역사적 산출량을 주장하지 않는다. 물류·황실의 나머지 수치는 T4-93·T4-94의 검토된 설정을 따른다.

가문 이름 후보 214개는 `integration191` 장수 이름에서 검수한 복성 접두를 먼저 떼고 1~2글자 한글을 추출한 기존 제안을 보존했다. 원자료 출처는 [기존 자원 고지](../NOTICE.md)에 있다. 이름으로 성별·혈연을 추정하지 않는다. 출산 5%·누적 2,500명 등 공개 기본값은 D-069를 따른다.

이 파일의 추가만으로 공개 생성 목록에 설정을 노출하지 않는다. 생성 요청·엔진·초기화 연결과 실제 검증은 해당 구현에서 진행한다.
