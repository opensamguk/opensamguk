# 초기 장수 성별 자료

`191-sex.json`은 가문 기능을 켠 새 월드의 초기 성별 자료다. 《삼국연의》 제90회 [원문](https://zh.wikisource.org/wiki/三國演義/第090回)에서 맹획을 가리킨 「既為男子」와 축융의 「我雖是一婦人」·「妻祝融夫人」을 확인했다. 고전 원문의 두 성별 사실과 확인에 필요한 짧은 문구만 기록했다. 원문 전체·번역·이미지를 복제하지 않았다.

장수 ID·한국어 이름·한자 인물은 `191-five-stats.json`의 대응과 대조한다. ID108은 맹획·孟獲이며 ID439는 축융·祝融이다. 시나리오1030과 integration191의 같은 ID·이름에만 적용한다. 이름·초상·직책으로 성별을 추정하지 않는다. 원장에 없는 인물은 `UNKNOWN`이다.

`sourceRevision`은 한자 인물·성별·원문 주소·선택 문구를 정규 JSON으로 직렬화한 SHA-256이다. 페이지 HTML의 해시는 아니다. `review.contentSha256`은 검토 메타데이터를 제외한 판·대상 시나리오·원장 행 전체의 해시다. 실제 적용 값은 월드를 만들 때 재생 원본과 초기 상태 해시에 고정한다. 진행 중인 월드에는 다시 적용하지 않는다.

`191-sex-2.json`은 1판의 두 행을 보존하고 검토된 남성 12명의 사실을 추가한 전체 스냅숏이다. 《삼국연의》 [제1회](https://zh.wikisource.org/w/index.php?title=三國演義/第001回&oldid=2583915), [제8회](https://zh.wikisource.org/w/index.php?title=三國演義/第008回&oldid=5314829), [제15회](https://zh.wikisource.org/w/index.php?title=三國演義/第015回&oldid=8729938), [제29회](https://zh.wikisource.org/w/index.php?title=三國演義/第029回&oldid=2567991), [제79회](https://zh.wikisource.org/w/index.php?title=三國演義/第079回&oldid=2568043)의 형제·아들·아버지 표현과 각 인물의 대응을 독립 검토했다. 직접 근거가 부족한 조조는 추가하지 않았다. 関羽·張宝·孫権은 원문의 關羽·張寶·孫權과 같은 인물임을 대조했다. 계보나 역사상 실제 혈연을 등록한 자료는 아니다.

1판 파일과 이미 저장한 성별은 바꾸지 않는다. 새 생성은 최신 판을 쓰며, 기록된 초기 해시가 있는 생성 요청과 기존 월드 초기화는 같은 해시를 만든 판을 유지한다. 재생은 생성 때 고정한 값을 읽는다. 새 판에 없는 인물은 계속 `UNKNOWN`이며, 별도 `general_ex` 인물은 추가하지 않는다.

`191-sex-3.json`은 1·2판의 사실 14행을 보존하고 남성 9명을 추가한 전체 스냅숏이다. 《삼국연의》 [제31회 고정판](https://zh.wikisource.org/w/index.php?title=三國演義/第031回&oldid=2567992)의 아들 지칭으로 원담·원희·원상, [제40회 고정판](https://zh.wikisource.org/w/index.php?title=三國演義/第040回&oldid=2568003)의 아들 지칭으로 유기·유종, [제57회 고정판](https://zh.wikisource.org/w/index.php?title=三國演義/第057回&oldid=2568020)의 아들·조카 지칭으로 마초·마휴·마철·마대를 확인했다. 독립 자료 검수에서 마철의 병렬 아들 지칭과 부자 세 사람 문맥을 함께 대조했다. 원희의 袁煕·袁熙, 마철의 馬鉄·馬鐵은 인물 대응을 확인한 뒤 자료와 원문의 표기를 각각 유지했다.

성별만 추가하며 원문의 가족관계·배우자·나이를 게임에 등록하지 않는다. 기존 1·2판 파일과 저장 값은 그대로 보존한다. 3판의 확인 인물은 23명(남성 22명·여성 1명)이며 여성 수는 늘지 않는다. 자연 혼인이나 다세대 계승의 실제 발생을 이 자료만으로 증명하지 않는다.

`191-sex-4.json`은 3판의 인물 사실 23행을 그대로 사용한다. 원작 1030과 삼10 191년 1·2판의 기본 장수 491행을 대조한 뒤 두 삼10 리비전을 적용 대상에 더했다. 삼10의 이후 리비전은 인물 대응을 다시 확인해야 한다. 이미 생성한 월드와 초기 해시가 기록된 요청은 당시의 원장 판으로 해석한다.
