# 시간과 턴

> 상태: 초안 (T2-17, AC-M2-11) · 사실 기준: main `0115e6b` · 참고: core2026 `docs/user/time-and-turns.md` (구성만)
> 이 문서가 답할 질문: 내 턴은 언제 오고 예턴은 어떻게 소비되나?

## 1. 현실 시간과 게임 달력

게임 달력의 한 달이 한 턴입니다. 현실 시간으로 한 달이 몇 분인지는 월드를 만들 때 정하며 월드마다 다릅니다.
메인 머리글에 `현재 191년 1월 · 턴 60분`처럼 보이면 현실 60분마다 게임이 한 달씩 갑니다.

모든 장수가 같은 순간에 움직이지는 않습니다. 장수마다 한 달 안에서 자기 턴이 오는 위치가 정해져 있고 매달 같은 위치에서 턴을 맞습니다.
새 장수의 위치는 만들 때 무작위로 정해집니다. 다음 턴 시각은 장수 정보 칸의 다음 턴과 위쪽 띠의 남은 시간에 보입니다.

위쪽 띠에 남은 시간 대신 다른 글이 보이면 월드 상태가 바뀐 것입니다.

| 표시 | 뜻 |
| ---- | -- |
| 개시 전 | 아직 시작하지 않은 월드입니다 |
| 일시 정지 | 운영자가 멈췄습니다. 시간이 흐르지 않고 밀린 턴도 생기지 않습니다. 예턴 저장은 됩니다 |
| 종료 | 기수가 끝났습니다. 예턴을 저장할 수 없습니다 |
| 턴 처리 중 | 남은 시간이 0이 되어 엔진이 턴을 실행하는 중입니다 |

## 2. 예턴 30칸

예턴은 미리 넣어 두는 명령 30칸입니다. 메인 오른쪽의 명령 목록 칸에서 편집하고 메뉴의 예턴에서 넓게 볼 수 있습니다.
칸마다 실행 시기 열에 그 칸이 실행될 연월과 시각이 보입니다.

턴이 오면 1번 칸이 실행됩니다. 성공하든 실패하든 그 칸은 쓰이고 나머지가 한 칸씩 앞으로 당겨지며 30번 칸은 빈 칸이 됩니다.
편집기도 새 목록을 받아 한 칸 당겨진 모습을 보여 줍니다.

편집 조작은 아래와 같습니다. 넣기·당기기·밀기·반복은 화면에만 반영되고 [저장]을 눌러야 서버에 갑니다.

| 조작 | 하는 일 |
| ---- | ------- |
| 칸 고르기 | 칸을 누르면 고르거나 풀고 Shift를 누른 채 누르면 범위를 고릅니다. 전체·홀수 칸·짝수 칸·선택 해제 단추도 있습니다 |
| 넣기 | 명령 찾기에서 명령을 고르고 대상·수량을 채운 뒤 [N번 칸에 넣기]를 누릅니다 |
| 당기기·밀기 | 모든 칸을 칸 수만큼 앞이나 뒤로 옮깁니다. 비는 자리는 빈 칸이 됩니다 |
| 반복 | 이어진 한 구간을 바로 뒤에 횟수만큼 이어 붙입니다 |
| 저장 | 30칸을 한 번에 보냅니다. 저장하지 않은 편집 수가 위에 보입니다 |

다른 탭에서 저장했거나 그 사이 턴이 실행되어 목록이 바뀌었으면 저장할 때 `다른 곳에서 먼저 바뀌었습니다` 안내가 나옵니다.
[내 편집 다시 적용]을 누르면 최신 목록에 같은 편집을 같은 순서로 다시 하고 확인한 뒤 다시 저장합니다.

### 빈 칸과 기본 방침

아무 명령도 넣지 않은 칸은 휴식으로 실행됩니다. 휴식은 비용이 없고 부상을 1 줄입니다.
빈 칸에서 할 일을 정해 두는 기본 방침은 준비 중입니다 ([장수와 도시, 내정](./general-and-city.md#5-기본-방침)).

### 국가 예턴

나라에도 국가 명령을 넣는 예턴 30칸이 있습니다. 군주의 턴이 시작될 때 국가 예턴 1번 칸이 먼저 실행되고 그다음 군주의 장수 예턴이 실행됩니다.

국가 예턴을 넣는 화면은 아직 없습니다. 그래서 지금은 플레이어가 군주인 나라에서 선전포고, 천도, 포상 같은 국가 명령이 실행되지 않습니다. NPC 나라는 컴퓨터가 국가 명령을 고릅니다.

## 3. 넣을 수 있어도 실행에 실패하는 이유

저장할 때는 명령 이름과 입력 형식만 봅니다. 금이 모자라거나 다른 도시에 있어도 저장은 됩니다.
사전 검사 열은 지금 상태로 본 결과입니다. 가능 또는 경고와 이유가 보입니다. 실제 실행은 그 칸의 턴이 왔을 때의 상태로 다시 검사합니다.

그 사이에 상황이 바뀌면 사전 검사가 가능이었던 칸도 실패합니다. 앞 칸에서 금을 다 썼거나 월간 정산으로 보급이 끊겼거나 도시를 빼앗긴 경우입니다.
실패하면 아무것도 바뀌지 않고 칸만 쓰입니다. 개인 기록에 실패와 이유가 남습니다.


## 5. 기수가 끝날 때

한 판(기수)은 두 경우에 끝납니다. 한 국가가 남은 국가를 모두 없애고 중립 도시까지 전부 차지하면 천하통일로 끝나고 그 국가가 승자입니다.
월드를 만들 때 종료 연도를 정해 두었다면 그 해 12월 정산을 마친 순간에도 끝납니다. 이때는 승자가 없습니다. 종료 연도는 월드마다 다르고 정하지 않은 월드는 통일로만 끝납니다.

판이 끝나면 메인 화면 맨 위에 기수 결과 칸이 나옵니다. 끝난 이유(천하통일 또는 종료 연도 도달), 승자 국가 이름(없으면 승자 없음), 종료 연월, 남은 국가 수를 볼 수 있습니다.
위쪽 띠의 연월은 종료 연월에 멈추고 상태 칸에 종료가 보입니다. 새로고침하거나 장수가 없는 계정으로 열어도 같은 결과가 나옵니다.

끝난 판에서는 예턴을 바꿀 수 없습니다. 저장 버튼은 막혀 있고 누르면 이유가 나옵니다. 지도와 장수·도시·국가 정보, 기록은 그대로 볼 수 있습니다.

운영자가 판을 빠르게 진행시키면 위쪽 띠 상태 칸에 가속 진행 중이 보이고 다음 턴까지 남은 시간은 나오지 않습니다. 가속 중에도 저장한 예턴은 순서대로 실행되고 빈 칸은 휴식입니다. 열어 둔 화면은 몇 초 간격으로 새 연월과 기록을 받아 오고 판이 끝나면 새로고침 없이 결과 칸이 나옵니다.
| 자주 보이는 이유 | 뜻 |
| ---------------- | -- |
| 국가에 소속되어야 합니다. | 재야입니다. 먼저 임관합니다 |
| 자기 국가 도시에서만 가능합니다. | 다른 나라나 공백지에 있습니다. 귀환이나 이동으로 내 나라 도시로 갑니다 |
| 보급이 끊긴 도시입니다. | 수도와 이어지지 않은 도시입니다 |
| 금이 부족합니다. | 내 장수의 금이 비용보다 적습니다 |
| 이미 최대치입니다. | 그 수치가 이미 최대입니다 |

모든 이유와 대처는 [명령과 실행 시기](./commands-and-timing.md#3-실패-이유와-대처)에 있습니다.

## 4. 달이 바뀔 때 일어나는 일

달이 끝나면 엔진이 월간 정산을 아래 순서로 합니다. 달 경계와 같은 시각에 턴이 있는 장수는 정산이 끝난 뒤 실행됩니다.

1. 세입과 봉급. 1월과 7월이 끝날 때 금, 4월과 10월이 끝날 때 쌀이 들어옵니다. 나라마다 자기 도시의 상업(금) 또는 농업(쌀) × 주민 ÷ 1,000 × 0.2를 모두 더합니다.
   그 절반을 등장한 소속 장수가 똑같이 나눠 받고 나머지는 국고에 들어갑니다. 보급이 끊긴 도시도 세입에 들어갑니다.
2. 인구와 민심. 모든 도시의 주민이 최대치와의 차이의 2%만큼 늘어납니다. 지금 세율(20%)에서는 민심이 변하지 않고 소수점만 반올림됩니다.
3. 보급. 보급을 다시 계산합니다. 보급이 끊긴 나라 도시는 농업·상업·치안·수비·성벽이 10% 줄고 그 도시에 있는 장수는 훈련과 사기가 10씩 내려갑니다.
4. 외교 기한. 기한이 지난 선전포고는 교전이 되고 기한이 지난 불가침은 끝나 중립이 됩니다.
5. 연감. 나라별 도시 수·장수 수·국고·군량을 기록합니다. 국가 기록, 중원 정세, 순위가 이 값을 씁니다.

정산에는 재해나 사건이 없고 난수도 쓰지 않습니다.
