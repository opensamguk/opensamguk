# 국가 재정과 외교

> 상태: 초안 (T2-17, AC-M2-11) · 사실 기준: main `0115e6b` · 참고: core2026 `docs/user/economy-and-diplomacy.md` (구성만)
> 이 문서가 답할 질문: 나라의 돈은 어떻게 돌고 외교 상태는 어떻게 바뀌나?

## 1. 세율과 지급률

지금은 세율과 봉급 비율이 모든 나라에서 같고 바꿀 수 없습니다. 세율은 20%이고 국가 정보 칸에 `세율 20%`로 보입니다.
세입의 절반이 봉급으로 소속 장수에게 가고 나머지 절반이 국고에 남습니다.

나라마다 세율과 지급률(봉급으로 나눠 줄 비율)을 정하는 기능은 준비 중입니다.

## 2. 국고가 들어오고 나가는 길

| 길 | 들어옴·나감 | 언제 |
| -- | ----------- | ---- |
| 세입 | 국고에 남는 몫이 들어옵니다 | 1월·7월이 끝날 때 금, 4월·10월이 끝날 때 쌀 |
| 봉급 | 세입의 절반을 등장한 소속 장수가 똑같이 나눠 받습니다 | 세입과 같은 때 |
| 헌납 | 장수의 금·쌀이 국고로 들어옵니다 | 장수가 헌납 명령을 실행할 때 |
| 포상·몰수 | 국고 → 장수, 장수 → 국고 | 군주의 국가 명령 |
| 원조 | 다른 나라에 금·쌀을 보냅니다 | 군주의 국가 명령 |

세입 계산은 [시간과 턴](./time-and-turns.md#4-달이-바뀔-때-일어나는-일)에 있습니다. 내 장수의 금과 쌀을 서로 바꾸려면 개인 명령인 군량매매를 씁니다. 금과 쌀을 1:1로 바꾸고 내 나라 보급 연결 도시에서만 됩니다.

## 3. 선전포고·교전·종전·불가침

두 나라 사이의 외교 상태는 넷 중 하나입니다.

| 상태 | 뜻 | 끝나는 때 |
| ---- | -- | --------- |
| 중립 | 아무 관계가 없습니다. 출병할 수 없습니다 | 선전포고나 불가침으로 바뀔 때 |
| 선전포고 | 전쟁을 예고한 상태입니다. 아직 출병할 수 없습니다 | 1개월 기한이 지난 뒤 첫 월간 정산에서 교전이 됩니다 |
| 교전 | 서로 출병할 수 있습니다. 교전국 도시와 맞닿은 도시는 전선이 되어 내정 효과가 절반입니다 | 기한이 없습니다. 종전 제의가 받아들여져야 끝납니다 |
| 불가침 | 서로 공격하지 않기로 한 상태입니다 | 12개월 뒤 중립으로 돌아갑니다. 파기 제의로 일찍 끝낼 수도 있습니다 |

선전포고는 중립인 나라에만, 불가침 제의는 중립인 나라에만, 종전 제의는 교전 중인 나라에만 할 수 있습니다. 교전이나 선전포고 상태인 나라에는 원조할 수 없습니다.

제의를 받은 쪽이 NPC 나라면 종전, 불가침, 원조는 바로 받아들이고 불가침 파기는 거절합니다. 플레이어 나라가 받으면 응답 대기로 기록만 남고 아무것도 바뀌지 않습니다. 플레이어가 제의에 답하는 방법은 준비 중입니다.

NPC 나라는 교전이나 선전포고 상대가 없으면 맞닿은 나라에 선전포고합니다.

위 명령은 모두 국가 예턴으로 실행하는 군주의 국가 명령입니다. 국가 예턴을 넣는 화면이 아직 없어서 지금은 플레이어 군주가 선전포고나 제의를 할 수 없습니다 ([시간과 턴](./time-and-turns.md#국가-예턴)).
플레이어 나라는 지금 공백지로 출병하거나 NPC 나라가 걸어 온 교전에서 싸웁니다.
