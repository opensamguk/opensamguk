# 장수와 도시, 내정

> 상태: 초안 (T2-17, AC-M2-11) · 사실 기준: main `0115e6b` · 참고: core2026 `docs/user/general-and-city.md` (구성만)
> 이 문서가 답할 질문: 내 화면의 숫자는 무슨 뜻이고 내정으로 무엇을 키우나?

## 1. 장수의 능력과 자원

메인의 장수 정보 칸에 내 장수의 값이 모두 있습니다. 능력치는 장수를 만들 때 정하고 지금 규칙에서는 오르지 않습니다.

| 값 | 뜻 |
| -- | -- |
| 통솔 | 거느릴 수 있는 최대 병력이 통솔 × 100입니다. 정착 장려와 주민 선정의 효과를 정합니다 |
| 무력 | 치안 강화, 수비 강화, 성벽 보수의 효과를 정합니다 |
| 지력 | 농지 개간, 상업 투자, 기술 연구의 효과를 정합니다 |
| 금 | 내 장수의 돈입니다. 내정, 모병, 훈련, 사기진작 비용을 여기서 냅니다 |
| 쌀 | 내 장수의 식량입니다. 전투 중 병사가 먹습니다 |
| 병력 | 거느린 병사 수입니다. 모병·징병으로 늘립니다 |
| 훈련·사기 | 0~100입니다. 높을수록 전투 피해가 커집니다 |
| 경험·공헌 | 내정에 성공하면 오릅니다. 공헌은 헌납으로도 오릅니다. 순위에 쓰입니다 |
| 부상 | 휴식하면 1, 요양하면 10 줄어듭니다 |
| 나이 | 새 장수는 20세로 시작합니다 |
| 다음 턴 | 내 장수의 다음 턴 시각입니다 |

통솔·무력·지력은 지금 전투 피해 계산에 들어가지 않습니다. 어떤 내정을 맡을지 정할 때 봅니다.
지금 규칙에는 부상이 생기는 일도, 나이가 드는 일도 없습니다.

## 2. 도시의 수치

지도에서 도시를 누르면 메인의 도시 정보 칸이 그 도시로 바뀝니다.
수치는 내 나라 도시이거나 내 장수가 있는 도시일 때만 보입니다. 다른 도시는 주인, 규모, 보급, 연결 도시만 보입니다.

| 수치 | 뜻 |
| ---- | -- |
| 주민 | 모병·징병으로 병사가 되는 사람입니다. 세입에도 곱해집니다. 달마다 최대치와의 차이의 2%만큼 늘어납니다 |
| 농업 | 4월과 10월 정산에 들어오는 쌀 세입을 정합니다 |
| 상업 | 1월과 7월 정산에 들어오는 금 세입을 정합니다 |
| 치안 | 치안 강화로 올립니다. 도시를 빼앗기면 절반이 됩니다. 지금 규칙에서는 세입과 전투에 들어가지 않습니다 |
| 수비 | 성벽과 싸울 때 성벽의 방어에 더해집니다. 도시를 빼앗기면 0이 됩니다 |
| 성벽 | 수비 장수를 모두 이긴 공격 장수가 마지막으로 싸우는 성벽의 병력입니다 |
| 민심 | 0~100입니다. 모든 내정 효과에 민심 ÷ 100이 곱해집니다. 징병하면 5, 빼앗기면 20 내려갑니다 |
| 규모 | 도시 크기(1~8)입니다. 지도에서 점의 크기로 보입니다 |
| 보급 | 보급 연결 또는 보급 끊김입니다. [지도와 보급](./map-and-supply.md)에서 설명합니다 |

수치 옆 막대는 최대치까지 얼마나 찼는지 보여 줍니다. 최대치에 닿은 수치는 내정으로 더 올릴 수 없습니다.

## 3. 내정 명령 8종

내정은 도시나 나라의 수치를 올리는 명령입니다. 명령마다 쓰는 능력치가 다릅니다.

| 명령 | 올리는 값 | 쓰는 능력치 |
| ---- | --------- | ----------- |
| 농지 개간 | 농업 | 지력 |
| 상업 투자 | 상업 | 지력 |
| 치안 강화 | 치안 | 무력 |
| 정착 장려 | 주민 | 통솔 |
| 주민 선정 | 민심 | 통솔 |
| 수비 강화 | 수비 | 무력 |
| 성벽 보수 | 성벽 | 무력 |
| 기술 연구 | 나라의 기술 | 지력 |

조건과 비용은 [명령 목록의 내정 절](./command-catalog.generated.md#내정)에 있습니다. 공통으로 나라에 속해 있어야 하고 내 나라 도시에 있어야 하며 그 도시가 보급 연결이어야 합니다. 비용은 내 장수의 금에서 나갑니다.

효과는 능력치 × 민심 ÷ 100을 바탕으로 0.8~1.2배 사이에서 정해집니다. 열 번에 한 번쯤 크게 성공해 몇 배가 됩니다. 열 번에 한 번쯤 부진해 절반 아래로 떨어집니다.
교전 중인 나라의 도시와 연결된 전선 도시에서는 효과가 절반입니다. 선전포고만 한 상태는 전선이 아닙니다.
성공하면 경험과 공헌이 함께 오릅니다.

민심이 낮은 도시는 다른 내정 효과도 낮습니다. 농업과 상업은 세입을 늘리고 기술은 전투 피해를 최대 2배까지 키웁니다.

## 4. 내 금·쌀과 국고

내 장수의 금·쌀과 나라의 국고·군량은 따로 셉니다. 국가 정보 칸의 국고와 군량은 내 나라일 때만 보입니다.

| 흐름 | 방향 | 하는 쪽 |
| ---- | ---- | ------- |
| 봉급 | 국고 → 소속 장수 | 월간 정산. 세입의 절반을 등장한 소속 장수가 똑같이 나눠 받고 나머지는 국고에 남습니다 |
| 헌납 | 내 금·쌀 → 국고 | 장수 명령(개인). 헌납한 만큼 공헌이 오릅니다 |
| 포상 | 국고 → 장수 | 국가 명령(군주) |
| 몰수 | 장수 → 국고 | 국가 명령(군주) |

국가 명령은 국가 예턴으로 실행됩니다. 국가 예턴을 넣는 화면은 아직 없어서 지금은 플레이어 군주가 포상과 몰수를 쓸 수 없습니다 ([시간과 턴](./time-and-turns.md#국가-예턴)).

## 5. 기본 방침

기본 방침은 비워 둔 예턴 칸에서 할 일(예: 권농이면 농지 개간)을 정해 두는 기능입니다. 준비 중이며 아직 쓸 수 없습니다. 지금은 비워 둔 칸이 모두 휴식으로 실행됩니다.

> 원작과 다른 점
>
> 원작의 자율 행동 설정과 쓰임이 비슷하지만 같지 않습니다. 오픈삼국의 기본 방침은 비워 둔 칸에만 적용되고 직접 넣은 명령과 직접 넣은 휴식은 그대로 실행합니다.
> 방침이 고르는 명령은 내정과 훈련 몇 가지뿐이고 실패하면 휴식합니다.
