# 명령과 실행 시기

> 상태: 초안 (T2-17, AC-M2-11) · 사실 기준: main `0115e6b` · 참고: core2026 `docs/user/commands-and-timing.md` (구성만)
> 이 문서가 답할 질문: 명령의 조건은 어디서 읽고 실패하면 무엇을 고치나?

## 1. 명령 분류

명령은 장수가 쓰는 장수 명령과 군주가 국가 예턴으로 쓰는 국가 명령으로 나뉩니다. 장수 명령은 다시 네 분류입니다.

| 분류 | 무엇 | 명령 목록 |
| ---- | ---- | --------- |
| 내정 | 도시와 나라의 수치를 올립니다 | [내정](./command-catalog.generated.md#내정) |
| 군사 | 병사를 모으고 기르고 움직이고 출병합니다 | [군사](./command-catalog.generated.md#군사) |
| 인사 | 나라에 들고 나며 나라를 세웁니다. 지금 편집기에는 전략으로 보입니다 | [인사](./command-catalog.generated.md#인사) |
| 개인 | 휴식, 요양, 헌납, 군량매매처럼 내 장수만 관련된 명령입니다 | [개인](./command-catalog.generated.md#개인) |
| 국가 | 포상, 천도, 선전포고처럼 나라 전체에 대한 명령입니다 | [국가](./command-catalog.generated.md#국가) |

명령은 원작과 대조해 계속 늘어납니다. 이 안내는 명령 수를 정해 두지 않습니다. 지금 쓸 수 있는 장수 명령은 예턴 편집기의 명령 찾기에 나오는 것이 전부입니다.
국가 명령은 넣는 화면이 아직 없습니다 ([시간과 턴](./time-and-turns.md#국가-예턴)).

## 2. 명령별 조건을 읽는 법

[명령 목록](./command-catalog.generated.md)의 표는 명령마다 대상·수량 입력, 조건, 비용을 한 줄로 적습니다. 조건은 아래 순서로 읽으면 빠릅니다.

| 묻는 것 | 예 |
| ------- | -- |
| 누가 | 재야만, 나라에 속한 장수만, 군주만 |
| 어디서 | 내 나라 도시, 보급 연결 도시, 공백지 |
| 무엇에 | 연결된 도시, 교전 중인 나라, 재야 장수 |
| 얼마나 | 내 장수의 금·쌀, 통솔 × 100까지의 병력, 도시 주민 |
| 언제까지 | 그 수치가 최대치보다 작을 때 |

조건은 저장할 때가 아니라 그 칸이 실행될 때의 상태로 봅니다. 앞 칸이 실행된 결과(금을 썼거나 도시를 옮겼거나)가 다음 칸의 조건이 됩니다.
편집기의 사전 검사 열은 지금 상태로 본 것이라 앞 칸의 결과를 미리 계산하지 않습니다.

## 3. 실패 이유와 대처

실패한 칸은 개인 기록에 실패와 아래 이유 가운데 하나로 남습니다. 같은 뜻의 이유는 한 줄로 묶었습니다.

| 이유 | 뜻 | 이렇게 하면 됩니다 |
| ---- | -- | ------------------ |
| 국가에 소속되어야 합니다. | 재야입니다 | 임관하거나 건국합니다 |
| 자기 국가 도시에서만 가능합니다. 자기 국가 도시에서 출병해야 합니다. | 내 나라 도시가 아닌 곳에 있습니다 | 귀환하거나 이동합니다 |
| 보급이 끊긴 도시입니다. | 그 도시가 수도와 이어지지 않았습니다 | 귀환하거나 길을 다시 잇습니다 |
| 금이 부족합니다. 쌀이 부족합니다. 자원이 부족합니다. | 내 장수의 금·쌀이 모자랍니다 | 봉급을 기다리거나 군량매매로 바꿉니다 |
| 이미 최대치입니다. 통솔 가능한 병력을 넘습니다. 부상이 없습니다. | 더 올릴 수 없습니다 | 다른 명령을 넣습니다 |
| 병력이 없습니다. 출병할 병력이나 사기가 부족합니다. | 병력이나 사기가 0입니다 | 모병하거나 사기진작합니다 |
| 도시 인구가 부족합니다. | 뽑으려는 수가 도시 주민보다 많습니다 | 수량을 줄이거나 다른 도시에서 뽑습니다 |
| 연결된 도시가 아닙니다. | 대상이 바로 이어진 도시가 아닙니다 | 연결된 도시로 먼저 이동합니다 |
| 교전 중인 국가가 아닙니다. | 상대 나라와 교전 상태가 아닙니다 | 선전포고 기한이 지나 교전이 될 때까지 기다립니다 |
| 군주만 실행할 수 있습니다. | 군주 전용 명령입니다 | 군주에게 부탁합니다 |
| 소집해제 후 병종을 바꿀 수 있습니다. | 지금 병종과 다른 병종을 뽑으려 했습니다 | 같은 병종을 뽑거나 소집해제합니다 |
| 명령 대상이 다릅니다. 명령 인자가 잘못되었습니다. | 대상이나 수량이 맞지 않습니다 | 칸을 다시 넣습니다 |
| 재야 장수만 가능합니다. 재야 장수만 임관할 수 있습니다. | 이미 나라에 속해 있습니다 | 하야한 뒤 씁니다 |
| 수락할 등용 제안이 없습니다. | 받은 등용 제안이 없거나 그 나라가 수도를 잃었습니다 | 제안을 기다립니다 |
| 같은 이름의 국가가 있습니다. | 건국하려는 이름이 이미 있습니다 | 다른 이름으로 다시 넣습니다 |

메인의 개인 기록에는 이유 앞에 `NO_SUPPLY` 같은 영문 코드가 함께 보입니다. 코드는 개발용 이름이고 뜻은 뒤의 이유와 같습니다. 메뉴의 예턴 화면에 있는 최근 실행 결과에는 이유만 보입니다.

저장 단계에서 바로 돌아오는 안내도 있습니다. `명령과 인자를 확인하세요.`는 명령 이름이나 입력 형식이 틀린 경우이고 `종료된 월드입니다.`는 기수가 끝난 경우입니다.

## 4. 전체 명령 목록

전체 명령의 조건과 비용은 [명령 목록](./command-catalog.generated.md)에 있습니다. 이 문서는 명령 정의에서 자동으로 만들며 손으로 고치지 않습니다. 명령이 바뀌면 다시 생성합니다.
자동 생성 문서는 준비 중이라 아직 열리지 않을 수 있습니다. 그동안은 예턴 편집기의 명령 찾기와 사전 검사 열로 확인합니다.
