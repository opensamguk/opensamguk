# 용어 사전

> 상태: 초안 (T2-17, AC-M2-11) · 사실 기준: main `0115e6b` · 참고: core2026 `docs/user/glossary.md` (구성만)
> 이 문서가 답할 질문: 화면과 다른 플레이어의 말에 나오는 낱말은 무슨 뜻인가?

## 1. 게임 용어

| 용어 | 뜻 |
| ---- | -- |
| 월드 | 게임 한 판이 돌아가는 서버 안의 세계입니다. 월드마다 턴 간격과 종료 연도가 다릅니다 |
| 기수 | 월드 한 판입니다. 천하통일이나 종료 연도로 끝납니다 |
| 턴 | 장수가 한 달에 한 번 예턴 1칸을 실행하는 차례입니다 |
| 턴 간격 | 게임의 한 달에 해당하는 현실 시간(분)입니다 |
| 예턴 | 미리 넣어 두는 명령 30칸입니다 |
| 빈 칸 | 명령을 넣지 않은 예턴 칸입니다. 지금은 휴식으로 실행됩니다 |
| 국가 예턴 | 군주의 턴에 먼저 실행되는 국가 명령 30칸입니다 |
| 사전 검사 | 저장 전에 지금 상태로 본 실행 가능 여부입니다. 경고가 있어도 저장됩니다 |
| 월간 정산 | 달이 끝날 때 세입·봉급, 인구, 보급, 외교 기한, 연감을 차례로 처리하는 일입니다 |
| 재야 | 나라에 속하지 않은 장수입니다. 새 장수는 재야로 시작합니다 |
| 군주 | 나라의 우두머리 장수입니다. 국가 명령과 등용을 합니다 |
| 수뇌 | 나라를 이끄는 높은 직책 장수들을 묶어 부르는 말입니다. 지금은 군주만 있습니다 |
| NPC | 플레이어가 맡지 않은 장수와 나라입니다. 컴퓨터가 명령을 고릅니다 |
| 국고·군량 | 나라의 금과 쌀입니다. 장수의 금·쌀과 따로 셉니다 |
| 공백지 | 주인 없는 도시입니다. 교전 없이 출병할 수 있고 건국할 수 있습니다 |
| 속령 | 나라가 가진 도시 수입니다 |
| 수도 | 보급이 시작되는 도시입니다. 임관하거나 귀환하면 이곳으로 갑니다 |
| 보급 | 수도에서 내 나라 도시만 밟고 이어진 상태입니다 |
| 전선 | 교전 중인 나라의 도시와 맞닿은 도시입니다. 내정 효과가 절반입니다 |
| 민심 | 도시 사람들의 마음(0~100)입니다. 내정 효과에 곱해집니다 |
| 기술 | 나라의 기술 수치입니다. 전투 피해를 최대 2배까지 키웁니다 |
| 공헌·경험·전공 | 장수 순위의 기준입니다. 전공은 이긴 수와 점령한 수의 합입니다 |
| 국력 | 나라 순위의 기준이 되는 공개 국력입니다 |
| 천통 | 천하통일. 한 나라가 지도의 모든 도시를 가지는 것입니다 |

## 2. 전쟁 은어

| 은어 | 뜻 |
| ---- | -- |
| 모출 | 모병한 뒤 바로 출병하도록 예턴을 넣는 것입니다 |
| 모훈사출 | 모병, 훈련, 사기진작, 출병 순서로 넣는 예턴 조합입니다 |
| 점사 | 여러 장수가 같은 목표를 같은 때 함께 치는 것입니다 |
| 양파 | 병력을 거듭 보충하면서 수비를 이어 가는 방식입니다 |
| 땅따 | 땅따먹기. 초반에 공백지를 먼저 차지하려는 경쟁입니다 |

조합과 수비는 [전쟁과 예턴 조합](./war-and-orders.md), 공백지와 보급은 [지도와 보급](./map-and-supply.md)에 있습니다.

## 3. 외교 은어

| 은어 | 뜻 |
| ---- | -- |
| 선포 | 선전포고입니다. 1개월 기한 뒤 교전이 됩니다 |
| 불가침 | 서로 공격하지 않기로 한 상태입니다. 12개월 뒤 끝납니다 |
| 최후 2국 | 마지막 두 나라, 또는 그때까지 서로 남겨 두자는 약속입니다 |

외교 상태의 흐름은 [국가 재정과 외교](./economy-and-diplomacy.md)에 있습니다.
