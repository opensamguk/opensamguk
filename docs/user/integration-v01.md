# 통합판의 5능력치와 휘하·부곡

> AC-INT-11 · 통합판 v0.1의 5능력치·휘하 기능을 켠 월드 기준. 구형 3능력치 월드의 생성·명령·전투 규칙은 그대로 유지합니다.

## 장수 만들기와 능력치

통합판에서는 통솔·무력·지력·정치·매력을 각각15~90, 합계275로 정합니다. 지휘관·무장·책사·내정가·인재 담당 프리셋을 고른 뒤 수치를 바꿀 수 있습니다. 고르게 나누기는 다섯 값을55로 맞춥니다. 역사 인물의 능력치를 이 생성 합계에 맞추지는 않습니다.

| 능력치 | 쓰는 곳 |
| --- | --- |
| 통솔 | 실제 지휘관의 전체 병력 상한, 받는 피해, 훈련과 수비 강화 |
| 무력 | 일반 전투에서 가하는 피해, 치안 강화와 탈취 |
| 지력 | 기술 연구, 화계·파괴와 계략 저항 |
| 정치 | 농지 개간·상업 투자·성벽 보수, 정착 장려와 수비 공사 |
| 매력 | 주민 선정, NPC 서약 호응, 모병 비용과 사기진작 |

내정 점수는 농지·상업·성벽이 정치, 연구가 지력, 주민 선정이 매력입니다. 정착은 정치60%·매력40%, 수비는 통솔70%·정치30%, 치안은 무력70%·정치30%를 반올림합니다. 예턴의 사전 검사에서 지금 가능한지와 비용·점수·상승량을 확인합니다. 앞 칸의 결과를 미리 실행한 예측은 아니므로 실제 실행 때 조건을 다시 검사합니다.

## 개인 휘하와 본인의 동의

메인 아래의 개인 휘하·부곡에서 가신·부장·식객 관계를 제안합니다. 같은 거점의 동국·재야 중 화면에 후보로 나온 인물에게 제안할 수 있습니다. 다른 나라의 소속·현재 상관·직책 등으로 자격이 없으면 후보가 되지 않습니다.

사람 장수는 제안을 받은 본인이 수락하거나 거절합니다. 제안자가 대신 수락하지 못하며 사람의 응답에는 NPC 서약 비용이나 호응 확률을 적용하지 않습니다. 휘하가 되어도 각자의30칸 예약과 사람 장수의 이동 권한은 유지됩니다.

유효한 NPC 서약은 성공과 거절 모두 금500을 씁니다. 호응 확률은25+floor(매력/2)%이며 같은 NPC에게는 장수별 게임 월1회만 시도합니다. 같은 요청의 재전송은 비용을 다시 쓰거나 결과를 다시 뽑지 않습니다. 비용·확률·그달 시도 여부는 제안 전에 화면에서 확인합니다.

처음 직속 명망 수용량은30입니다. 인물의 명망 비용은 다섯 능력치 합을50으로 나눈 값을 올림하며 최소1입니다. 직속 휘하의 비용만 내 수용량에서 셉니다. 매력이 높아도 명망 상한이나 다른 사람을 조작할 권한은 늘지 않습니다.

## 부곡 편성과 준비

빈 부곡 편성에서 본인 또는 직속 NPC 부장을 지휘관으로 고릅니다. 편성만으로 병력이 생기지는 않습니다. 예턴에서 모병·징병을 고르고 부곡 번호·병종 번호·수량을 넣습니다. 군사 준비 비용과 전투 군량은 소유 장수의 금·쌀에서 나갑니다.

실제 지휘관이 맡는 모든 부곡의 병력 합계가 그 지휘관의 통솔×100을 넘을 수 없습니다. 부곡을 여러 개 만들거나 소유자와 부장의 통솔을 더해 상한을 늘릴 수 없습니다. 모병 비용에는 소유자의 매력 배율1.25-매력/200을 적용하고 올림합니다. 징병은 기본 병종 비용의 절반을 올림하며 매력 할인을 다시 적용하지 않습니다. 징병하면 도시 민심이5 내려갑니다.

훈련은 금100으로8+floor(실제 지휘관 통솔/25), 사기진작은 금100으로8+floor(점수/25)만큼 오릅니다. 사기 점수는 지휘관 매력60%·통솔40%를 반올림한 값입니다. 최대값은100입니다. 새 병사가 섞이면 훈련·사기의 병력 가중 평균이 내려갑니다.

부곡의 병력·훈련·사기·지휘관·현재 거점은 개인 휘하·부곡에서 봅니다. 주둔 장수 표의 지휘 병력은 그 장수가 실제 지휘하는 부곡의 합계이며 평균 훈련·사기는 병력으로 가중한 값입니다. 소유자와 지휘관이 다르면 지휘관 행에 병력이 나옵니다. 비공개인 다른 국가 장수의 수치는 공개하지 않습니다.

병력 있는 부곡의 지휘관을 바꾸려면 기존 지휘관과 새 지휘관이 모두 소유자와 같은 거점에 있어야 합니다. 다른 사람이 소유한 부곡이나 사람 휘하의 예약을 대신 편집할 수 없습니다. 부곡을 해산하려면 먼저 예턴의 소집해제로 병력을 풉니다.

## 이동·귀환·출병

이동은 연결된 거점으로, 귀환은 소속 국가의 수도로 갑니다. 사람 소유자와 같은 거점에 있던 NPC 부장이 병력 있는 부곡을 지휘하면 그 병력과 함께 따라갑니다. 빈 부곡만 지휘하는 부장은 따라가지 않습니다. 사람 휘하의 위치는 따라 바꾸지 않습니다. 행군 시간·거리 비용·중간 위치·휴대 군량은 없습니다.

출병은 소유자와 같은 거점에 모인 자기 부곡 중 병력·사기가 남은 부곡으로 진행합니다. 목적지는 연결된 공백지 또는 교전 중인 다른 국가 거점입니다. 선전포고만 한 상태로는 적국에 출병하지 못합니다. 다른 소유자의 부곡을 자기 공격 편성에 넣지 않습니다.

기존 병종·훈련·사기·기술·성벽 계산에 실제 지휘관의 두 보정을 한 번 적용합니다. 가하는 피해는0.9+무력/500배, 받는 피해는1.1-통솔/500배입니다. 지휘관 없는 성벽에는 능력치 보정을 만들지 않습니다. 지력·정치·매력을 일반 전투 피해에 다시 곱하지 않습니다.

수비 부곡을 물리치고 성벽을0으로 만들었을 때 공격 병력·사기가 남으면 점령합니다. 관문도 점령 대상이지만 경제 도시나 수도로 세지 않습니다. 항구는 도시 시설이고 전장은 지명 표시입니다. 별도 항구 이동 턴이나 전장 조작은 없습니다.

## 처리 중일 때

관계·편성·지휘 요청을 접수하면 엔진이 처리할 때까지 결과가 미확정입니다. 같은 탭에서 새로고침해도 저장한 요청 번호로 결과를 확인합니다. 오래된 상태나 잘못된 입력은 화면의 실패 이유를 확인한 뒤 현재 상태에서 다시 판단합니다. 종료된 기수에는 새 명령을 넣지 못합니다.
