# 시작하기

> 상태: 초안 (T2-17, AC-M2-11) · 사실 기준: main `0115e6b` · 참고: core2026 `docs/user/index.md` (구성만)
> 처음 온 사람이 이 문서 하나로 장수를 만들고 예턴을 넣을 수 있게 씁니다. 화면 캡처는 넣지 않고 화면 이름과 메뉴 위치를 글로 적습니다.

## 1. 이 게임은 무엇인가요

오픈삼국은 삼국지 시대를 배경으로 한 웹 전략 게임입니다. 플레이어는 장수 한 명을 맡습니다.
나라에 들어가 도시를 키우고 군사를 모아 다른 나라의 도시를 빼앗습니다.
한 나라가 지도의 모든 도시를 가지면 천하통일로 그 판이 끝납니다. 이 한 판을 기수라고 부릅니다.
월드에 종료 연도가 정해져 있으면 그해 12월 정산까지 통일한 나라가 없을 때 승자 없이 끝납니다.

한 월드에는 여러 플레이어와 컴퓨터가 움직이는 NPC 장수가 함께 있습니다. 한 계정은 월드마다 장수를 하나만 만들 수 있습니다.

## 2. 버튼을 눌러도 바로 실행되지 않는 이유

이 게임은 예약 방식입니다. 명령을 넣으면 예턴에 저장되고 내 장수의 턴이 올 때 1번 칸이 실행됩니다.
예턴은 미리 넣어 두는 명령 30칸입니다. 턴은 게임 달력으로 한 달에 한 번 옵니다.
현실 시간으로 몇 분마다 오는지는 월드마다 다르며 메인 머리글의 `턴 N분`에 보입니다.

명령 하나에는 시점이 셋 있습니다.

| 시점 | 일어나는 일 | 보이는 곳 |
| ---- | ----------- | --------- |
| 저장 | [저장]을 누르면 서버가 30칸을 받아 둡니다. 명령 이름과 입력 형식만 봅니다 | 편집기 위 `저장했습니다.` |
| 실행 | 턴이 오면 엔진이 그 순간의 상태로 조건을 다시 보고 실행합니다 | 메인 아래쪽 개인 기록 |
| 실패 | 조건이 맞지 않으면 아무것도 바뀌지 않고 칸만 넘어갑니다 | 개인 기록의 실패와 이유 |

저장하기 전에도 편집기의 사전 검사 열이 지금 상태로 가능한지 알려 줍니다. 경고가 있어도 저장은 됩니다. 실행할 때 상황이 바뀌어 있을 수 있기 때문입니다.
자세한 흐름은 [시간과 턴](./time-and-turns.md)에 있습니다.

## 3. 첫 접속에서 할 일 5단계

로그인 화면 오른쪽(좁은 화면에서는 아래)과 로비의 월드 목록 위에서 진행 중인 월드의 지도를 탭으로 골라 볼 수 있습니다. 10분 이상 지난 모습이고 도시 주인과 국가 이름만 나옵니다.

1. 가입과 로그인. 로그인 화면의 [가입하기]에서 이메일과 비밀번호(10~128자)로 가입합니다.
2. 월드 들어가기. 로그인하면 로비로 갑니다. 로비에서 월드를 고르고 장수가 없으면 [장수 만들기], 있으면 [들어가기]를 누릅니다.
3. 장수 만들기. 메인의 명령 목록 칸에 `이 월드에 내 장수가 없습니다`와 [장수 만들기]가 보입니다.
   이름(한글·한자·영문·숫자 1~6글자), 통솔·무력·지력(합계 165, 각각 15~80), 초상을 고르고 [장수 만들기]를 누릅니다.
   새 장수는 나라에 속하지 않은 재야로 지도의 아무 도시에서 시작하고 금 1,000과 쌀 1,000을 가집니다.
4. 나라에 들어가기. 재야는 내정과 모병을 할 수 없습니다. 명령 목록에서 1번 칸을 누르고 명령 찾기에 임관을 입력합니다.
   들어갈 나라를 고른 뒤 [1번 칸에 넣기]를 누릅니다. 나라를 가리지 않으면 무작위 임관을 씁니다. 임관하면 그 나라 수도로 옮겨 갑니다.
5. 예턴 채우고 저장하기. 2번 칸부터 농지 개간 같은 내정 명령을 넣고 [저장]을 누릅니다.
   다음 턴 시각은 장수 정보 칸의 다음 턴과 위쪽 띠의 남은 시간에 보입니다. 결과는 개인 기록에 쌓입니다.

첫 턴은 그 달 안의 아무 시점에 옵니다. 장수마다 한 달 안에서 자기 차례의 위치가 다릅니다.
