# 국가 운영과 주요 기능

> 상태: 초안 (T2-17, AC-M2-11) · 사실 기준: main `0115e6b` · 참고: core2026 `docs/user/nation-and-features.md` (구성만)
> 이 문서가 답할 질문: 직책마다 무엇을 할 수 있고 국가 화면에는 무엇이 있나?

## 1. 직책과 권한

지금 직책은 셋입니다. 장수 정보 칸의 소속 옆에 보입니다.

| 직책 | 누구 | 할 수 있는 일 |
| ---- | ---- | ------------- |
| 군주 | 나라를 세운 장수, 시나리오의 각 나라 임금 | 국가 명령, 등용. 하야할 수 없습니다 |
| 일반 | 나라에 속한 나머지 장수 | 장수 명령 전부 |
| 재야 | 나라에 속하지 않은 장수 | 이동, 임관, 건국, 등용 수락 같은 명령 |

군주가 소속 장수에게 직책을 주는 임명과 발령에 장수가 답하는 발령 응답은 준비 중입니다.

> 원작과 다른 점
>
> 발령 응답은 오픈삼국에서 새로 더하는 방식입니다. 발령을 받은 장수가 응답하고 그 자리에서 바로 행동할 수 있게 할 예정입니다.

## 2. 나라에 들고 나는 명령

이 명령들은 명령 찾기의 인사 분류에 있습니다. 지금 편집기에는 이 분류가 전략으로 보입니다. 조건은 [명령 목록의 인사 절](./command-catalog.generated.md#인사)에 있습니다.

| 명령 | 하는 일 |
| ---- | ------- |
| 임관 | 재야가 고른 나라에 들어갑니다. 그 나라 수도로 옮기고 직책은 일반입니다 |
| 무작위 임관 | 임관과 같지만 나라를 무작위로 고릅니다 |
| 하야 | 나라를 떠나 재야가 됩니다. 병력과 위치는 그대로입니다 |
| 등용 | 군주가 재야 장수에게 들어오라고 제안합니다 |
| 등용 수락 | 재야가 받은 제안을 받아들여 그 나라에 들어갑니다 |
| 건국 | 재야가 공백지에서 금 1,000으로 나라를 세웁니다. 나라 이름과 색을 정합니다 |
| 거병 | 건국과 같지만 병력이 있어야 합니다 |

헌납은 개인 분류에 있습니다. 내 금이나 쌀을 국고로 보내고 그만큼 공헌이 오릅니다.

## 3. 국가 정보 화면

메인의 국가 정보 칸에 내 나라의 요약이 있습니다. 같은 칸에서 소속 장수 표와 소유 도시 표를 펼칩니다.
표 머리글을 누르면 정렬되고 보급 끊긴 도시, 부상 장수, 훈련·사기가 50 미만인 장수에 관리 필요 표시가 붙습니다.

| 보이는 값 | 누구에게 |
| --------- | -------- |
| 이름, 색, 속령(도시 수), 장수 수 | 모두 |
| 국고, 군량, 세율, 기술, 수도, 성향 | 그 나라 장수 |

다른 나라 장수는 이름과 소속만 보입니다. 재야면 이 칸에 `재야입니다`가 보입니다.

## 4. 메시지와 공지, 알림

나라 안 메시지, 공지, 디스코드 알림 설정은 모두 준비 중입니다. 지금은 게임 안에서 다른 플레이어에게 글을 보낼 수 없습니다.

## 5. 기록과 순위

| 화면 | 내용 |
| ---- | ---- |
| 개인 기록 | 내 장수 명령의 결과와 실패 이유 |
| 국가 기록 | 내 나라의 달별 도시 수, 장수 수, 국고, 군량. 재야면 비어 있습니다 |
| 중원 정세 | 달별로 나라마다 가진 도시 수와 장수 수, 공백지 수 |
| 순위 | 장수는 공헌·경험·전공, 나라는 도시·장수·국력 기준 |

세 기록은 메인 아래쪽에 있고 메뉴의 [기록]에서 넓게 봅니다. 국가 기록과 중원 정세는 월간 정산 뒤에 쌓입니다.

순위는 메뉴의 [순위]에 있고 월간 정산 때 저장한 값입니다. 전공은 출병에서 이긴 수와 점령한 수를 더한 값입니다.
국력은 자원, 기술, 보급 연결 도시의 개발도, 장수 능력을 더한 값에 작은 난수를 곱해 보여 줍니다. 다른 나라의 기술을 정확히 거꾸로 계산하지 못하게 하려는 것입니다.

기수가 끝나면 위쪽 띠에 `종료`가 보입니다. 승자와 결과를 보여 주는 화면은 준비 중입니다.

## 6. 앞으로 더할 기능

> 원작과 다른 점
>
> 오픈삼국은 원작에 없는 기능을 핵심 규칙 위에 덧붙입니다. 같은 나라 장수가 목표와 시점을 맞추는 작전판, 빈 칸의 기본 방침, 조약서 외교, 교역, 알림이 준비 중입니다. 들어오는 대로 이 안내에 더합니다.
