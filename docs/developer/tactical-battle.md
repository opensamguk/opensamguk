# 전술 전투 서버 계약

상태: 구현·단위 검증 중. AC-INT-28·AC-INT-09·AC-M1-10·AC-M1-12·AC-M1-15에 연결한다. 실제 DB 인수와 화면 E2E 전에는 완료로 판정하지 않는다.

## 시간과 잠금

월드 시계와 비참가자의 월간 처리는 계속 진행한다. 참가 부곡·도시 수비병·대상 거점·참가 장수의 이동·배속·재출병을 예약한다. 쌀은 개시 때 별도 원장으로 옮기고 미사용분만 정산 때 돌려준다. 충돌 명령은 `BATTLE_BUSY`로 실패하며 대기 출병으로 바꾸지 않는다.

회의는 120초다. LIVE 간격은 `min(60000, floor((월드 턴 간격 밀리초 - 120000) / 30))`이며 전체 종료 시한도 둔다. 2분 이하 월드는 120초 회의와 LIVE를 함께 수용할 수 없어 예약 전투로 진행한다. 관리자 정지 시간은 두 마감에서 제외한다. 총대장 접속은 15초 heartbeat와 45초 임대로 판단한다.

월간 수입은 기존 원장에 정상 적립한다. 잠긴 병력의 보급 단절·재난 감소와 성벽 감소는 전술과 중복 적용하지 않는다. 전술 군량은 턴마다 소비한다. 휴전·동맹, 참가 장수 사망·하야·소속 변경, 국가 멸망은 다음 전술 단계에서 손실을 정산하고 종료한다. 관직만 바뀌면 개시 당시 지휘자를 유지한다. 발령 기한에 도달한 참가자는 전투 종료 뒤 월간 처리에서 이동한다.

## 입력과 화면

`battle.council.get`, `battle.council.set`, `battle.plan.set`, `battle.presence.heartbeat`, `battle.turn.get`, `battle.turn.submit`, `battle.receipt.get`, `battle.replay.get`을 사용한다. 모두 `worldId`가 필요하며 영수증 조회를 제외하면 `battleId`도 보낸다.

변경 입력은 `expectedRevision`, `windowNo`, `mapHash`, `idempotencyKey`를 보낸다. 직접 명령에는 `turnNo`, `unitId`, `expectedUnitOrderRevision`, `action`도 필요하다. 행위자는 서버 세션에서 정한다. 같은 키의 다른 본문, 만료 마감, 다른 사람 부곡 조작은 거절한다. 요청 상한은 64KiB, 부대 40개, 경로 64칸, 규칙 8개다. 배치를 바꾸면 해당 부대의 기존 경로 예약을 지운다.

조회는 shared의 `TacticalBattle`과 같은 필드를 갖는다. `frames[0]`은 시작 상태다. 각 사본의 `turn`·`units`·`bases`·`totals`·`events`·`siege`를 읽는다. `generalName`, `crewTypeName`, `x/y`, `route`, `defense`는 화면과 같은 이름이다. 수비병 ID는 `-crewType`이며 가짜 장수를 만들지 않는다. 숨은 적·상대 쌀·상대 예약은 시야 사본에서 제외한다. 상대 총계의 보이지 않는 값은 0이다.

`blockedCells`는 원본 칸 자료가 없어 통행할 수 없는 좌표다. 입력 좌표는 전장 `x/y` 정수이며 마름모 투영은 화면이 맡는다. 다시보기는 `afterTurn`과 최대 5개 `limit`을 쓴다. 취소로 마지막 턴 사본이 갱신되면 `revision`을 보고 현재 턴을 다시 조회한다. 변경은 기존 참가자 `turn.result` 알림으로 재조회한다.

직접 명령의 영수증은 마감 전까지 `PENDING`이다. 마감에서 세션·제재·지휘권을 다시 확인한 뒤 `APPLIED/REJECTED`를 반환한다. 새 명령에 대체되면 `SUPERSEDED`, 시간 상한 종료는 `TIME_LIMIT`이다. `withdraw`는 총대장의 군 전체 철수이며 일반 `retreat`는 한 부대 후퇴다.

## 저장과 재생

활성 상태는 기존 campaign 저장·재생 경로에 포함한다. 종료 전투는 새 전투 개시 때 월드 사본에서 덜어낸다. 기록은 `Battle`·`BattleTurn`·`BattleEvent`에 보관한다. `BattleReservation`의 활성 키 유일성과 월드 행 잠금으로 중복 사용을 막는다. `BattlePresence`는 접속 임대다.

엔진은 입력·턴·정산을 기존 리스와 월드 잠금 아래 원자적으로 저장한다. 시스템 `battle.step`에 시각·접속 결정·확정 명령을 기록하므로 재생은 현재 접속을 묻지 않는다. 병종·지도·규칙 판과 행동별 RNG를 고정한다. 물리 전투 해시는 시간·접속 모드를 제외한다. 월드 전체 원장에는 실제 시간과 모드가 남는다.

계산 실패는 해당 전투를 `FAULTED`로 남기고 예약을 보존한다. 비참가자 전략 진행은 계속한다. 자동 재추첨은 하지 않는다. 관리자 종료·초기화는 마지막 피해를 정산한 뒤 예약을 해제한다.

## 자료와 인수 제한

현재 전장은 R3 경로 원장의 실제 칸과 간선을 최대 64×64 범위로 추출한다. 경유와 선택한 경로도 같은 해석기를 사용한다. 원장 밖 지형을 평지 통로로 추정하지 않는다. 물길을 통과할 수 없는 병종은 사전 검사에서 거절한다. 현재 병종표의 수군·상륙 전장과 원장 수문·급수 태그를 보강하기 전에는 모든 물길 전투와 물·독 함정 사용을 인수할 수 없다. 불·돌·구덩이와 고무·신속·수색은 지형·점수 조건을 검사한다.

새 migration 적용, 실제 DB 동시 접수·실패 복구·정산 원자성, 화면 E2E, 동시 32개 부하는 별도 검증이 필요하다. 관련 AC 상태를 완료로 바꾸지 않는다.

## 야전 칸과 시야 (D-105)

`board.terrain`에 `sandbar`를 더한다. 이동 비용은 평지1·모래톱1.5·여울2이며 불함정은 초지·다리, 구멍은 초지·평지·가도에만 설치한다. 수문·급수 자료가 필요한 물·독 함정 제한은 유지한다. `schemes[].kind = fire`로 화계를 예약하며 점수3을 쓴다. 호우 중에는 접수를 거절하고 실행 때 호우로 바뀌면 점수를 쓰지 않고 취소한다.

운영 지도 v3의 선택 필드 `tacticalCells`는 16단위 격자 좌표 `x/y`, 선택 지형 `terrain`, 선택 지물 `object`를 담는다. `object`는 `kind`와 다리일 때 `direction`만 갖는다. 좌표 중복과 지도 밖 좌표는 거절한다. 경로에 있는 칸만 보급 원장에 고정하고 전장으로 추출한다. 자료가 없으면 기존 원장의 지형을 쓰며 모래톱이나 숲을 임의로 만들지 않는다. 행군 SP 비용은 기존 원장대로이고 전술 이동 점수와 구분한다.

`board.objects`는 전장 좌표를 가진 지물 목록이다. 다리는 `direction: NE-SW | NW-SE`이며 방향은 그림용이고 통행은 기존 간선을 따른다. 성채는 `fort-small | fort-medium | fort-large`, 나머지는 `gate | camp | village | earthwork | rubble`이다. 목적지에 명시 지물이 없으면 관은 관문, 진은 진영, 도시 단계0~2는 마을·3~4는 작은 성채·5~7은 중간 성채·8~9는 큰 성채로 정한다. 폐허 원장에 남은 도시는 무너진 터로 그린다. 기존 다툼 거점은 기본 진영이며 명시된 거점 지물 종류가 있으면 `frames[].bases[].structure`에 싣는다. 흙더미 위 부대는 교전에서 받는 피해를 0.85배로 계산하며 무너진 터에 진입하는 이동 비용은1 늘어난다. 나머지 지물에는 별도 이동·방어 효과가 없다. 성벽·성문의 기존 공성 계산은 유지한다.

기상과 바람은 매 프레임 `environment`에, 보이는 타는 칸은 `burningCells`에 담는다. 불은 정산 시작의 기상 변경 뒤 책략·행동으로 붙고 행동이 끝나면 바람 쪽 한 칸으로 번짐을 시도한 뒤 피해를 준다. 번짐 도중 새로 붙은 칸은 그 정산에 다시 번지지 않는다. 호우가 올 때까지 불이 남으며 물 칸으로 번지지 않는다. 부상 누적은 `units[].injury`이고 전투에서 새로 입은 부상만 센다. 같은 장수가 여러 부대를 이끌면 가장 큰 누적 부상 하나를 종료 때 반영한다.

각 프레임의 `visibleCells`는 요청한 편의 시야 좌표 목록이다. 목록에 없는 칸은 화면에서 가린다. 부대의 실제 시야 반경은 `units[].vision`이다. 적은 시야 안에 있고 복병이 아닐 때만 `units`에 남는다. 숨은 부대가 주체·대상인 사건과 시야 밖 불도 뺀다. 복병은 숲·산에서 시작하고 이동·공격 또는 반경1 수색으로 해제한다. 지도 지형·고정 지물·거점 위치 자체는 공개 정보다. 전체 필드 형식과 수치·검증 결과는 [야전 규칙 보고](../../REPORT-field-rules.md)에 있다.
