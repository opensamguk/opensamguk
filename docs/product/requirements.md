# 요구사항

> 2026-10-27 D-037·038 우선. 현재 제작은 [동결 통합판 v0.1](../plans/integration-release.md)과 [5능력치](./five-stats.md)를 따른다. 아래 이전 M1~M3 설계·코드 상태는 이력/기존 판의 설명이며 새 판은 통솔·무력·지력·정치·매력을 쓴다.

> 상태: 초안 v0.1 (2026-10-20) · 근거: [PRD](./prd.md) · 검증: [인수조건](./acceptance-criteria.md)
> (가정 A14) 같은 표시는 [가정 원장](./prd.md#가정-원장)의 확인 대기 항목입니다.

요구사항 ID는 바뀌지 않습니다. 지우는 요구사항은 줄을 지우지 않고 "폐기"로 표시합니다.
관문 칸은 그 요구사항이 처음 필요해지는 관문입니다.

## 1. 용어

| 용어      | 뜻                                                                 |
| --------- | ------------------------------------------------------------------ |
| 월드      | 독립적으로 진행되는 게임 서버 한 판. 시나리오·턴 간격·규칙 프리셋을 가진다 |
| 기수      | 한 월드의 시작부터 종료까지                                        |
| 장수      | 플레이어(또는 NPC)가 맡는 인물                                     |
| 예턴      | 미리 예약한 행동 목록. 장수 30칸, 국가 12칸                         |
| 턴        | 장수가 예턴 1칸을 실행하는 차례. 1턴 = 게임 1개월                  |
| 월간 정산 | 달이 바뀔 때 수입·인구·보급·외교 기한 등을 처리하는 일             |
| 엔진      | 월드별로 턴과 월간 정산을 실행하는 프로세스                        |
| 관문      | M1·M2·M3. 인수조건이 전부 통과해야 넘어가는 단계                   |

## 4. 범위 밖

MVP에서 하지 않는 것이다. 다시 넣으려면 [결정 기록](./decisions.md)에 남긴다.

- 원작과 동작·수치·난수의 1:1 일치, 원작 데이터 이관
- 아이템·특기·계략·경매·토너먼트·부대·전투 시뮬레이터
- 소셜 로그인, 모바일 앱, 무중단 배포
- 원작 화면과 픽셀 단위 비교

- TypeScript 하나로 서버·엔진·화면을 만든다
- 서버 1대에서 운영한다 (가정 A13)
