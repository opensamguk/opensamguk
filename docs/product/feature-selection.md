# 현재 기능과 동결 범위

2026-10-27 사용자 요청으로 정리했다. 기준은 원격 main e3cd34f8707526995e37c04090a8532c47e12b02와 이번 작업트리다. 사용자가 5능력치를 지정하고 기획·목록 동결을 지시했다. D-038과 integration-release.md가 이번 v0.1의 정본이다. 아래 필수·우선 도입·기존 유지 기능을 만들고 후속 후보·제외 항목은 이번 완료 분모에서 보류한다. 기능 동결은 구현 완료나 기존 코드 삭제를 뜻하지 않는다.

[5능력치 역할과 첫 산식](./five-stats.md), [구현 비교와 세부 일정](../plans/integration-release.md)을 함께 따른다.

2026-10-29 사용자가 추가한 도시 금·쌀·수비병과 권한자의 부곡 배속은 [D-040](./decisions.md#d-040-도시가-금쌀수비병을-보유하고-권한자가-부곡에-배속한다-2026-10-29), [INT-18](../plans/INT-18.md)을 따른다. 기존 개인·국고와 진행 중인 판은 보존한다. 급여 뒤 세수는 해당 도시에 쌓고 도시가 모병·수비 군량을 부담한다. 철·목재·말·휴대 군량을 추가하지 않으며 이 후속의 구현·인수는 아직 미완료다.

## 게임의 중심

사람마다 장수 한 명을 맡고 나라에 소속해 내정·전쟁·외교에 참가한다. 개인 휘하·부곡으로 장수의 선택을 늘린다. 지도는 실제 지리를 바탕으로 만들고 이동은 현재 main 방식을 유지한다.

상태는 main의 화면·API·실행 경로가 있는 기능, 규칙만 있는 기능, 이번 작업의 초안, 아직 후보인 기능으로 구분했다. 코드가 있다는 표시를 전체 검증·공개 운영 완료로 읽지 않는다.

## 이번 v0.1 뒤로 보류할 후보

- 첩보와 추가 전략 명령. 화계·파괴·선동·탈취 4종은 5능력치 역할에 맞춰 이번 범위에 포함하고 INT-17에서 실제 게임에 연결한다.
- 군사 조언과 초보 안내. 현재 도움말은 있으나 상황별 군사 조언 전체가 구현된 것은 아니다. 처음에는 규칙으로 판단하고 LLM 설명은 미룬다.
- 역할별 역사 인물 입장과 빙의. 장수 생성과 구분해 검토한다.
- 관직 주재 효과, 월단평. 인사 권한 구현만으로 도시 보너스나 월단평이 완성됐다고 세지 않는다.
- 장비·특기·상성·전투태세. 효과 합산 틀은 있으나 등록된 modifier provider는 비어 있다. 효과가 없는 데이터 칸을 완성 기능으로 세지 않는다.
- 특수 병종 연구 9종. 현재 보병·궁병·기병과 수비 성벽부터 균형을 확인한다.
- 계절·재해·역사 사건 선택지·인물 관계망. 결과를 이해할 수 있는 규모부터 검토한다.
- 포로·석방·등용·일기토. 현재 핵심 전투 완료와 별도로 다룬다.
- 명성과 칭호·업적. 능력치 혜택 없이 기수 기록·꾸미기 위주로 검토한다.
- 야간 휴전. 실시간 접속 부담을 실제 플레이에서 확인한 뒤 프리셋으로 검토한다.

## 이번 v0.1에서 제외하는 것

- 여러 달 지속 행군, 거리별 이동 속도, 간선 중간 위치, 행군 잠금. D-034로 제외 확정.
- 군현·프로빈스 1천여 개의 개별 세금·태수·점령 관리. 사용자가 군현 단위를 쓰지 않기로 정함.
- 실시간·격자 전술 전투와 별도 전투 조작 화면. 현재 예약형 웹 게임의 접속 방식과 개발 규모에 맞지 않는다.
- 모든 명령의 카드화. 기존 명령·예약·실패 처리와 같은 기능을 두 번 만든다.
- 철·목재·말 추가, 도시별 창고망·수송선·휴대 군량·보급 차량. 이번에는 금·쌀과 기존 소비를 유지한다.
- 막부·봉신 국가·황실·조정·작위의 동시 대규모 도입. 국가 직책과 개인 휘하를 먼저 완성한다.
- 혈연·혼인·가문·다세대 계승 전체. 현재 한 기수의 전쟁과 협동보다 별도 게임에 가까워진다.
- 기수 사이에 쌓이는 유산 능력치·숨은 전투 버프. 신규 참가자와 같은 출발선을 지킨다.
- 경매·국가 베팅·상시 토너먼트. 토너먼트는 현재 대진·경기 순수 코드가 있지만 참가·운영·화면이 완성된 서비스는 아니다. 본게임 다음으로 미룬다.
- 기존 프론트 전체 재작성·네이티브 앱·별도 Kotlin 엔진 동시 운영. main의 TS 런타임과 현재 화면을 확장한다.

## 명령은 몇 개가 실제로 있는가

기본 레지스트리에는 37개 명령이 있다. 장수 내정 8개, 휴식, 군사 8개, 인사 7개, 개인 3개와 국가 10개다. 외교 일부는 기능별 조약 경로가 대신하며 교역도 설정을 켠 월드에 추가된다. 명령 대응표의 88개 항목과 미해결 원본 3개를 모두 구현된 명령으로 세면 안 된다. 대응표의 engine 상태도 최신 기능 연결보다 뒤처진 항목이 있어 실제 레지스트리·API를 같이 봤다.

내정은 농지 개간·상업 투자·치안 강화·정착 장려·주민 선정·수비 강화·성벽 보수·기술 연구다. 군사는 모병·징병·훈련·사기진작·출병·이동·귀환·소집해제, 인사는 임관·무작위 임관·건국·거병·하야·등용·등용 수락이다. 개인은 요양·군량매매·헌납이며 휴식도 있다. 국가는 휴식·포상·몰수·발령·천도·선전포고·종전 제의·불가침 제의·불가침 파기 제의·원조다.

D-038로 이번 v0.1은 기존 기본 명령·교역·4계략과 필수 휘하/부곡 동작을 완성한다. 전체 90개 원작 명령의 D-022 목표는 후속으로 보류하며 코드·기존 월드의 호환 경로를 삭제하지 않는다. 기능을 더하지 않고 새 지도·5능력치·휘하·부곡과 실제 한 판 완주를 검증한다.
