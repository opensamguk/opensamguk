# 제품 문서

무엇을, 왜, 언제까지 만드는지를 정하는 문서들입니다. 코드보다 먼저 바뀌고 코드가 이 문서를 따릅니다.

| 질문                         | 문서                                         |
| ---------------------------- | -------------------------------------------- |
| 무엇을 왜 만드나?            | [PRD](./prd.md)                              |
| 정확히 무엇이 필요한가?      | [요구사항](./requirements.md)                |
| **언제 끝났다고 하나?**      | [인수조건](./acceptance-criteria.md)         |
| 어떤 순서로 하나?            | [단계 계획](./phases.md)                     |
| 무엇을 저장하나?             | [데이터 모델](./data-model.md)               |
| 원작과 무엇이 다른가?        | [차별화 기능 후보](./differentiation.md)     |
| 어디서 아이디어를 가져왔나?  | [아이디어 수집](./idea-harvest.md)           |
| 왜 이렇게 정했나?            | [결정 기록](./decisions.md)                  |
| 나중에 할 아이디어는?        | [백로그](./backlog.md)                       |
| core2026 문서와 어떻게 대응? | [문서 대응표](./doc-map.md)                  |

## 흐름

```text
PRD ──▶ 요구사항(FR·NFR ID) ──▶ 인수조건(AC ID) ──▶ 단계 계획(AC 순서)
 │                                   │
 └── 가정 원장 ⚠️                    └── 상태(⬜🟨✅)가 곧 진행률
결정 기록 ◀── 방향을 바꿀 때 먼저 여기
백로그   ◀── 현재 관문 밖의 아이디어는 전부 여기
```

## 가정 확인

PRD 끝의 [가정 원장](./prd.md#가정-원장)에 아직 확인받지 않은 가정이 있습니다. 문서 곳곳의 (가정 A2) 같은 표시가
같은 가정을 가리킵니다. 틀린 가정을 발견하면 원장을 고치고 결정 기록에 남깁니다.
