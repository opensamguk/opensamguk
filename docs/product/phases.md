# 단계 계획

> 상태: 확정 v0.2 (2026-10-20, D-011) · 완료 판정: [인수조건](./acceptance-criteria.md)

Phase 1(MVP)은 관문 세 개로 나눕니다. 관문마다 **데모 한 장면**으로 끝을 정의합니다.
작업 순서는 의존 관계 순서이며, 각 단계는 끝나는 AC ID를 가집니다.

```text
Phase 1 (MVP) ─┬─ M1 혼자+NPC 완주 ─┬─ M2 지인 테스트 ─┬─ M3 공개 오픈 ══▶ MVP 완료
               │   (내부, 월드 1개)  │  (월드 2개)      │  (누구나 가입)
Phase 2 (확장) ─┴────────────────────┴──────────────────┴─▶ 명령 확장, 부대·장비·계략, D7~D9
Phase 3 (고도화) ─────────────────────────────────────────▶ PWA, LLM 조언, 시즌 메타
```

## M1. 혼자 + NPC로 한 판 완주

**데모:** 사람 1명이 장수를 만들어 임관·내정·모병·출병·점령을 화면으로 하고, 가속해서 판이 끝나는 것까지 본다.

| 순서 | 작업                                                                 | 끝나는 AC          |
| ---- | -------------------------------------------------------------------- | ------------------ |
| 1    | 저장소 뼈대: pnpm workspace, lint·타입·테스트, Docker DB              | M1-01, M1-02       |
| 2    | 리소스 로더와 월드 생성: 시나리오·지도·병종 읽기, 시드 고정 생성     | M1-03, M1-04       |
| 3    | 규칙 코어: 도시·장수·국가 모델, 명령 틀, 내정 명령                   | M1-14 일부         |
| 4    | 엔진: 시계, 리스, 턴 실행, 월간 정산, 재생                           | M1-10 ~ M1-13      |
| 5    | 전쟁: 모병·훈련·출병·전투·점령·멸망·보급                             | M1-15, M1-16, M1-14 |
| 6    | NPC AI와 헤드리스 시뮬레이터                                         | M1-17, M1-18       |
| 7    | API와 계정, 장수 생성, 예턴 편집                                     | M1-05 ~ M1-09      |
| 8    | 화면 6개와 초상 해석                                                 | M1-19, M1-20       |
| 9    | 완주 데모                                                            | M1-21              |

규칙과 엔진(3~6)을 화면(7~8)보다 먼저 합니다. 화면 없이도 시뮬레이터로 "한 판이 끝나는지"를 확인할
수 있어야, 화면 작업 중에 규칙이 흔들리지 않습니다.

## M2. 지인 테스트

**데모:** 지인 5명 이상이 서로 다른 월드 2개에서 한 기수를 끝까지 한다.

| 순서 | 작업                                                           | 끝나는 AC              |
| ---- | -------------------------------------------------------------- | ---------------------- |
| 1    | 다중 월드: 월드별 엔진, 로비, 규칙 프리셋 (D5)                 | M2-01 ~ M2-03          |
| 2    | 국가 운영: 직책·권한·인사 + **D11 발령 응답**                  | M2-05, M2-16           |
| 3    | 외교: **D1 조약서 외교 + D16 교역** (원작식 외교 대신)          | M2-06, M2-14           |
| 4    | 소통: 메시지, 국가 공지, SSE 실시간                            | M2-04, M2-07           |
| 5    | **D2 국가 작전판**                                             | M2-15                  |
| 6    | **D12 기본 방침**                                              | M2-17                  |
| 7    | 운영 기반: 배포 명령, 백업·복구, 오류 알림                     | M2-08 ~ M2-10          |
| 8    | 플레이어 가이드, 명령 목록 자동 생성                           | M2-11                  |
| 9    | 지인 테스트 1기 진행과 버그 정리                               | M2-12, M2-13           |

지인 테스트에서 차별화 기능을 실제 사람들로 검증하기 위해, 협업·외교·부재 관련 기능을 M2에 둡니다.

**데모:** 처음 보는 사람이 가입하고, 월드를 골라 장수를 만들고, 첫 턴 결과를 본다.

| 순서 | 작업                                                                  | 끝나는 AC          |
| ---- | --------------------------------------------------------------------- | ------------------ |

| 2    | 보안: 요청 제한, 쿠키·CSRF, 전체 API 권한 테스트                      | M3-03              |
| 3    | 관리자 콘솔, 감사 로그, 제재, 부정 조사                               | M3-04, M3-05       |

| 6    | 반응형, 성능·부하, 모니터링                                           | M3-07 ~ M3-09      |

## 차별화 기능의 범위 조정 순서

2026-10-20에 9개를 골랐습니다 (D-010). 1인 기준 추정으로 **약 4개월 분량**이 MVP에 더해집니다.
주간 점검에서 늦어지고 있다고 판단되면, 기준을 낮추지 않고 아래 순서대로 Phase 2로 미룹니다.
미룰 때는 결정 기록에 남깁니다.

| 미루는 순서 | 기능            | 이유 |
| ----------- | --------------- | ---- |
| 1           | D17 관직 주재 효과 | 없어도 핵심 루프와 다른 차별화가 성립 |
| 2           | D15 역할별 입장 | 직접 생성으로 대신할 수 있음 |
| 3           | D10 월단평      | 볼거리. 기록 화면으로 일부 대신 |
| 4           | D11 발령 응답   | 기존 발령으로 대신할 수 있음 |
| 5           | D16 교역        | 조약서(D1)만으로도 외교 차별화 성립 |
| 끝까지 지킴 | D1, D2, D3, D12 | 원작의 외교·협업·입문·부재 불편을 직접 푸는 핵심 차별화 |

## Phase 2. 확장 (MVP 뒤)

- 명령 확장: 계략, 전략 명령, 특수 병종 연구, 첩보·강행·방랑, 선양·모반·해산, 국호·국기 변경
- 부대(집합), 장비·아이템, 특기, 경매, 토너먼트
- 전투 시뮬레이터
- 차별화 D4 천하 타임랩스, D7 인물 관계망, D8 역사 사건 선택지, D9 명성과 계보, D13 정보의 안개,
  D14 계략 패, D18 야간 휴전
- 시나리오 추가

## Phase 3. 고도화

- PWA와 모바일 최적화
- 군사 조언(D3)의 LLM 자연어 설명
- 시즌 메타와 기록실
- 무중단 배포

## 주간 점검

진행이 보이게 하는 장치입니다. 매주 같은 요일에 10분만 씁니다.

1. 지난주에 ✅로 바뀐 AC 개수를 [인수조건 요약표](./acceptance-criteria.md#요약)에 반영합니다.
2. 🟨인 AC가 막혀 있다면 이유를 한 줄로 적습니다.
3. **2주 연속 ✅가 0개면** 그 AC를 더 작게 나누거나 범위를 줄입니다. 기준을 낮추지는 않습니다.
4. 새로 떠오른 아이디어는 [백로그](./backlog.md)로만 보냅니다.
