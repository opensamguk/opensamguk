# 수치 상태 정책

> 상태: 뼈대 · 필요 시점: M1 · 관련 AC: M1-13 (재생 일치) · 참고: core2026 `docs/numeric-state-policy.md`
> 이 문서가 답할 질문: 어떤 값이 정수이고 언제 반올림하나? 재생 결과가 기기마다 달라지지 않으려면?

## 1. 원칙

- 도메인에서 정수인 값(인구, 내정치, 금, 쌀, 병력, 경험, 공헌)은 **정해진 경계에서만** 정수로 바꿉니다.
- 소수가 누적되는 값(기술, 민심 등)은 소수 그대로 저장합니다.
- 화면 표시의 자릿수는 상태 정밀도와 별개입니다.
- 정수화 위치와 순서는 규칙의 일부입니다. 리팩터링으로 옮기면 재생 테스트가 깨집니다.

## 2. 값별 규칙


| 값       | 종류 | 정수화 시점 | 함수 |
| -------- | ---- | ----------- | ---- |
| 인구     | 정수 | 효과 적용 시 반올림·0~최대치 | applyEffects |
| 내정치   | 정수 | 효과 적용 시 반올림·0~최대치 | applyEffects |
| 금·쌀    | 정수 | 효과 적용 시 반올림·0 하한 | applyEffects |
| 병력     | 정수 | 효과 적용 시 반올림·0 하한 | applyEffects |
| 기술     | 소수 | 하지 않음   | —    |
| 민심     | 소수 | 하지 않음   | —    |

### 병력과 전투

모집 상한은 통솔 × 100명입니다. 모병 비용은 `ceil(수량 × 병종 cost)`이고 징병 비용은 여기에 0.5를 곱해 올림합니다. 기존 훈련·사기는 `floor(기존 값 × 기존 병력 / 새 병력)`으로 희석합니다. 수량은 정수이며 모집 인구를 같은 양만큼 뺍니다. 훈련·사기는 0~100, 부상은 0~100입니다. 징병 민심은 5를 빼고 0에서 멈춥니다.

한 페이즈 피해는 아래 식을 반올림한 뒤 최소 1, 상대 병력 이하로 제한합니다. 성벽 병력은 도시 wall이며 성벽 defence에는 도시 defence를 더합니다. 공격측·수비측 피해는 각 한 번씩 이 순서로 RNG를 소비하며 동시에 적용합니다.

```text
병력 × (공격 병종 attack / max(1, 상대 병종 defence + 도시 defence))
× 공격 병종 attackCoef[상대 armType] / max(0.01, 상대 병종 defenceCoef[공격 armType])
× (50 + 훈련) / 150 × (50 + 사기) / 150
× (1 + 국가 기술 / 12000) × 0.1 × U(0.9, 1.1)
```

계수가 없으면 1입니다. 페이즈마다 양쪽 사기를 5 줄이고 0에서 멈춥니다. 교전마다 시작 병력의 0.01배를 올림해 쌀에서 빼며 0 아래로 내리지 않습니다. 쌀이 0이면 사기를 30 줄입니다. 점령 시 치안은 절반을 반올림하고 민심은 20을 뺍니다. 전투의 페이즈·피해·보정 상수는 `balance.ts`에 모았습니다. 병종 상성은 저장된 unitSet을 그대로 씁니다. 원작의 회피·특기·장비·전략 효과는 M1에서 제외했습니다.

주민 선정 로그는 소수 1자리로 표시하지만 효과 상태의 민심 정밀도는 줄이지 않습니다. 국가 예턴 RNG는 `nation-turn, tick, nationId`, 장수 예턴은 기존 `turn, tick, generalId` 스트림을 씁니다. 국가 명령을 더해도 기존 장수 명령의 난수 소비는 바뀌지 않습니다.

정착 장려의 인구 변화는 `round(점수 × 10)`, 주민 선정의 민심 변화는 `점수 × 0.1`이며 소수를 유지합니다. 두 명령의 경험·공헌은 이 단위 배율을 적용하기 전 점수에서 정수화합니다.

월간 정산은 단계 끝에서 정수화합니다. 세입은 도시별 `(상업 또는 농업) × 인구 / 1,000 × 0.2`를 국가별로 합산한 뒤 `Math.round`합니다. 봉급 예산은 세입의 0.5를 반올림하며 장수별 봉급은 예산을 등장한 소속 장수 수로 나눈 몫을 내림합니다. 지급하고 남은 수입은 국고에 둡니다. 수입이 없는 달에는 봉급도 없습니다.

인구는 `round(인구 + 0.02 × (최대 인구 − 인구))` 뒤 0~최대치로 제한합니다. 월간 민심은 `round(민심 + (0.2 − 세율) × 10)` 뒤 0~100으로 제한하며 이 경계에서만 기존 소수도 정수화합니다. 보급이 끊긴 도시의 내정치 5종은 각각 0.9를 곱해 반올림합니다. 주둔 장수 훈련·사기는 각각 10을 빼고 0 아래로 내려가지 않게 합니다. 연감 국력은 국고 금·쌀, 소유 도시 인구, 등장한 소속 장수 병력을 합산해 반올림합니다.

## 3. 결정성을 지키는 규칙

- 게임 계산에 `Math.random()`, 현재 시각, 객체 키 순서에 기대는 반복을 쓰지 않습니다.
- 여러 장수·도시를 도는 순서는 ID 순처럼 명시적으로 정합니다.
- 부동소수 결과가 플랫폼마다 달라질 수 있는 함수(예: 삼각함수)는 게임 계산에 쓰지 않습니다.
