# UI 지침

> 상태: 초안 (T1-13) · 레퍼런스: [design/references](./design/references/README.md) · 관련 결정: D-007 · 관련 AC: M1-19, M3-08
> 참고: core2026 `frontend-css-architecture.md`, `frontend-typography.md`, `frontend-page-navigation.md` (셋을 합침)

## 1. 방향: 원작 정보량 + 모던 정리

1. 한 화면에 내 장수·도시·국가·다음 턴 시각이 다 보입니다.
2. 숫자는 오른쪽 정렬, 고정폭 숫자(`font-variant-numeric: tabular-nums`). 변화량은 색과 부호를 함께 씁니다.
3. 국가색은 지도와 국가 이름표에만 씁니다. 성공·실패·경고 색은 따로 고정합니다.
4. 표는 촘촘하되 행 간격·구분선·고정 머리글로 읽기 쉽게 합니다.
5. 색만으로 의미를 전하지 않습니다 (NFR-08).

### 이전 시도(v1)에서 가져온 원칙

출처: [아이디어 수집 A절](./product/idea-harvest.md#a-이전-시도-opensamguk-v1-2026-05--10)

- 못 쓰는 버튼은 숨기지 않고 점선 테두리로 두며 누르면 이유를 보여 줍니다. 가능 여부는 서버가 정합니다.
- 빈 목록과 불러오기 실패를 다르게 보여 줍니다.
- 턴 시각은 서버가 준 값만 보여 줍니다. 정지 뒤 밀린 턴을 따라잡을 때는 배속과 예상 시간을 띄웁니다.
- 게시 공간은 공개 커뮤니티, 국가 회의실, 기밀실(누가 읽었는지 기록)로 나눕니다 (M2 메시지 설계 때 검토).

## 2. 메인 작업 화면 (M1)

> 기준: [D-020](./product/decisions.md#d-020-메인-한-화면에서-지도와-예턴을-함께-다룬다-2026-10-21) 소유자 UI 정정 (2026-10-21), 레퍼런스 R1 core2026 `MainView.vue` `df6c926`.
> 이전 초안은 화면 6개를 각각 다른 주소로 나눴다. 그 표는 아래 기록으로 남긴다.

지도와 예턴 편집, 장수·도시·국가 정보, 기록을 메인 한 화면(`/w/:worldId`)에 함께 두고 그 자리에서 조작합니다.
핵심 플레이를 위해 다른 주소로 옮겨 가지 않습니다.

│ 메인  현재 191년 1월 · 턴 60분 · 국가 21 · 도시 94                                   │
├──────────────────── 지도 (1~7열) ───────────────┬── 명령 목록 (8~10열, 두 행) ──┤

| -- | ------------ | ---- | --- |

| 명령 목록 | 30칸 예턴(실행 시기·명령·인자·사전 검사), 저장하지 않은 편집 수 | T1-15 `TurnEditor`. 칸 고르기·명령 넣기·당기기·밀기·반복·저장·충돌 안내를 이 칸에서 한다 (아래 예턴 편집 조작) | `turns.*`, `commands.list`, `home.get` |

| 국가 정보 | 속령·장수 수, 소속국만 국고·군량·세율·기술·수도·성향 | 소유 도시·소속 장수 표를 같은 칸에서 펼친다. 머리글 정렬, 관리 필요 표시 | `home.get`, `nation.get` |
| 장수 정보 | 초상, 이름, 소속, 직책, 위치, 통솔·무력·지력, 금·쌀·병력·훈련·사기·경험·공헌, 다음 턴 시각 | 위치를 누르면 지도에서 그 도시를 고른다 | `home.get` |
| 기록 | 개인 기록, 국가 기록(전달 대비 변화), 중원 정세 | 더 보기로 이어 받는다 | `records.*` |

- 공개 범위 밖 값은 서버가 보내지 않습니다. 화면은 —와 이유(마우스를 올리면 보이는 글, 칸 위 안내 한 줄)를 보여 줍니다.
- 다음 턴 시각은 서버의 `nextTurnAt`만 씁니다. 1초마다 화면에서 줄이고 0초가 되면 `home.get`·`world.summary`·기록을 한 번 다시 받습니다.
  서버가 같은 시각을 다시 주면 5·10·20·30초 간격으로 네 번만 더 묻고 멈춥니다 (`apps/web/src/game/countdown.ts`).
- 관리 필요 표시: 보급 끊긴 도시는 빨강 `보급 끊김`, 부상 장수와 병력이 있는데 훈련·사기가 50 미만인 장수는 노랑 글자 표시.
- 지도 선택은 예턴 편집기의 대상 고르기 힌트로만 넘깁니다(`selectedCityKey`). 초안을 덮거나 저장하지 않습니다. 지도 선택·재조회 때 편집기를 다시 만들지도 않습니다.
- 턴 결과는 같은 메인에서 봅니다. 엔진이 칸을 실행하면 편집기가 새 목록을 받아 한 칸 당기고(10초 주기), 실행 결과와 실패 이유는 개인 기록 칸에 쌓입니다.
- 원작에서 빼거나 미룬 것: 장수 동향(전체 장수 행동 피드, 조회 API 없음), 메시지, 국가·전체 메뉴 띠, 도시 관직 칸, NPC 표시(응답에 NPC 여부가 없음).
- 장수가 없으면 명령·국가·장수 칸에 장수 만들기 안내가 나옵니다. 지도·도시·중원 정세는 공개 범위 안에서 그대로 보입니다.

### 예턴 편집 조작

T1-15 편집기(`apps/web/src/turns/TurnEditor.tsx`)의 조작입니다. 메인 명령 칸과 보조 주소 `/w/:worldId/turns`가 같은 부품을 씁니다.

- 칸을 누르면 그 칸을 고르거나 풀고 Shift를 누른 채 누르면 마지막으로 누른 칸부터 범위를 더합니다. 전체·홀수 칸·짝수 칸·선택 해제 버튼이 있습니다.
- 키보드: 표에 초점을 두고 위아래 화살표로 옮깁니다. Shift+화살표는 범위를 더하고 Space는 고르거나 풉니다. Enter는 명령 찾기 칸으로 갑니다.
  명령 찾기에서 Enter를 누르면 첫 결과를 고릅니다. 인자가 없으면 바로 고른 칸에 넣고 표로 돌아옵니다. 인자가 있으면 첫 인자 칸으로 갑니다.
- 넣기·당기기·밀기·반복은 화면 초안만 바꿉니다. [저장]을 눌러야 서버에 갑니다. 바뀐 칸에는 바뀜 표시가 붙고 위에 저장하지 않은 편집 수가 보입니다.
- 대상 도시 인자는 지도에서 고른 도시를 기본값으로 채웁니다. 다른 도시를 고른 뒤에는 [지도에서 고른 도시(이름) 쓰기]로 되돌립니다. 넣기 전에는 칸이 바뀌지 않습니다.
- 사전 검사는 칸마다 가능, 또는 경고와 그 이유로 보입니다. 경고가 있어도 저장되며 실행할 때 엔진이 다시 검사합니다.
- 다른 탭 저장이나 턴 실행으로 서버 목록이 먼저 바뀌면 저장 때 다른 곳에서 먼저 바뀌었다는 안내와 최신 목록을 보여 줍니다.
  [내 편집 다시 적용]과 [내 편집 버리기] 중 고르게 합니다. 다시 적용하면 최신 목록에 같은 편집을 같은 순서로 적용합니다. 사용자는 확인한 뒤 다시 저장합니다.
- 저장 중 로그인이 풀리면 [다시 로그인] 링크를 보여 줍니다. 저장하지 않은 편집은 탭에 남아 같은 계정으로 다시 로그인하면 이어서 저장합니다.
- 못 쓰는 버튼(고른 칸이 없을 때 넣기, 바꾼 칸이 없을 때 저장, 이어지지 않은 구간의 반복)은 점선으로 두고 누르면 이유를 보여 줍니다.

### 로그인 가드 (T1-14)

- `/`와 `/w/:worldId/…`는 `beforeLoad`에서 `auth.me`를 확인합니다. 로그인 안 됨 → `/login?next=<원래 주소>`.
- 가드는 **화면을 옮길 때마다 서버에 `auth.me`를 다시 묻습니다** (`fetchQuery`, `staleTime: 0`). 캐시만 믿으면 다른 탭에서
  로그아웃했거나 세션이 만료된 뒤에도 이전 사용자로 통과하기 때문입니다. 이동 한 번에 요청 하나가 듭니다.
- 가드는 라우터 context의 `queryClient`·`trpc`(`apps/web/src/trpc.ts`의 하나뿐인 인스턴스)를 씁니다.
  로그인·가입 성공은 캐시를 비우고 `auth.me`를 새 사용자로, 로그아웃은 `null`로 바꿔 둡니다 (이전 사용자 데이터가 남지 않게).
- `next`는 같은 사이트 경로만 받습니다(`safeNext`: `/`로 시작, `//`·`\`·공백·`/login`·`/signup` 거부). 아니면 `/`로 갑니다.
- `/`는 로그인했으면 `world.list`의 첫 RUNNING 월드 메인으로 보냅니다. 없으면 참가할 월드 화면에 열린 월드가 없다고 보여 줍니다 (T1-16).
- `auth.me`를 못 받으면(네트워크) 가드 자리에 "다시 시도"를 보여 줍니다. <!-- lint-text-ignore J-2 -->
- 장수 없음: 메인 칸마다 장수 만들기(`/w/:worldId/create`) 안내를 둡니다. 생성 화면은 T1-15.
- 위쪽 띠 메뉴는 메인·예턴·기록입니다. 보조 화면에는 메인에서 보기 링크가 있습니다. 왼쪽 장수 요약 띠는 메인 폭을 위해 없앴습니다 (§2).

### 로그인·가입 화면

- 한 부품(`apps/web/src/auth/AuthForm.tsx`)에서 문구·API·`autocomplete`(`current-password`/`new-password`)만 다릅니다.
- 화면 검사(이메일 형식, 비밀번호 10~128자)는 보내기 전에 칸 아래에 보여 주고 최종 판단은 서버입니다.
- 서버 답: `UNAUTHORIZED` → "이메일 또는 비밀번호가 맞지 않습니다", `CONFLICT` → "이미 가입된 이메일입니다". <!-- lint-text-ignore J-2 -->
  답을 못 받으면(네트워크·서버 오류) "다시 시도" 버튼이 **지금 폼 값으로** 다시 제출합니다 (검사도 다시 함). <!-- lint-text-ignore J-2 -->
- 제출 중에는 버튼을 막고 "로그인 중…"으로 바꿉니다. 비밀번호 칸 옆 "보이기" 토글(`aria-pressed`). <!-- lint-text-ignore J-2 -->
- 로그아웃은 위쪽 띠 오른쪽 끝에 있습니다.
- 데이터는 TanStack Query + `@trpc/tanstack-react-query`의 `useTRPC()`로 가져옵니다.
