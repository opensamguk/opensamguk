# UI 지침

> 상태: 초안 (T1-13) · 레퍼런스: [design/references](./design/references/README.md) · 관련 결정: D-007 · 관련 AC: M1-19, M3-08
> 참고: core2026 `frontend-css-architecture.md`, `frontend-typography.md`, `frontend-page-navigation.md` (셋을 합침)

## 1. 방향: 원작 정보량 + 모던 정리

1. 한 화면에 내 장수·도시·국가·다음 턴 시각이 다 보입니다.
2. 숫자는 오른쪽 정렬, 고정폭 숫자(`font-variant-numeric: tabular-nums`). 변화량은 색과 부호를 함께 씁니다.
3. 국가색은 지도와 국가 이름표에만 씁니다. 성공·실패·경고 색은 따로 고정합니다.
4. 표는 촘촘하되 행 간격·구분선·고정 머리글로 읽기 쉽게 합니다.
5. 색만으로 의미를 전하지 않습니다 (NFR-08).

### 이전 시도(v1)에서 가져온 원칙

출처: [아이디어 수집 A절](./product/idea-harvest.md#a-이전-시도-opensamguk-v1-2026-05--10)

- 못 쓰는 버튼은 숨기지 않고 점선 테두리로 두며 누르면 이유를 보여 줍니다. 가능 여부는 서버가 정합니다.
- 빈 목록과 불러오기 실패를 다르게 보여 줍니다.
- 턴 시각은 서버가 준 값만 보여 줍니다. 정지 뒤 밀린 턴을 따라잡을 때는 배속과 예상 시간을 띄웁니다.
- 게시 공간은 공개 커뮤니티, 국가 회의실, 기밀실(누가 읽었는지 기록)로 나눕니다 (M2 메시지 설계 때 검토).

## 2. 메인 작업 화면 (M1)

> 기준: [D-020](./product/decisions.md#d-020-메인-한-화면에서-지도와-예턴을-함께-다룬다-2026-10-21) 소유자 UI 정정 (2026-10-21), 레퍼런스 R1 core2026 `MainView.vue` `df6c926`.
> 이전 초안은 화면 6개를 각각 다른 주소로 나눴다. 그 표는 아래 기록으로 남긴다.

지도와 예턴 편집, 장수·도시·국가 정보, 기록을 메인 한 화면(`/w/:worldId`)에 함께 두고 그 자리에서 조작합니다.
핵심 플레이를 위해 다른 주소로 옮겨 가지 않습니다.

```text
┌ 위쪽 띠: 월드 이름 · 현재 연월 · 다음 턴까지 남은 시간 · 메뉴 · 로그아웃 ───────────────┐
│ 메인  현재 191년 1월 · 턴 60분 · 국가 21 · 도시 94                                   │
├──────────────────── 지도 (1~7열) ───────────────┬── 명령 목록 (8~10열, 두 행) ──┤
│ 94도시 SVG, 소유국 색, 연결선, 보급 끊김, 내 위치  │ 30칸 예턴 편집기 (T1-15)      │
├──────────────────── 도시 정보 ───────────────────┤ 선택·명령 넣기·당기기·저장    │
│ 지도에서 고른 도시. 수치·최대치, 주둔 장수        │                               │
├──────────── 국가 정보 (1~5열) ──┬───────── 장수 정보 (6~10열) ─────────────────┤
│ 국고·군량·세율·기술, 펼치면 소속 장수·소유 도시 표 │ 초상·능력치·자원·다음 턴 시각 │
├──────────── 개인 기록 ──────────┴───────── 국가 기록 ──────────────────────────┤
├──────────────────────────────── 중원 정세 ────────────────────────────────────┤
```

| 칸 | 보여 주는 것 | 조작 | API |
| -- | ------------ | ---- | --- |
| 지도 | 94도시, 소유국 색(이름표 글자색은 대비로 자동), 연결선, 보급 끊김(국가 도시만, 점선 테두리·사선·글자), 내 위치(굵은 테두리·글자) | 도시를 누르거나 Enter. 주소의 `?city=`만 바뀌고 화면은 그대로 | `world.map` |
| 명령 목록 | 30칸 예턴(실행 시기·명령·인자·사전 검사), 저장하지 않은 편집 수 | T1-15 `TurnEditor`. 칸 고르기·명령 넣기·당기기·밀기·반복·저장·충돌 안내를 이 칸에서 한다 (아래 예턴 편집 조작) | `turns.*`, `commands.list`, `home.get` |
| 도시 정보 | 지도에서 고른 도시(기본은 내 도시). 수치와 최대치 막대, 주둔 장수 표, 연결 도시 | 연결 도시를 누르면 같은 칸이 그 도시로 바뀐다. 내 도시로 돌아가기 | `city.get` |
| 국가 정보 | 속령·장수 수, 소속국만 국고·군량·세율·기술·수도·성향 | 소유 도시·소속 장수 표를 같은 칸에서 펼친다. 머리글 정렬, 관리 필요 표시 | `home.get`, `nation.get` |
| 장수 정보 | 초상, 이름, 소속, 직책, 위치, 통솔·무력·지력, 금·쌀·병력·훈련·사기·경험·공헌, 다음 턴 시각 | 위치를 누르면 지도에서 그 도시를 고른다 | `home.get` |
| 기록 | 개인 기록, 국가 기록(전달 대비 변화), 중원 정세 | 더 보기로 이어 받는다 | `records.*` |

- 공개 범위 밖 값은 서버가 보내지 않습니다. 화면은 —와 이유(마우스를 올리면 보이는 글, 칸 위 안내 한 줄)를 보여 줍니다.
- 다음 턴 시각은 서버의 `nextTurnAt`만 씁니다. 1초마다 화면에서 줄이고 0초가 되면 `home.get`·`world.summary`·기록을 한 번 다시 받습니다. SSE가 이어져 있으면 0초 재조회는 쉬고 턴 결과 알림이 대신합니다 (T2-10).
  서버가 같은 시각을 다시 주면 5·10·20·30초 간격으로 네 번만 더 묻고 멈춥니다 (`apps/web/src/game/countdown.ts`).
- 위쪽 띠는 장수가 없거나 정지 중이어도 `world.summary`를 주기적으로 다시 받습니다. 가속 진행 중은 5초, 실시간·정지는 15초이고 끝난 판·개시 전·다시 물어도 같은 오류(없는 월드, 로그인 풀림)에서는 멈춥니다.
  상태나 시계 모드가 바뀌면 `home.get`과 기록을 한 번 다시 받고 가속 중에는 5초마다 함께 받습니다(장수가 없으면 `home.get`은 뺍니다). 가속 중 상태 칸은 카운트다운 대신 가속 진행 중입니다 (`apps/web/src/game/worldWatch.ts`, T1-27).
- 끝난 판은 메인 맨 위에 기수 결과 칸(끝난 이유, 승자 국가 이름표 또는 승자 없음, 종료 연월, 남은 국가 수)을 두고 위쪽 띠 연월은 결과의 종료 연월입니다. 예턴 편집은 저장을 막고 이유를 한 줄 보여 주며 모든 주기 조회를 멈춥니다.
- 관리 필요 표시: 보급 끊긴 도시는 빨강 `보급 끊김`, 부상 장수와 병력이 있는데 훈련·사기가 50 미만인 장수는 노랑 글자 표시.
- 지도 선택은 예턴 편집기의 대상 고르기 힌트로만 넘깁니다(`selectedCityKey`). 초안을 덮거나 저장하지 않습니다. 지도 선택·재조회 때 편집기를 다시 만들지도 않습니다.
- 턴 결과는 같은 메인에서 봅니다. 엔진이 칸을 실행하면 편집기가 새 목록을 받아 한 칸 당기고(10초 주기), 실행 결과와 실패 이유는 개인 기록 칸에 쌓입니다.
- 원작에서 빼거나 미룬 것: 장수 동향(전체 장수 행동 피드, 조회 API 없음), 국가·전체 메뉴 띠, 도시 관직 칸, NPC 표시(응답에 NPC 여부가 없음).
- 장수가 없으면 명령·국가·장수 칸에 장수 만들기 안내가 나옵니다. 지도·도시·중원 정세는 공개 범위 안에서 그대로 보입니다.

### 예턴 편집 조작

T1-15 편집기(`apps/web/src/turns/TurnEditor.tsx`)의 조작입니다. 메인 명령 칸과 보조 주소 `/w/:worldId/turns`가 같은 부품을 씁니다.

- 칸을 누르면 그 칸을 고르거나 풀고 Shift를 누른 채 누르면 마지막으로 누른 칸부터 범위를 더합니다. 전체·홀수 칸·짝수 칸·선택 해제 버튼이 있습니다.
- 키보드: 표에 초점을 두고 위아래 화살표로 옮깁니다. Shift+화살표는 범위를 더하고 Space는 고르거나 풉니다. Enter는 명령 찾기 칸으로 갑니다.
  명령 찾기에서 Enter를 누르면 첫 결과를 고릅니다. 인자가 없으면 바로 고른 칸에 넣고 표로 돌아옵니다. 인자가 있으면 첫 인자 칸으로 갑니다.
- 넣기·당기기·밀기·반복은 화면 초안만 바꿉니다. [저장]을 눌러야 서버에 갑니다. 바뀐 칸에는 바뀜 표시가 붙고 위에 저장하지 않은 편집 수가 보입니다.
- 대상 도시 인자는 지도에서 고른 도시를 기본값으로 채웁니다. 다른 도시를 고른 뒤에는 [지도에서 고른 도시(이름) 쓰기]로 되돌립니다. 넣기 전에는 칸이 바뀌지 않습니다.
- 사전 검사는 칸마다 가능, 또는 경고와 그 이유로 보입니다. 경고가 있어도 저장되며 실행할 때 엔진이 다시 검사합니다.
- 다른 탭 저장이나 턴 실행으로 서버 목록이 먼저 바뀌면 저장 때 다른 곳에서 먼저 바뀌었다는 안내와 최신 목록을 보여 줍니다.
  [내 편집 다시 적용]과 [내 편집 버리기] 중 고르게 합니다. 다시 적용하면 최신 목록에 같은 편집을 같은 순서로 적용합니다. 사용자는 확인한 뒤 다시 저장합니다.
- 저장 중 로그인이 풀리면 [다시 로그인] 링크를 보여 줍니다. 저장하지 않은 편집은 탭에 남아 같은 계정으로 다시 로그인하면 이어서 저장합니다.
- 못 쓰는 버튼(고른 칸이 없을 때 넣기, 바꾼 칸이 없을 때 저장, 이어지지 않은 구간의 반복)은 점선으로 두고 누르면 이유를 보여 줍니다.
- 교역 명령의 대상 도시 칸은 교역 조약이 유효한 이웃 도시만 후보로 둡니다(`treaty.tradeTargets`, T2-08). 후보가 없으면 서버가 준 이유를 칸 아래에 보여 줍니다.
  지도에서 고른 도시가 후보 밖이면 기본값으로 채우지 않습니다. 저장은 같은 [저장]으로 합니다.
- 고른 칸도 저장하지 않은 편집처럼 탭에 남습니다. 외교실에 갔다 돌아와도 초안과 선택이 그대로입니다.

### 작전에 맞추기

- 작전 상세의 내 예턴은 같은 30칸 편집기를 쓴다. [내 예턴을 작전에 맞추기]는 `operation.suggest`의 바뀌는 칸만 지금과 제안을 나란히 보여 줍니다.
- [초안에 넣기]는 바뀌는 칸마다 편집기 초안 훅의 `edit({ put })`를 부릅니다. 저장하지 않은 편집이 있으면 덮기 전에 묻습니다. 저장은 편집기의 [저장] 하나뿐입니다.
- 저장 충돌이면 편집기의 충돌 안내를 그대로 쓰고 작전 비교는 최신 예턴으로 다시 받습니다. 미리보기를 닫거나 다른 화면에 갔다 와도 초안과 고른 칸은 남습니다.
- 판정은 아이콘·글자·색을 함께 씁니다(○ 준비됨, △ 미흡, ! 늦음, ✕ 없음). 모두 예턴만 본 예상이라고 적습니다. 목표 전 6개월만 먼저 보이고 더 보기로 넓힙니다.

### 외교실의 즉시 행동

- 제안·수락·거절·파기 단추를 누르면 `requestId`를 만들어 보내기 전에 탭에 둡니다(키에 계정과 월드). 결과가 `applied`나 `rejected`로 정해질 때만 지웁니다.
- `pending`이면 그 카드에 처리 중을 두고 단추를 잠근 뒤 `treaty.request`를 1초마다 묻습니다. 새로 고치거나 다시 로그인하면 저장한 `requestId`로 다시 묻습니다.
  같은 국가 다른 장수의 대기 요청은 `treaty.list`의 `pending`으로 처리 중을 보입니다. 목록에서 제안이 사라진 것으로 결과를 추측하지 않습니다.
- 응답을 받지 못하면 [같은 요청 다시 보내기]가 같은 `requestId`와 같은 내용으로 다시 보냅니다. 로그인이 풀리면 [다시 로그인]을 보이고 `requestId`는 남깁니다.
- 단추마다 서버의 `canAccept`·`canReject`·`canBreak`를 따로 보고 `code`로 나눕니다. `NO_PERMISSION`이면 단추를 그리지 않고 읽기만 한다고 알립니다. 다른 이유는 점선 단추로 두고 이유를 보입니다.
- 파기는 신의 기록에 남는다는 확인을 거칩니다.

### 빈 칸과 기본 방침 (T2-14)

> 계약: [T2-13](./plans/T2-13.md)의 `SlotView`·`PolicyResponse`. API가 main에 들어오기 전 임시 타입은 `apps/web/src/policy/contract.ts`에만 둡니다.

예턴 칸은 두 가지입니다. 사용자가 아무것도 넣지 않은 빈 칸(`explicit: false`)과 직접 넣은 칸입니다. 직접 넣은 휴식도 직접 넣은 칸이며 빈 칸과 다릅니다.

- 빈 칸은 흐린 보통 굵기로 `(권농) 농지 개간`처럼 지금 확정된 방침 이름과 그 방침이 빈 칸에서 할 명령을 적습니다. 방침이 `none`이거나 방침을 못 읽었으면 `(빈 칸) 휴식`입니다. 색만으로 가르지 않도록 괄호 안 글자를 늘 붙입니다.
- 직접 넣은 칸은 지금처럼 굵은 명령 이름입니다. 직접 넣은 휴식은 굵은 `휴식`입니다.
- [고른 칸 비우기]는 고른 칸을 빈 칸으로 되돌립니다. 당기기·밀기로 생긴 칸도 빈 칸이고 반복은 복사한 칸의 구분을 그대로 둡니다.
- 저장할 때 빈 칸은 `null`, 직접 넣은 칸은 `{ commandKey, args }`로 보냅니다. 바뀜 표시와 충돌 뒤 다시 적용도 빈 칸과 직접 넣은 휴식을 다른 칸으로 봅니다.
- 편집기 위에 기본 방침 고르기 줄을 둡니다. 고르면 예턴 저장과 따로 바로 보내고 저장하지 않은 예턴 초안은 그대로 둡니다.
  엔진이 처리하기 전에는 고른 값 옆에 처리 중을 두고 고르기를 막습니다. 그동안 빈 칸 표시와 안내 문장은 옛 방침을 따르고 문장 끝에 엔진이 처리하면 바뀔 방침을 적습니다.
  거절되면 이유를 빨간 글로 보이고 고르기 칸은 지금 방침으로 돌아갑니다.
- 안내 문장은 `빈 칸은 농지 개간을 합니다. 실패하면 휴식합니다.`처럼 서버가 준 명령 이름으로 만듭니다. 화면에 방침 표를 따로 두지 않습니다.
- 장수 정보 칸에 지금 방침 이름을 둡니다.
- 장기 미접속 안내 한 줄은 사용자 결정 U63-1·U63-2가 정해진 뒤에 넣습니다.

### 메시지 패널과 실시간 상태 (T2-10)

- 위쪽 띠의 [메시지] 단추가 오른쪽 접이식 패널을 엽니다. 단추 옆 배지는 볼 수 있는 범위의 안 읽음 수를 더한 값입니다.
  패널은 Esc나 [닫기]로 닫고 초점은 [메시지] 단추로 돌아옵니다. [전체 화면]은 `/w/:worldId/messages`로 갑니다. 두 곳은 같은 부품(`apps/web/src/messages/MessagePanel.tsx`)입니다.
- 탭은 개인·국가·외교·전체입니다. 서버가 안 읽음 수를 null로 준 범위(재야의 국가·외교, 군주·참모가 아닌 장수의 외교)는 탭을 숨깁니다. 탭 이름에 안 읽음 수를 붙입니다.
- 탭을 열어 첫 쪽이 보이면 그 안의 받은 메시지를 읽음 처리합니다. 따로 누르는 버튼은 없습니다. 목록은 메시지 id마다 한 줄이고 보낸 시각, id 순으로 내려 갑니다.
- 보내기 실패(도배 제한, 권한 없음, 연결 실패)는 입력칸 아래에 이유를 보이고 입력은 지우지 않습니다. 오류 문장은 입력칸의 설명(`aria-describedby`)으로 붙습니다.
- 작성 칸, 고른 탭, 국가 공지 고치기 초안은 query 캐시 밖(`apps/web/src/messages/drafts.ts`)에 둡니다. 패널을 접었다 펴도, 재조회가 돌아도 남고 새로고침이나 로그아웃 때 사라집니다.
- 전체 탭 맨 위에 월드 공지를 고정 공지부터 둡니다. 전체 메시지는 운영자만 보내므로 작성 칸이 없습니다.
- 국가 공지는 메인 국가 정보 칸 아래에서 읽고 군주·참모만 고칩니다. 바뀐 공지는 소속 장수가 다음 접속 때 팝업으로 한 번 봅니다. 팝업을 닫으면 팝업에 띄운 국가와 판(revision)을 그대로 보냅니다.
- 실시간 갱신은 월드 SSE 연결 하나로 합니다(`apps/web/src/realtime/useWorldEvents.ts`). 알림마다 해당 query만 다시 받고 이어질 때마다(ready) 화면 전체를 한 번 다시 받습니다.
  재조회는 서버 데이터만 바꿉니다. 지도 선택, 30칸 미저장 초안, 작성 칸은 그대로입니다. 예턴이 서버에서 바뀌면 편집기의 기존 안내와 STALE 흐름을 탑니다.
- 연결 상태는 위쪽 띠에 작게 둡니다. 이어져 있으면 실시간 연결됨, 3초 넘게 끊기면 다시 잇는 중입니다. 짧은 끊김에는 표시가 바뀌지 않습니다. 끊긴 동안에는 0초 재조회가 대신 돌고 화면은 그대로 씁니다.

### 로그인 가드 (T1-14)

- `/`와 `/w/:worldId/…`는 `beforeLoad`에서 `auth.me`를 확인합니다. 로그인 안 됨 → `/login?next=<원래 주소>`. `/lobby`는 가드가 없습니다.
- 가드는 **화면을 옮길 때마다 서버에 `auth.me`를 다시 묻습니다** (`fetchQuery`, `staleTime: 0`). 캐시만 믿으면 다른 탭에서
  로그아웃했거나 세션이 만료된 뒤에도 이전 사용자로 통과하기 때문입니다. 이동 한 번에 요청 하나가 듭니다.
- 가드는 라우터 context의 `queryClient`·`trpc`(`apps/web/src/trpc.ts`의 하나뿐인 인스턴스)를 씁니다.
  로그인·가입 성공은 캐시를 비우고 `auth.me`를 새 사용자로, 로그아웃은 `null`로 바꿔 둡니다 (이전 사용자 데이터가 남지 않게).
- `next`는 같은 사이트 경로만 받습니다(`safeNext`: `/`로 시작, `//`·`\`·공백·`/login`·`/signup` 거부). 안전한 `next`가 있으면 그 주소로, 없으면 `/lobby`로 갑니다 (T2-04).
- `/`는 로그인했으면 `/lobby`로 보냅니다. T1-16의 첫 RUNNING 월드로 보내기를 로비가 대신합니다.
- `auth.me`를 못 받으면(네트워크) 가드 자리에 "다시 시도"를 보여 줍니다. <!-- lint-text-ignore J-2 -->
- 장수 없음: 메인 칸마다 장수 만들기(`/w/:worldId/create`) 안내를 둡니다. 생성 화면은 T1-15.
- 위쪽 띠 맨 앞에 `로비` 링크가 있습니다. 메뉴는 메인·예턴·기록·순위·전투 시뮬레이터·도움말입니다. 보조 화면에는 메인에서 보기 링크가 있습니다. 왼쪽 장수 요약 띠는 메인 폭을 위해 없앴습니다 (§2).

### 로비 (T2-04)

- 공지(`lobby.notices`)는 서버 순서대로 두고 첫 줄만 펼칩니다. 한 번에 하나만 엽니다.
- 공지와 월드 목록 사이에 지연 공개 지도 자리(`data-slot="public-map"`)가 있습니다. 지도는 T2-25가 넣습니다 (D-026). 비어 있으면 보이지 않습니다.
- 월드 카드에는 상태(`진행 중`·`가오픈`·`멈춤`·`끝남`, `Tag`로 글자와 색을 함께), 프리셋 이름(null이면 칸 없음), 이름, `시나리오(시작 연도) · 게임 연월 · 턴 N분 · 장수 N · 시작 M/D`가 있습니다. 시작하지 않은 월드는 `시작 전`입니다.
- 정원 키(`maxHumanGenerals`)가 응답에 없으면 인원만 씁니다. D-025 승인 뒤 키가 오면 `장수 3/10`, null이면 `장수 34/—`입니다.
- 버튼은 `auth.me`와 `myGeneral`, `createBlockedReason`만 보고 고릅니다 (`apps/web/src/lobby/lobbyView.ts`의 `lobbyAction`). 내 장수가 있으면 `들어가기`, 없으면 `장수 만들기`, 로그인 안 했으면 `로그인하고 참가`(`/login?next=/lobby`)입니다. 서버가 이유를 주면 그 버튼을 `DisabledReason`으로 막고 이유를 보입니다.
- 월드가 0개면 `EmptyState`, 목록이나 `auth.me`를 못 받으면 `ErrorState`와 다시 시도입니다. 공지를 못 받으면 공지 자리에만 `ErrorState`를 둡니다.
- T2-03 API가 main에 들어오기 전까지 응답 타입은 `apps/web/src/lobby/contract.ts`에 둡니다.

### 로그인·가입 화면

- 한 부품(`apps/web/src/auth/AuthForm.tsx`)에서 문구·API·`autocomplete`(`current-password`/`new-password`)만 다릅니다.
- 화면 검사(이메일 형식, 비밀번호 10~128자)는 보내기 전에 칸 아래에 보여 주고 최종 판단은 서버입니다.
- 서버 답: `UNAUTHORIZED` → "이메일 또는 비밀번호가 맞지 않습니다", `CONFLICT` → "이미 가입된 이메일입니다". <!-- lint-text-ignore J-2 -->
  답을 못 받으면(네트워크·서버 오류) "다시 시도" 버튼이 **지금 폼 값으로** 다시 제출합니다 (검사도 다시 함). <!-- lint-text-ignore J-2 -->
- 제출 중에는 버튼을 막고 "로그인 중…"으로 바꿉니다. 비밀번호 칸 옆 "보이기" 토글(`aria-pressed`). <!-- lint-text-ignore J-2 -->
- 로그아웃은 위쪽 띠 오른쪽 끝에 있습니다.
- 데이터는 TanStack Query + `@trpc/tanstack-react-query`의 `useTRPC()`로 가져옵니다.

### 로그인·로비 공개 지도 (T2-25)

> 결정: [D-026](./product/decisions.md#d-026-로그인과-로비에-지연-공개-지도를-둔다-2026-10-23) · 부품: `apps/web/src/publicMap/PublicMapTabs.tsx` · API: `world.publicMaps` (T2-24)

- 로그인 화면은 양식이 왼쪽, 공개 지도가 오른쪽입니다. 640px 이하에서는 양식 아래로 지도가 내려갑니다. 지도 칸 폭은 비어 있을 때도 잡아 두어 양식이 움직이지 않습니다.
- 로비는 월드 목록 위에 같은 부품을 둡니다 (T2-04가 들어온 뒤 붙임). 로비 카드의 선택과 지도 탭은 따로 움직입니다.
- 진행 중인 월드(RUNNING, PAUSED) 하나가 탭 하나입니다. PAUSED는 이름 옆에 `멈춤` 표시를 붙입니다. 처음에는 첫 탭을 열고 고른 월드의 지도만 그립니다.
- 탭은 `role="tablist"`·`role="tab"`·`aria-selected`를 쓰고 고른 탭만 Tab 키 초점을 받습니다. 왼쪽·오른쪽 방향키는 끝에서 반대쪽으로 돌고 Home·End는 처음과 끝으로 갑니다.
- 지도 위 한 줄에 사본의 연월과 찍은 실제 시각(`190년 3월 · 오후 2시 10분 기준`, 오늘이 아니면 날짜를 붙임), 그리고 응답의 `delayMinutes`로 `10분 이상 지난 상태입니다`를 씁니다.
- 지도는 메인 `WorldMap`을 `onSelect` 없이 써서 읽기 전용으로 그립니다. 도시는 초점을 받지 않고 눌러도 이동하지 않습니다. 범례는 국가 색 견본·이름·도시 수와 공백지뿐이며 내 위치·보급 끊김 항목이 없습니다.
- 화면은 응답에서 공개 범위(도시 소유와 국가 이름·색) 안의 키만 골라 씁니다 (`toPublicMaps`). 서버가 다른 값을 섞어 보내도 그리지 않습니다.
- 사본 없는 월드 탭은 `아직 공개 지도가 없습니다`만 보여 줍니다. 공개할 월드가 없거나 응답을 받는 중이면 탭 줄도 문구도 없이 자리만 둡니다. 불러오지 못하면 그 자리에 한 줄로 알립니다.
