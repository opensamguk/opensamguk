# 게임 시계

> 상태: 뼈대 · 필요 시점: M1 · 관련 AC: M1-04, M1-10, M1-11, M1-12
> 참고: core2026 `game-clock.md`, `time-domains.md`, `game-clock-reconciliation.md` (셋을 이 문서 하나로 합침)

## 1. 이미 정한 것

- 1턴은 게임 1개월입니다. 월드의 턴 간격(분)이 현실 시간과 게임 1개월의 비율입니다.
- 장수마다 그 달 안에서 자기 턴 시각(`nextTurnTick`)이 다릅니다.
- 게임 진행의 기준은 `World.clockTick`입니다. 날짜 문자열은 화면용입니다.
- 일시정지 중에는 게임 시간이 흐르지 않습니다 (FR-ENG-08).

## 2. 시간의 종류

core2026은 시간을 셋으로 나눕니다. 이 구분을 그대로 씁니다.

| 종류   | 기준                  | 쓰는 곳                                  |
| ------ | --------------------- | ---------------------------------------- |
| GAME   | `World.clockTick`     | 장수 턴, 월간 정산, 외교 기한            |
| WALL   | DB의 UTC 시각         | 세션 만료, 메시지 시각, 감사 로그, 리스  |
| 경과   | 프로세스의 monotonic  | 타임아웃, 성능 측정                      |

GAME 규칙을 WALL 시각으로 판정하지 않습니다. 반대도 마찬가지입니다.

## 3. 시계 모드

| 모드        | 동작                                       | 쓰는 곳 |
| ----------- | ------------------------------------------ | ------- |
| realtime    | 벽시계 경과를 tick으로 바꿔 진행           | 운영 월드 |
| manual      | 벽시계를 읽지 않고 최대 속도로 진행        | 시뮬레이터, 테스트, 관문 데모의 가속 (FR-ENG-07) |
| paused      | tick이 멈춤                                | 일시정지 |
