# 두 런타임의 기능 동등성

> 결정: D-061 · AC: AC-P2-35 · 작업: T4-98 · 상태: 구현·교차 검증 전

사용자는 opensamguk와 Cloudflare 버전의 기능에 차이가 없어야 한다고 정했다. 기존 잔여 작업과 새 기능 모두에 적용한다. 한쪽 구현의 병합은 그쪽 진행 증거이며 양쪽 완료의 증거가 아니다.

## 공유하는 계약

게임 규칙·명령 정의·설정·원생성·시드 난수·재생은 `packages/rules`를 공유한다. 화면·HUD·입력·접근성은 `apps/web`을 공유하고 Claude Code가 아티팩트 설계로 구현한다. `packages/shared`의 공개 계약도 upstream을 따른다. 런타임별 분기에서 기능이나 권한을 숨겨 차이를 맞췄다고 하지 않는다.

HTTP 어댑터는 세션·입력·응답을 처리하고 응용 서비스는 유스케이스와 저장소 포트를 사용한다. PostgreSQL과 DO·D1의 세부 구현은 저장 어댑터에 둔다. 게임 규칙에 저장소·HTTP·실시간 시계를 넣지 않으며 프론트에 업무 규칙을 복제하지 않는다.

## 달라도 되는 구현과 같아야 하는 결과

| 영역 | opensamguk | Cloudflare | 같은 결과의 증거 |
| --- | --- | --- | --- |
| 상태 변경 | 엔진·PostgreSQL 단일 턴 트랜잭션 | WorldDO의 원자적 상태·입력 기록 | 같은 원생성·입력·시드의 결과·상태 해시·순서 |
| 세션·권한·제재 | 기존 서버·DB 어댑터 | Worker 응용 서비스·계정 저장 어댑터 | 같은 허용/거부·오류 코드·변경 없음 |
| 예약·접수 | revision·InputEvent | 같은 revision·멱등 입력 | 충돌·중복·타인 조작·재시작 뒤 결과 |
| 조회·실시간 | 기존 조회·SSE | 같은 공개 조회·갱신 계약 | 같은 시야·정보·정렬·최종 화면 |
| 유산 등 월드 밖 기록 | DB 트랜잭션·고유 키 | 영수증·멱등키·복구 절차 | 중복 지급/사용 없음·실패 뒤 복구 |
| UI·HUD·그림 | 공통 웹·Codex 생성 자원 | 같은 웹·자원 | 같은 데이터로 375/1440·밝음/어두움·키보드·실제 저장 |

DO와 D1을 하나의 트랜잭션으로 간주하지 않는다. D1 조회 사본이 늦어져도 권한 판정과 게임 쓰기는 정본을 사용하고 접수/처리/반영 중 상태를 기존 계약대로 구분한다.

## 인수 범위

기존 Cloudflare 이식 인수조건과 upstream의 AC를 대응시킨다. 카드 선택(P2-29), 자원·창고·수송(P2-30), 통치(P2-31), 혼인·계승(P2-32), 유산(P2-33), UI·HUD(P2-34)도 각각 같은 실제 장면을 양쪽에서 실행한다. 기존 계정·명령·도시 자원·장수 지시·운영·기록 기능을 비교 대상에서 빼지 않는다.

순수 규칙 시험만으로 저장·HTTP·브라우저의 동등성을 주장하지 않는다. 같은 고정 입력을 실제 PG/서버/엔진과 실제 Worker/DO/D1 실행에 넣고 응답·상태·재생을 대조한다. 실제 실행 환경, 소스 SHA, 설정·시드·입력과 결과를 해당 계획에 기록한다. 대역·skip·미병합 상태는 최종 인수 증거가 아니다.

프론트는 upstream에서 구현하고 Cloudflare가 정상 병합으로 받는다. 서버·엔진·DB 변경은 Cloudflare의 저장소 포트와 어댑터에도 연결한 뒤 검증한다. 각 담당의 독립 리뷰와 필수 CI를 통과한 PR은 즉시 정상 머지하되 보호 규칙을 우회하지 않는다.
