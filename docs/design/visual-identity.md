# 화면 정체성: 한지 군략도

> 상태: 구현 중 (INT-20) · 결정 [D-047](../product/decisions.md) · 시안: 사용자 비공개 캔버스 47장

원작 정보량은 그대로 두고 한지 위에 그린 도트 군략도로 옷을 바꾼다. 고전 전략 게임의 장르 관습만 가져오고 특정 게임의 그림·색·창틀은 따르지 않는다.

## 색

| 이름 | 값 | 쓰는 곳 |
| --- | --- | --- |
| 한지 | `#F4ECD8` | 첩(패널) 바탕 |
| 바탕 | `#E5D9BD` | 화면 바탕, 점 두 겹의 섬유 결 |
| 먹 | `#221D17` | 글자, 테두리, 상단 배너 |
| 옅은 먹 | `#5A5044` | 보조 글자 (한지 위 대비 6.6:1) |
| 주칠 | `#9B2C1F` | 제목패, 주요 버튼, 위험 |
| 석록 | `#2F6E5E` | 성공, 막대 |
| 금니 | `#A8822F` | 첩 안쪽 실선, 장식 |
| 남색 | `#263552` | 정보, 운영자 화면 |

다크 모드는 먹 바탕에 한지 글자로 뒤집는다. 국가색은 데이터에서 오고 군기 천에만 칠한다.

## 글꼴

제목·제목패·지명은 도스명조 서브셋(OpenSamguk Myungjo), 큰 표제는 도스이야기 굵은체 서브셋(OpenSamguk Iyagi)이다. 비트맵 글꼴이라 16·32·48px에서만 쓴다. 연월·남은 시간 같은 큰 숫자는 DotGothic16, 본문과 표는 Pretendard다.

## 부품

첩은 2px 먹 테두리 안쪽에 금니 실선 한 줄, 그림자는 흐리지 않고 4px 계단으로 떨어뜨린다. 버튼은 먹 테두리와 2px 계단 그림자, 주요 버튼은 주칠이다. 못 쓰는 버튼은 숨기지 않고 점선으로 두며 이유를 보인다. 모서리는 둥글리지 않는다.

## 그림

| 종류 | 파일 | 만드는 법 |
| --- | --- | --- |
| 바탕 지도 | `apps/web/src/main/pixel-basemap.png` | Natural Earth를 16색 도트로 (`tools/map-data/build-pixel-basemap.py`) |
| 아이콘 16종 | `apps/web/src/art/icons/` | Codex image_gen, 32px·16색 이하 (`tools/pixel-assets/build.py`) |
| 지도 표식 | `apps/web/src/art/map/` | 위에서 본 도시·관문(남북·동서)·항구·전장 |
| 군기 | `apps/web/src/art/flag/` | 깃대·테두리와 흰 천 마스크를 나눠 천에 국가색을 칠한다 |
| 대표 그림 | `apps/web/src/art/keyart.png` | 480×270, 48색 |

## 지도 표식의 크기

표식은 위에서 내려다본 그림이고 규모마다 지도 위 크기가 다르다. 크기는 1000×700 지도 단위로 경 20, 특 16, 대 14, 중 12, 소 10, 수·진·관·이 8, 무 6이다. 확대하면 같은 비율로 커져서 가장 크게 볼 때 경이 화면을 채운다. 화면에서 16px보다 작으면 그림 대신 국가색 네모로 줄이고 48px까지는 32px 그림, 그보다 크면 128px 그림(`*@128.png`)을 쓴다. 관문은 지나는 도로 방향에 따라 남북판(`pass`)과 동서판(`pass-ew`)을 고른다.

생성 그림은 글 프롬프트만 쓰고 참조 그림을 넣지 않는다. 프롬프트에 게임·회사·작가 이름을 넣지 않는다. 원본 해시와 프롬프트는 `apps/web/src/art/sources.json`에 둔다.

## 하지 않는 것

와룡전과 그 리메이크의 그림을 입력·참조·따라 그리기에 쓰지 않는다 (D-028). 실존 장수 얼굴을 생성하지 않는다.
