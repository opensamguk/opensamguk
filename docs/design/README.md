# 기능 설계 문서

> 상태: 초안 (틀) · 차별화 기능이나 큰 기능을 만들기 전에 이 틀로 문서 하나를 씁니다.

## 언제 쓰나

- [차별화 기능](../product/differentiation.md)을 착수하기 전
- 명령·규칙을 3개 이상 새로 만들거나 바꾸기 전
- 화면 하나를 새로 설계하기 전 (레퍼런스 이미지도 여기에)

작은 버그 수정이나 AC 하나로 끝나는 작업에는 쓰지 않습니다.

## 틀

파일 이름: `docs/design/<기능-이름>.md`. 만든 뒤 [문서 지도](../index.md)에 올립니다.

```markdown
# 기능 이름

> 상태: 설계 중 · 차별화 ID: D? · 배정 관문: M? · 결정 기록: D-0xx

## 푸는 문제
누가, 언제, 무엇이 불편한가. 근거 한 줄.

## 플레이 장면
플레이어가 실제로 하는 일을 3~5단계로.

## 규칙
무엇이 계산되고 저장되나. 핵심 규칙에 닿는 지점.

## 하지 않는 것
이번에 일부러 빼는 것.

## 데이터
새 테이블·필드.

## 인수조건
AC-M?-?? 형식으로. 각 AC에 검증 방법.

## 위험
```
