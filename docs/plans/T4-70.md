## 계획 (Claude)

### 목표

AC-M1-14의 이 명령 몫이다. 원작 `nation:che_부대탈퇴지시`에 대응하는 확장 국가 명령 `nation_troop_expel`이 켠 월드에서 국가 예턴으로 실행되어 같은 국가 장수 한 명을 그가 속한 부대에서 뺀다. 본인·부대장·부대원 아님은 실패한다. 성공 1건과 대표 실패 1건 단위 시험이 있다. HTTP 저장·사전 검사·실행·표시는 T4-50·T4-51 뒤 같은 ID 아래에서 받는다.

### 범위

| 파일 | 내용 |
| ---- | ---- |
| `packages/rules/src/commands/ext/nation_troop_expel/nation_troop_expel.ts` (새 파일) | `defineCommand({...})` 한 번 |
| `ext/nation_troop_expel/nation_troop_expel.test.ts` (새 파일) | §5 단위 시험 |
| `ext/registry.ts`, `ext/state.ts` | 등록 한 줄과 `{ commandKey: 'nation_troop_expel', target: 'nation', sliceKeys: [<T4-19 부대 조각 key>] }` 한 줄. 명세 §7의 ID 오름차순 자리 |

### 하지 않는 것

- 부대 상태, 부대 만들기·가입·탈퇴의 즉시 행동, 집합. T4-19(규칙)와 T4-20(저장·즉시 행동, C15)이 맡는다. 이 명령은 T4-19가 내는 순수 함수로 한 장수를 빼기만 한다.
- 국가 명령의 직책별 실행 권한 표. T2-05의 `personnel/permissions.ts`가 맡는다([T2-05 계획](./T2-05.md) 직책과 권한 결정 절).
- 화면(T4-51이 대상 장수 선택 행을 만든다), NPC 판단(C11).

### 3. 기술 계약 초안 (Codex 계획 기술 검토 전)

#### 3.1 정의

| key | name | category | target | args |
| --- | ---- | -------- | ------ | ---- |
| `nation_troop_expel` | 부대 탈퇴 지시 | `nation` | `nation` | `z.strictObject({ generalId: positive })` |

인자 이름은 우리 `invite`의 `generalId`에 맞춘다(`commands/personnel.ts:106`). 확장 상태 조각을 바꾸므로 `defineCommand`로 `{ kind: 'world' }` 효과를 낸다. `cloneWorld`는 T4-02 계약으로 `ext`를 보존한다([T4-02 2.4](./T4-02.md#24-ext-순수-경로)).

#### 3.2 T4-19에 요구하는 것

T4-19 상세 계획이 아래 셋을 내면 이 명령이 그것만 쓴다. 이름은 T4-19가 정한다.

| 필요 | 모양 (제안) |
| ---- | ----------- |
| 부대 조각 key | 예 `troop`. 이 명령의 `sliceKeys`에 그대로 넣는다 |
| 소속 읽기 | `troopOf(view, generalId): { leaderId: number } \| null`. 부대장이면 `leaderId === generalId` |
| 한 명 빼기 | `removeFromTroop(state, generalId): void`. 부대장은 받지 않는다(예외). T4-20의 즉시 탈퇴와 같은 함수를 쓴다 |

원작처럼 부대장 id를 부대 번호로 쓰는지, 부대원이 0명이 된 부대를 남기는지는 T4-19의 결정이다. 이 명령은 그 결정을 따른다.

#### 3.3 검사 순서와 실패

| 순서 | 조건 | code | 이유 |
| ---- | ---- | ---- | ---- |
| 1 | 장수 없음 | `NO_ACTOR` | 장수가 없습니다. (`defineCommand`) |
| 2 | 인자 형식 | `BAD_ARGS` | 명령 인자가 잘못되었습니다. (`defineCommand`) |
| 3 | 실행 직책 아님 | `NOT_RULER` | 지금은 `ruler`(`support.ts:20-26`)가 낸다. T2-05 병합 뒤에는 그 권한 표의 code와 문구를 따른다 |
| 4 | 대상 장수가 없거나 다른 국가 | `BAD_TARGET` | 같은 국가 장수를 골라야 합니다. |
| 5 | 대상이 본인 | `BAD_TARGET` | 자신에게는 지시할 수 없습니다. |
| 6 | 대상이 부대원이 아님 | `BAD_STATE` | 부대에 속한 장수가 아닙니다. |
| 7 | 대상이 부대장 | `BAD_STATE` | 부대장은 부대에서 뺄 수 없습니다. |

원작은 5~7을 실행 단계에서 기록으로 처리한다. 우리는 검사로 옮긴다. 상태만 읽는 판단이라 예약 화면의 사전 검사가 이유를 미리 보일 수 있다(쟁점 R2).

#### 3.4 실행

- `removeFromTroop(state, 대상)` 한 번. 다른 값은 바꾸지 않는다. RNG는 쓰지 않는다.
- `logs`: `{대상 장수} 부대 탈퇴 지시`.
- `reports`: `[{ generalId: 대상, text: '{행위자}의 지시로 부대에서 나왔습니다.' }]`.

부대 탈퇴는 원작에서 다른 상태(부대장 도시 이동, 집합 예약)를 건드리지 않는다. 대상 장수의 30칸 예턴에 집합류 예약이 남아 있어도 이 명령은 지우지 않는다.

### 4. 엔진과 즉시 행동의 경계

부대 가입·탈퇴는 C4·C15에 따라 즉시 행동 `InputEvent`로 처리한다(T4-20). 이 명령은 즉시 행동이 아니라 국가 예턴이다. 엔진이 국가 턴을 실행할 때 같은 트랜잭션에서 `ext` 부대 조각을 바꾸고(C5, T4-03의 `ext` 저장) 재생은 같은 예턴 입력으로 같은 결과를 낸다. 같은 tick에 대상 장수의 즉시 탈퇴 입력과 이 명령이 겹치는 순서는 T4-20의 입력 처리 순서(C15)가 정한다. 그 순서에서 먼저 처리된 쪽 뒤에 이 명령의 6번 검사가 다시 돌아 `BAD_STATE`가 된다.

### 5. 검증

| ID | 내용 | 명령 |
| -- | ---- | ---- |
| V1 | 같은 국가 부대원 하나를 빼고 부대장과 다른 부대원은 그대로다 | `pnpm exec vitest run packages/rules/src/commands/ext/nation_troop_expel/nation_troop_expel.test.ts --maxWorkers=2` |
| V2 | 같은 입력 두 번이 같고 `view`가 바뀌지 않는다. RNG 소비 0회 | 같음 |
| V3 | `cloneWorld`를 지난 결과에 부대 조각이 남는다 | 같음 |
| X1 | §3.3 실패마다 code와 문구 | 같음 |
| X2 | 군주가 아닌 장수의 국가 명령은 지금 `NOT_RULER`. T2-05 병합 뒤 권한 표 사례로 바꾼다 | 같음 |
| X3 | `{}`, `{ generalId: 0 }`은 `BAD_ARGS`. 장수 명령 대상으로 부르면 `BAD_ARGS` | 같음 |
| X4 | 꺼진 resolver에서 `COMMAND_DISABLED`. 부대 조각이 없는 끈 월드에는 `ext`가 없다 | `createCommandResolverWithCommands` 주입 |

연결 뒤 단계는 T4-50(`nationTurns` 저장·사전 검사·실행), T4-20(부대 저장), T4-51(화면) 뒤 같은 ID로 받는다. 권한 단계에는 `nationTurns`의 무인증·다른 사용자·제재·잘못된 입력 사례와 함께 직책 없는 장수, 다른 국가 장수 대상 사례를 넣는다.

### 6. 상대 영역에 필요한 것

- T4-19(Codex): §3.2의 조각 key와 두 함수. 부대장이 다른 국가 장수를 부대에 둘 수 없다는 불변식.
- T4-20(Codex): 즉시 탈퇴와 같은 `removeFromTroop`을 쓰고 C15의 처리 순서에 이 국가 명령과의 겹침 사례를 시험으로 둔다.
- T2-05(Codex): 권한 표에 `nation_troop_expel` 행. 원작 기준으로는 군주·참모·수뇌 모두 실행한다. 확장 명령 행을 그 표가 받을지, 확장 정의 쪽에 둘지는 T2-05·T4-50과 맞출 쟁점 R1이다.
- T4-50(Codex): `nationTurns` 검사 연결이 이 key를 켠 월드에서만 받는지.
- T4-51(Claude): 같은 국가 장수 가운데 부대원만 고르는 입력 행. 목록 범위는 T4-20의 부대 조회 API를 쓴다. 국가 도움말(`docs/user/nation-and-features.md`)에 한 줄.
