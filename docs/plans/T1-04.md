# T1-04 월드 설정과 일시정지 명령줄

> 대기열: T1-04 · AC: AC-M1-04 · 구현: Codex · 리뷰: Claude
> 선행: T1-03 · 관련: [게임 시계](../architecture/game-clock.md), [런타임](../architecture/runtime.md) §5

## 계획 (Claude)

### 목표

월드를 만들 때 턴 간격(분)과 시드를 정하고, 명령줄로 일시정지·재개할 수 있다.
일시정지 동안 게임 시간이 흐르지 않는다 (AC-M1-04).

### 범위

- `World.status`(PREOPEN·RUNNING·PAUSED·ENDED), `turnTermMinutes`, `seed`, `clockTick`, `clockAnchorAt` 필드 (T1-03에서 없으면 추가)
- `packages/rules/src/clock/`: 시간 계산 순수 함수
- `apps/engine/src/cli/`: `world:start`, `world:pause`, `world:resume`, `world:status`

### 하지 않는 것

턴 실행(T1-06). 이 작업은 "지금 게임 시각이 몇 tick인가"를 정확히 계산하는 것까지다.

### 결정: tick 단위

- **1개월 = 10,000 tick.** `TICKS_PER_MONTH = 10_000`을 `packages/rules/src/clock/constants.ts`에 둔다.
- 게임 연월 = `startYear`, 1월부터 `floor(clockTick / 10_000)`개월 지난 날.
- 현실 1 tick = `turnTermMinutes × 60_000 / 10_000` ms.
- core2026은 1턴 = 36,000,000 tick이지만, 우리는 장수 턴 위치를 1만 칸으로 나누는 것으로 충분하다.
- 데이터 모델 문서의 "정할 것"을 이 결정으로 고친다.

### 시계 계산 (순수 함수)

```text
RUNNING:  nowTick = clockTick + floor((now - clockAnchorAt) / msPerTick)
PAUSED:   nowTick = clockTick        (흐르지 않음)
pause:    clockTick ← nowTick(now), clockAnchorAt ← now, status ← PAUSED
resume:   clockAnchorAt ← now, status ← RUNNING   (clockTick 그대로)
```

- 현재 시각 `now`는 인자로 받는다 (rules는 `Date.now()` 금지).
- 벽시계가 뒤로 가도 `nowTick`은 줄지 않는다 (`max(clockTick, …)`).
- 상태 전환은 PREOPEN → RUNNING → PAUSED ⇄ RUNNING → ENDED만 허용한다. 그 밖은 오류.

### 접근

1. `clock` 순수 함수: `nowTick(world, now)`, `pause(world, now)`, `resume(world, now)`, `toGameDate(startYear, tick)`.
2. 엔진 명령줄 4개. 상태 전환은 DB 트랜잭션 하나에서 `status`를 확인하고 바꾼다 (동시에 두 번 눌러도 한 번만 적용).
3. [런타임](../architecture/runtime.md) §5와 [게임 시계](../architecture/game-clock.md) §4·§5를 이 결정으로 채운다.

### 검증

| 무엇 | 어떻게 |
| ---- | ------ |
| 시계 | 단위: 턴 간격 10분, 25분 경과 → 25,000 tick, 게임 연월 2개월 뒤 |
| 일시정지 | 단위: 10분 흐른 뒤 pause, 1시간 뒤 nowTick 그대로, resume 뒤 5분 → +5,000 |
| 역행 | 단위: now가 앞선 값보다 작아도 nowTick 감소 없음 |
| 상태 전환 | 단위: ENDED → RUNNING 거부, PAUSED에서 pause 거부 |
| 명령줄 | 통합: create → start → pause → status 출력의 tick 고정 → resume |
