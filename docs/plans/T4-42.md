## 계획 (Claude)

### 1. 목표

AC-P2-20 제안 문장(U-13 1차 범위에 맞춤): 인물 관계망 기능을 켠 월드에서 사료로 확인한 주요 인물 사이의 혈연·결의·군신 관계가 장수 정보에 보인다. 관계는 등용 성공률과 배신 확률에만 영향을 준다. 전투 사기, 내정, 전투 계산은 바뀌지 않는다. 같은 시드와 같은 입력이면 등용 결과가 같다. 기능을 끈 월드의 상태 해시, 12개월 재생 해시, 등용 동작은 지금과 같다.

U-13의 사용자 결정은 아래 셋이다.

- 관계 종류는 혈연·결의·군신 3종이다. 원수·향당은 뺀다.
- 자료는 사료로 확인한 주요 인물만 손으로 쓴 목록이다.
- 효과는 등용 성공률과 배신 확률만이다. 전투 사기는 뺀다.

#### 4.3 군신

군신은 군주가 특별히 믿은 신하 관계다. 단순한 소속은 군신으로 세지 않는다.

순욱(「吾之子房也」, 三國志 卷10)과 장소(「升堂拜母，如比肩之舊」, 三國志 卷52)는 正史 구절이 있지만 1030 장수 목록에 없어 넣지 않았다. 조홍, 유표도 목록에 없다.

1030에서 이 목록이 걸리는 장면은 이렇다. 조운은 공손찬 소속이고 유비와 군신(K2)이다. 제갈량·제갈근·손권·조비·관평은 시작 때 재야다. 그래서 등용 성공률(재야 대상)과 배신 확률(타국 장수 대상) 두 효과가 첫해부터 실제로 쓰인다.

목록 추가는 같은 절차(색인 원문, 사서·권·구절, 1030 id 대조)를 거친 행만 계획 개정으로 한다. 구현 중에 행을 더하지 않는다.

`buildFeatureData(initial)`은 `initial.scenarioKey`의 표를 골라 행마다 두 장수가 `initial.generals`에 있고 이름이 같은지 본다. 하나라도 다르면 예외로 월드 생성을 막는다. 결과는 `{ pairs: [[a, b, kind, ref], ...] }`다. 행마다 `a < b`이고 목록은 오름차순이며 중복이 없다. 표가 없는 시나리오는 빈 배열이고 `checkOrigin`은 빈 배열을 거부하지 않는다. 기능은 켜졌지만 효과가 없는 월드가 된다.

조각 `relations`의 값은 `featureData.relations`와 같다. 월드가 진행돼도 바뀌지 않는다. 새로 만든 사람 장수는 표에 없으므로 관계가 생기지 않는다. 이름이 같은 사람 장수가 관계를 얻는 일도 id로 막는다.

### 6. 열린 사용자 결정

지금 코드에는 등용 성공률도 배신도 없다(§3). U-13은 효과를 이 둘로 정했으므로 효과가 걸릴 자리부터 정해야 한다. 아래 권장안은 원작 등용의 대상 규칙을 빌려 오고 새 판정을 한 군데(등용 실행)에만 두는 안이다. 사용자가 정하기 전에는 (나)의 `invite` 분기를 계약 준비로 올리지 않는다. (가)의 자료·조회 함수와 (다)의 표시는 결정 없이 진행할 수 있다.

| ID | 결정할 것 | 선택지 | 권장 |
| -- | --------- | ------ | ---- |
| RQ42-1 | 등용 성공률이 걸릴 자리 | (가) 관계 기능을 켠 월드에서 재야 NPC를 대상으로 한 등용은 실행 때 바로 판정한다. 성공하면 그 자리에서 임관하고 실패하면 장수 로그에 남는다. 사람 장수 대상은 지금처럼 제안과 수락이다. (나) 지금 제안 방식을 두고 NPC 재야의 임관 선택(`npc/index.ts:94`) 점수에 관계를 더한다. NPC 판단 변경이라 C11·U-18에 닿는다. (다) 둘 다 | (가). NPC 대상 등용이 지금 결과가 없으므로(§3) 판정 자리가 생긴다. 사람의 선택은 건드리지 않는다 |
| RQ42-2 | 배신 확률이 걸릴 자리 | (가) 관계 기능을 켠 월드에서 다른 국가의 NPC 장수(군주 제외)도 등용 대상으로 받는다. 그 판정 확률을 배신 확률로 쓴다. 원작 `che_등용`의 대상 규칙이다. (나) 월간 정산에 NPC 장수 이탈 판정을 새로 둔다. (다) 배신 효과를 2차로 미룬다 | (가). 판정 자리가 등용 하나로 모이고 같은 시드·입력이면 결과가 같다. 월간 이탈은 관계가 없는 장수에게도 새 규칙을 만든다 |
| RQ42-3 | 수치 | 기본 등용 확률 p0, 기본 배신 확률 q0, 종류별 보정(혈연·결의·군신), 상한 pmax·qmax. 식 틀은 `p = clamp(p0 + 보정(대상, 등용 국가), 0, pmax)`, `q = clamp(q0 + 보정(대상, 등용 국가) − 보정(대상, 지금 국가), 0, qmax)` | 수치는 정하지 않는다. 원작에 근거 수치가 없어 U-19 환산이 아니라 새 값이다 |
| RQ42-4 | 보정을 세는 상대 | (가) 국가의 군주와의 관계만 (나) 국가 장수 누구와든 관계가 있으면 (다) (나)에 사람 장수 제외 | (가). 군신 관계의 뜻과 맞고 계산이 단순하다 |
| RQ42-5 | 결의 기준 | J1·J2·J4는 正史 구절로 넣는다. J3(관우·장비 사이, 演義 근거)과 J5(동탁·여포 의부자)를 넣을지 | J3은 넣지 않고 J5는 넣는다. J3은 正史가 유비를 가운데 둔 구절이다. J5는 正史에 맹세가 적혀 있다 |
| RQ42-6 | 화면에 확률을 보일지 | (가) 종류만 (나) 등용 인자 화면에 예상 확률 | (가). 1차 범위를 작게 둔다 |

판정 방식의 공통 규칙은 결정과 관계없이 이렇게 둔다. 판정은 `rng.next() < 확률` 한 번이며 NPC 대상이고 기능을 켠 월드일 때만 소비한다. 끈 월드와 사람 대상은 RNG를 쓰지 않는다. 확률 0이어도 한 번 쓴다(T4-05 §4.5와 같은 단순화).

RQ42-2 (가)를 고르면 원작 대상 규칙을 옮기므로 `personnel.ts` 분기 머리에 `core2026 df6c926 packages/logic/src/actions/turn/general/che_등용.ts의 대상 규칙(다른 국가 장수, 군주 제외)을 옮겼다. MIT (c) 2025 devsam. resources/NOTICE.md.`를 적고 `resources/NOTICE.md` 출처 목록에 한 줄을 더한다. 원작 비용식과 서신은 옮기지 않는다.
