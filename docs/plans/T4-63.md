### 4.4 계산과 효과

- `delta = S1 (나) ? BALANCE.TRAIN_GAIN : 30`
- `score = Math.round(leadership × 100 × delta × 2 / (crew × 3))`. 부상은 쓰지 않는다(K6).

| 순서 | 효과 |
| ---- | ---- |
| 1 | 훈련 `min(100, train + score)` |
| 2 | 사기 `min(100, atmos + score)` |
| 3 | 경험 `+150`, 공헌 `+100` |
| 4 | MQ-1 (가)·(나)면 `addProficiency(state, actor, armType, score × 2)`. 계열이 없으면 건너뛴다 |

RNG는 쓰지 않는다. 손 계산(S1 (나)): 통솔 80·병력 8,000이면 7, 통솔 80·병력 2,000이면 27, 통솔 50·병력 100이면 333이고 상한으로 100이 된다.
