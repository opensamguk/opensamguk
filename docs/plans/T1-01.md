### GitHub #26, #27 후속 수정 (2026-10-21)

CI 기반시설 리뷰(PR #7)의 비차단 P3 권고 두 건을 고쳤다. 기존 T1-01 완료와 AC-M1-01 증거는 그대로 둔다.

- `playwright.config.ts`: `const isCI = Boolean(process.env.CI)` 하나로 `forbidOnly: isCI`, `webServer.reuseExistingServer: !isCI`를 정한다.
  CI에서는 test.only가 있으면 실패하고 이미 떠 있는 서버 대신 그 checkout의 서버를 띄운다. 로컬은 예전처럼 test.only를 허용하고 dev 서버를 재사용한다.
  testDir, project, baseURL, dev 명령, 포트, timeout, worker 정책은 바꾸지 않았다.
- 회귀 시험 `tools/playwright-ci.test.ts`(`pnpm check`의 단위 시험에 들어간다): `tools/playwright-ci/fixture.config.ts`가 루트 설정을 import해
  두 옵션을 그대로 쓰고 시험 폴더와 서버 명령·주소만 바꾼다. 실제 Playwright CLI를 자식 프로세스로 돌리며 서버는 시험이 직접 띄운 127.0.0.1 임의 포트만 쓴다.
  확인하는 경우는 다섯 가지다. CI에서 test.only 거부(exit 0 아님), 로컬에서 test.only 하나만 실행, CI에서 빈 포트면 자기 서버로 통과한 뒤 포트 정리,
  CI에서 이미 떠 있는 서버를 재사용하지 않고 실패, 로컬에서 이미 떠 있는 서버 재사용.
- 검증 (GitHub 표준 runner, 로컬은 자원 대기로 exit 75라 실행하지 않음): 첫 구현 커밋 `332dba3`의 실행 39530174942(push)·39530202980(pull_request)에서
  두 필수 검사가 통과했다. frozen 설치, `pnpm check` 단위 127개(main `0507791` 실행 39528721877의 122개에 새 시험 5개), 실제 PostgreSQL 통합 43개,
  Chromium E2E 26개(main과 같은 수, skip 0), 웹 빌드.
- 대조군: 같은 시험에 설정만 `0507791`로 되돌린 `b881a9b`(브랜치 `ctl/t_7d43ea8c-old-config`, 병합하지 않음)의 실행 39530186161에서
  opensamguk-check가 실패했다. 실패한 시험은 CI test.only 거부와 CI 기존 서버 재사용 거부 두 개다. 둘 다 `1 passed`로 일부 실행·기존 서버 재사용이 일어났다.
  나머지 세 시험과 database-browser는 통과했다.
