### 리뷰 (Claude, 2026-10-21)

검토한 head는 `e128d70f2a03c2772da427bd9e00c4223c32b079`이고 판정은 수정 요청이다.
워크플로 pin은 아래 확인을 모두 통과했다. 고칠 것은 이 절의 문장 하나다.

base `97aadc9` 대비 바뀐 파일은 `.github/workflows/ci.yml`과 이 문서뿐이다. 워크플로에서는 Node 두 곳,
PostgreSQL image, 주석 두 줄만 바뀌었다. ubuntu-24.04, action SHA 3개, pnpm 10.33.0, source SHA 검사,
`contents: read`, 두 job 이름, 127.0.0.1의 전용 DB 두 개, 시험 명령은 그대로다. PyYAML로 읽으면 두 job의
`node-version`이 모두 문자열 `24.22.0`이다. prettier 3.9.9 검사와 `git diff --check`도 통과했다.

기준 CI39530034962의 raw 로그를 직접 받아 check job은 Node 24.21.0, database-browser job은 24.22.0을 썼음을 확인했다.
같은 로그에서 `postgres:18-alpine`을 받은 digest가 `sha256:77f585114c32fbca283dc835b0596f4e52b51b4c6662d7810b2f4084f60a1873`이고
서버는 PostgreSQL 18.6이었다. 새로 고정한 digest는 기준 CI가 실제로 쓴 이미지와 같다.

공식 출처도 따로 조회했다. nodejs.org `index.json`에서 v24.22.0(2026-10-14, LTS Krypton)은 v24의 최신 patch다.
SHASUMS256의 `node-v24.22.0-linux-x64.tar.xz` 값은 구현 기록과 같다. Docker Hub registry에서 `18.6-alpine` tag,
digest URL, `18-alpine` tag의 `docker-content-digest`가 모두 위 digest였다. tag와 digest 응답 본문은 바이트 단위로 같고
본문 SHA-256도 digest와 일치한다. mediaType은 OCI image index이며 16개 항목 가운데 linux/amd64는
`sha256:d8703cd7fba306b9fec9268ecedfa8a966846c053036a60e3635791957eb2f66`(`18.6-alpine3.24`)다.
setup-node는 nodejs.org tar.xz가 아니라 `actions/node-versions` 빌드를 받는다. 기록한 SHA-256은 공식 배포가 있다는 근거이고
CI가 대조하는 값은 아니다.

exact head의 PR 실행 [39531552314](https://github.com/peppone-choi/opensamguk/actions/runs/39531552314)와
push 실행 [39531545925](https://github.com/peppone-choi/opensamguk/actions/runs/39531545925)에서 check run 네 개(app 15368)가
모두 성공했고 skip된 step은 없다. 네 job의 raw 로그 모두 checkout과 source 검사가 `e128d70`을 가리키고 Node는 v24.22.0이다.
check job은 frozen 설치, Prettier, 단위 17파일 135개, 웹 build를 통과했다. database-browser job은 고정한 digest로 이미지를 받아
PostgreSQL 18.6을 띄웠고 통합 7파일 53개, migration 5개, Chromium E2E 26개를 통과했다. 구현 head `cc7fd80`의
실행 39531294274도 같은 수치였다. main 보호 규칙의 필수 검사 두 개는 strict로 걸려 있다.

고칠 것은 구현 기록의 `공식 출처에서 확인한 값은 아래와 같다.` 한 문장이다. [글쓰기 규칙](../writing-style.md) D-3(S1)의
도입구라 지우거나 표 내용을 가리키는 구체 문장으로 바꾼다. 워크플로는 다시 고치지 않는다.
PR35 head `e779752`와 이 head를 합치면 이 문서에서 충돌이 난다. 통합할 때 두 절과 기존 리뷰를 모두 남긴다.
AC-M1-01 상태와 대기열 단계는 바꾸지 않았다.
