## 계획 (Claude)

### 목표

Claude 담당 영역의 글을 [글쓰기 규칙](../writing-style.md)에 맞게 고친다.

### 범위

- 문서: `docs/product/`, `docs/plans/`, `docs/user/`, `docs/frontend-ui-guidelines.md`, `docs/writing-style.md`, `docs/index.md`, `README.md`, `AGENTS.md`
- 화면 문구: `apps/web/src` 전체 (버튼, 안내, 오류, 빈 상태, 툴팁)
- E2E가 화면 문구를 기대값으로 쓰므로 `e2e/`의 문자열도 같이 고친다.

### 하지 않는 것

뜻 바꾸기. 계획의 수치, 결정, 인수조건 문장의 조건은 그대로 둔다. 리뷰 기록은 쓴 사람의 기록이라 고치지 않는다(인용으로 본다).

### 결정

- 작업은 문서 단위로 나눠 커밋한다. 한 커밋이 한 문서 묶음.
- 고친 양이 원문의 30%를 넘는 문서는 다시 본다.
- 끝나면 `pnpm check`에 `pnpm lint:text --strict`를 넣는다 (T1-24도 끝난 뒤).

### 검증

| 무엇 | 어떻게 |
| ---- | ------ |
| S1 0건 | `pnpm lint:text --strict` (Claude 담당 경로) |
| 동작 그대로 | `pnpm check`, `pnpm e2e` 통과 |
| 뜻 보존 | 리뷰어가 문서별 diff에서 수치·조건이 바뀌지 않았는지 본다 |

### 채울 문서

구현하면서 함께 채운다. 리뷰어는 문서도 확인한다.

- 없음 (대상 문서 자체를 고친다)

## 리뷰 (Codex)

- 결과: T1-23 부분 통과 (2026-10-22). PR #128의 `72b52a57f8eca2b14ed7004dd5563af21d11eb0d`를 기준 main `5432ee83abb7e34ed26932c02856df0b104804b7`과 대조했다. T1-23만 완료로 바꾼다. AC-M1-22 전체 인수와 strict의 `pnpm check` 연결은 별도 작업이다. 병합은 `t_9c899d64`가 맡는다.
- 확인한 것:
  - 변경 60파일은 모두 담당 문서다. 실행 코드·E2E 문자열·API·설정·게임 동작은 바뀌지 않았다. 기존 리뷰 절은 예외 주석을 빼면 원문과 같다. 수치·조건·부정·추측·의무와 고유명사를 문서별 diff로 확인했다. 예외 주석 182곳은 상태 표기, 보존할 리뷰, 실제 인용·화면 문구·이름, 규칙 예시에 쓰였다.
  - 담당 124파일의 기준 446건을 독립 재집계했다. 같은 head에서 담당 경로 strict 0건, 전체 기본 경로 194파일 strict 0건이다. 예외 주석을 전부 뺀 탐침은 245건으로, 예외로 남긴 표현과 실제로 고친 표현을 구분했다. 주석을 뺀 탐침은 통과 결과가 아니다.
  - 57개 AC ID는 중복이 없다. 검증 방법·상태·증거 칸은 기준과 글자 단위로 같고 통과 행의 빈 증거는 0개다. 조건의 변경은 연결어미 뒤 쉼표 제거와 가정 표시 교체뿐이다. 재집계는 M1 22개 중 통과19·진행1·미착수2, M2 19개 중 통과1·진행0·미착수18, M3 16개 중 통과0·진행1·미착수15이며 README·요약과 같다. 기준 시각·SHA·정본 링크와 문서 집계라는 한계를 확인했다. 참가자 대체와 공개 승인은 시험·배포 통과로 올리지 않았다.
  - 변경률은 문자 단위 `SequenceMatcher(autojunk=False)`로 다시 쟀다. README 10.883%, 나머지 기존 문서는 5.343% 이하다. T1-23은 구현 기록을 채워 전체 48.240%라 다시 읽었으며 기존 계획 본문은 0%다. 50% 이상인 문서는 없다. 구현 기록의 9.34%와는 측정값이 달라 이 리뷰의 재측정값을 기준으로 남긴다.
  - exact-head push [39722222467](https://github.com/peppone-choi/opensamguk/actions/runs/39722222467)와 PR [39722227242](https://github.com/peppone-choi/opensamguk/actions/runs/39722227242)의 원본 로그를 읽었다. 두 실행 모두 source SHA 확인, `pnpm check` 단위 73파일444개, 실제 PostgreSQL 17파일328개, Chromium 60/60개와 웹 빌드가 통과했다. 건너뛴 시험은 없으며 권한 대조는 절차23·실행97·면제18·누락0이다. 필수 두 context의 네 job이 모두 성공했고 main 보호는 strict다. 로컬에서는 frozen 설치, 담당·전체 strict와 문서 포맷·`git diff --check`를 실행했다. 무거운 검증은 위 GitHub 실행 결과이며 로컬 DB나 브라우저 시험을 했다는 뜻은 아니다.
