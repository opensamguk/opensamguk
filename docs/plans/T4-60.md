### 2.3 조각 `generalProficiency`

`packages/rules/src/commands/ext/proficiency/state.ts`(새 파일)가 낸다. 처음 쓰는 쪽은 T4-60 PR 0으로 고정한다(2.5). 조각 파일, 아래 네 함수, `extSlices` 등록은 그 PR만 만들고 다른 행은 import만 한다. 이 조각을 쓰는 T4-61~T4-63, T4-65, T4-66(S7 (나)일 때)은 MQ-1이 (가)나 (나)일 때 T4-60 PR 0의 병합을 구현 선행에 둔다. 단련 명령(PR 1)의 병합은 기다리지 않는다([T4-57](./T4-57.md) 2.2).

```ts
// 값: { [generalId]: { [armType]: 정수 숙련도 } }
export const generalProficiencySlice: ExtSlice<Record<string, Record<string, number>>>;
export function armTypeOf(unitSet: DeepReadonly<UnitSetResource> | undefined, crewType: number): number | null;
export function proficiencyOf(view: WorldView, generalId: number, armType: number): number; // 없으면 0
export function addProficiency(state: WorldState, generalId: number, armType: number, delta: number): number; // 더한 뒤 값
export function setProficiency(state: WorldState, generalId: number, armType: number, value: number): void;
```

- `create`는 `{}`다. 시나리오 장수와 나중에 만든 장수 모두 칸이 없으면 0이다.
- `validate`는 두 겹 객체이고 바깥 key가 양의 정수 문자열, 안쪽 key가 양의 정수 문자열, 값이 0 이상 안전 정수인지 본다.
- 값은 정수다. `addProficiency`는 `Math.round(delta)`를 더하고 결과가 0 미만이면 0으로 둔다. 원작은 소수를 남길 수 있지만(전투태세 `병력 / 100 × 3`) 해시와 DB 왕복을 단순하게 하려고 정수로 둔다. 상한은 원작처럼 없다.
- 0이 된 칸은 지우지 않는다. 칸이 생긴 뒤에는 0도 값이다. 골든은 이 규칙으로 고정한다.
- `armTypeOf`는 `crewTypes`에서 `id === crewType`인 병종의 `armType`을 찾고 그 계열이 `armTypes`의 key에 있을 때만 낸다. 성벽 병종(계열 0)이나 자료에 없는 병종은 `null`이다.
- 숙련도를 바꾸는 명령은 `sliceKeys`에 `generalProficiency`를 넣는다. 숙련도 부수 효과만 있는 명령(T4-62, T4-63, T4-65, T4-66)은 MQ-1 (가)·(나)일 때만 넣는다.
- 숙련도를 화면에 보이는 조회는 2.4 쟁점이다.

### 2.4 조회 쟁점

숙련도는 확장 상태 안에 있어 지금 장수 조회 응답에 없다. 보이려면 서버 조회에 칸을 더해야 한다. 자기 장수에만 보일지, 다른 국가 장수에도 공개할지는 공개 범위 결정이다(`apps/server/src/visibility.ts`, 명세 C9). 이 계획은 정하지 않고 Q60-1로 둔다. 규칙 PR은 조회 없이 병합할 수 있고 ui 단계 증거는 그 조회가 생긴 뒤 받는다.

### 4.4 RNG와 계산

1. `pickWeighted(rng, [['success', 0.34], ['normal', 0.33], ['fail', 0.33]])`. `rng.next()` 한 번.
2. `mult = { success: 3, normal: 2, fail: 1 }[결과]`
3. `base = Math.round(crew × train × atmos / 20 / 10000)`, `score = base × mult`
4. `exp = Math.round(crew / 400)`

RNG 소비는 한 번이다. 손 계산 예: 병력 1,000·훈련 100·사기 100이면 `base = 50`이고 숙련도 증가는 150, 100, 50, 경험은 3(2.5의 반올림)이다.

### 4.5 효과

2. 금 `max(0, gold − 비용)`, 쌀 `max(0, rice − 비용)`. 비용은 S1 값(권장 20)이다
3. 경험 `+ exp`
