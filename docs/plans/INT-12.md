## 계획

목표는 전체 53도시 지도와 정식 191년·21국·491장수 판을 실제 화면·서버·PostgreSQL로 한 기수 끝까지 진행한다. 두 월드·재시작·중복·백업 복원·재생·전체 검사와 반대쪽 리뷰를 마친다. 공개 배포 완료로 부르지 않는다.

수정 범위는 e2e/, tools/, apps/engine/src/, docs/product/acceptance-criteria.md다. 새 기능을 더하지 않는다. 기존 main·v1 기준 SHA와 자원 출처는 통합 기준 문서를 따른다. 세부 코드 경계·API 인증·엔진 단독 상태 변경·시드 RNG·턴 트랜잭션을 지킨다.

검증은 pnpm check, pnpm test:int, pnpm e2e, 고정 시드/두 월드/복원과 archive 재생의 매월·종료 해시. skip·mock만·합성 소형 월드만으로 통과하지 않는다.

선행 인수 뒤 착수하고 검증 결과와 구현하지 않은 담당의 리뷰를 같은 문서에 남긴다. 구현자가 스스로 완료로 바꾸지 않는다.

## 구현 기록

2026-10-27 정식 판 생성·사람의 전체 조작, 장애·중복·두 월드 격리, 백업 복원·재생·최종 인수의 세 묶음으로 나눠 착수한다. 각각1~2일이며 AC-INT-12에 연결한다. 기존 개발 월드는 보존하고 정식191년21국·491명과 동결 기능을 사용하는 전용 판을 새로 만들었다. 종료 연도는201년이며 아직 시작하지 않았다. CLI가 자원 프로필과 요청 기능을 합친 뒤 정렬하지 않아 생기는 생성 오류를 고쳤다. 관련8건과 실제 PostgreSQL 생성이 통과했고 수정본 독립 리뷰를 받았다. 판 생성만으로 한 기수 인수를 통과시키지 않는다.

## 별도 포트의 전체 브라우저 검사

2026-10-28 기존 개발 화면과 데이터를 보존하려고 새 검사 DB와5177·13007 포트를 준비했다. 전체194건 실행에서 로그인·로비의 같은 출처 단언 두 곳과 메인 준비 문맥이5173을 고정해 별도 포트를 따르지 않는 문제를 확인했다. 세 파일은 기존 `appOrigin()`으로 설정된 출처를 읽는다. 외부 `next` 거부·로비 이동 단언을 유지하고 출처의 scheme도 함께 대조한다. 검사 선택·시간 제한·제품 동작은 바꾸지 않는다. 이 수리는1일 이내의 AC-INT-12 검증 환경 몫이며 실제 별도 포트 실행·독립 리뷰·전체 회귀를 확인한 뒤 근거를 더한다.

첫 실행에서 직접 Playwright CLI를 호출할 때 `npm_execpath`를 전달하지 않은 환경 오류도 구분했다. 월드 생성 도구의 거부 검사를 유지하고 실행 환경과 사전 검사를 보완한다. 기존 실행 DB와 실패 기록을 보존하며 다음 전체 검사는 새 DB에서 시작한다. 이 기록은 전체 검사 통과나 정식 기수 완료 증거가 아니다.
