# INT-02 운영 지도 v3·불변 자원·월드 계약

> AC-INT-02 · 구현 Codex · 리뷰 Claude · 선행 INT-01, INT-14 · 견적 3일
> 사용자 지시로 동결한 [통합판 v0.1](./integration-release.md)과 [5능력치](../product/five-stats.md)를 따른다.

## 계획

목표는 도시 경제와 관문 상태, 항구 시설과 전장 표시를 분리한다. 안정 ID·자원 판·기존 cityKey 앵커를 정의하고 생성·저장·조회·해시·재생을 연결한다. 간선 중간 위치나 행군 상태는 만들지 않는다.

수정 범위는 packages/rules/src/world/, packages/db/prisma/, apps/engine/src/world/, apps/server/src/resourceAdmin/다. 새 기능을 더하지 않는다. 기존 main·v1 기준 SHA와 자원 출처는 통합 기준 문서를 따른다. 세부 코드 경계·API 인증·엔진 단독 상태 변경·시드 RNG·턴 트랜잭션을 지킨다.

검증은 잘못된 참조·중복·잘못된 판·권한 없는 게시 거부, 옛 월드/자원 해시 보존, 새 판 생성·로드·재시작·재생

선행 인수 뒤 착수하고 검증 결과와 구현하지 않은 담당의 리뷰를 같은 문서에 남긴다. 구현자가 스스로 완료로 바꾸지 않는다.

## 구현 기록

아직 착수하지 않았다.
