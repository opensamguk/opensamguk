# T2-08 조약서·교역 화면

> 대기열: T2-08 · AC: AC-M2-06, AC-M2-14 (화면) · 구현: Claude · 리뷰: Codex
> 선행: T2-07 (API)

## 계획 (Claude)

### 목표

조약을 조항 체크리스트로 쓰고 받은 제안에 답하며 맺은 조약과 각국의 신의 기록을 본다. 교역은 예턴 편집에서 고른다.

### 범위

`apps/web`: `/w/:id/diplomacy` (외교실: 조약 목록, 받은 제안, 조약서 쓰기, 국가별 신의), 예턴 편집의 교역 대상 선택.

### 화면

```text
조약서 쓰기 ─ 상대: [원소 ▾]
  ☑ 불가침   기간 [24]개월
  ☐ 통행 허용  도시 [선택…]
  ☑ 정기 원조  우리 → 원소  금 [500] 쌀 [0] / 월, [12]개월
  ☐ 교역 허용  기간 [ ]개월
  ☐ 도시 이양
  ☐ 기록만 남길 약속 [                    ]
  비용: 우리 금 1,200 · 상대 금 1,200        [제안 보내기]
```

- 조항을 고르면 비용과 "서버가 집행하는 것 / 기록만 남는 것"을 바로 보여 준다.
- 받은 제안 카드: 조항 요약, 상대의 신의 기록(파기 횟수), 기한, [수락] [거절]. 비용이 모자라면 수락만 `DisabledReason`이고 거절은 그대로 쓴다.
  버튼마다 `canAccept`·`canReject`·`canBreak`를 따로 보고 `code`로 분기한다. 사유 문자열을 비교하지 않는다.
- 조약 목록: 진행 중·끝남·파기됨 탭, 남은 기간, [파기] (확인 창: "신의 기록에 남습니다").
- 권한 없는 직책에게는 읽기만 (서버가 준 `canPropose`·`canAccept`·`canReject`의 `NO_PERMISSION`으로 판단).
- 제안·수락·거절·파기는 엔진이 처리한 뒤에 결과가 정해진다(T2-07 즉시 행동 처리). 단추를 누를 때 `requestId`(UUID)를 만들어 보내기 전에 이 탭의 sessionStorage에 둔다.
  키는 예턴 초안처럼 계정 ID와 월드 ID를 넣는다(`apps/web/src/turns/useTurnDraft.ts:33-37`). 응답을 잃거나 오류 없이 연결이 끊기면 같은 `requestId`로 다시 보낸다.
  `pending`을 받으면 그 카드에 "처리 중"을 두고 단추를 잠근 뒤 `treaty.request`를 1초마다 묻는다. 새로 고침이나 다시 로그인한 뒤에는 저장해 둔 `requestId`와 `treaty.list`의 `pending[].requestId`로 대기 상태를 되살린다.
  `applied`나 `rejected`를 받기 전에는 성공 문구를 띄우지 않는다. 거절되면 그 요청의 `reason`을 보여 준다. 끝난 요청의 `requestId`는 지운다.
  목록에서 제안이 사라진 것으로 결과를 추측하지 않는다. `UNAUTHORIZED`면 로그인 안내를 띄우고 `requestId`는 남겨 둔다. `treaty`가 null이면 결과 문구만 보이고 조약 내용은 그리지 않는다.
- 교역 대상 고르기는 따로 저장하는 편집기를 만들지 않는다. T1-15의 재사용 30칸 편집기 `TurnEditor`(`apps/web/src/turns/TurnEditor.tsx`, 메인 배치는 T1-16)와 초안 훅 `useTurnDraft`(`apps/web/src/turns/useTurnDraft.ts`)의 초안 하나에 교역 칸을 넣고 같은 저장 경로(`turns.set`)로 저장한다 (검토 R62-6).
  대상 고르기 칸을 열고 닫거나 지도에서 도시를 고르거나 외교실로 갔다 돌아와도 미저장 초안과 선택을 지우지 않는다. 저장 충돌은 `useTurnDraft`의 STALE 흐름(최신 30칸을 받고 내 편집을 보관한 채 다시 적용할지 묻기)을 그대로 쓴다.

### 검증

| 무엇 | 어떻게 |
| ---- | ------ |
| 제안·수락 | Playwright: 군주 A 제안 → 군주 B 수락 → 엔진 처리 전에는 처리 중, 처리 뒤 양쪽 목록에 진행 중 |
| 거절된 행동 | Playwright: 수락 접수 뒤 국고를 줄여 엔진이 거절 → 성공 문구 없이 이유 표시 |
| 재전송·재접속 | Playwright: 처리 중에 새로 고침 → 같은 카드가 처리 중으로 돌아오고 엔진 처리 뒤 결과 표시. 응답을 끊은 뒤 다시 누름 → 같은 `requestId`로 가서 입력 하나. 처리 중 로그아웃 뒤 다시 로그인 → 결과 회수 |
| 비용 안내 | Playwright: 국고 부족 → 수락만 잠기고 이유 표시, 거절은 누를 수 있음 |
| 파기 | Playwright: 파기 확인 → 신의 기록 +1이 제3국 화면에 보임 |
| 교역 | Playwright: 교역 조약 뒤 메인 30칸 편집기에서 교역 대상 선택 가능, 조약 없으면 사전 검사 경고 |
| 초안 보존 | Playwright: 메인에서 30칸 초안을 고치다 지도 도시 선택·외교실 이동·교역 대상 칸 취소 → 돌아와도 초안과 선택이 그대로. 저장 → 엔진 실행 뒤 결과 로그. 다른 탭에서 예턴을 고친 뒤 저장 → STALE 안내, 초안 유지 |
| 권한 | Playwright: 수뇌는 쓰기 버튼 없음 |

## 구현 기록 (Claude)

- 바꾼 것: `apps/web/src/diplomacy/`에 외교실(`/w/:worldId/diplomacy?tab=…`)을 만들었다. 탭은 받은 제안, 보낸 제안, 진행 중, 끝남(끝남·거절됨·기한 지남), 파기됨, 조약서 쓰기, 국가별 신의다.
  조약서는 조항 7개(종전, 불가침, 통행, 정기 원조, 교역 허용, 도시 이양, 기록만 남길 약속)를 체크리스트로 고르고 `treaty.quote`의 비용과 조항별 문제를 바로 보인다(`TreatyComposer.tsx`, 폼 계산은 `clauses.ts`).
  종전은 `relation`이 교전·선포일 때만 고른다. 카드(`TreatyCard.tsx`)는 집행 조항과 기록 조항을 나누고 수락 비용, 상대 신의, 기한, 남은 기간을 보인다.
  즉시 행동은 `requests.ts`(상태 전이)와 `useTreatyRequests.ts`(보내기·재전송·1초 조회)가 맡는다. 화면 메뉴에 외교를 더했다.
  교역 대상은 `TurnEditor`가 명령 목록에 `trade`가 있을 때 `treaty.tradeTargets`를 묻고 `CommandPicker`의 대상 도시 후보만 바꾼다(`tradeTargets.ts`, `cityChoicesFor`). 저장 경로는 그대로다.
  고른 칸을 탭에 남겨(`useStoredSelection`) 외교실에 갔다 와도 초안과 선택이 남는다.
- 임시 계약: treaty 라우터가 main에 없어 `apps/web/src/diplomacy/contract.ts` 한 파일에 T2-07 응답 모양과 호출(`trpcClient` 캐스트 한 곳)을 두었다. Codex API가 main에 들어오면 AppRouter 타입으로 바꾼다.
  미결정 U62-2a(비용 공식), U62-3(상대 사정 거절 이유), U62-5(형식 2 소유), U62-6(형식 1 월드)은 화면이 숫자와 서버 문장만 보여 주게 해서 응답 모양이 바뀌어도 화면 분기가 없다. 그 가정을 `contract.ts` 끝에 모았다.
- 계획과 달라진 점과 이유:
  - 교역 명령의 인자 모양이 계획에 없어 출병처럼 정수 `cityKey` 하나로 가정했다(`TRADE_COMMAND_KEY`). 편집기는 `argsSchema`의 `cityKey`를 대상 도시 칸으로 그리므로 서버가 다른 이름을 쓰면 후보 교체가 붙지 않는다.
  - 제안 기한은 입력 칸 없이 6개월(`PROPOSAL_EXPIRES_MONTHS`)로 보낸다. T2-07 조항 결정이 6개월로 고정했다.
  - 응답을 잃은 요청은 자동으로 다시 보내지 않고 [같은 요청 다시 보내기]를 둔다. 새로 고친 뒤 `treaty.request`가 `NOT_FOUND`면(서버가 받은 적 없음) 같은 단추를 보인다. 사용자가 떠난 뒤 행동이 저절로 나가지 않게 했다.
  - 엔진이 대기 5초 안에 거절해 변경 요청이 오류로 오면(서버 코드가 있는 오류) 그 문장을 거절 이유로 확정하고 `requestId`를 지운다. 응답이 없는 오류만 재전송 대상이다.
