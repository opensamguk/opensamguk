# INT-04 191년 시나리오 이전

## 계획

목표는 main 1030의 191년·21국·491장수 ID·소유·수도·초기 병력을 새 지도에 대응한다. v1의 1,000명·42부곡·228관계를 무조건 합치지 않는다. 대응 불명확한 위치는 자동 추정하지 않는다.

수정 범위는 resources/scenario/, apps/engine/src/world/, packages/rules/src/world/다. 새 기능을 더하지 않는다. 기존 main·v1 기준 SHA와 자원 출처는 통합 기준 문서를 따른다. 세부 코드 경계·API 인증·엔진 단독 상태 변경·시드 RNG·턴 트랜잭션을 지킨다.

검증은 전체 정식 데이터 생성·로드·첫 월 정산·재시작·초기 해시/자원 해시, 장수·국가·수도·병력 보존 대조

선행 인수 뒤 착수하고 검증 결과와 구현하지 않은 담당의 리뷰를 같은 문서에 남긴다. 구현자가 스스로 완료로 바꾸지 않는다.

## 구현 기록

2026-10-27 정식 자원·기존 거점 대응, DB 게시/월드 생성/출처 보존, 첫 월·재시작·재생/다른 월드 보존의 세 묶음으로 나눠 착수한다. 각각 하루 이내이며 AC-INT-04에 연결한다. 원본491명은 모두 위치가 null이므로 기존 bootstrap 시드 배치를 유지한다. 원본 장수·국가 ID와 소속·초기 병력·금/쌀은 바꾸지 않는다. 원본은 보존하고 새 시나리오에 검수한491명5값·출처와 초상표를 연결한다. 새 자원4종은 별도 이름1판으로 게시하며 기존 게시판을 갱신하지 않는다.

## 리뷰

구현하지 않은 담당이 정식491명·21국의 ID/출처 보존, 명시적 수도 대응, 불변 자원 게시, CLI와 실제 DB 검사를 독립 검토했다. 검사 실패 뒤에도 진행하던 비동기 월 정산을 다음 검사 전에 기다리도록 고쳤으며 수정본을 다시 검토했다. 각 월의 엔진 실행과 순수 재생은 별도 검사로 나눴고 기존 assertions와30초 제한을 유지한다.

순수 자료 대조2파일65건과 실제 PostgreSQL11건이 통과했다. 실제 검사는 게시의 멱등성·해시/상태 충돌 거부·기존 월드 보존, CLI 생성, 정식191년 첫 월과 DB 재접속 뒤 둘째 월, 각 월의 동일 시드 재생, 다른 월드 격리, 새 트랜잭션의 지도 원장 변조 거부를 포함한다. 전용 개발 DB에도 정식491명·21국·61거점 월드를 별도로 생성했으며 기존 월드는 보존했다. DB 재접속 검사는 프로세스 재시작 인수를 대신하지 않는다. 전체 검사·필수 CI·선행 변경과 이 변경의 병합 전이므로 AC는 미완료다.

## 병합 뒤 인수 근거
