# INT-04 191년 시나리오 이전

> AC-INT-04 · 구현 Codex · 리뷰 Claude · 선행 INT-02, INT-03, INT-16 · 견적 2일
> 사용자 지시로 동결한 [통합판 v0.1](./integration-release.md)과 [5능력치](../product/five-stats.md)를 따른다.

## 계획

목표는 main 1030의 191년·21국·491장수 ID·소유·수도·초기 병력을 새 지도에 대응한다. v1의 1,000명·42부곡·228관계를 무조건 합치지 않는다. 대응 불명확한 위치는 자동 추정하지 않는다.

수정 범위는 resources/scenario/, apps/engine/src/world/, packages/rules/src/world/다. 새 기능을 더하지 않는다. 기존 main·v1 기준 SHA와 자원 출처는 통합 기준 문서를 따른다. 세부 코드 경계·API 인증·엔진 단독 상태 변경·시드 RNG·턴 트랜잭션을 지킨다.

검증은 전체 정식 데이터 생성·로드·첫 월 정산·재시작·초기 해시/자원 해시, 장수·국가·수도·병력 보존 대조

선행 인수 뒤 착수하고 검증 결과와 구현하지 않은 담당의 리뷰를 같은 문서에 남긴다. 구현자가 스스로 완료로 바꾸지 않는다.

아직 착수하지 않았다.
