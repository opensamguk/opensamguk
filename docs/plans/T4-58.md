# T4-58 전투 특기 초기화 (`reset_war_trait`)

> 대기열: T4-58 (명세 §6 행, phases.md 행 없음) · AC: AC-M1-14 (D-022 전체 명령) · 구현: Codex (`opensamguk-implement`) · 리뷰: Claude (`opensamguk-review`)
> 상태: 상세 계획 제안. Codex 계획 기술 검토(G-03) 전이다. U-07, U-19, U-01의 준비 턴 기간은 결정되지 않았다.
> 명세: [Phase 2 확장 기술 명세](./phase2-expansion.md) §6 T4-58 행, §9 U-01·U-07·U-19
> 함께 보는 문서: [누락 명령 문서](./mvp-command-gaps.md#t4-58-reset_war_trait-전투-특기-초기화), [T4-57](./T4-57.md)(묶음 공통 규약 2절, 재사용 대기 조각 3절, 특기 초기화 공통 4절)

이 명령은 T4-57과 구조가 같다. 공통 규약, 재사용 대기 조각, 특기 초기화 공통 함수, T4-25에 요구하는 R1~R5는 [T4-57](./T4-57.md)을 그대로 따르고 이 문서에는 다른 점만 적는다.

## 0. 근거와 착수 조건

| 구분 | 위치 | 확인한 것 |
| ---- | ---- | --------- |
| 원작 | core2026 `df6c926` `packages/logic/src/actions/turn/general/che_전투특기초기화.ts` | T4-57 원본과 줄 단위로 대조했다. 다른 곳은 검사 칸이 `role.specialWar`(L29), 이전 목록 칸이 `prev_types_special2`이고 종류 수가 `WAR_TRAIT_KEYS.length`(L77-84), 다음 특기 나이 칸이 `specage2`(L86-87), 로그 문구(L88)다. 준비 턴 1(L42-44), 재사용 대기 60(L46-48)은 같다 |
| 현재 소스 | main `53dd348` | 우리 장수에는 전투 특기 칸 자체가 없다(`world/bootstrap.ts:63`의 `special` 하나). 전투 특기가 효과를 낼 자리는 T4-18의 `battle.dealt`·`battle.taken` 단계다(`modifiers/index.ts:4`) |
| 명령 key | `docs/product/command-coverage.json` | `reset_war_trait` ← `general:che_전투특기초기화` |

착수 조건은 T4-57 0절의 다섯과 같다. 하나를 더한다. U-07이 전투 특기를 범위에 넣지 않으면 이 명령은 비울 칸이 없다. 그때 이 행을 어떻게 닫을지(해당 없음 근거로 둘지, 범위에서 뺄지)는 사용자 결정이며 이 계획이 정하지 않는다.

## 1. 목표

AC-M1-14의 이 명령 행(`reset_war_trait`)이 대응표 11단계 증거를 모두 갖는다. 켠 월드의 장수가 전투 특기를 비우면 이전 전투 특기 목록에 남고 60턴 동안 다시 쓸 수 없으며 새 전투 특기는 T4-25의 획득 규칙으로 다시 얻는다. 끈 월드와 기본 명령 37개는 바뀌지 않는다.

## 2. 하지 않는 것

T4-57 2절과 같다. 전투 특기의 효과 수치와 전투 계산 연결은 T4-25가 한다.

## 3. 기술 계약 초안 (Codex 계획 기술 검토 전)

### 3.1 정의

`ext/reset_war_trait/reset_war_trait.ts`가 `defineCommand({ key: 'reset_war_trait', name: '전투 특기 초기화', category: 'personal', target: 'general', args: noArgs, check, change })`를 글자 그대로 둔다. `check`와 `change`는 `checkTraitReset`·`applyTraitReset`을 `'war'`로 부르는 화살표 함수다([T4-57](./T4-57.md) 4.1, 2.2의 대응표 도구 조건).

| key | name | category | target | args | sliceKeys |
| --- | ---- | -------- | ------ | ---- | --------- |
| `reset_war_trait` | 전투 특기 초기화 | `personal` | `general` | `noArgs` | `['generalCooldown', <T4-25 전투 특기 조각>]` |

### 3.2 검사 순서와 실패

| 순서 | 조건 | code | 문구 |
| ---- | ---- | ---- | ---- |
| 1 | 장수 없음 | `NO_ACTOR` | 장수가 없습니다. |
| 2 | 재사용 대기 중 | `BAD_STATE` | 전투 특기 초기화는 아직 다시 쓸 수 없습니다. |
| 3 | 전투 특기 없음 | `BAD_STATE` | 전투 특기가 없습니다. |

### 3.3 효과와 로그

T4-57 4.7과 같은 순서이고 칸만 전투 특기다. 이전 목록은 전투 특기 종류 수로 다시 시작한다. 재사용 대기는 `setCooldown(state, actor, 'reset_war_trait', actor.tick + 60 × TICKS_PER_MONTH)`이다. 내정 특기 초기화의 대기와 key가 달라 서로 막지 않는다.

| 경우 | `logs` (장수) |
| ---- | ------------- |
| 성공 | `전투 특기 초기화: {특기 이름} 비움` |
| 준비 칸(Q57-2에서 명령이 낼 때) | `전투 특기 초기화 준비 ({단계}/{전체})` |

### 3.4 C10 수치 분리와 U-19 제안

T4-57 4.6의 S1(재사용 대기 60턴)과 S2(다음 특기 시점)를 그대로 쓴다. 원작은 전투 특기의 다음 나이 칸을 내정과 따로 두었다(`specage2`). S2를 고르면 두 칸 모두 같은 규칙으로 정하고 시점 값도 칸마다 따로 둔다.
