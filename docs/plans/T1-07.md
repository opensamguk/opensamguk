# T1-07 월간 정산과 재생 테스트

> 대기열: T1-07 · AC: AC-M1-12, AC-M1-13 · 구현: Codex · 리뷰: Claude
> 선행: T1-06 · 관련: [게임 시계](../architecture/game-clock.md) §6, [수치 상태 정책](../numeric-state-policy.md)

## 계획 (Claude)

### 목표

- 달이 바뀌면 세금·봉급 → 인구·민심 → 보급 → 외교 기한 → 연감 순서로 처리된다 (AC-M1-12).
- 같은 시드와 같은 입력 기록으로 12개월을 다시 돌리면 상태 해시가 같다 (AC-M1-13).

### 범위

- `packages/rules/src/monthly/`: 단계별 순수 함수와 `runMonthly(state, month, rng)`
- `packages/db`: `NationHistory`, `YearbookSnapshot`, `InputEvent`(재생용 기록)
- `apps/engine`: 달 경계에서 월간 정산 실행, 같은 트랜잭션으로 저장
- `tools/replay.ts`: 기록을 다시 돌려 해시를 비교하는 스크립트

### 하지 않는 것

재해·사건·NPC 생성, 장수 나이·사망(Phase 2), 원작 수치 맞추기.

### 결정: 달 경계

- 달 경계 tick(`k × 10,000`)에 도달하면, **그 tick보다 앞선 장수 턴을 모두 처리한 뒤** 월간 정산을 한 번 실행한다.
- 월간 정산은 한 트랜잭션. 펜싱 토큰 조건 포함.
- RNG는 `rngFor(seed, 'monthly', 연, 월)`. 단계 안에서 국가·도시는 ID 순으로 돈다.

### 결정: 단계별 공식 (단순화, 상수는 `balance.ts`)

| 순서 | 단계 | 처리 |
| ---- | ---- | ---- |
| 1 | 세금·봉급 | 1·7월 금, 4·10월 쌀 (myosam·원작과 같은 반기 구조). 수입 = Σ 도시(상업 또는 농업 × 인구 계수 × 세율). 봉급 = 소속 장수에게 지급률만큼 나눠 줌 |
| 2 | 인구·민심 | 인구 += 정착 계수 × (인구 최대 − 인구), 세율이 높으면 민심 감소, 낮으면 증가 (core2026 `economy-and-diplomacy.md`의 5%·30% 표가 방향 참고) |
| 3 | 보급 | 수도에서 같은 나라 도시로 BFS. 끊긴 도시는 `supplied = false`, 내정치 −10%, 주둔 장수 훈련·사기 감소 |
| 4 | 외교 기한 | `untilTick`이 지난 선포는 교전으로, 불가침은 중립으로 |
| 5 | 연감 | `YearbookSnapshot`: 국가별 도시 수·장수 수·국력, **도시별 소유 국가** (D4 타임랩스가 이것만으로 재생) |

그 밖에: 15세가 된 장수의 `activeFromYear` 도달 처리(T1-03 참고), 정수화는 각 단계 끝에서 `Math.round`.

### 결정: 재생

- 재생에 필요한 입력: 월드 시드, 리소스 버전, 예턴 변경 기록, `InputEvent`. 이번에는 **예턴 변경을 `InputEvent(kind: 'turns.set')`로 남긴다.**
- `tools/replay.ts --from <월드 생성 기록> --months 12`가 메모리에서 다시 돌려 매달 해시를 출력·비교한다.

### 검증

| 무엇 | 어떻게 |
| ---- | ------ |
| 순서 | 골든: 고정 시드 월드 1개월 → 기대 스냅샷 파일과 비교. 단계마다 호출 순서를 기록하는 테스트 |
| 반기 수입 | 단위: 1월 금만, 4월 쌀만 |
| 보급 | 단위: 수도-A-B 직선에서 A를 잃으면 B 끊김, 우회로가 있으면 유지 |
| 재생 | 통합: 12개월 진행 기록 → 재생 → 매달 해시 같음 |
| 결정성 lint | `Math.random` 0건 (lint가 이미 막음) |
