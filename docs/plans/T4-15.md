## 계획 (Claude)

### 목표

### 원작 동작

선양:

| 항목 | 원작 |
| ---- | ---- |
| 제약 | 자신을 고르면 그 하나만 보고 `본인입니다`. 그 밖은 군주 → 대상 장수 있음 → 대상이 같은 국가 순서 |
| 실행 때 검사 | 대상에게 군주·건국·외교 징계가 있으면 `선양할 수 없는 장수입니다.`로 끝난다 |
| 효과 | 대상 관직 12, 실행 장수 관직 1, 실행 장수 경험 = round(경험 × 0.7), 둘 다 관할 도시 0, 국가 군주 id = 대상 |
| 대상 조건 | NPC 여부를 보지 않는다 |
| 난수 | 없음 |
| 기록 | 전체 역사, 국가 기록, 양쪽 장수 행동 기록과 열전 |

해산:

| 항목 | 원작 |
| ---- | ---- |
| 제약 | 군주 → 방랑군(국가 규모 0) |
| 첫 달 | 지금 연월이 월드 시작 연월 이하면 `다음 턴부터 해산할 수 있습니다.`를 남기고 인재탐색으로 바꿔 실행한다 |
| 장수 | 국가 장수 전원(실행 장수 마지막) 재야, 관직 0, 부대 0, 금 = min(금, 기본 1,000). 쌀 상한 1,000은 실행 장수에게만 걸린다(원작 저장 조건의 버릇이며 원작 주석이 밝힌다) |
| 실행 장수 | 재임관 제한 12턴 |
| 도시 | 국가 도시 전부 공백지 |
| 국가 | 삭제하지 않고 무너짐 표시 |
| 난수 | 없음 |
| 기록 | 실행 장수 행동 기록·열전, 전체 요약·역사 `멸망`, 장수마다 행동 기록·열전 |

원작에서 방랑군은 거병 직후의 도시 없는 세력이다. 건국해야 규모 1이 된다. 그래서 해산은 도시를 얻지 못한 거병 세력이 흩어지는 명령이다. 우리 건국과 거병은 바로 도시를 가진 규모 0 국가를 만들어서 규모 0을 방랑군으로 읽으면 정상 국가 전부가 해산할 수 있게 된다([누락 명령 문서](./mvp-command-gaps.md) [방랑] 조건과 같은 이유).

### 기술 계약 초안 (Codex 계획 기술 검토 전)

두 명령 모두 `defineCommand`(`support.ts:27-59`)로 만든다. 관직과 국가 소속을 바꾸므로 world 효과가 필요하다. 대응표 도구가 읽을 수 있게 `key`를 글자 그대로 둔다.

#### A. 선양 `abdicate`

| 칸 | 값 |
| -- | -- |
| name | 선양 |
| category | `strategy` (하야·건국과 같은 분류, `personnel.ts:88`) |
| args | `z.strictObject({ generalId: positive })` |

검사 순서:

| 순서 | 조건 | code | 문구 |
| ---- | ---- | ---- | ---- |
| 1 | 장수 없음 | `NO_ACTOR` | 장수가 없습니다. (`defineCommand`) |
| 2 | 대상이 자신 | `BAD_TARGET` | 자신에게는 선양할 수 없습니다. |
| 3 | 국가 없음 | `NOT_NATION` | 국가에 소속되어야 합니다. (`ruler`) |
| 4 | 군주 아님 | `NOT_RULER` | 군주만 실행할 수 있습니다. (`ruler`) |
| 5 | 대상 장수 없음 | `BAD_TARGET` | 장수가 없습니다. |
| 6 | 대상이 다른 국가 | `BAD_TARGET` | 같은 국가 장수에게만 선양할 수 있습니다. |
| 7 | SD2 (나): 대상 미등장 | `BAD_TARGET` | 아직 등장하지 않은 장수입니다. |

- 2를 3·4보다 먼저 보는 것은 원작(자신을 고르면 그 검사 하나만)과 같다.
- 3·4는 officerLevel 12를 직접 보는 이 폴더의 작은 함수로 본다. 문구는 `ruler`(`support.ts:20-26`)와 같다. T2-05가 `ruler`를 국가 명령 권한 표 검사로 바꿔도 선양·해산의 뜻이 바뀌지 않게 하려는 것이다(쟁점 Z1).

효과:

| 순서 | 바뀌는 것 |
| ---- | --------- |
| 1 | 대상 `officerLevel = 12` |
| 2 | 실행 장수 `officerLevel = 1`, `experience = Math.round(experience × 0.7)` |

- 대상이 수뇌(5~11)였다면 그 직책은 비게 된다. T2-05 뒤 `syncOffices`가 그 직책 칸을 비운다. 이 명령은 직책 칸을 직접 다루지 않는다.
- 국가 예턴(`nationTurns`)은 국가에 남고 새 군주의 턴에 실행된다. 준비 턴 진행(T4-07)은 직책 12 기준이라 이어진다(T4-07 쟁점 Z5와 같은 원칙).
- 난수 없음.
- 기록: 실행 장수 로그 `선양: {대상}`, 대상 보고 `{국가}: {실행 장수}에게서 군주 자리를 물려받았습니다.`, 국가 기록 `선양: {실행 장수} → {대상}`.

#### B. 해산 `disband` (PR 2)

| 칸 | 값 |
| -- | -- |
| name | 해산 |
| category | `strategy` |
| args | `noArgs` |

검사 순서:

| 순서 | 조건 | code | 문구 |
| ---- | ---- | ---- | ---- |
| 1 | 장수 없음 | `NO_ACTOR` | |
| 2 | 국가 없음 / 군주 아님 | `NOT_NATION` / `NOT_RULER` | `ruler`와 같은 문구(선양과 같은 이 폴더 함수) |
| 3 | SD4 (가): 방랑 국가 아님 | `BAD_STATE` | 방랑 중인 국가만 해산할 수 있습니다. |
| 4 | SD5 (가): 월드 첫 달(`Math.floor(tick / TICKS_PER_MONTH) === 0`) | `BAD_STATE` | 다음 달부터 해산할 수 있습니다. |

- 3은 T4-48의 `isWandering(view, nationId)`를 import해 부른다. 방랑 조각이 없는 월드에서는 거짓이므로 해산은 늘 거부된다.
- 원작 순서는 군주 → 방랑 → (실행 때) 첫 달이다.

효과(`change`):

| 순서 | 바뀌는 것 |
| ---- | --------- |
| 1 | 국가 소속 장수 전원(`id` 오름차순): `gold = min(gold, 1000)`, `rice = min(rice, 1000)` (SD6 (가)) |
| 2 | 국가 소유 도시 전부 `nationId = null`(방랑 국가면 보통 없다) |
| 3 | `removeNation(state, nationId)`: 국가 삭제, 외교 행·국가 칸·등용 제안 정리, 소속 장수 `nationId = null`·`officerLevel = 0` |
| 4 | 2에서 도시를 풀었으면 `refreshSupply(state)` |

- 원작은 국가를 무너짐 표시만 하고 남기지만 우리는 지운다. 우리에게 무너진 국가를 남기는 모델이 없고 출병 멸망(`attack.ts`)도 지운다. 지울 때 이름·색은 T4-56 (가)의 보존 경로가 남긴다.
- T4-48이 방랑 국가를 조각 `wander`에 두면 해산된 국가 id가 그 조각에 남는다. 지울지는 T4-48 계약이 정한다(상대 영역).
- 난수 없음.
