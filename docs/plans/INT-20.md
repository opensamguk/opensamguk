# INT-20 한지 군략도 화면 개편

> AC-INT-20 · 구현 Claude · 리뷰 Codex · 결정 [D-047](../product/decisions.md) · 사용자 직접 요청 2026-10-30

## 계획

와룡전 리메이크 같은 고전 전략 게임 느낌으로 화면 배치와 겉모습을 바꾼다. 원작과 리메이크의 그림은 입력·참조·따라 그리기 어디에도 쓰지 않는다. 규칙·API·DB·엔진은 바꾸지 않으며 화면의 접근성 이름·제목·test id도 이번에는 유지한다. 기준은 [화면 정체성](../design/visual-identity.md)과 사용자 비공개 시안 캔버스다.

| 묶음 | 범위 | 상태 |
| --- | --- | --- |
| 기반 | 토큰, 글꼴, 창틀, 먹색 배너, 도트 아이콘 레일 | 구현 |
| 자산 | 도트 바탕 지도, 생성 아이콘·지도 표식·군기·대표 그림, 제목 글꼴 서브셋 | 구현 |
| 입구·계정 | 로비, 로그인·가입·인증, 계정, 약관, 알림, 장수 생성, 초상 액자, 도움말 | 구현 |
| 도구·운영 | 공통 부품(군기 NationBadge), 외교, 작전, 순위, 전투 시뮬레이터, 타임랩스, 운영자 | 구현 |
| 메인·지도 | 지도 중심 메인 배치, 군령첩, 도로 픽셀·위에서 본 표식·관문 방향 | 지도 표식·도로·바탕 구현, 메인 배치·군령첩 남음 |

빼는 것은 D-047에 적었다. 2026-10-30 사용자 결정으로 첫 턴 안내와 받은 제안함은 화면만으로 만들 수 있어 이 작업에 넣는다. 메뉴 이름을 군략도·막부로 바꾸는 일은 메인 구현 때 E2E와 함께 한다. 시안에서 빠졌던 기존 기능은 작업용 시안 누락 점검표(커밋하지 않음)로 대조한다. 안개와 이동 재생은 서버 시야 규칙을 정한 뒤 별도 작업으로 올린다.

검증은 `pnpm check`, 공개 빌드와 자산 검사, 기존 실제 Chromium E2E 전체, 375·768·1440px와 라이트·다크 화면 확인, 글자 대비 4.5:1이다. 생성 그림과 글꼴은 출처·해시를 남기고 같은 원본에서 같은 결과가 나오는지 확인한다.

## 구현 기록

2026-10-30 기반과 자산을 만들었다. 도트 바탕 지도는 두 번 생성해 같은 해시를 확인했다. 입구·계정과 도구·운영 묶음은 진행 중이다. 독립 리뷰 전이다.

같은 날 메인·지도 묶음 가운데 두 PR과 겹치지 않는 부분을 새 파일로 먼저 만들었다. 규모별 표식 크기와 그림 고르기, 네모 축약, 관문 방향은 `apps/web/src/main/siteMarkers.ts`, 도로 픽셀은 `roadPixels.ts`, 그리는 부품은 `MapSiteMarker.tsx`와 `RoadPixelLayer.tsx`다. 운영 지도에 붙이는 일은 두 PR 병합 뒤에 한다.

2026-10-31 INT-19와 PR #305가 main에 들어와 운영 지도에 붙였다. 거점은 규모별 위에서 본 표식과 국가 군기로, 도로는 흙색 도트 층으로 그린다. 기존 경로 선은 경로마다 하나씩 투명하게 남겨 일방통행 화살표와 시험 표지를 유지한다. 접근성 이름과 test id는 바꾸지 않았다. PR #305가 새 월드의 기본을 SAN10 1400×1000 판으로 바꿔 같은 Natural Earth II 래스터와 v5.1.2 강·호수 벡터를 해시로 검증해 받아 SAN10 범위로 잘랐다(`tools/map-data/build-san10-relief.py`). 도트 바탕 생성은 `--map san10`을 받고 두 번 만들어 같은 해시를 확인했다. 기존 1000×700 도트 바탕은 바이트가 같다. 공개 빌드 승인 목록은 실제로 배포하는 도트 바탕 2장과 생성 그림 46장으로 맞췄고 운영 지도가 더 이상 쓰지 않는 옛 아이콘 4장과 지형 그림은 뺐다. 실제 Chromium E2E 전체, 375px·다크 화면 확인과 독립 리뷰는 남았다.

같은 날 사용자 요청으로 확대 지형 타일과 길 타일을 더했다. 도트 바탕의 한 칸이 화면에서 12px 이상이면 그 칸의 지형 16종 타일을 깐다. 지형 타일은 Codex 내장 image_gen에 글 프롬프트만 넣어 만든 지형 13장을 `tools/pixel-assets/build-tiles.py`로 32px로 줄였다. 평균 색은 도트 바탕의 같은 지형 색에 맞추고 반 칸 밀어 섞어 이음새를 없앴다. 프롬프트는 `tools/pixel-assets/tiles-prompts.json`, 원본 해시는 `apps/web/src/art/sources.json`에 있다. 길은 거점 표식의 동서남북 문으로만 드나들고 문 사이를 가로세로 곧은 줄로 한두 번만 꺾어 잇는다. 사용자가 준 리메이크 판 지도는 길이 놓이는 규칙과 화풍의 참고로만 봤고 그림은 저장소에 넣거나 생성 입력으로 쓰지 않았다. 길 타일은 같은 도구가 코드로 그린다. 칸 폭 1/4쯤의 미색 띠, 둥근 모서리, 연결 모양 16가지이며 물 칸을 지나는 곧은 길은 나무다리다. 물 위를 지나는 땅길 22개는 화면에서만 바다·강 칸을 따라 물빛 점선으로 그린다. 이동 규칙과 경로 종류는 바꾸지 않았고 실제 물길 규칙은 별도 결정 뒤의 일이다. 가장 깊은 확대는 보기 너비 60단위다. 이름표 글자는 화면에서 14px보다 커지지 않는다.

이어서 사용자 요청으로 강·산·거점 표식을 고쳤다. SAN10 판은 강과 산을 실제보다 크게 그린다. 장강·황하는 Natural Earth 이름으로 골라 도트 바탕에서 4칸, 큰 강은 2칸 폭이다. 단순화한 해안선 때문에 바다에 못 닿던 두 강의 하구는 가장 가까운 바다 칸까지 잇는다. 강은 확대해도 도트다. 강·호수 칸에 물 타일을 깔고 땅과 맞닿은 변에 도트 강둑 타일(연결 15가지)을 덧댄다. 호수는 확대하면 강 타일을 함께 쓴다. 산·고산은 둘레 1칸 넓히고 확대 타일은 2×2칸 그림이다. 구릉 1·산 2·고산 3단 높이 차이만큼 남쪽·동쪽 칸에 그림자를 드리운다. 거점 표식은 생성 그림의 원래 색을 그대로 쓰고 위에 덧그리지 않는다. 소속은 오른쪽 위 세력 색 깃발로만 나타낸다. 수(1)는 항구도시, 진(2)은 작은 진영, 관(3)은 관문, 이(4)는 이민족 진지 그림이다. 표식 크기를 줄였고 진영은 3.5단위다. 기존 1000×700 통합 지도의 도트 바탕은 바뀌지 않았다.

강을 과장하면서 강가 거점 39곳이 물 칸에 놓였다. 도트 바탕을 만들 때 표식 칸을 땅으로 되돌렸다. 그리로 흐르던 강은 거점 둘레 2칸 고리를 짧은 쪽으로 돌아 흐르게 했다. 물 위에 남은 거점은 없다. 사용자 요청으로 SAN10 판의 지형을 고전 전략 지도풍으로 다시 칠했다. 원작 그림은 쓰지 않고 색과 덩어리감만 모티브로 삼았다. 밝은 초록 평지, 짙은 초록 숲·산, 선명한 파란 물의 표시 색 판을 따로 두었다. 땅 칸은 5×5 다수결로 두 번 다듬어 큰 덩어리로 뭉쳤다. 확대 타일도 같은 색 판으로 물들였다. 화면은 지도 판마다 자기 색 판으로 지형을 읽는다. 중간 배율의 도트 길은 확대 길과 같은 미색이다.

사용자 결정으로 켜진 물길이 쓰지 않는 항구 시설은 지도에 그리지 않는다. SAN10에는 물길이 없어 항구 6곳(강하항·여강항·시상항·건업항·강릉항·오항)이 숨는다. 이어 [D-049](../product/decisions.md)로 SAN10 지도 자료에서도 뺐다(153표식).

같은 날 거점 정리 때문에 끊겼던 강을 다시 이었다. 강 조각을 한 줄로 이어 따라가며 땅으로 바뀐 구간을 거점 자리를 피한 2칸 폭 물길로 잇는다. 도트 바탕 생성은 장강·황하가 바다까지 이어지고 물 위 거점이 없는지 검사하고 어기면 실패한다. 물길 표시는 강이 끊겨 보이지 않게 모든 배율에서 작은 흰 물결 점만 쓴다. 표식이 붙거나 겹치던 13쌍은 SAN10 지도 자료의 좌표를 거점마다 12단위 안에서 밀어 띄웠다.
