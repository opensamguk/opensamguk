## 2. 단계 (가) 지금 달 그림 내보내기

### 2.1 화면

- 재생 조작 줄 끝에 `이 달 그림 내려받기` 버튼. 재생 중에도 누를 수 있고 누르면 재생을 멈춘다.
- 기록 없는 달(`view.kind === 'missing'`)이면 점선 버튼이고 누르면 `국가 기록이 없는 달은 내려받을 수 없습니다.` 그림을 대신 만들지 않는다.
- 파일 이름 `opensamguk-{월드 이름}-{연}-{월}.png`. 월드 이름의 파일 이름에 쓸 수 없는 글자는 `_`로 바꾼다.
- 만드는 동안 버튼에 `만드는 중`. 실패하면 버튼 옆에 `그림을 만들지 못했습니다.`

### 2.2 그림

```ts
// apps/web/src/timelapse/export.ts
export type DrawOp =
  | { kind: 'rect'; x: number; y: number; w: number; h: number; fill: string }
  | { kind: 'line'; x1: number; y1: number; x2: number; y2: number; stroke: string }
  | { kind: 'circle'; x: number; y: number; r: number; fill: string; stroke: string; dashed: boolean }
  | { kind: 'text'; x: number; y: number; text: string; size: number; color: string; align: 'left' | 'right' };
export function frameDrawOps(input: {
  worldName: string;
  date: string; // frameDate 결과
  view: Extract<FrameView, { kind: 'ok' }>;
  map: readonly MapCity[];
}): DrawOp[];
```

- 순수 함수가 그리기 명령 목록을 만들고 `exportCanvas.ts`가 캔버스에 옮겨 `toBlob('image/png')`로 받는다. 시험은 명령 목록을 비교하고 캔버스는 E2E가 본다.
- 크기는 지도 `MAP_WIDTH × MAP_HEIGHT`에 위 제목 줄과 아래 범례 줄을 더한 고정 크기, 배율 2다.
- 들어가는 것: 제목 `{월드 이름} · {연}년 {월}월`, 연결선, 도시 점(재생 화면과 같은 색·크기·기록 없는 도시 점선 원), 범례(국가 이름·도시 수, 공백지), 아래 한 줄 `국가 이름과 색은 그 달에 기록된 값입니다. 오픈삼국`.
- 들어가지 않는 것: 도시 이름 전부(작은 그림에서 읽히지 않는다), 내 장수 위치, 현재 국가 값.
- 글꼴은 이미 불러온 `--font-sans`(Pretendard)를 쓴다. 캔버스에 그리기 전에 `document.fonts.ready`를 기다린다.

## 3. 단계 (나)·(다)

### 3.1 (나) 재생 전체 내보내기

- 버튼 `재생 전체 내려받기`는 모든 페이지를 받은 뒤(`hasMore = false`)에만 열린다. 받는 중이면 점선 버튼과 이유.
- 프레임마다 2.2의 그리기 명령을 만들어 한 장씩 붙인다. 기록 없는 달은 넣지 않고 그 자리에 `{연}년 {월}월 국가 기록 없음` 글자 한 장을 넣는다. 지어낸 지도를 넣지 않는다.
- 한 프레임 1초(재생 화면과 같음).
- 형식은 U37-3이다. 선택지는 아래와 같다.

| 형식 | 방법 | 비용 |
| ---- | ---- | ---- |
| WebM | 캔버스 `captureStream` + `MediaRecorder`. 새 의존성 없음 | 실제 시간만큼 걸린다(120개월이면 2분). Safari 지원이 약하다 |
| GIF | 브라우저 GIF 인코더 라이브러리 하나(라이선스·크기 확인 필요) | 바로 만든다. 국가 색이 많으면 색 수 제한으로 색이 바뀔 수 있다. 저장된 색을 그대로 보인다는 원칙과 부딪힐 수 있다 |
| 그림 묶음 | PNG 여러 장을 zip 하나로. zip 라이브러리 필요 | 재생 파일이 아니다 |

- 프레임 수 상한을 둔다(예: 600). 넘으면 처음 600개월만 넣고 알린다. 숫자는 구현 때 메모리를 재서 정하고 구현 기록에 적는다.

### 3.2 (다) 로그인 없는 공유 화면

- 경로 `/share/timelapse/$worldId`. 로그인 가드 밖이다. 재생 부품(`TimelapseView`)을 그대로 쓰고 위쪽 띠·메뉴가 없다. 맨 위에 월드 이름과 `로그인 없이 보는 공유 화면입니다.`, 아래에 로비 링크.
- 재생 패널의 공유 버튼 `공유 링크 복사`는 주소를 클립보드에 넣는다. 서버에 공유를 등록하지 않는다(U37-5).
- 공유가 허락되지 않은 월드(U-10 답, 예: 진행 중 월드)면 공개 API가 거부하고 화면은 `이 월드는 공유하지 않습니다.`
- 받는 값과 보이는 값은 D-026 공개 범위와 같다. 화면은 응답에서 도시 소유와 국가 이름·색, 연월만 골라 쓴다(`publicMap/`의 `toPublicMaps`와 같은 방식).

### 3.3 (다)에 필요한 Codex 작업 (이 문서가 만들지 않음)

명세 §7상 `router.ts` 등록은 순서가 정해진 공유 파일이고 API는 Codex 단독 소유다(C7). 아래는 새 대기열 행(가칭 T4-37b)의 요청서다.

- 공개 절차 `timelapse.publicFrames({ worldId, cursor? })`. `publicProcedure`, 응답 모양은 `timelapse.frames`와 같고 `currentNations`는 뺀다.
- 허용 조건(U-10 답에 따름). 기본안은 ENDED 월드만이다. 진행 중 월드를 허락하면 D-026처럼 가장 최근 프레임을 지연 시간(`PUBLIC_MAP_DELAY_MINUTES`) 뒤에만 내고 그보다 새 프레임은 뺀다.
- 무인증 요청 제한. 지금 `publicProcedure`(`apps/server/src/trpc.ts:15`)에는 한도가 없고 사용자당 한도는 `protectedProcedure`(`:16-26`)에만 있다. `world.publicMaps`와 같은 방식으로 둘지, 주소별 한도를 새로 둘지 그 작업이 정한다.
- 권한 대조 다섯 범주 증거 또는 면제(`authz/exemptions.ts`의 `world.publicMaps` 면제 문구 선례).
- 공개 범위 시험: 응답에 국력·국고·군량·장수 수 키가 없다. ENDED가 아닌 월드는 거부(기본안).
