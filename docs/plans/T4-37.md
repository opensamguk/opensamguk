## 2. 단계 (가) 지금 달 PNG 내보내기

### 2.1 화면

- 재생 조작 줄 끝에 `이 달 그림 내려받기` 버튼. `TimelapseView` 안에 두므로 로그인 재생 탭과 공유 화면 모두에 나온다. 재생 중에도 누를 수 있고 누르면 재생을 멈춘다.
- 기록 없는 달(`view.kind === 'missing'`)이면 점선 버튼이고 누르면 `국가 기록이 없는 달은 내려받을 수 없습니다.` 그림을 대신 만들지 않는다.
- 파일 이름 `opensamguk-{월드 이름}-{연}-{월}.png`. 월드 이름의 파일 이름에 쓸 수 없는 글자는 `_`로 바꾼다.
- 만드는 동안 버튼에 `만드는 중`. 실패하면 버튼 옆에 `그림을 만들지 못했습니다.`

### 2.2 그림

```ts
// apps/web/src/timelapse/export.ts
export type DrawOp =
  | { kind: 'rect'; x: number; y: number; w: number; h: number; fill: string }
  | { kind: 'line'; x1: number; y1: number; x2: number; y2: number; stroke: string }
  | { kind: 'circle'; x: number; y: number; r: number; fill: string; stroke: string; dashed: boolean }
  | { kind: 'text'; x: number; y: number; text: string; size: number; color: string; align: 'left' | 'right' };
export interface PngDrawing {
  width: number;
  height: number;
  ops: readonly DrawOp[];
}
export function frameDrawing(input: {
  worldName: string;
  date: string; // frameDate 결과
  view: Extract<FrameView, { kind: 'ok' }>;
}): PngDrawing;
```

- 순수 함수가 CSS 크기와 그리기 명령 목록을 담은 `PngDrawing`을 만든다. `frameDrawing` → `DownloadPng` → `renderPng`으로 `width`·`height`·`ops`를 그대로 넘기고 `exportCanvas.ts`가 그 크기의 캔버스에 옮겨 `toBlob('image/png')`로 받는다. 시험은 크기와 명령 목록을 비교하고 캔버스는 E2E가 본다.
- CSS 너비는 700px, 배율은 2다. CSS 높이 656px은 최소 높이다. 범례는 4열이고 최소 4행을 위한 자리를 둔다. 공백지를 포함한 실제 범례 항목 수를 `N`이라 할 때 행 수는 `ceil(N / 4)`, CSS 높이는 `656 + max(0, ceil(N / 4) - 4) × 20`이다. PNG 너비는 1400px이고 높이는 계산한 CSS 높이의 두 배다. 지도 크기·좌표와 기존 제목 자리는 바꾸지 않는다.
- 들어가는 것: 제목 `{월드 이름} · {연}년 {월}월`, 연결선, 도시 점(재생 화면과 같은 색·크기·기록 없는 도시 점선 원), 범례(국가 이름·도시 수, 공백지), 아래 한 줄 `국가 이름과 색은 그 달에 기록된 값입니다. 오픈삼국`.
- 범례는 재생 화면의 순서대로 국가 이름·도시 수와 공백지를 모두 남긴다. 국가가 15개를 넘는다는 이유로 이름을 빼거나 `그밖`으로 합치지 않는다. 4행을 넘는 범례는 행마다 CSS 높이 20px을 더 쓰고 footer는 늘어난 그림의 하단으로 옮긴다. footer와 마지막 범례 행이 겹치거나 캔버스 밖으로 잘리면 실패다.
- 기존 E1의 국가 15개 이하 고정물은 PNG 1400×1312를 그대로 기대한다. 예를 들어 국가 16개와 공백지 1개로 17항목이면 5행이며 CSS 높이 676px, PNG 크기 1400×1352다. 기존 13개 E2E의 입력·픽셀·다운로드·거부 기대값은 줄이거나 바꾸지 않고 이 경계 밖 검증을 추가한다.
- 들어가지 않는 것: 도시 이름 전부(작은 그림에서 읽히지 않는다), 내 장수 위치, 현재 국가 값.
- 글꼴은 이미 불러온 `--font-sans`(Pretendard)를 쓴다. 캔버스에 그리기 전에 `document.fonts.ready`를 기다린다.
- 공유 화면의 PNG도 같은 함수로 만든다. 입력은 공개 응답에서 고른 값뿐이라 로그인 재생과 공개 범위가 같다.

## 3. 단계 (나) 종료 월드 공유

### 3.1 공개 범위

공유 PNG도 2.2의 최소 크기 계약을 따른다. CSS 높이 656px은 최소값이며 국가 이름·도시 수와 공백지 범례를 모두 담는 데 필요한 행만큼 높이를 늘린다.

| 월드 상태 | 로그인 없는 공유 화면 |
| --------- | ---------------------- |
| ENDED | 재생과 PNG 내려받기 |
| RUNNING, PAUSED, PREOPEN | 공개 API가 거부하고 화면은 `종료된 월드만 로그인 없이 볼 수 있습니다.`와 로그인 링크. 프레임을 하나도 그리지 않는다 |
| 없는 월드 | `월드를 찾을 수 없습니다.` |

| 보이는 것 | 보이지 않는 것 |
| --------- | -------------- |
| 달마다 도시 소유(`cityKey`·`nationId`), 그 달에 저장된 국가 ID·이름·색, 연월, 월드 이름, 종료 연월, 지도 좌표·연결 | 국력·국고·군량·장수 수, 장수 이름·능력치, 지금 국가 행 값(`currentNations`), 보급·도시 수치, 사건 자막 |

### 3.2 화면

- 경로 `/share/timelapse/$worldId`. 로그인 가드 밖이다. 재생 부품(`TimelapseView`)을 그대로 쓰고 위쪽 띠·메뉴가 없다. 맨 위에 월드 이름, 종료 연월과 `로그인 없이 보는 종료 월드 기록입니다.`, 아래에 로비 링크.
- `sharedSource.ts`는 응답에서 3.1의 보이는 것만 골라 `TimelapseView` 입력을 만든다. 서버가 다른 키를 섞어 보내도 그리지 않는다(`publicMap/`의 `toPublicMaps`와 같은 방식). 지도는 공개 다섯 칸을 3.4의 `TimelapseMapCity`로 옮기기만 하고 `level`·`nationId`·`supplied`를 지어 채우지 않는다.
- 이어 받기·계약 위반 처리·기록 없는 달 처리는 T4-36의 패널과 같다.
- 공유 링크 버튼 `공유 링크 복사`는 로그인 재생 탭에서 월드가 ENDED일 때만 나온다(`world.summary.status`). 주소를 클립보드에 넣을 뿐이고 서버에 공유를 등록하지 않는다. ENDED가 아니면 버튼을 두지 않는다.

### 3.3 서버 계약 ([T4-91](./T4-91.md), Codex)

API는 Codex 단독 소유다(명세 C7). 1차 원고의 요청서는 T4-91로 옮겨 확정됐고 아래는 화면이 기대는 몫의 요약이다. 정본은 T4-91 2~3절이다. 화면 담당은 서버 파일을 고치지 않는다.

| 항목 | T4-91 계약 | 화면에 주는 뜻 |
| ---- | ---------- | -------------- |
| 절차 | `timelapse.publicFrames`, `publicProcedure`, query. 이미 등록된 `timelapse` 라우터 안이라 `router.ts`를 고치지 않는다(T4-91 범위) | 타입은 `inferRouterOutputs<AppRouter>['timelapse']['publicFrames']`를 `import type`으로 받는다. 공유 타입 파일을 따로 만들지 않는다 |
| 입력 | `recordsInput`(`{ worldId, cursor? }` strict). 모르는 칸·행위자 ID는 `BAD_REQUEST`(T4-91 2.1, 2.3) | 공유 화면은 `worldId`와 `cursor`만 보낸다 |
| 출력 | `world`(이름, 종료 연월), 첫 페이지에만 `map.cities`(`cityKey`·`name`·`x`·`y`·`connections`), `items`(30개 오름차순, 그 달 저장 국가만), `nextCursor`. `currentNations` 없음(T4-91 2.1) | `sharedSource.ts`가 이 칸만 골라 `TimelapseView` 입력으로 옮긴다. 지도는 `cityKey`→`key`, `connections`→`links`로 이름만 옮기고 3.4의 최소 지도형으로 넘긴다(T4-91 T91-Q2). | 상태 검사와 조회 순서 | 한 `readWorld` RepeatableRead 트랜잭션에서 없는 월드 `NOT_FOUND` → ENDED가 아니면 프레임을 읽기 전에 `FORBIDDEN`(`종료된 월드만 로그인 없이 볼 수 있습니다.`) → ENDED인데 결과 행이 없으면 `INTERNAL_SERVER_ERROR` → 첫 페이지면 지도 → 스냅숏 → 저장 국가. 현재 `Nation`은 읽지 않는다(T4-91 2.2, 3.1) | 거부 안내는 오류 코드로만 가른다(`data.reason`은 늘 null). 500은 일반 실패 안내다 |

### 3.4 최소 지도형

문제. 공개 응답의 지도는 다섯 칸(`cityKey`, `name`, `x`, `y`, `connections`)뿐이다. 이름을 `key`·`links`로 옮겨도 지금 재생 부품에는 넣을 수 없다. `TimelapseView`의 `map`과 `frameView`의 `map`, `FrameCityView.city`가 `MapCity`를 요구하고(후보 소스 `apps/web/src/timelapse/frames.ts:1`, `:60-63`, `:74`, `TimelapseView.tsx:2`, `:34`) `MapCity`는 `world.map` 응답의 도시 전체 모양이라(`game/types.ts:9`) 지금 소유 `nationId`, 규모 `level`, 보급 `supplied`까지 있어야 한다. 가짜 `level = 0`, `nationId = null`, `supplied = false`를 채우거나 타입 단언으로 넘기는 것은 금지다. API 쪽 공개 범위를 넓히는 것도 하지 않는다.

해결. 재생 부품이 실제로 읽는 칸만으로 좁힌다. 후보 소스의 `TimelapseView.tsx`는 도시에서 `key`, `name`, `x`, `y`와 `mapLinks`를 거쳐 `links`만 읽는다.

```ts
// apps/web/src/timelapse/frames.ts
import type { MapCity } from '../game/types';
export type TimelapseMapCity = Pick<MapCity, 'key' | 'name' | 'x' | 'y' | 'links'>;
export interface FrameCityView {
  city: TimelapseMapCity;
  nation: Exclude<FrameNation, { kind: 'missing' }> | null;
}
export function frameView(frame: TimelapseFrame, map: readonly TimelapseMapCity[], source: NationDisplaySource): FrameView;
```

- `TimelapseView`의 `map` 입력을 `readonly TimelapseMapCity[]`로 좁힌다. 2.2의 `frameDrawing`은 `FrameView`의 도시를 읽으므로 지도 인자를 따로 받지 않는다.
- `MapCity`가 이 다섯 칸을 모두 가지므로 로그인 재생 패널이 넘기는 `MapCity[]`는 고치지 않고 그대로 들어간다(구조 타입의 너비 호환).
- `main/WorldMap.tsx`의 `mapLinks`는 이미 `T extends Pick<MapCity, 'key' | 'links'>` 제네릭이라(후보 소스 `WorldMap.tsx:15`) 고치지 않는다. 공용 `game/types.ts`도 고치지 않는다.
- 런타임 그리기는 바뀌지 않는다. 타입만 좁힌다.
- `sharedSource.ts`는 공개 다섯 칸을 `{ key: cityKey, name, x, y, links: connections }`로 옮긴 객체만 만든다.

검증 계약(4.1 X9·X10과 `pnpm check`의 web 타입 검사).

- 공개 다섯 칸에서 만든 지도로 `sharedSource` → `TimelapseView` → `frameDrawing`(PNG 그리기 입력)까지 타입 단언 없이 타입 검사가 통과한다.
- 로그인 재생 패널의 `MapCity[]` 입력과 T4-36의 기존 단위 시험이 고치지 않고 통과한다.
- 소스 검사로 `timelapse/` 아래에 `as MapCity`, `as unknown as`, `level: 0`, `supplied: false` 같은 채움·단언이 없다.

### 4.3 증거로 인정되는 것

정확한 SHA의 CI에서 `pnpm check`(단위, `pnpm lint:text --strict` 0건)와 E1~E8이 skip 없이 통과. E1~E7을 구현한 기존 13개 E2E의 입력·기대값은 보존하고 E8을 더한다. (나) API의 HTTP·PostgreSQL·권한 증거는 T4-91이 따로 받는다.
