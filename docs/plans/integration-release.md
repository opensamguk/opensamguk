# 통합판 v0.1 동결 범위·구현 비교·일정

2026-10-30 사용자 추가 범위는 [INT-19 장수 지시·수신·실행](./INT-19.md)과 D-046을 따른다. 개인 사병·복수 부곡·직속 상급자 한 명·사람의 30칸 권한을 보존한다. 이전 완료·도시 자원·지도 추가 인수와 별도로 AC-INT-19A~C를 구현·검증한다. 기존 서버의 배포 설정은 사용자 후속 입력까지 기다리고 구현을 먼저 진행한다.

> 2026-10-27 사용자 지시와 D-038. 이 문서와 [5능력치](../product/five-stats.md), [기능 목록](../product/feature-selection.md)이 이번 제작의 정본이다. 새 기획을 추가하지 않고 구현·시험·독립 리뷰에 집중한다.

## 완료할 제품

로컬에서 사람 장수가 생성·출사·내정·휘하 영입·부곡 편성·기존 이동·전투·점령을 거쳐 한 기수를 끝내는 통합판이다. 실행 기반은 main의 TS 엔진·API·React·PostgreSQL이며 v1의 기능과 데이터는 필요한 부분만 옮긴다.

2026-10-29 추가 승인 [D-040](../product/decisions.md#d-040-도시가-금쌀수비병을-보유하고-권한자가-부곡에-배속한다-2026-10-29)은 [INT-18](./INT-18.md)로 분리한다. 새 판에서는 도시가 금·쌀·수비병을 보유하고 권한자가 도시 병력을 부곡에 배속한다. 급여 뒤 세수는 해당 도시에 적립하고 모병·수비 군량은 도시가 부담한다. 아래 기존 15개 AC의 완료 증거는 보존하며 새 공개 후보는 이 후속 구현과 전체 정식 인수를 다시 거쳐야 한다.

- 통솔·무력·지력·정치·매력 5능력치. 명령별 역할·첫 산식·생성 합계는 five-stats 문서를 따른다.
- 1턴 1개월, 장수 예약 30칸과 기존 국가 예약·이동·귀환·출병 방식을 유지한다. 지속 행군·속도·거리 비용·중간 위치·출정 전용 보급망은 제외한다.
- 지도는 실제 GIS 지형을 바탕으로 53도시·8관문·6항구 시설·13전장 표시를 쓴다. 거점 배치는 게임에 맞게 조정하며 실제/게임 좌표를 나누어 표시하지 않는다. 새 아이콘은 도트이며 기존 자작 자산부터 재사용한다.
- 도시는 경제·인구·수도 단위, 관문은 통제·방어 거점이다. 항구는 도시 시설이며 전장은 지명 표시다. 항구·전장 표시를 경유한다는 이유로 이동에 빈 턴을 추가하지 않는다. 기존처럼 연결된 전략 목표로 한 번 이동한다. 별도 항구 내정·전장 운영·해전 조작은 만들지 않는다.
- 191년 군웅할거의 main 21국·491장수 ID를 유지해 대응한다. v1의 1,000명을 전부 더하지 않는다. 5능력치·이름 대응의 출처는 보존한다.
- 개인 휘하·명망·부장·부곡을 도입한다. 같은 병력을 General.crew와 부곡에 중복 저장하지 않는다. 사람의 동의·예약 권한을 보존한다.
- 기본 내정·군사·국가·외교·NPC·메시지·기록을 유지하고 화계·파괴·선동·탈취 4종을 연결한다. 기존 작전판·순위·타임랩스·시뮬레이터는 유지하되 새 확장은 하지 않는다.
- 금·쌀, 기존 월간 소비·전투 소비를 유지한다. 부곡 때문에 같은 병력의 군량을 두 번 내지 않는다. 휴대 군량·철·목재·말·창고망·피로 체계는 추가하지 않는다.

전체 90개 원작 명령 완료(D-022), 모든 v1 백로그, 특수 병종 9종·장비·관계망·황실·봉신·계보·카드 명령·실시간/격자 전투는 이번 v0.1 완료 조건에서 보류한다. 기존 코드·기록을 삭제하라는 뜻이 아니다. 공개 배포·메일 서비스·새 공개 초상·약관·최종 운영 관문은 별도 M3 목록에 남기며 이 로컬 일정에 포함하지 않는다.

## 각 작업의 작은 순서

- INT-01은 실패 재현 0.5일, 환경·제품 결함 분류/수정 0.5~1일, 정확한 기준과 로컬 점검 0~0.5일로 나눈다. 기존 실패를 2일 안에 격리하지 못하면 다음 일정의 낙관 가정을 철회하고 다시 계산한다.
- INT-14는 계약·프로필/마이그레이션 1일, 생성·조회/리소스 1일, 재시작·재생·옛 월드 보존 시험 1일이다.
- INT-16은 대조 도구 1일, 458명 후보 검증과 33명 별칭/미수록 조사 1~2일, 정식 원장·시나리오 검증 1일이다. 미해결을 0·평균·스탯 복사로 채우지 않는다.
- INT-15는 내정 가중 점수 1일, 모병·훈련·사기와 NPC 1일, 경계/재생 반례와 미리보기 보완 0~1일이다.
- INT-02는 v3 종류·자원 판 1일, 저장·생성·조회 1일, 해시·권한·기존 판 보존 1일이다.
- INT-03은 거점/도시 귀속 1일, 육수로·8관문 필수 길목 1~2일, 운영 그래프·막힘·가독성 시험 1일이다.
- INT-04는 21국·수도·소유와 491장수의 위치 대응 1일, 새 판 생성·로드·월 정산과 대응표 확인 1일이다.
- INT-05는 canonical 필드 대응·반례 보완 0.5일, 순수 규칙 재검증·독립 리뷰 0.5일이다.

## 중간 시연과 종료 조건

새 통합판은 `campaign-v1`과 `campaign-assignment-v2`를 함께 선택해 원생성에 고정한다. 후자는 발령의 기한 수락에도 집결한 NPC 부장이 명시 수락과 같이 동행하도록 고친 판이다. 기존 기능 목록과 원장·월 해시는 변경하지 않는다. 이전 판에서 진행한 플레이는 보존하며 보완판의 한 기수 인수로 대신하지 않는다.

전용 개발 DB를 환경 변수로 연결한 뒤 새 판을 만든다. 생성된 월드 ID와 초기 해시를 기록하고 기존 월드의 기능 목록은 고치지 않는다.

```sh
pnpm world:create --scenario integration191 --map integration --stat-rules five-stats --portrait-map 191-map --rule-features 'campaign-assignment-v2,campaign-v1,five-stats,operational-map,personnel,policy,stratagem-basic,treaty' --seed integration-v01-formal-campaign-191-20261027 --turn-term 60 --end-year 201 --name "통합판 v0.1 정식 인수"
```

첫 단계는 합성 최소 월드에서 5능력치 생성·저장·조회·재시작을 확인한다. 그다음 정식 데이터와 53도시 새 판, 이어 실제 API의 휘하·부곡·전투, 마지막에 전체 UI와 한 기수 완주를 시연한다. 합성 월드를 정식 전체 판의 인수로 세지 않는다.

완료는 pnpm check·실제 PostgreSQL 통합·실제 Chromium E2E·고정 시드 재생·두 월드 격리·복원과 반대쪽 리뷰를 통과하고 AC 증거를 채운 상태다. 현재의 전체 검사 실패는 먼저 분류하며 skip·mock·로컬 화면 한 번을 전체 인수로 바꾸지 않는다.

추가 기능·새 스탯·자원·지도 관리 단위 변경은 보류한다. 이번 범위의 오류·접근성·기존 약속과 다른 동작은 고친다. 기능 동결을 바꾸려면 사용자 지시와 영향·대체 범위·늘어나는 작업을 기록한다.
