# T3-08 군사 조언·역할별 입장·월단평 화면

> 대기열: T3-08 · AC: AC-M3-13, AC-M3-14, AC-M3-15 (화면) · 구현: Claude · 리뷰: Codex
> 선행: T3-07 · 관련: [T3-07 계획](./T3-07.md), [T1-15 장수 생성 화면](./T1-15.md), [T1-16 핵심 화면](./T1-16.md), [T2-04 로비 화면](./T2-04.md), [T2-10 실시간 갱신](./T2-10.md), [UI 지침](../frontend-ui-guidelines.md)

## 계획 (Claude)

### 목표

- 메인 화면에서 추천 예턴 3개와 이유를 보고 누르면 예턴에 들어간다. 재야면 나라 추천을 보고 임관을 넣는다 (AC-M3-13의 화면, E2E).
- 장수 생성 화면에서 시나리오 인물을 역할별로 보고 골라 시작한다. 남이 맡은 인물은 보이지 않고 직접 만들기도 그대로 된다 (AC-M3-14, E2E).
- 기록 화면의 월드 정세 탭에서 달마다 월단평 순위와 한 줄 평을 본다 (AC-M3-15의 화면).

### 담당과 수정 범위

| 담당 | 에이전트 | 고치는 곳 |
| ---- | -------- | --------- |
| 구현 | opensamguk-frontend-implement (Claude) | `apps/web/src/advice/`(새로), `apps/web/src/entry/`(새로), `apps/web/src/review/`(새로), 메인 화면과 기록 화면 컴포넌트(T1-16이 만든 파일)에 자리 하나씩, 장수 생성 화면(T1-15)에 탭, `apps/web/src/router.tsx`(검색 인자), `e2e/advice.spec.ts`·`e2e/entry.spec.ts`·`e2e/review.spec.ts`(새로) |
| 리뷰 | opensamguk-frontend-review (Codex) | 화면 E2E, 문구, 채울 문서 |

API 모양은 T3-07의 tRPC `AppRouter` 타입만 import한다. 서버 코드는 고치지 않는다.

맡기 결과는 `entry.possess`·`entry.possessStatus` 출력의 판별 union(`possessed`·`pending`·`rejected`)으로 읽는다. 거절 코드 타입은 `inferRouterOutputs<AppRouter>`에서 가져오고 목록을 화면 쪽에 다시 적지 않는다. tRPC 오류의 `cause`와 message는 읽지 않는다. 오류는 T3-02 오류 계약(PR5 `dd4b29a`, `docs/plans/T3-02.md:105-124`)의 `data.code`·`data.reason`만 본다.

### 하지 않는 것

- 서버 API, 규칙, 문장 틀 (T3-07).
- 메인·지도·예턴을 한 화면으로 합치기. 승인 대기 중인 핵심 규칙 변경(10번)이다. 기존 화면 구조는 두고 자리만 더한다.
- 375px 전수 점검 (T3-10). 새로 만드는 부분은 처음부터 375px에서 가로 스크롤이 없고 누르는 대상이 44px 이상이게 만든다.
- 조언 자연어 설명(LLM, Phase 3), 월단평 알림.

### 메인의 군사 조언

```text
┌ 군사 조언 ─────────────────────────────────────────── [접기] ┐
│ 작전   출병 · 복양        복양 192년 3월 작전 준비          [1칸에 넣기] │
│ 지시   모병 · 보병 1000    국가 공지: 서쪽 전선 병력 보충     [1칸에 넣기] │
│ 조언   농지 개간           진류 농업이 최대치의 40%          [1칸에 넣기] │
│ 지금 넣을 수 없는 지시: 출병 · 업 (교전 중인 나라가 아님)               │
└──────────────────────────────────────────────────────────────┘
```

- 자리는 메인의 예턴 앞 5칸 미리보기 바로 위다. 출처(작전·지시·조언)를 글자로 먼저 쓰고 색은 보조로만 쓴다.
- `[1칸에 넣기]`는 `turns.edit`의 `put`으로 0번 칸에 넣는다. 0번 칸이 휴식이 아니면 확인을 받는다 (예: `1칸의 상업 투자를 농지 개간으로 바꿉니다`). 넣은 뒤 예턴 미리보기와 조언을 다시 조회한다.
- `STALE`이면 T1-15와 같은 문구로 알리고 예턴과 조언을 다시 불러온다. 넣으려던 추천이 새 목록에 없으면 그대로 끝낸다.
- 재야 장수는 나라 카드 3개(국가색 칩, 나라 이름, 이유)와 `[임관 넣기]`를 본다.
- `skipped`는 넣기 버튼 없이 회색 한 줄로 이유를 보여 준다. 추천이 하나도 없으면 `지금 추천할 예턴이 없습니다`.
- 펼침 기본값은 월드 프리셋의 `features.advisor`다. 켜진 월드(초보)는 펼친 채, 꺼진 월드는 접힌 채 시작한다. 사용자가 바꾼 상태는 월드별로 `localStorage`에 둔다.

### 장수 생성 화면의 역할별 입장

```text
/w/:worldId/create?mode=roles
[직접 만들기] [역사 인물로 시작]
[군주 21] [중견 n] [부하 n] [재야 n]      나라 [전체 ▾]  이름 [      ]
군주: 나라의 인사와 외교를 정하고 국가 예턴을 맡는다.
┌ 초상 ┬ 이름 ┬ 소속 ┬ 위치 ┬ 통 ┬ 무 ┬ 지 ┐
│      │ 조조 │ 조조 │ 진류 │ .. │ .. │ .. │   선택 → 아래 확인 칸
└──────┴──────┴──────┴──────┴────┴────┴────┘
[조조로 시작]
```

- 주소는 `/w/:worldId/create` 그대로다. 검색 인자 `mode`가 없으면 지금처럼 직접 만들기를 연다. 기존 링크(T2-04 로비의 `장수 만들기`)와 T1-15 E2E는 바꾸지 않는다. 화면 위쪽 탭으로 두 방식을 오간다.
- 역할 탭 네 개에 남은 인물 수를 붙인다. 탭 아래에 그 역할의 할 일을 한 줄로 쓴다. 아래 표는 문구 초안이며 구현할 때 글쓰기 규칙으로 다시 본다.

  | 역할 | 한 줄 |
  | ---- | ----- |
  | 군주 | 나라의 인사와 외교를 정하고 국가 예턴을 맡는다 |
  | 중견 | 수뇌 후보로 내정과 군사의 중심을 맡는다 |
  | 부하 | 군주와 수뇌의 지시를 받아 내정과 출병을 한다 |
  | 재야 | 어느 나라에도 속하지 않은 채 시작해 임관할 나라를 고른다 |

- 표는 초상(T1-17 해석), 이름, 소속(국가색 칩), 위치, 통솔·무력·지력을 보여 준다. 재야 탭에는 추천 나라와 이유를 한 칸 더한다. 정렬은 서버 순서가 기본이고 열 머리를 눌러 바꾼다.
- 인물을 고르면 아래 확인 칸에 요약과 역할 설명이 나오고 `[○○로 시작]`을 누른다.
- 누를 때 `crypto.randomUUID()`로 `idempotencyKey`를 만들고 그 시도가 끝날 때까지 쓴다. 네트워크 오류로 다시 보낼 때도 같은 키를 쓴다. 키는 `sessionStorage`에 월드·인물과 함께 두어 새로고침 뒤에도 같은 시도를 이어서 확인한다. 결과가 `possessed`나 `rejected`로 정해지면 지운다.
- `pending`이면 `자리를 맡는 중입니다`를 보여 주고 `entry.possessStatus`를 2초마다 다시 조회한다. `general.mine`만 보지 않는다. 그것만으로는 pending 뒤 거절된 요청의 이유를 알 수 없다.
- `possessed`면 메인으로 간다. `rejected`면 `rejectCode`대로 처리한다.

  | `rejectCode` | 화면 |
  | ------------ | ---- |
  | `TAKEN` | `다른 사람이 먼저 맡았습니다`, 목록을 다시 불러온다 |
  | `ALREADY_HAS_GENERAL` | 메인으로 보낸다 |
  | `FULL` | `DisabledReason`으로 사람 장수 자리가 찼다고 알린다 |
  | `NOT_ELIGIBLE` | `이 인물은 지금 맡을 수 없습니다`, 목록을 다시 불러온다 |
- 정원이 찼거나 고를 인물이 없으면 그 이유를 쓰고 직접 만들기 탭으로 가는 링크를 둔다.

### 기록 화면의 월단평

- 자리는 `/w/:worldId/records?tab=world`의 맨 위다. 제목은 `191년 3월 월단평`처럼 연월을 붙인다.
- 순위 표는 순위, 장수 이름, 소속(국가색 칩), 한 줄 평이다. 점수는 작은 글씨로 오른쪽 정렬한다. 메달·왕관 같은 장식과 이모지는 쓰지 않는다.
- 연월 선택(`review.months`)으로 이전 달을 본다. 순위가 없는 달은 `이번 달은 평판에 오른 장수가 없다`.
- SSE `monthly.done`을 받으면 `review.latest`와 `review.months`를 다시 조회한다 (T2-10의 무효화 방식).
- 장수 이름을 누르면 그 장수가 있는 국가 정보로 간다. 재야면 링크가 없다.

| 공통 | 문구 | `pnpm lint:text` 0건, 반대쪽 리뷰가 문구도 본다 |
| 공통 | 단위 | Vitest: 출처 표시, 덮어쓰기 확인 판단, 펼침 기본값, 빈 상태, `rejectCode` 넷의 문구·이동, 재전송 때 같은 키 |

달 넘김과 작전·지시 준비는 E2E 준비 단계에서 기존 도우미(manual 시계 엔진 실행, 고정 시드 fixture)로 만든다. E2E를 위해 서버에 시계 조작 API를 열지 않는다. 월단평의 계산 증거는 T3-07 골든이고 이 작업은 화면 표시를 확인한다.
