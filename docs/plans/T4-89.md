# T4-89 지도 판별 바탕 그림 메타데이터

AC-P2-28의 서버 범위다. D-028과 [T4-83](./T4-83.md)·[T4-84](./T4-84.md)의 판별 그림 계약을 따른다. 계획은 Claude, 기술 검토·구현은 Codex, 구현 뒤 독립 리뷰는 구현하지 않은 Codex가 맡는다.

`MapBackground`는 게시된 MAP 자원 하나에 연결된다. 지도 내용 해시와 이미지 바이트 해시·크기·이미지 저장소 커밋을 저장한다. 기존 게시 자원 내용은 수정하지 않으며 같은 값의 재등록만 허용한다. 그림 경로는 정규 자원 키에서 `maps/<키>/base.webp`로 만든다. 다른 판을 대신 고르지 않는다.

등록 명령은 `pnpm exec tsx --env-file-if-exists=.env tools/map-background.ts register`다. 표준 입력 JSON은 `{mapKey,imageRepository,imageCommit}`이며 DB 주소는 환경변수로만 받는다. 이미지 저장소의 정확한 커밋에서 해당 경로의 Git blob을 읽어 무손실 WebP 크기와 SHA-256을 계산한다. 등록 대상은 같은 DB에 게시된 MAP이어야 한다. 웹 mutation과 외부 파일 요청은 추가하지 않는다.

`world.map` 응답에는 `background: {path,width,height} | null`을 추가한다. `world.publicMaps`는 각 월드 줄에 같은 칸을 둔다. 그림은 판의 고정 자산이며 공개 사본의 지연과 별개다. 사본의 도시·국가 공개 범위와 시각은 기존 규칙을 유지한다. 그림이 없거나 판 키·지도 해시가 맞지 않으면 null이다. 내부 해시·커밋·자원 id는 공개하지 않는다.

실제 PG·TCP 검증은 판 격리·동시 등록·게시 자원 불변·DB 제약·지도 인증·공개 범위·지연을 확인한다. 전체 검사와 독립 리뷰·필수 CI·병합 전에는 구현 완료로 세지 않는다. 실제 그림 생성·출처는 T4-83, 화면과 E2E는 Claude의 T4-84다. 이 서버 작업만으로 AC-P2-28을 완료하지 않는다.
