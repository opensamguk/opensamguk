# T2-25 로그인·로비 지연 지도 화면

> 대기열: T2-25 · AC: AC-M2-20 (화면) · 구현: Claude · 리뷰: Codex
> 선행: T2-24 (API, Codex), T2-04 (로비 화면) · 결정: [D-026](../product/decisions.md#d-026-로그인과-로비에-지연-공개-지도를-둔다-2026-10-23)

## 계획 (Claude)

### 목표

로그인 화면과 로비에서 진행 중인 월드를 탭으로 골라 그 월드의 지연 공개 지도를 하나씩 본다.

### 범위

- `apps/web`: 공용 부품 `PublicMapTabs`(새로), 로그인 화면(`apps/web/src/pages/LoginPage.tsx`)과 로비 화면(T2-04)에 배치.
- 지도 그리기는 메인 지도(`apps/web/src/main/WorldMap.tsx`)를 읽기 전용으로 다시 쓴다. 도시를 눌러도 도시 화면으로 가지 않는다.

### 화면

- 탭 하나가 월드 하나다. 탭 이름은 월드 이름이고 PAUSED 월드는 이름 옆에 `멈춤`을 붙인다. 처음에는 첫 탭을 연다.
- 탭 아래에 고른 월드의 지도 하나만 그린다. 다른 월드 지도는 탭을 바꿀 때 그린다.
- 지도 위 한 줄: `190년 3월 · 오후 2시 10분 기준`처럼 사본의 연월과 실제 시각을 함께 쓴다. 지연 시간도 응답의 `delayMinutes`로 `10분 이상 지난 상태입니다`처럼 적는다.
- 도시는 소유 국가 색으로 칠하고 지도 옆이나 아래에 국가 이름과 색 견본 목록을 둔다. 장수, 병력, 보급 표시는 없다.
- `map: null`인 월드 탭은 `아직 공개 지도가 없습니다`만 보여 준다.
- 공개할 월드가 하나도 없으면 탭 줄도 문구도 없이 그 자리를 빈 공간으로 둔다 (2026-10-23 소유자 지시). 양식 자리는 움직이지 않는다.
- 로그인 화면에서는 로그인 양식이 먼저다. 좁은 화면(640px 이하)에서는 양식 아래로 지도가 내려간다.
- 로비에서는 월드 목록 위에 둔다. 로비 카드의 탭 선택과 지도 탭은 따로 움직인다.
- 탭은 `role="tablist"`·`role="tab"`·`aria-selected`를 쓰고 왼쪽·오른쪽 방향키로 옮긴다.

### 검증

| 무엇 | 어떻게 |
| ---- | ------ |
| 로그인 화면 | Playwright: 로그아웃 상태 `/login`에서 탭 수가 공개 월드 수와 같다. 탭을 바꾸면 지도 하나만 바뀌고 기준 시각 줄이 그 월드 값으로 바뀐다 |
| 로비 | Playwright: 로그인 뒤 `/lobby`에서 같은 탭과 지도 |
| 지연 | Playwright(실제 엔진·DB, manual 시계): 사본을 찍은 뒤 도시 소유를 바꾸고 지연 시간이 지나기 전에는 화면 색이 예전 그대로다 |
| 공개 범위 | Playwright: 지도 안에 장수·병력 표시가 없다 |
| 빈 상태 | Playwright: 사본 없는 월드 탭 문구. 월드 0개면 탭과 문구가 없고 지도 자리가 비어 있으며 로그인 양식 위치는 그대로다 |
| 키보드 | Playwright: 방향키로 탭 이동, `aria-selected` |
| 좁은 화면 | Playwright 375px: 양식 아래 지도, 가로 스크롤 없음 |

## 구현 기록 (Claude)

2026-10-23, 로그인 화면 몫만 구현했다. 화면은 PR #167로 먼저 들어왔고 이번에 main의 T2-24 API(`world.publicMaps`)에 연결했다. 로비 자리(`data-slot="public-map"`)는 로비 API(T2-03)가 main에 없어 붙이지 않았다.

- 바꾼 것: `apps/web/src/publicMap/contract.ts`의 임시 타입과 캐스트를 지우고 `trpc.world.publicMaps.queryOptions()`를 쓴다. 응답 타입은 `apps/web/src/game/types.ts`의 `PublicMapsResponse`(`AppRouter` 출력)다. `toPublicMaps`는 그 응답을 받아 공개 범위 키만 골라 담는다. 그리고 문자열로 오는 도시 `key`·`links`를 숫자로 바꿔 `WorldMap`에 넘긴다. 숫자로 읽을 수 없는 키는 버린다. `e2e/publicMap.spec.ts`는 skip과 fixme를 모두 없앴다. 시작 전에 전용 월드 둘을 E2E 전용 DB에 만든다. 하나는 시험이 엔진 실행권을 쥔 RUNNING 월드이고 엔진의 `persistPublicMap`에 시각을 넣어 사본을 찍는다. 다른 하나는 사본 없는 PAUSED 월드다.
- 계획과 달라진 점과 이유: 화면은 계획대로 `key`·`links`를 문자열로 받는다. PR #167은 `mapCity`를 따라 숫자로 받았는데 실제 API는 계획의 문자열을 따른다. 서버 계약은 계획과 맞아 Codex 작업을 더하지 않았다. 지연 시험은 지연 시간 동안 기다리지 않고 사본 시각으로 manual 시계를 대신한다. 사본 A를 지연 시간 두 배 전에, DB의 도시 소유를 바꾼 뒤 사본 B를 1분 전에 찍고 화면이 A의 국가 이름과 색인지 본다. 이어 B의 시각을 지연 시간보다 앞으로 옮기면 화면이 B로 바뀌는지도 본다. 시험 월드 둘은 끝날 때 PAUSED로 남는다. 월드 0개와 375px 넓은 지도 두 경우만 응답의 `publicMaps` 칸을 바꿔 화면 동작을 본다. 로비 검증 행은 로비 연결 때 한다.
- 검증 결과: `pnpm exec vitest run apps/web/src/publicMap` 11개 통과. `pnpm typecheck`, `pnpm lint`, `pnpm lint:text --strict` 통과. 실제 dev 서버(`CI=1`, Playwright가 이 checkout의 `pnpm dev`를 띄움)와 전용 DB `opensamguk_t2_25_e2e_test`로 `pnpm exec playwright test e2e/publicMap.spec.ts --workers=1`을 돌려 6개 모두 통과했다. skip은 없다. 웹 전체 단위 시험은 370개 중 369개가 통과했다. 실패한 1개는 `apps/web/src/help/help.test.tsx`이며 Windows checkout의 `core.autocrlf=true`로 `docs/user/index.md`가 CRLF가 된 탓이다. 이번 변경과 관계없다.
