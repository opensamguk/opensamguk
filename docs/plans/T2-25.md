# T2-25 로그인·로비 지연 지도 화면

> 대기열: T2-25 · AC: AC-M2-20 (화면) · 구현: Claude · 리뷰: Codex
> 선행: T2-24 (API, Codex), T2-04 (로비 화면) · 결정: [D-026](../product/decisions.md#d-026-로그인과-로비에-지연-공개-지도를-둔다-2026-10-23)

## 계획 (Claude)

### 목표

로그인 화면과 로비에서 진행 중인 월드를 탭으로 골라 그 월드의 지연 공개 지도를 하나씩 본다.

### 범위

- `apps/web`: 공용 부품 `PublicMapTabs`(새로), 로그인 화면(`apps/web/src/pages/LoginPage.tsx`)과 로비 화면(T2-04)에 배치.
- 지도 그리기는 메인 지도(`apps/web/src/main/WorldMap.tsx`)를 읽기 전용으로 다시 쓴다. 도시를 눌러도 도시 화면으로 가지 않는다.

### 화면

- 탭 하나가 월드 하나다. 탭 이름은 월드 이름이고 PAUSED 월드는 이름 옆에 `멈춤`을 붙인다. 처음에는 첫 탭을 연다.
- 탭 아래에 고른 월드의 지도 하나만 그린다. 다른 월드 지도는 탭을 바꿀 때 그린다.
- 지도 위 한 줄: `190년 3월 · 오후 2시 10분 기준`처럼 사본의 연월과 실제 시각을 함께 쓴다. 지연 시간도 응답의 `delayMinutes`로 `10분 이상 지난 상태입니다`처럼 적는다.
- 도시는 소유 국가 색으로 칠하고 지도 옆이나 아래에 국가 이름과 색 견본 목록을 둔다. 장수, 병력, 보급 표시는 없다.
- `map: null`인 월드 탭은 `아직 공개 지도가 없습니다`만 보여 준다.
- 공개할 월드가 하나도 없으면 탭 줄도 문구도 없이 그 자리를 빈 공간으로 둔다 (2026-10-23 소유자 지시). 양식 자리는 움직이지 않는다.
- 로그인 화면에서는 로그인 양식이 먼저다. 좁은 화면(640px 이하)에서는 양식 아래로 지도가 내려간다.
- 로비에서는 월드 목록 위에 둔다. 로비 카드의 탭 선택과 지도 탭은 따로 움직인다.
- 탭은 `role="tablist"`·`role="tab"`·`aria-selected`를 쓰고 왼쪽·오른쪽 방향키로 옮긴다.

### 검증

| 무엇        | 어떻게                                                                                                                                  |
| ----------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| 로그인 화면 | Playwright: 로그아웃 상태 `/login`에서 탭 수가 공개 월드 수와 같다. 탭을 바꾸면 지도 하나만 바뀌고 기준 시각 줄이 그 월드 값으로 바뀐다 |
| 로비        | Playwright: 로그인 뒤 `/lobby`에서 같은 탭과 지도                                                                                       |
| 지연        | Playwright(실제 엔진·DB, manual 시계): 사본을 찍은 뒤 도시 소유를 바꾸고 지연 시간이 지나기 전에는 화면 색이 예전 그대로다              |
| 공개 범위   | Playwright: 지도 안에 장수·병력 표시가 없다                                                                                             |
| 빈 상태     | Playwright: 사본 없는 월드 탭 문구. 월드 0개면 탭과 문구가 없고 지도 자리가 비어 있으며 로그인 양식 위치는 그대로다                     |
| 키보드      | Playwright: 방향키로 탭 이동, `aria-selected`                                                                                           |
| 좁은 화면   | Playwright 375px: 양식 아래 지도, 가로 스크롤 없음                                                                                      |
