## 계획 (Claude)

### 목표

AC-P2-18의 조회 몫이다. 명세 문장은 이렇다. 다른 국가 도시의 상세값은 첩보 기록으로만 보이고 몇 개월 전 기록인지 표시된다. 적 병력은 U-11에서 정한 구간으로 보인다.

이 작업이 끝나면 `spy`를 켠 월드에서 아래가 HTTP로 성립한다.

- `city.get`이 공개 범위 밖 도시에 대해 자기 국가의 첩보 기록을 몇 개월 전과 함께 낸다. 기록이 없거나 표시 기간을 넘으면 상세값이 없다.
- 기록의 병력은 U-11 구간으로만 나간다. `intel.records`와 `city.get`이 같은 함수를 쓴다.
- U-11이 주둔 장수 목록을 가리기로 하면 공개 범위 밖 도시의 주둔 장수 목록이 빠진다.
- `spy`를 끈 월드의 모든 응답은 지금과 바이트 단위로 같다(IC-10).

## 3. 기술 계약 초안 (Codex 계획 기술 검토 전)

### 3.1 `fog.ts`

```ts
export const FOG = {
  CREW_BANDS: [/* F1 결정값. (가)면 [0, 1, 1_000, 5_000, 10_000, 20_000, 50_000] 각 구간의 하한 */],
  MAX_AGE_MONTHS: null as number | null, // F2. (가)면 null
  HIDE_FOREIGN_GARRISON: false, // F3. (나)면 true
  LIVE_WHEN_PRESENT: true, // F4. (가)면 true
} as const;

export function crewBand(crew: number): { min: number; max: number | null };
export function withinFogAge(ageMonths: number): boolean;
export function fogCityInfo(input: {
  live: boolean; // visibility(viewer).city(city) 결과를 F4로 보정한 값
  record: IntelRecordView | null; // 자기 국가 기록, 표시 기간 거르기 뒤
}): { intel: IntelRecordView | null; garrisonHidden: boolean };
```

- `crewBand`: 하한 배열에서 `crew` 이하인 가장 큰 하한을 `min`, 다음 하한 − 1을 `max`, 마지막 구간이면 `max: null`. 0은 `{ min: 0, max: 0 }`. 음수나 정수가 아닌 값은 예외다(기록 검증을 지난 값이라 정상 경로에서는 없다). F1이 (다)면 `{ min: crew, max: crew }`.
- `withinFogAge`: `MAX_AGE_MONTHS === null`이면 늘 참, 아니면 `ageMonths <= MAX_AGE_MONTHS`. 경계 달은 포함한다.
- 값은 서버 상수다. 게임 상태를 바꾸지 않고 재생 해시에 들어가지 않는 표시 규칙이라 `packages/rules`가 아니라 공개 범위 함수 옆에 둔다(명세 §6이 정한 경로). 이 판단은 G-03 검토 대상이다.

### 3.3 `city.get` 출력

켠 월드에서만 키 하나를 더한다.

```ts
type CityGetOutput = ReturnType<typeof cityInfo> & {
  generals: GeneralInfo[];
  fog?: {
    intel: IntelRecordView | null; // T4-12 §2.2와 같은 모양
    garrisonHidden: boolean; // F3 (나)이고 live가 아니면 true. 이때 generals는 []
  };
};
```

처리 순서는 `readWorld` 한 트랜잭션 안에서 이렇다.

1. 지금처럼 viewer, 도시, 장수를 읽는다. 없는 도시는 `NOT_FOUND`.
2. 월드 행의 `preset`으로 `worldResolver`를 만들고 `spy`가 꺼졌으면 지금 응답을 그대로 낸다. 끝.
3. `live = visibility(viewer).city(city)`. F4가 (나)면 같은 국가 도시일 때만 참이다.
4. `live`가 아니고 viewer가 국가에 속하면 `intel` 조각에서 `[viewer 국가][cityKey]` 하나를 읽어 `intelRecordInfo`로 투영하고 `withinFogAge`로 거른다. 읽기·검증 실패는 T4-12 2.3의 5단계와 같이 `INTERNAL_SERVER_ERROR`다.
5. `fogCityInfo`로 `fog`를 만들고 `garrisonHidden`이면 `generals`를 빈 배열로 낸다.

`cityInfo`와 `generalInfo`는 바꾸지 않는다. 지금 값의 공개 범위는 그대로이고 안개는 그 위에 기록만 더한다. 세션 장수가 없는 계정은 지금처럼 공개 칸을 받고 `fog.intel`은 `null`이다.

### 4.3 인수 증거

증거는 위 시험 이름과 실행 명령(`pnpm check`, `pnpm test:int`), 권한 대조 출력(새 절차가 없어 누락 0이 그대로인지), 커밋이다. AC-P2-18은 이 작업과 T4-39 화면이 모두 끝나고 반대쪽 리뷰가 끝나야 통과다.
