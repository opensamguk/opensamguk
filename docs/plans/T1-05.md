# T1-05 규칙 코어: 모델, 명령 틀, 내정 명령

> 선행: T1-03 · 관련: [명령 프로토콜](../architecture/command-protocol.md), [수치 상태 정책](../numeric-state-policy.md)

## 계획 (Claude)

### 목표

명령 하나를 정의·검사·실행·기록하는 틀을 만들고 내정 명령 8종과 휴식을 그 틀로 구현한다.
이후 모든 명령(T1-08)이 같은 틀을 쓴다.

### 범위

`packages/rules/src/` 아래:

| 경로 | 내용 |
| ---- | ---- |
| `model/` | `WorldState`(국가·도시·장수·외교 맵), 엔티티 타입 |
| `commands/types.ts` | 명령 정의 인터페이스, 결과 타입 |
| `commands/effects.ts` | 상태 변경 묶음(Effect)과 `applyEffects()` |
| `commands/registry.ts` | key → 정의 |
| `commands/domestic/*.ts` | 농지 개간, 상업 투자, 치안 강화, 정착 장려, 주민 선정, 수비 강화, 성벽 보수, 기술 연구 |
| `commands/rest.ts` | 휴식 |
| `balance.ts` | 모든 수치 상수 한곳 |

### 하지 않는 것

군사·인사·국가 명령(T1-08), 엔진 연결(T1-06), 특기·장비 보정(Phase 2), 원작과 같은 수치 맞추기.

### 명령 정의 모양 결정

```ts
interface CommandDef<Args> {
  key: string;                 // 'farm'
  name: string;                // '농지 개간'
  target: 'general' | 'nation';
  args: z.ZodType<Args>;
  precheck(view, actor, args): Failure | null;   // 예턴에 넣을 때. 경고만
  check(view, actor, args): Failure | null;      // 실행 순간. 실패면 실행 안 함
  execute(view, actor, args, rng): { effects: Effect[]; logs: LogEntry[] };
}
```

- `view`는 읽기 전용 `WorldState`. 명령은 **상태를 직접 바꾸지 않고 Effect 목록만 돌려준다.**
- Effect: `{ kind: 'city' | 'general' | 'nation', id, field, op: 'add' | 'set', value }`. `applyEffects`가 최대치·0 하한을 적용한다.
- `Failure`: `{ code: 'NOT_OWN_CITY' | 'NO_GOLD' | 'AT_MAX' | …, message }`. 실패 코드 목록은 [명령 프로토콜](../architecture/command-protocol.md)에 정리한다.
- 명령 key는 영어 소문자(`farm`, `commerce`, `security`, `settle`, `goodwill`, `defence`, `wall`, `research`, `rest`), 화면 이름은 한국어.

### 내정 공식 결정 (core2026 `che_상업투자.ts`를 단순화)

```text
점수   = 능력치 × (민심 / 100) × U(0.8, 1.2)
치명   = 10%: ×U(2.2, 3.0) 성공, 10%: ×U(0.2, 0.4) 실패, 나머지 보통   (원작은 능력치·민심에 따라 변함)
전선   = 그 도시가 교전 중인 적 도시와 이어져 있으면 ×0.5
도시값 += round(점수), 최대치에서 멈춤
경험   += round(점수 × 0.7), 공헌 += round(점수)
비용   = 금 DEVEL_COST (balance.ts)
```

| 명령 | 오르는 값 | 쓰는 능력치 |
| ---- | --------- | ----------- |
| 농지 개간 | 농업 | 지력 |
| 상업 투자 | 상업 | 지력 |
| 치안 강화 | 치안 | 무력 |
| 수비 강화 | 수비 | 무력 |
| 성벽 보수 | 성벽 | 무력 |
| 정착 장려 | 인구 | 통솔 |
| 주민 선정 | 민심 | 통솔 |
| 기술 연구 | 국가 기술 | 지력 |

- **값마다 단위가 다르다 (계획 수정, 2026-10-20 리뷰).** 원작(core2026 `che_정착장려.ts` 95행, `che_주민선정.ts` 109행)처럼 결과에 배율을 둔다.

  | 명령 | 도시값 변화 | 비용 |
  | ---- | ----------- | ---- |
  | 정착 장려 | 인구 += round(점수 × 10) | DEVEL_COST × 2 |
  | 주민 선정 | 민심 += 점수 ÷ 10 (소수 유지) | DEVEL_COST × 2 |
  | 나머지 6종 | 해당 값 += round(점수) | DEVEL_COST |

  경험·공헌은 배율 전 점수로 계산한다 (명령마다 보상이 비슷하게). 배율과 비용 배수는 `balance.ts`에 둔다.
- 공통 조건: 장수가 국가 소속, 현재 도시가 자기 국가 소유, 보급 연결, 금 ≥ 비용, 해당 값이 최대치 미만.
- RNG 소비 순서를 주석으로 고정한다: 점수 난수 → 치명 판정 → 치명 배율. 바꾸면 재생 테스트가 깨진다.

### 접근

1. 모델과 Effect, `applyEffects` + 테스트.
2. 명령 정의 인터페이스와 레지스트리.
3. 내정 공통 함수 하나 + 명령 8개(설정만 다름) + 휴식.
4. 각 명령: 성공 1건, 대표 실패 1건(소유 아님·금 부족·최대치) 테스트.
5. `balance.ts`의 값은 원작 근처로 정하고 출처를 주석 한 줄로 남긴다.

### 검증

- 단위: 고정 시드에서 농지 개간 결과(점수, 도시 농업, 경험·공헌, 금) 스냅샷
- 단위: 명령 9개 × 성공·실패
- lint: rules 경계 규칙 그대로 통과

## 구현 기록 (Codex)

- 바꾼 것: 읽기 전용 WorldView와 명령 정의·레지스트리·실패 코드, 순수 Effect 적용기, 내정 8종과 휴식을 구현했다. 0 하한·최대치·정수 반올림을 적용하고 RNG 소비 순서를 고정했다.
- 계획과 달라진 점과 이유: 내정은 공통 투자 함수와 설정 목록으로 구성했다. 금 비용 100(정착 장려·주민 선정은 200)·기술 최대 12000·민심 최대 100, 휴식 부상 회복 1을 balance.ts에서 관리한다. 휴식의 대표 실패는 존재하지 않는 장수다.
- 검증 결과: 명령 9종의 성공·실패 18개, 농지 개간 골든 결과, 소유·보급·최대치·인자 검사, 전선·치명 RNG, Effect 경계까지 22개 통과. rules 타입 검사·전체 lint 통과. Claude 리뷰 대기.

### 리뷰 반영 1차 (Codex, 2026-10-20)

- 정착 장려의 인구 증가에 ×10·정수 반올림, 주민 선정의 민심 증가에 ×0.1·소수 유지를 적용했다. 둘 다 비용은 금 200이며 사전·실행 검사에서 실제 비용을 확인한다. 단위·비용 배율은 balance.ts에 둔다.
- 경험·공헌은 도시값 단위 배율 전 점수를 사용한다. RNG 소비 순서와 기존 농지 개간 골든 결과는 유지한다.

- 명령 프로토콜과 수치 상태 정책에 단위·비용·정수화 규칙을 함께 반영했다. `pnpm check` 전체 통과: lint·타입 6개 패키지·단위 88개. Claude 재리뷰 대기.
