# INT-29 지도 바탕 게임 화면 (초안)

> AC-INT-29(초안) · 화면 Claude · 사용자 직접 요청 2026-11-14 · 짝 계획 [INT-27 3D 군략도](./INT-27.md)·[INT-28 영지 칸 내정](./INT-28.md)
> 상태: **초안**. 시안을 보이고 사용자가 고르면 결정(D 번호)으로 올린다. D-085(원작 배치 시안 A)의 화면 배치를 바꾸는 일이라 결정이 먼저다.

## 사용자 요청 (2026-11-14)

천하 전도 참고 그림을 보고 게임 화면도 바꾸자고 했다. 전체 지도를 바탕에 깔고 그 위에 UI를 배치한다.

참고 그림의 배치:

- 위 띠: 세력 표지·군주 이름·도시·장수 수, 다음 턴, 군령 막대, 공수 기세 막대, 금·쌀 등 자원, 알림, 메뉴.
- 왼쪽 위: 둥근 큰 단추 넷(건설·장수·정책·설정)과 작은 단추 줄(부대·연결·문서·메시지, 읽지 않은 수 표시).
- 오른쪽 가장자리: 세로 메뉴(친구·서열·통계·외교·정보·상점).
- 왼쪽 아래: 기록 창과 탭(전체·전투·세력·시스템·귓속말), 접기·펼치기.
- 오른쪽 아래: 나침반(北), 확대·축소·전체 단추, 작은 전도(미니맵)와 격자 표시·배율.
- 맨 아래 줄: 커서 칸 좌표·지형·설치 가능 여부, 시야 아군·적군 수, 서버 시각, 지연.

## 지금 상태 (2026-11-14)

- 메인 `/w/:id`는 D-085 시안 A 배치다. 위 띠와 공통 메뉴 띠 아래에 지도(왼쪽)와 예턴 30칸(오른쪽)이 있다. 그 아래에 국가·내 장수 메뉴 2줄, 도시, 국가·장수, 기록 3칸, 메시지가 차례로 쌓인다.
- 3D 지도는 `?map=3d`일 때만 켜지는 시제품이다(INT-27). 2:1 판, 영지 칸·국경·깃발이 있다.
- 전용 화면(현재 도시·세력 정보·통치·휘하·내 정보 등)은 주소가 따로 있다.

## 성공 기준

| 기준 | 값 |
| --- | --- |
| 한 화면 | 1440×900에서 메인이 스크롤 없이 한 화면이다. 지도가 화면 넓이의 100%를 바탕으로 쓴다 |
| 원작 정보 | D-085가 메인에 둔 정보(도시 수치 8칸, 국가 18항목, 장수 정보, 예턴 30칸, 기록 3칸, 메시지 4칸)가 모두 한 번 누르기 안에 열린다 |
| 지도 가림 | 아무 창도 열지 않았을 때 UI가 덮는 넓이가 화면의 25% 이하 |
| 첫 화면 | 지도 바탕 첫 프레임 데스크톱 2초 이하, 휴대폰 4초 이하. WebGL2가 없으면 SVG 지도 바탕 |
| 접근성 | 키보드로 모든 단추·창에 닿는다. 창은 Esc로 닫는다. 글자 대비 4.5:1. 375px 휴대폰에서도 같은 기능 |
| 시험 | 기존 실제 Chromium E2E 전체 통과(선택자 이전 포함) |

## 기본안 (추천)

1. **바탕:** 메인은 3D 지도(없으면 SVG)를 화면 전체에 깐다. 위 띠와 맨 아래 줄만 지도를 가리는 고정 띠다.
2. **위 띠:** 지금 위 띠(로비·월드·연월·다음 턴·실시간·계정)에 내 세력 표지, 군주·도시·장수 수, 금·쌀, 알림을 더한다.
3. **왼쪽 위 단추:** 둥근 단추 넷은 우리 메뉴로 바꾼다. 명령(예턴), 장수(내 장수 메뉴), 국가(국가 메뉴), 설정이다. 누르면 왼쪽 서랍이 열린다. 작은 단추 줄은 휘하·부곡, 제안함, 메시지, 기록이다. 읽지 않은 수를 표시한다.
4. **오른쪽 세로 메뉴:** 지금 공통 메뉴 띠(세력 일람·장수 일람·순위·기록·영토 재생·첩보 기록·전투 시뮬레이터·도움말)를 옮긴다.
5. **창:** 도시·국가·장수 정보와 예턴 30칸은 지도 위에 뜨는 창(서랍)이다. 지도에서 도시를 누르면 도시 창이 열린다. 창은 겹쳐 열 수 있다. 지도는 창 뒤에서 계속 움직인다.
6. **왼쪽 아래 기록 창:** 탭은 전체·전투·세력·시스템·메시지다. 원작 기록 3칸(장수 동향·개인 기록·중원 정세)과 메시지 4칸(전체·국가·개인·외교)을 이 탭에 나눈다. 접으면 한 줄만 남는다.
7. **오른쪽 아래:** 나침반, 확대·축소·전체, 작은 전도(나라 색 영지와 지금 보는 범위 네모)를 둔다. 작은 전도를 눌러 그 자리로 간다.
8. **맨 아래 줄:** 커서가 가리키는 칸의 좌표·지형·영지 주인(INT-28), 서버 시각, 지연.
9. **휴대폰:** 지도 바탕은 같다. 왼쪽 위 단추와 오른쪽 메뉴는 아래 탭 막대로 모은다. 창은 아래에서 올라오는 시트다.
10. **전용 화면:** 지금 주소는 그대로 둔다. 같은 내용을 메인에서는 창으로, 주소로 들어오면 지도 바탕 위 큰 창으로 연다.

## 위험

- D-085와 충돌: 원작 배치(시안 A)를 바꾼다. 원작 정보 동등성은 유지하고 배치만 바꾸는 새 결정이 필요하다.
- E2E: 메인 배치에 기댄 선택자가 많다. 창을 여는 단계가 늘어난다. 시험 도우미에 "창 열기"를 두고 한꺼번에 옮긴다.
- 성능: 메인에 늘 3D 지도가 돈다. 창이 열려 지도가 가려지면 그리기를 멈춘다. 저사양은 SVG 바탕을 쓴다.
- 정보 밀도: 원작은 한 화면에 수치를 많이 펼친다. 창 하나에 원작 칸 배치를 그대로 담아 한눈에 보이게 한다.

## 단계

0. 시안: 기본안과 대안 둘(창 대신 고정 옆판, 원작 배치 위에 지도만 크게)을 실물 시안으로 보인다. 사용자가 고른 안을 결정으로 올린다.
1. 껍데기: 지도 바탕, 위 띠, 맨 아래 줄, 왼쪽 위 단추, 오른쪽 메뉴, 오른쪽 아래 조작부. 지금 메인 내용은 창 하나에 임시로 담는다.
2. 창 나누기: 도시·국가·장수·예턴·기록·메시지 창, 지도 고르기와 연결.
3. 작은 전도와 칸 정보 줄(INT-28 영지 계약을 읽는다).
4. 휴대폰 시트, E2E 이전, 375/768/1440·라이트/다크·대비 검증.
