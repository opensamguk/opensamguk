## 사용자 요청 (2026-11-14)

천하 전도 참고 그림을 보고 게임 화면도 바꾸자고 했다. 전체 지도를 바탕에 깔고 그 위에 UI를 배치한다.

참고 그림의 배치:

- 위 띠: 세력 표지·군주 이름·도시·장수 수(우리 화면은 그 앞에 플레이어 장수를 둔다), 다음 턴, 군령 막대, 공수 기세 막대, 금·쌀 등 자원, 알림, 메뉴.
- 왼쪽 위: 둥근 큰 단추 넷(건설·장수·정책·설정)과 작은 단추 줄(부대·연결·문서·메시지, 읽지 않은 수 표시).
- 오른쪽 가장자리: 세로 메뉴(친구·서열·통계·외교·정보·상점).
- 왼쪽 아래: 기록 창과 탭(전체·전투·세력·시스템·귓속말), 접기·펼치기.
- 오른쪽 아래: 나침반(北), 확대·축소·전체 단추, 작은 전도(미니맵)와 격자 표시·배율.
- 맨 아래 줄: 커서 칸 좌표·지형·설치 가능 여부, 시야 아군·적군 수, 서버 시각, 지연.

## 지금 상태 (2026-11-14)

- 메인 `/w/:id`는 D-085 시안 A 배치다. 위 띠와 공통 메뉴 띠 아래에 지도(왼쪽)와 예턴 30칸(오른쪽)이 있다. 그 아래에 국가·내 장수 메뉴 2줄, 도시, 국가·장수, 기록 3칸, 메시지가 차례로 쌓인다.

## 기본안 (추천)

1. **바탕:** 메인은 3D 지도(없으면 SVG)를 화면 전체에 깐다. 위 띠와 맨 아래 줄만 지도를 가리는 고정 띠다.
2. **내 장수(플레이어):** 위 띠 맨 앞에 플레이어가 맡은 장수를 늘 보인다(사용자 요청 2026-11-14). 원형 초상(icon)과 나라 표지, 이름과 나 표시, 소속·관직·주둔 도시, 통솔·무력·지력·병력, 개인 금·쌀이다. 누르면 내 정보 화면이 열린다. 왼쪽 판은 나와 휘하로 내 장수를 맨 위에 두고 휘하·부곡을 그 아래에 둔다. 예턴 판 제목은 내 예턴 · 장수 이름이다. 맨 아래 줄에도 플레이 중인 장수를 적는다.
3. **위 띠:** 지금 위 띠(로비·월드·연월·다음 턴·실시간·계정)에 내 세력 표지, 군주·도시·장수 수, 금·쌀, 알림을 더한다.
4. **왼쪽 위 단추:** 둥근 단추 넷은 우리 메뉴로 바꾼다. 명령(예턴), 장수(내 장수 메뉴), 국가(국가 메뉴), 설정이다. 누르면 왼쪽 서랍이 열린다. 작은 단추 줄은 휘하·부곡, 제안함, 메시지, 기록이다. 읽지 않은 수를 표시한다.
5. **오른쪽 세로 메뉴:** 지금 공통 메뉴 띠(세력 일람·장수 일람·순위·기록·영토 재생·첩보 기록·전투 시뮬레이터·도움말)를 옮긴다.
6. **창:** 도시·국가·장수 정보와 예턴 30칸은 지도 위에 뜨는 창(서랍)이다. 지도에서 도시를 누르면 도시 창이 열린다. 창은 겹쳐 열 수 있다. 지도는 창 뒤에서 계속 움직인다.
7. **왼쪽 아래 기록 창:** 탭은 전체·전투·세력·시스템·메시지다. 원작 기록 3칸(장수 동향·개인 기록·중원 정세)과 메시지 4칸(전체·국가·개인·외교)을 이 탭에 나눈다. 접으면 한 줄만 남는다.
8. **오른쪽 아래:** 나침반, 확대·축소·전체, 작은 전도(나라 색 영지와 지금 보는 범위 네모)를 둔다. 작은 전도를 눌러 그 자리로 간다.
9. **맨 아래 줄:** 커서가 가리키는 칸의 좌표·지형·영지 주인(INT-28), 서버 시각, 지연.
10. **휴대폰:** 지도 바탕은 같다. 왼쪽 위 단추와 오른쪽 메뉴는 아래 탭 막대로 모은다. 창은 아래에서 올라오는 시트다.
11. **전용 화면:** 지금 주소는 그대로 둔다. 같은 내용을 메인에서는 창으로, 주소로 들어오면 지도 바탕 위 큰 창으로 연다.

## 위험

- D-085와 충돌: 원작 배치(시안 A)를 바꾼다. 원작 정보 동등성은 유지하고 배치만 바꾸는 새 결정이 필요하다.
- E2E: 메인 배치에 기댄 선택자가 많다. 창을 여는 단계가 늘어난다. 시험 도우미에 창 열기를 두고 한꺼번에 옮긴다.
- 성능: 메인에 늘 3D 지도가 돈다. 창이 열려 지도가 가려지면 그리기를 멈춘다. 저사양은 SVG 바탕을 쓴다.
- 정보 밀도: 원작은 한 화면에 수치를 많이 펼친다. 창 하나에 원작 칸 배치를 그대로 담아 한눈에 보이게 한다.

## 1단계 결과 (2026-11-14)

- 주소 `/w/:id?ui=map`이면 `apps/web/src/stage/MapStage.tsx`가 메인 대신 열린다. 다른 값이나 없으면 기존 메인이다(`router.tsx`).
- 바탕: WebGL2가 되면 주소의 `map=3d` 없이도 3D 군략도를 화면 가득(빈 띠 없이) 그린다. 배율 단추와 거점 고르기 상자는 오른쪽 아래에 뜬다(Map3D `stage`). WebGL2가 없으면 SVG 운영 지도다.
- 위 띠: 내 장수(원형 초상, 나라 표지, 이름과 나 표시, 소속·관직·도시, 통솔·무력·지력·병력·금·쌀, 누르면 내 정보), 소속 국가(도시·장수 수, 국고), 연월·다음 턴·턴 길이, 메시지(안 읽은 수), 기존 화면, 메뉴(국가·내 장수 메뉴, 로비, 계정).
- 왼쪽 나와 휘하 판: 내 장수·도시·국가 탭. 기존 GeneralInfo·CityInfo·NationInfo를 그대로 쓴다. 지도에서 도시를 누르면 도시 탭이 열린다.
- 오른쪽 내 예턴 판: 기본 방침과 30칸 예턴 편집기, 군사 조언. 닫아도 편집기를 내리지 않아 저장하지 않은 편집이 남는다.
- 왼쪽 아래 기록(접기·펼치기), 맨 아래 상태 줄(플레이 장수, 고른 거점, 연월, 다음 턴).
- 휴대폰(900px 미만): 판은 닫힌 채로 열고 아래쪽 손잡이로 연다. 위 띠는 내 장수와 메시지·메뉴만 둔다.
- 확인: 1600×900과 375×812에서 화면을 봤다. 지도에서 낙양을 누르면 주소에 city가 붙고 도시 탭이 열렸다. 웹 시험 187개, 타입 검사, 린트 통과. 새 화면 E2E는 4단계에서 더한다.
- 남은 것: 휘하·부곡 목록(지금은 내 장수만), 명령 카드 격자, 판 몸통의 옻칠 빛 테마(지금은 기존 부품의 밝은 바탕), 작은 전도, 칸 정보 줄(INT-28 서버 영지), 휴대폰 시트, E2E.

사용자 요청(2026-11-14): 기록과 모든 글에 나오는 장수·세력 이름 등에 효과를 준다.

서버 기록은 평문이라 월드의 장수·세력·도시 이름 목록(world.map 캐시)으로 글 안의 이름을 찾는다. 긴 이름 먼저, 이름 앞은 한글이 아닌 글자, 한 글자 이름(위·촉·오·업·완)은 뒤가 조사·경계일 때만 잡는다. 같은 이름이면 세력 → 장수 → 도시 순서다.

| 대상 | 효과 | 상태 |
| --- | --- | --- |
| 장수 | 원형 초상(소속 세력색 테두리) + 굵은 이름 + 세력색 밑줄. 안개로 목록에 없는 줄 주인공은 줄 자료의 초상으로 붙인다 | 기록에 적용 |

| 숫자 | 굵게·자릿수 고정폭. 부호 +는 초록, −는 빨강 | 기록에 적용 |
| 기록 종류 | 줄 앞 아이콘: 점령·승리·패배·교전·내정·배신·건국·멸망·선전포고·성공·실패·월단평, 색조 5가지(전쟁·좋음·나쁨·국가·평온) | 기록에 적용 |
| 관문·나루 | 관문 아이콘(관), 나루 아이콘 | 다음 |
| 병종 | 병종 아이콘(보·궁·기·차·수) + 이름 | 다음 |

| 날짜 | 작은 먹색 고정폭(지금 그대로) | 유지 |
