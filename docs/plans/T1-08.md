# T1-08 전쟁·점령·멸망·보급, MVP 명령 37개 완성

> 선행: T1-07 · 관련: [PRD §6.3](../product/prd.md#63-mvp-명령-세트), [명령 프로토콜](../architecture/command-protocol.md)

## 계획 (Claude)

### 목표

- MVP 명령 37개 각각에 성공 1건·대표 실패 1건 테스트가 있고 명령 목록과 테스트 목록이 자동으로 대조된다 (AC-M1-14).
- 출병하면 수비 장수와 차례로 싸우고 성벽을 거쳐 점령한다. 마지막 도시를 잃은 국가는 멸망하고 장수는 재야가 된다 (AC-M1-15).
- 보급 끊김과 회복 (AC-M1-16, 계산은 T1-07에 있음. 여기서는 점령으로 끊기고 되찾으면 풀리는 시나리오 테스트).

### 남은 명령 (T1-05의 내정 8 + 휴식 이후)

| 분류 | 명령 |
| ---- | ---- |
| 군사 (8) | 모병, 징병, 훈련, 사기진작, 출병, 이동, 귀환, 소집해제 |
| 인사·전략 (7) | 임관, 무작위 임관, 건국, 거병, 하야, 등용, 등용 수락 |
| 개인 (3) | 요양, 군량매매, 헌납 |
| 국가 (10) | 휴식, 포상, 몰수, 발령, 천도, 선전포고, 종전 제의, 불가침 제의, 불가침 파기 제의, 원조 |

- 국가 명령 실행 주체: M1은 **군주만**. 국가 예턴(`NationTurn`)은 군주 턴에 장수 예턴과 함께 1칸씩 실행한다.
- 종전·불가침·파기·원조는 M1에서 **"제안이 기록되고 NPC 국가는 규칙대로 즉시 수락·거절"**까지만. 사람 사이 제안·수락 화면은 M2(D1 조약서)에서 대체한다.

### 전투 결정 (core2026 `packages/logic/src/war/`를 크게 단순화)

```text
출병(목표 도시: 연결된 교전 상대 도시)
  수비 순서: 그 도시의 수비 참여 장수(병력 > 0, 훈련·사기 ≥ 수비 기준)를 병력 많은 순 → 마지막에 성벽
  한 교전: 최대 N 페이즈. 페이즈마다 양쪽 피해 = 공격력 × 병종 상성 × 훈련·사기 보정 × U(0.9, 1.1)
           한쪽 병력이 0이거나 사기가 바닥이면 끝
  성벽:   성벽을 병종 '성벽'(수비 + 성벽치)으로 보고 같은 방식. 성벽 0이면 점령
  점령:   도시 소유 변경, 수비 0, 치안·민심 하향, 공격 장수가 그 도시로 이동
  멸망:   국가 소유 도시 0 → 국가 멸망, 소속 장수 재야, 국가 예턴 삭제, 연감·역사 기록
```

- 병종 상성은 `resources/unitset/basic.json`의 `attackCoef`·`defenceCoef`를 그대로 쓴다.
- 군량: 교전마다 병력 비례로 쌀 소모. 쌀이 0이면 사기 급감.
- 페이즈 수, 피해 계수, 보정 표는 `balance.ts`. 시뮬레이터(T1-09)로 조정한다.
- 전투 로그: 양쪽 장수 로그와 국가 역사에 한 줄씩 (누구와, 남은 병력, 점령 여부).

- 공유 파일 범위: `turnLoop.ts`의 명령 실행·국가 예턴 연결, `persist.ts`의 world 효과 분기, Prisma의 NationTurn·BattleLog·World.commandMeta와 새 migration. InputEvent·기존 migration·general.create는 그대로 둔다. phases는 T1-08 행만 바꾼다.
- 바꾼 것: 장수 27개·국가 10개를 registry에 등록했다. 신규 28개의 category 값은 총괄 결정(military·strategy·personal·nation)을 따랐다. 공통 category 필드와 기존 9개 값은 T1-11 소유다. 최종 key·target·인자 표와 실패 코드는 command-protocol §4에 적었다.
- 바꾼 것: 수비 순서·동시 피해·군량·성벽·점령·멸망과 보급 즉시 표시를 순수 규칙으로 구현했다. 월간 보급 계산도 같은 연결 함수를 쓴다. 국가 예턴과 장수 예턴은 군주 턴 한 트랜잭션에서 실행하며 기존 장수 RNG 스트림을 유지했다. 상태 변경·국가 역사·수비 BattleLog·예턴·revision·sequence와 마지막 펜싱 검사를 함께 저장한다.
- 바꾼 것: 새 migration `20261021030000_commands_war`에 NationTurn·BattleLog·World.commandMeta를 추가했다. InputEvent와 기존 migration은 수정하지 않았다. 건국·등용 제안·국가 예턴을 초기 기록과 재생 해시에 포함했다. 두 채울 문서를 작성했고 주민 선정 로그는 상태 정밀도를 유지한 채 소수 1자리로 표시한다.
