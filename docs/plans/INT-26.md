## 계획 (Claude)

### 목표

사용자가 2026-11-13 정했다. 원작 화면에 나오는 정보가 우리에게 없으면 넣을지 묻지 않고 넣는다. 우리 규칙에 개념이 없으면 규칙부터 넣는다. 원작 화면 53장면과 명령 인자 화면을 우리 화면·응답·규칙과 줄마다 대조해 284건을 찾았다.

| 분류 | 건수 | 맡는 곳 |
| --- | --- | --- |
| 응답에 이미 있고 화면만 없다 | 100 | INT-25 PR 3 (Claude) |
| 규칙·DB에는 있고 응답에 없다 | 69 | 이 작업 |
| 규칙에 개념이 없다 | 81 | 이 작업 |
| 결정 기록으로 뺀 것 | 34 | 사용자 확인 뒤 정한다 |
