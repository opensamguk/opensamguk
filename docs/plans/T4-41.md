## 2. 화면 계약

### 2.1 30칸 시각

```ts
// apps/web/src/turns/schedule.ts (바뀐 서명)
export function slotTimes(
  count: number,
  clock: Clock | undefined,
  nextTurnTick: number | undefined,
  schedule: readonly string[] | null | undefined, // home.get.turnSchedule
  now = new Date(),
): SlotTime[];
```

- 칸 `i`의 `iso`는 `schedule[i]`, `time`은 `formatTime(new Date(schedule[i]), now)`다. `schedule`이 null이거나 칸이 모자라면 그 칸 시각은 비운다. 화면은 다른 칸 값으로 채우지 않는다.
- 연월은 지금 식 그대로(tick으로 셈).
- 파일 머리 주석(`schedule.ts:1-3`)을 서버 30칸 값만 쓴다는 문장으로 고친다.
- `nextTurnAt` 인자는 없어진다. 첫 칸은 서버 계약상 `turnSchedule[0] = nextTurnAt`이다(T4-40 2.5.1).

### 2.2 휴전 안내 (`TruceNotice`)

`world.summary.truce`가 null이면 아무것도 그리지 않는다. 있으면 위쪽 띠 바로 아래 한 줄이다.

| 상태 | 문구 |
| ---- | ---- |
| `active` | `야간 휴전 중입니다. {endsAt}에 시계가 다시 갑니다.` 강조 색 없이 `--color-info` 테두리와 글자 |
| 휴전 밖 | `매일 {시작}부터 {끝}까지 휴전합니다. 그동안은 턴이 진행되지 않습니다.` 보조 글자색 |

- `{시작}`·`{끝}`은 서버의 `nextStartsAt`·`nextEndsAt`을 보는 사람의 지역 시각 시:분으로 적는다. 화면은 휴전 시각을 스스로 계산하지 않는다.
- 월드가 RUNNING이 아니어도 설정은 보인다. 위쪽 띠 상태 문구가 정지·종료를 따로 알린다.
- `role="status"`가 아니라 일반 글이다. 바뀔 때만 `aria-live="polite"` 칸에서 읽는다(2.4).

### 2.3 위쪽 띠 상태 문구

`topbarStatus(world, noGeneral, countdown, remaining)`의 순서에 한 갈래를 더한다. RUNNING이 아니면 지금 문구, 가속이면 `가속 진행 중`, 그다음 `world.truce?.active`이면 `휴전 중 · {endsAt 시:분} 재개`, 그 뒤는 지금 순서(`내 장수 없음`, 남은 시간)다. 남은 시간은 휴전 밖에서 지금처럼 서버 `nextTurnAt`으로 센다. 휴전이 끝나는 순간 서버 `nextTurnAt`이 그대로이므로 화면이 따로 무효화할 것이 없다. 0초 재조회 규칙(`countdown.ts`)도 그대로다.

### 2.4 접근성

- 위쪽 띠 상태 칸은 지금처럼 `aria-live="off"`다. 휴전 시작·끝은 `TruceNotice` 안의 숨은 `aria-live="polite"` 칸이 한 번 읽는다(문구가 바뀔 때만).
- 칸 시각은 지금처럼 `<time dateTime>`이다. 색에 기대지 않는다.

## 3. 시험

### 3.1 단위 (`pnpm check`)

| ID | 대상 | 확인 |
| -- | ---- | ---- |
| W1 | `slotTimes` | 서버 배열 30칸을 그대로 쓴다. T4-40 R2의 시각(22:00, 23:00, 다음 날 08:00, 09:00)을 넣으면 그 값이 나온다. 배열이 null·짧음·잘못된 문자열이면 그 칸만 비운다. 연월은 지금 시험값과 같다 |
| W2 | 끈 월드 골든 | 지금 `turns.test.ts:172`의 입력에서 서버 배열을 `nextTurnAt + i × 턴 간격`으로 준 결과가 바뀌기 전 `slotTimes`의 결과와 칸마다 같다 |
| W3 | 계산 금지 | `schedule.ts`에 `turnTermMinutes × 60000`으로 시각을 더하는 식이 남지 않았다(소스 검사) |

### 3.2 Chromium E2E (`e2e/truce.spec.ts`, `pnpm e2e`)

`e2e/truceSeed.ts`는 휴전 칸이 있는 프리셋 사본으로 시험 월드를 만든다. 휴전 구간은 시험이 도는 순간의 UTC 시각으로 잡는다. 휴전 안 시험은 지금 −1시간부터 +2시간까지, 휴전을 건너는 시험은 지금 +30분부터 +3시간까지다. 그래서 하루 중 언제 돌아도 같은 흐름이 된다. 턴 간격은 60분이다.

| ID | 흐름 | 확인 |
| -- | ---- | ---- |
| E1 | 휴전 안 월드의 메인 | 안내 띠 `야간 휴전 중입니다`, 위쪽 띠 `휴전 중 ·` 문구 |
| E2 | 휴전을 건너는 월드의 메인 30칸 | 각 칸 `time[datetime]`이 같은 순간 받은 `home.get.turnSchedule[i]`와 같다. 칸 0의 값은 `nextTurnAt`과 같다. 휴전 시작 앞 칸 다음 칸은 휴전 끝 뒤 시각이다 |
| E3 | 같은 월드의 단독 편집기(`/w/:worldId/turns`) | E2와 같은 30칸 값 |
| E4 | 같은 월드의 장수 정보 다음 턴 | `nextTurnAt`과 같은 시각 |
| E5 | 끈 월드(기존 시험 월드) | 안내 띠 없음. 30칸 `datetime`이 `nextTurnAt + i × 턴 간격`과 같다(골든). 지금 main에서 같은 시험이 같은 값을 낸다 |
| E6 | 375px 폭 | 안내 띠가 줄바꿈되고 가로 스크롤이 없다 |

E2·E3은 같은 tick에서 비교해야 한다. 시험은 `home.get` 응답을 받은 직후 화면의 칸을 읽는다. 그 사이 턴이 지나 `nextTurnTick`이 바뀌었으면 한 번 다시 받는다.
