## 계획

목표는 v1 bc053629 scenario_3190의 personPolicies 1000행에서 필요한 491명만 대조한다. 이름만 같은 458후보도 인물/출처 ID를 확인한다. 미대응33명의 숫자 별칭·동명이인·미수록을 해결하고 모든5값과 출처를 정식 원장에 남긴다. 값 추정·복사·0 채움·main491 ID 변경은 하지 않는다.

수정 범위는 tools/ (새 이식 검사 도구), resources/scenario/, resources/NOTICE.md다. 새 기능을 더하지 않는다. 기존 main·v1 기준 SHA와 자원 출처는 통합 기준 문서를 따른다. 세부 코드 경계·API 인증·엔진 단독 상태 변경·시드 RNG·턴 트랜잭션을 지킨다.

검증은 491/491의 5능력치/범위/인물 ID/출처/리뷰 상태 검사, 누락·중복·별칭 잘못 결합을 실패 처리, 생성/로드·출처 고지·기존 시나리오 보존. 미해결은 막힘으로 보고하며 통과로 세지 않는다.

선행 인수 뒤 착수하고 검증 결과와 구현하지 않은 담당의 리뷰를 같은 문서에 남긴다. 구현자가 스스로 완료로 바꾸지 않는다.
