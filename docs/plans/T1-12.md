# T1-12 조회 API: 메인·지도·도시·국가·기록

> 대기열: T1-12 · AC: AC-M1-19 (API) · 구현: Codex · 리뷰: Claude

## 계획 (Claude)

### 목표

핵심 화면 6개(메인, 지도, 예턴 편집, 도시 정보, 국가 정보, 기록)가 쓸 읽기 API를 만든다.
예턴 편집은 T1-11이 이미 제공한다.

### 범위

`apps/server/src/routers/world.ts`, `city.ts`, `nation.ts`, `records.ts`. 모두 읽기 전용 `protectedProcedure`.

### 하지 않는 것

실시간 갱신(M2 SSE), 첩보·안개(D13 Phase 2), 순위 화면(M2).

### 공개 범위 결정

| 정보 | 누구에게 |
| ---- | -------- |
| 지도의 도시 소유·연결·보급 표시 | 모두 |
| 도시 수치(인구·내정·수비·성벽) | 자기 국가 도시, 또는 내 장수가 있는 도시 |
| 도시의 주둔 장수 | 자기 국가 장수만 상세, 다른 국가 장수는 이름·소속만 |
| 장수 금·쌀·병력·훈련·사기 | 본인과 같은 국가 장수 |
| 국가 국고·군량·세율 | 그 국가 소속만. 다른 국가는 이름·색·도시 수·장수 수 |

공개 범위 판단은 server의 한 함수(`visibility.ts`)에 모으고 테스트한다.

### API 계약 (화면이 쓸 모양)

```ts
world.summary({ worldId }) → { name, status, gameDate: { year, month }, nowTick, msPerTick, turnTermMinutes }
world.map({ worldId })     → { cities: [{ key, name, level, x, y, nationId | null, supplied, links: key[] }],
                                nations: [{ id, name, color }] }
home.get({ worldId })      → { general: {...본인 전체}, city: {...}, nation: {...} | null,
                                nextTurnAt(ISO), turnsPreview: Slot[5], recentLogs: Log[10] }
city.get({ worldId, cityKey })   → 공개 범위에 따라 필드가 빠진 도시 정보
nation.get({ worldId, nationId }) → 공개 범위에 따라 필드가 빠진 국가 정보 + 소속 장수 목록 + 소유 도시 목록
records.general({ worldId, cursor? }) → 내 장수 로그 (최신순, 30개씩)
records.nation({ worldId, cursor? })  → 내 국가 역사
records.world({ worldId, cursor? })   → 월드 정세
```

- `nextTurnAt`은 서버가 tick → 현실 시각으로 바꿔 준다. 화면은 직접 계산하지 않는다 (v1 UI 원칙).
- 숫자는 정수 그대로, 표시 형식은 화면이 정한다.

### 검증

| 무엇 | 어떻게 |
| ---- | ------ |
| 응답 모양 | API 테스트: 고정 시드 월드에서 각 procedure 스냅샷 |
| 공개 범위 | 단위(`visibility.ts`): 아군·적·재야 × 도시·국가·장수 표 |
| 권한 | 무인증 `UNAUTHORIZED`, 다른 국가 국고 요청 → 필드 없음 |
| 성능 | 지도 조회 1회 < 50ms (로컬, 94도시) |

- 고정 DTO와 T1-16 인계:
  - `world.summary`와 `world.map`은 계획의 필드명 그대로다. `city.get`의 도시 키도 지도와 같은 `key`이며 `generals`는 ID순 주둔 장수 목록이다. 적 장수는 `{ id, name, nationId }`만 반환한다.
  - `nation.get`은 `{ id, name, color, cityCount, generalCount, cities, generals }`가 공개 필드다. 도시는 지도의 공개 모양이며 장수 상세는 같은 국가만 본다. 소속국은 추가로 `description, tech, philosophy, level, capitalCityKey, gold, rice, taxRate`를 받는다.
  - `home.get`은 계획대로 `general, city, nation, nextTurnAt, turnsPreview, recentLogs`를 반환한다. 장수 상세는 T1-11의 `OwnGeneral`과 같은 게임 수치만 담는다. `userId, affinity, turnRevision`은 제외한다. 예턴은 `{ slot, commandKey, args }` 5개다. 없는 슬롯은 응답에서만 휴식으로 채운다. 로그는 `{ id: string, tick, commandKey, kind, text }`다. `PREOPEN/PAUSED/ENDED`에는 `nextTurnAt: null`이다. 실행 중에는 저장 tick·anchor와 분수 tick 간격을 그대로 써서 ISO 시각을 계산한다. 이미 지났으면 과거의 예정 시각을 반환한다.
  - 기록 응답은 모두 `{ items, nextCursor: string | null }`다. cursor는 마지막 항목의 tick을 10진 문자열로 넘긴다. 범위별 tick 고유키를 이용해 최신순 30개를 읽고 더 없으면 null이다. 요청에 장수·국가 ID를 넣어 권한을 고를 수 없다. cursor `0`은 빈 페이지다.
  - `records.general`은 세션 장수의 로그만 읽는다. `records.nation`은 현재 소속국의 `{ tick, nationId, cities, generals, gold, rice }` 월간 기록이다. 재야는 빈 페이지다. `records.world`는 `{ tick, year, month, nations: [{ nationId, cities, generals }], cities: [{ cityKey, nationId }] }` 공개 연감이다. 국력(`power`)도 비공개 자원·병력을 추정할 수 있어 제외한다.
- 계획과 달라진 점과 이유: 현재 국가 schema에 세율 필드가 없어 규칙의 고정 `BALANCE.MONTHLY_TAX_RATE`를 읽는다. 국가 역사·월드 정세는 T1-07에 저장된 월간 기록·연감을 사용하며 사건·전투 로그를 새로 만들지 않는다. 장수가 없는 인증 계정도 공개 조회는 가능하다. `home.get`, 개인·국가 기록은 장수가 없으면 404다. 정지 상태에는 예정 시각을 알 수 없어 null로 고정했다.
- 저장·조회 계약의 소스는 `49a96ae2370b30f8b4ed093155c50ecd8f1412a1`이다. `records.world`는 `packages/db/prisma/schema.prisma`의 `YearbookSnapshot`(월드·tick 고유키)을 읽는다. ## 사건 전용 국가 기록 수정 (Codex)

카드 `t_fb3208c8`은 main `888a4df`에서 시작했다. T1-08의 명령 사건과 T1-12의 월간 요약이 `NationHistory`를 함께 쓰면서 사건 전용 JSON이 요약 파싱을 깨뜨렸다. `records.nation`은 세션 장수 소속국과 JSON의 `nationId`를 DB에서 함께 검사한다. 사건 전용 행은 정렬·LIMIT 31 전에 빠진다. 응답 모양, 최신순 30개와 cursor, 재야·인증·월드 경계는 유지한다. 요약에 붙은 `events`는 기존 허용 목록에서 빠진다. 사건 표시와 web·e2e 변경은 범위 밖이다.

실제 PostgreSQL·TCP HTTP 회귀에는 국가·월드별 요약 35개, 요약 앞 사건 40개, 사이 사건 35개, 뒤 사건 40개를 섞었다. 기존 페이지 시험으로 30개·나머지 5개·정확히 30개·빈 페이지·중복 없음을 검사한다. 사건이 붙은 요약의 정확한 응답과 사건 전용 국가의 빈 응답도 검사한다. 기존 타국가·재야·무인증·위조·만료·제재·미생성 시험은 그대로 실행한다.

`TurnLoop`는 월 경계 정산을 같은 tick 명령보다 먼저 실행한다. 그래도 경계에 이미 사건이 있으면 기존 `createMany`는 고유키 충돌로 트랜잭션을 실패시킨다. tests-only `e479489`의 [실패 CI](https://github.com/peppone-choi/opensamguk/actions/runs/39569068985)에서 HTTP 500과 `NationHistory_pkey`의 `P2002`를 모두 재현했다. 월드 잠금 안에서 기존 JSON과 요약을 합쳐 upsert하도록 고쳤다. 회귀는 정산 전 사건 두 개와 정산 후 사건 하나의 보존, 요약 수치, 정산 재호출의 중복 없음과 재생 해시를 검사한다. 기존 정산 롤백·재시작 시험도 유지한다.

로컬 의존성 설치는 공유 메모리 제한으로 exit 75였다. 우회하지 않고 표준 GitHub CI에서 검사한다. 수정 head의 CI와 독립 리뷰는 PR·카드 인계에서 확인한다. T1-16 PR #48의 메인 화면 단언은 이 수정이 main에 병합된 뒤 T1-16 담당이 다시 실행한다. 이 기록만으로 AC-M1-19 전체를 완료 처리하지 않는다.
