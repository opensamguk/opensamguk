# T2-14 기본 방침 설정 화면

> 대기열: T2-14 · AC: AC-M2-17 (화면) · 구현: Claude · 리뷰: Codex
> 선행: T2-13 (API)

## 계획 (Claude)

### 목표

장수가 기본 방침을 고르고 빈 칸이 실제로 무엇을 할지 예턴 편집에서 미리 본다.

### 범위

`apps/web`: 메인의 지도와 T1-15의 재사용 30칸 편집기 `TurnEditor`(`apps/web/src/turns/TurnEditor.tsx`, 메인 배치는 합쳐진 T1-16의 `apps/web/src/pages/MainPage.tsx:80`, `:99`) 위쪽의 방침 선택, 편집기 안의 빈 칸 표시, 메인 장수 요약의 방침 표시.
별도 페이지나 앞 5칸만으로 기능을 끝내지 않는다 (검토 R63-8).

### 화면

- 예턴 편집 위: `기본 방침: [권농 ▾]  빈 칸은 '농지 개간'을 합니다. 실패하면 휴식합니다.`
- 빈 칸은 흐린 글씨로 "(권농) 농지 개간"이라고 보여 준다. 직접 넣은 휴식은 진한 "휴식"으로 구분.
- 미접속 안내를 한 줄로 둔다. 날 수는 `inactiveAfterDays`를 쓴다. 문장은 T2-13 사용자 결정 U63-1·U63-2가 정해진 뒤 그 내용대로 쓴다.
- 방침 바꾸기는 예턴 저장과 별개로 고르는 즉시 보낸다. 엔진이 처리하기 전에는 고른 방침 옆에 처리 중을 둔다. `applied`를 받거나 다시 읽은 `pending`이 null이 되면 확정으로 보여 준다(T2-13 방침 바꾸기 처리). `lastRejected`가 있으면 이유를 보여 주고 고르기 칸을 `current`로 되돌린다.
- 메인 장수 요약의 앞 5칸 미리보기도 같은 규칙으로 빈 칸을 흐리게 보여 준다. 응답 모양은 [T2-13](./T2-13.md)의 `SlotView`, `PolicyResponse`다.
