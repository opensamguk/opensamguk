# T2-14 기본 방침 설정 화면

> 대기열: T2-14 · AC: AC-M2-17 (화면) · 구현: Claude · 리뷰: Codex
> 선행: T2-13 (API)

## 계획 (Claude)

### 목표

장수가 기본 방침을 고르고 빈 칸이 실제로 무엇을 할지 예턴 편집에서 미리 본다.

### 범위

`apps/web`: 예턴 편집 위쪽의 방침 선택, 메인 장수 요약의 방침 표시와 예턴 앞 5칸의 빈 칸 표시.

### 화면

- 예턴 편집 위: `기본 방침: [권농 ▾]  빈 칸은 '농지 개간'을 합니다. 실패하면 휴식합니다.`
- 빈 칸은 흐린 글씨로 "(권농) 농지 개간"이라고 보여 준다. 직접 넣은 휴식은 진한 "휴식"으로 구분.
- 14일 넘게 접속하지 않으면 방침대로 AI가 대신한다는 안내를 한 줄로.
- 방침 바꾸기는 예턴 저장과 별개로 고르는 즉시 보낸다. 엔진이 처리하기 전에는 고른 방침 옆에 처리 중을 둔다. `applied`를 받거나 다시 읽은 `pending`이 null이 되면 확정으로 보여 준다(T2-13 방침 바꾸기 처리).
- 메인 예턴 앞 5칸도 같은 규칙으로 빈 칸을 흐리게 보여 준다. 응답 모양은 [T2-13](./T2-13.md)의 `SlotView`, `PolicyResponse`다.

### v1 근거

경로는 v1 저장소(`opensamguk-v1` `bc05362`) 기준이다. 원작이라고 적은 것은 core2026 `df6c926`의 `app/game-frontend/src/` 아래 경로다.
v1의 방침은 장수가 아니라 縣·군·군단에 거는 것이었다. 고르는 방식과 표시만 가져오고 대상은 장수 하나로 줄인다.
