# T2-14 기본 방침 설정 화면

> 대기열: T2-14 · AC: AC-M2-17 (화면) · 구현: Claude · 리뷰: Codex
> 선행: T2-13 (API)

## 계획 (Claude)

### 목표

장수가 기본 방침을 고르고, 빈 칸이 실제로 무엇을 할지 예턴 편집에서 미리 본다.

### 범위

`apps/web`: 예턴 편집 위쪽의 방침 선택, 메인 장수 요약의 방침 표시.

### 화면

- 예턴 편집 위: `기본 방침: [권농 ▾]  빈 칸은 '농지 개간'을 합니다. 실패하면 휴식합니다.`
- 빈 칸은 흐린 글씨로 "(권농) 농지 개간"이라고 보여 준다. 직접 넣은 휴식은 진한 "휴식"으로 구분.
- 14일 넘게 접속하지 않으면 방침대로 AI가 대신한다는 안내를 한 줄로.
- 방침 바꾸기는 바로 저장 (예턴 저장과 별개).

### 검증

| 무엇 | 어떻게 |
| ---- | ------ |
| 선택 | Playwright: 방침 바꾸기 → 새로고침 뒤 유지 |
| 미리보기 | Playwright: 빈 칸 표시가 방침에 따라 바뀜, 직접 휴식과 구분됨 |
| 실행 | Playwright: manual 시계로 턴 진행 → 최근 기록에 방침 명령 |

### 채울 문서

- `docs/frontend-ui-guidelines.md` (예턴 편집의 빈 칸 표시)
