# T2-16 명령 목록 자동 생성

> 대기열: T2-16 · AC: AC-M2-11 (생성 부분) · 구현: Codex · 리뷰: Claude
> 선행: M1 전체 · 다음: T2-17 플레이어 가이드 (Claude) · 참고: core2026 `tools/docs`, `docs/user/command-catalog.generated.md`

## 계획 (Claude)

### 목표

명령 레지스트리에서 플레이어용 명령 목록 문서를 자동으로 만들고 코드와 문서가 어긋나면 검사가 실패한다.

### 범위

- `tools/docs/generate-command-catalog.ts` → `docs/user/command-catalog.generated.md`
- 명령 정의에 플레이어용 설명 필드 추가: `summary`(한 줄), `requires`(조건 목록), `cost`(비용 설명)
- `pnpm docs:generate`, 그리고 `pnpm check`에 "생성 결과가 최신인지" 검사 추가

### 하지 않는 것

문서 사이트(VitePress, 백로그), 명령별 상세 수치 공식 공개.

### 결정

- 표 열: 분류 · 화면 이름 · 한 줄 설명 · 대상·수량 입력 · 조건 · 비용. 장수 명령과 국가 명령을 나눈다.
- 프리셋별로 쓸 수 없는 명령이 있으면 "일부 월드에서는 쓸 수 없음"과 프리셋 이름을 적는다 (T2-02).
- 생성 파일 머리에 "직접 수정 금지, 생성 명령"을 적는다.
- 설명 문구(`summary` 등)는 Codex가 규칙 기준으로 쓰고 표현 다듬기는 T2-17에서 Claude가 리뷰 때 제안한다.

### 검증

| 무엇 | 어떻게 |
| ---- | ------ |
| 생성 | `pnpm docs:generate` → 명령 수 = 레지스트리 수 |
| 최신 검사 | 명령 설명 한 줄을 바꾸고 생성 안 함 → `pnpm check` 실패 |
| 누락 | 단위: 설명 필드가 빈 명령이 있으면 생성 실패 |
