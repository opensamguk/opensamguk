# T2-16 명령 목록 자동 생성

> 대기열: T2-16 · AC: AC-M2-11 (생성 부분) · 구현: Codex · 리뷰: Claude
> 선행: M1 전체 · 다음: T2-17 플레이어 가이드 (Claude) · 참고: core2026 `tools/docs`, `docs/user/command-catalog.generated.md`

## 계획 (Claude)

### 목표

명령 레지스트리에서 플레이어용 명령 목록 문서를 자동으로 만들고 코드와 문서가 어긋나면 검사가 실패한다.

### 범위

- `tools/docs/generate-command-catalog.ts` → `docs/user/command-catalog.generated.md`
- 명령 정의에 플레이어용 설명 필드 추가: `summary`(한 줄), `requires`(조건 목록), `cost`(비용 설명)
- `pnpm docs:generate`, 그리고 `pnpm check`에 생성 결과가 최신인지 보는 검사 추가

### 하지 않는 것

문서 사이트(VitePress, 백로그), 명령별 상세 수치 공식 공개.

### 결정

- 표 열: 분류 · 화면 이름 · 한 줄 설명 · 대상·수량 입력 · 조건 · 비용. 장수 명령과 국가 명령을 나눈다.
- 프리셋별로 쓸 수 없는 명령이 있으면 "일부 월드에서는 쓸 수 없음"과 프리셋 이름을 적는다 (T2-02).
- 생성 파일 머리에 "직접 수정 금지, 생성 명령"을 적는다.
- 설명 문구(`summary` 등)는 Codex가 규칙 기준으로 쓰고 표현 다듬기는 T2-17에서 Claude가 리뷰 때 제안한다.
- 틀은 원작 생성기(core2026 `tools/docs/generate-command-reference.mjs`, 생성물 `docs/user/command-catalog.generated.md`)의 분류별 표와 머리 경고를 따른다. 조건·비용 열은 v1 도움말의 "이 명령의 규칙"(누가·언제·어디에·대상·비용, v1 `web/game/components/help/HelpTopicView.tsx:44-56`)에서 가져온다.

### 가이드(T2-17)가 기대하는 생성 결과 모양

명령 정의(`packages/rules/src/commands/types.ts`의 `CommandDef`)에 아래 필드를 더한다.

```ts
interface PlayerDoc {
  summary: string;      // 한 줄. 무엇이 바뀌는지를 쓴다. 빈 문자열이면 생성 실패
  requires: string[];   // 실행 조건 한 줄씩. 조건이 없으면 [] (표에는 '없음')
  cost: string | null;  // 비용 한 줄. 없으면 null (표에는 '없음'). 공식 대신 무엇을 얼마나 쓰는지만
}
interface CommandDef<Args = unknown> {
  // 기존 필드 그대로
  doc: PlayerDoc;
}

// 분류의 화면 이름은 rules 한곳에 둔다. 예턴 편집 화면과 가이드가 같은 이름을 쓴다
const COMMAND_CATEGORY_NAMES: Record<CommandCategory, string> = {
  domestic: '내정', military: '군사', strategy: '인사', personal: '개인', nation: '국가',
};
```

생성기는 표 한 줄마다 아래 값을 내보낸다.

```ts
type CatalogRow = {
  target: 'general' | 'nation';  // '## 장수 명령' / '## 국가 명령' 절을 가른다
  category: CommandCategory;     // '### 내정' 같은 소제목. 순서는 COMMAND_CATEGORIES
  name: string;                  // 화면 이름
  summary: string;
  needsInput: boolean;           // args 스키마가 빈 객체가 아니면 true → '필요' / '없음'
  requires: string[];            // 칸 안에서 '<br>'로 잇는다
  cost: string | null;
  unavailableIn: string[];       // 이 명령을 뺀 프리셋 이름 (T2-02). 비어 있지 않으면 조건 칸 끝에 "일부 월드에서는 쓸 수 없음: …"
};
// 같은 소제목 안은 레지스트리 등록 순서. 실행할 때마다 같은 파일이 나와야 최신 검사가 의미 있다
```

| T2-17 가이드에서 쓰는 곳 | 생성 결과 |
| ------------------------ | --------- |
| commands-and-timing §1 명령 분류 | `## 장수 명령`·`## 국가 명령` 아래 `###` 분류 소제목 (링크 주소로 쓰므로 이름을 바꾸지 않는다) |
| commands-and-timing §2 조건 읽는 법 | 조건·비용 열 |
| commands-and-timing §4 생성 문서 안내 | 파일 머리의 "직접 수정 금지, 생성 명령" 줄 |
| general-and-city 내정 8종, war-and-orders 모병·훈련·출병 | 해당 분류 소제목으로 링크. 가이드 본문에 명령 표를 다시 쓰지 않는다 |
| 프리셋별 차이 | `unavailableIn` |

실패 이유 코드(`Failure['code']`)의 뜻은 생성하지 않는다. T2-17이 `types.ts`를 보고 commands-and-timing §3에 직접 쓴다.

### 검증

| 무엇 | 어떻게 |
| ---- | ------ |
| 생성 | `pnpm docs:generate` → 명령 수 = 레지스트리 수 |
| 최신 검사 | 명령 설명 한 줄을 바꾸고 생성 안 함 → `pnpm check` 실패 |
| 누락 | 단위: 설명 필드가 빈 명령이 있으면 생성 실패 |
