## 계획 (Claude)

### 1. 목표

AC-P2-21 제안 문장(U-14 1차 범위에 맞춤): 역사 사건 기능을 켠 1030 시나리오 월드에서 사료 연도에 맞춘 고정 사건 5~8개가 월간 정산 때 일어난다. 사건마다 관련 국가의 군주가 선택지 두 개 가운데 하나를 고르고 기한의 월간 정산에서 국가 자원, 외교, 소속 장수 사기에 작은 효과가 난다. 고르지 않으면 정해 둔 기본 선택지가 적용된다. 관련 국가가 그 사이 사라졌으면 사건은 일어나지 않는다. 같은 시드와 같은 입력이면 결과가 같다. 기능을 끈 월드의 상태 해시와 12개월 재생 해시는 지금과 같다.

U-14의 사용자 결정은 아래와 같다.

- 시나리오 1030 연도에 맞춘 고정 사건 5~8개. 예로 헌제 옹립, 관도, 적벽.
- 사건마다 선택지 2개. 효과는 자원·외교·사기 소폭.
- 월간 정산에 더하고 D-029 기능 표시로 켜고 끈다.
- 문구는 사료 근거를 확인해 새로 쓴다.

| 몫 | 내용 | 구현 → 리뷰 |
| -- | ---- | ----------- |
| (가) | 사건 표, 기능 정의, 상태 조각, 월간 처리, 선택 입력의 순수 판정 | Codex → Claude |
| (나) | 선택 입력 kind 등록, 엔진 국가 기록 저장, 조회·선택 API | Codex → Claude |
| (다) | 군주 사건 카드, 기록 탭의 사건 목록, 플레이어 가이드 | Claude → Codex |

차별화 원칙대로 사건은 월간 정산 뒤에 덧붙는 단계다. 명령, 예턴, 전투 규칙은 바꾸지 않는다. 계절 사건과 변방 민족(아이디어 수집 A11)은 U-14 1차 범위가 아니다.

### 3. 사건 후보 (사료 확인)

연도와 달은 `historical-sources` 색인의 원문으로 확인했다. 後漢書 卷009 孝獻帝紀는 해와 달 순으로 적혀 있어 연대의 기준으로 썼다. 게임 달력은 1030 시작 191년에서 그대로 센다. 달이 사료에 없으면 그해 1월에 두는 안을 RQ43-2에서 확인받는다.

뺀 후보와 이유는 아래와 같다.

- 192년 동탁 피살(後漢書 卷009 初平三年 「夏四月辛巳，誅董卓」): 1030의 이각 국가가 시작부터 동탁 잔당이라 시나리오 전제와 맞지 않는다.
- 200년 손책의 죽음(같은 권 建安五年 「是歲，孫策死，弟權襲其餘業」): 우리 게임에 장수 사망이 없다(§8 A-08). 장수가 살아 있는데 죽음 사건을 내면 화면과 상태가 어긋난다.

사건은 실제 역사의 결과를 강요하지 않는다. 고르는 국가가 그 시점에 남아 있을 때 그 군주에게 선택을 묻는 장면이다. 국호가 바뀌어도(T4-16) 국가 번호가 같으면 일어난다.

### 4. 사건 문구 초안

문구는 사료 내용을 바탕으로 새로 썼다. 원문을 그대로 옮기지 않는다. 효과의 방향만 적었고 크기는 §6 RQ43-3의 세 단위(자원 R, 사기 A, 불가침 개월 M)로 적는다. 기본 선택지는 군주가 고르지 않을 때 적용된다.

| ID | 제목 | 상황 한 줄 | 선택지 1 (효과) | 선택지 2 (효과) | 기본 |
| -- | ---- | ---------- | --------------- | --------------- | ---- |
| E1 | 도겸의 부탁 | 병이 깊어진 도겸이 서주를 맡길 사람으로 유비를 떠올립니다. | 유비에게 뒤를 부탁한다 (유비와 불가침 M개월, 금 −R) | 가문에 맡긴다 (쌀 +R) | 2 |
| E2 | 천자를 맞을까 | 낙양의 천자가 머물 곳을 찾고 있습니다. | 천자를 허로 모신다 (금 −R, 장수 사기 +A) | 근거지부터 다진다 (쌀 +R) | 2 |
| E3 | 황제의 칭호 | 하내 사람 장형이 올린 부명을 들어 황제를 칭하자는 말이 나옵니다. | 황제를 칭한다 (금 +R, 장수 사기 −A) | 칭호를 미룬다 (장수 사기 +A) | 2 |
| E4 | 서주 공방 | 조조의 군대가 서주로 밀려왔습니다. | 성을 지킨다 (쌀 −R, 장수 사기 +A) | 화친을 청한다 (조조와 불가침 M개월, 금 −R) | 1 |
| E5 | 역경 공방 | 원소의 군대가 역경 아래까지 들어왔습니다. | 역경에서 버틴다 (쌀 −R, 장수 사기 +A) | 화친을 청한다 (원소와 불가침 M개월, 금 −R) | 1 |
| E6 | 관도의 대치 | 관도에서 원소와 맞선 지 여러 달이 지났습니다. 허로 물러나자는 말이 나옵니다. | 물러나지 않는다 (쌀 −R, 장수 사기 +A) | 허로 물러난다 (쌀 +R, 장수 사기 −A) | 1 |
| E7 | 융중의 선비 | 서서가 융중에 사는 제갈량을 직접 찾아가라고 권합니다. | 세 번 찾아간다 (금 −R, 장수 사기 +A) | 사람을 보내 부른다 (효과 없음) | 2 |
| E8 | 적벽 | 조조가 수군을 이끌고 장강을 따라 내려옵니다. | 맞서 싸운다 (쌀 −R, 장수 사기 +A) | 화친을 논한다 (조조와 불가침 M개월, 금 −R) | 1 |

E7의 효과는 제갈량을 데려오지 않는다. 장수 이동은 자원·외교·사기 밖이라 U-14 범위가 아니다. 등용은 지금 명령(T4-42 관계 기능을 켰다면 그 판정)으로 한다.

국가 기록 문구는 이렇게 쓴다. 조사 처리가 필요 없게 제목 뒤에 쌍점을 둔다(T4-05 §4.7과 같다).

| 시점 | 국가 기록 (고르는 국가) | 국가 기록 (상대 국가, 불가침 효과일 때) |
| ---- | ----------------------- | --------------------------------------- |
| 일어남 | `{제목}: 군주의 결정을 기다립니다.` | 없음 |
| 적용 | `{제목}: {선택지 문구}` 뒤에 효과 요약, 기본 적용이면 `(기한이 지나 기본 선택)` | `{제목}: {고른 국가}와 불가침 {M}개월` |
| 적용되지 않은 불가침 | `{제목}: {상대 국가}와 이미 전쟁 중이라 불가침을 맺지 못했습니다.` | 없음 |

### 5. 범위와 계약 초안

#### 5.1 (가) 순수 규칙 (Codex)

| 파일 | 내용 |
| ---- | ---- |
| 새 파일 `packages/rules/src/features/historicEvents/events1030.ts` | §3·§4 표. 행마다 `{ id, year, month, chooser: { nationId, name }, counterpart?: { nationId, name }, title, text, options: [opt, opt], defaultOption, ref }`. 사서·권·구절은 행 위 주석 |
| 새 파일 `features/historicEvents/index.ts` | 기능 정의 `historicEventsFeature`, `buildFeatureData(initial)`, 조각 `historicEvents`, `afterMonthly`, 순수 판정 `applyChooseInput(state, payload, actor)` |
| 새 파일 `features/historicEvents/historicEvents.test.ts` | §7 시험 |

기능 자료(DX-2): `buildFeatureData`는 `initial.scenarioKey`의 표를 고르고 행마다 고르는 국가와 상대 국가의 번호·이름이 `initial.nations`와 같은지 본다. 다르면 예외다. 결과는 사건 표의 사본이며 재생은 이 사본만 쓴다. 표가 없는 시나리오는 빈 목록이다.

상태 조각 `historicEvents`(DX-3):

```ts
interface HistoricEventsSlice {
  pending: { id: string; nationId: number; firedTick: number; closesAtMonth: number; choice: 0 | 1 | null }[];
  done: { id: string; nationId: number; choice: 0 | 1; defaulted: boolean; resolvedTick: number }[];
  skipped: string[]; // 일어날 때 고르는 국가가 없던 사건
}
```

`closesAtMonth`는 `floor(tick / TICKS_PER_MONTH)`로 센 달 번호다. 한 사건 id는 세 목록 가운데 한 곳에만 한 번 나온다.

효과 종류는 넷만 둔다. 다른 종류는 `validate`가 거부한다.

| 종류 | 적용 |
| ---- | ---- |
| `gold` (값 v) | 고르는 국가 `gold += v`. 0 아래로 내려가지 않는다 |
| `rice` (값 v) | 같은 꼴 |
| `atmos` (값 v) | 고르는 국가 소속이고 등장한(`activeFromYear <= 연도`) 장수마다 `atmos += v`, 0~100으로 자른다 |
| `nonAggression` (개월 m) | 상대 국가가 있을 때만. 외교 행이 없으면 `NON_AGGRESSION`, `untilTick = tick + m × 10,000`. 이미 불가침이면 `untilTick = max(기존, 새 값)`. `WAR`·`DECLARED`면 바꾸지 않고 기록만 남긴다 |

`afterMonthly(state, { tick, date, rng })` 순서는 아래로 고정한다. RNG는 쓰지 않는다.

1. `pending` 가운데 `closesAtMonth <= floor(tick / TICKS_PER_MONTH)`인 것을 id 오름차순으로 적용한다. 고르는 국가가 없어졌으면 효과 없이 `done`에 `defaulted: true`로 옮긴다. 아니면 `choice ?? defaultOption`의 효과를 적용하고 `done`으로 옮긴다.
2. 사건 표에서 `year === date.year && month === date.month`이고 세 목록에 없는 사건을 id 오름차순으로 본다. 고르는 국가가 있으면 `pending`에 `closesAtMonth = 지금 달 + W`(RQ43-4)로 넣는다. 없으면 `skipped`에 넣는다.
3. 국가 기록 문구를 `history`로 돌려준다(DX-4).

같은 정산에서 1이 2보다 먼저라서 기한 W가 1이어도 일어난 달에 바로 적용되지 않는다.

선택 입력(DX-5)은 kind `historic-events.choose`, payload `z.strictObject({ eventId: z.string().min(1).max(32), option: z.union([z.literal(0), z.literal(1)]) })`다. `applyChooseInput`의 순서와 거부 code는 아래와 같다.

| 순서 | 조건 | code |
| ---- | ---- | ---- |
| 1 | 기능이 꺼짐 | `FEATURE_DISABLED` (T2-26 공통) |
| 2 | 행위 장수가 없거나 국가가 없음 | `NO_GENERAL` (T4-49 공통) |
| 3 | `pending`에 그 `eventId`가 없음 (`done`·`skipped` 포함) | `EVENT_CLOSED` |
| 4 | 사건의 고르는 국가가 행위 장수의 국가가 아님 | `NOT_YOUR_EVENT` |
| 5 | 행위 장수가 그 국가의 군주(`officerLevel === 12`)가 아님 | `NOT_RULER` |
| 6 | 이미 `choice`가 있음 | `ALREADY_CHOSEN` |

통과하면 `choice`만 바꾼다. 효과는 기한의 월간 정산에서 난다. `whilePaused`는 `hold`다. 행위자는 서버가 세션에서 정한 장수다.
