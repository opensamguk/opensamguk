## 계획 (Claude)

### 목표

AC-P2-05와 AC-P2-06의 엔진 몫이다. 준비 턴 명령과 특수 병종 연구를 운영 목록에 등록하고 실제 엔진·PostgreSQL에서 아래가 성립함을 보인다.

- 준비 턴 N인 명령은 같은 명령을 N+1칸 연속 실행해야 효과가 나고 다른 명령이 끼면 처음부터 다시 센다. 실패한 칸은 진행을 남긴다([T4-07](./T4-07.md) P7·P8).
- 준비 진행과 연구 결과는 턴과 같은 트랜잭션에 저장되고 commit 직전 실패면 되돌려지며 엔진 재시작 뒤 이어지고 12개월 재생 해시가 같다.
- 연구를 마친 국가만 특수 병종을 모병·징병하고 조건이 맞지 않으면 사전 검사 응답에 이유가 있다. 연구 전 국가와 확장을 끈 월드는 기존 병종만 쓴다.
- 확장을 끈 월드의 상태 해시, 재생 기록, 명령 37개 결과는 바뀌지 않는다.

- 권한: 국가 명령은 엔진 실행 검사의 직책 실패(수뇌 미만)를 E11의 대표 실패로 둔다. HTTP 저장 권한 5범주는 T4-50의 몫이며 이 작업 증거로 세지 않는다. 장수 명령 모병의 사전 검사(E8·E9)는 기존 `turns.precheck`의 권한 시험을 그대로 쓴다.
- 준비 턴 23인 연구는 시험에서 24번 군주 턴을, 11인 연구는 12번을 돌려야 한다. 가속 시계(`apps/engine/src/accelerated.integration.test.ts`의 방식)와 장수가 적은 고정물로 시간을 줄인다. 연구 key마다 실제 엔진 실행의 성공 1건과 대표 실패 1건이 있어야 E11과 명세 C19(`phase2-expansion.md:165`)를 채운다. 순수 재생 시험이나 다른 연구의 엔진 시험으로 대신하지 않는다. 한 월드에서 여러 국가가 서로 다른 연구를 동시에 진행하게 해 군주 턴 수를 key 수만큼 곱하지 않는다. 그래도 시험 시간이 CI 제한을 넘으면 구현을 멈추고 조율 세션에 알린다(시험 분할이나 제한 조정은 그쪽 결정이다).
- 화륜차는 T4-72의 `nation_scorch` 조각이 없으면 모집 불가 경로만 시험한다.

AC 판정: AC-P2-05는 T4-07·T4-08 규칙 증거, 이 시험, T4-50 국가 예턴 HTTP 증거, 반대쪽 리뷰가 모두 있어야 판정 대상이다. AC-P2-06은 T4-09(와 승인되면 T4-10) 규칙 증거, 이 시험, 반대쪽 리뷰가 있어야 한다.
