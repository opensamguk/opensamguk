## 1. 목표

AC-M1-14의 이 명령 행(`battle_ready`)이 대응표 11단계 증거를 모두 갖는다. 켠 월드에서 병력이 있고 훈련·사기가 문턱 미만인 장수가 연속 칸에 전투태세를 예약하면 마지막 칸에서 훈련·사기가 문턱 이상으로 오르고 경험·공헌을 얻는다. 방랑 국가와 재야는 실패한다. 끈 월드와 기본 37개는 바뀌지 않는다.

### 4.3 검사 순서와 실패

| 순서 | 조건 | code | 문구 |
| ---- | ---- | ---- | ---- |
| 1 | 장수 없음 | `NO_ACTOR` | 장수가 없습니다. |

| 4 | 현재 도시가 자기 국가 도시 아님 | `NOT_OWN_CITY` | 자기 국가 도시에서만 가능합니다. |
| 5 | 병력 0 | `NO_CREW` | 병력이 없습니다. |
| 6 | 금 < `round(crew / 100 × 3 × techCost)` | `NO_GOLD` | 금이 부족합니다. |
| 7 | 훈련 ≥ 90 | `AT_MAX` | 훈련이 이미 충분합니다. |
| 8 | 사기 ≥ 90 | `AT_MAX` | 사기가 이미 충분합니다. |

`techCost = 1 + min(12, floor(nation.tech / 1000)) × 0.15`. 원작의 쌀 0 이상 검사는 언제나 참이라 뺀다. 3은 국가 규모(`level`)를 읽지 않는다.

### 4.4 효과 (마지막 칸)

`defineCommand`의 `change`가 차례로 한다. RNG는 쓰지 않는다.

1. 훈련 `max(train, 95)`, 사기 `max(atmos, 95)`
2. 경험 `+300`, 공헌 `+210`
3. S1 (나)면 금 `− round(crew / 100 × 3 × techCost)`
4. MQ-1 (가)·(나)면 지금 계열에 `addProficiency(state, actor, armType, crew / 100 × 3)`. `armTypeOf`가 `null`이면 숙련은 건너뛴다

효과는 world 하나다. 손 계산: 병력 2,000, 기술 3,500이면 `techCost = 1.45`, 금 `round(20 × 3 × 1.45) = 87`, 숙련 +60.
