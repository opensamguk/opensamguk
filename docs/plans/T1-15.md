# T1-15 장수 생성·예턴 편집 화면

> 대기열: T1-15 · AC: AC-M1-06 ~ AC-M1-09 (화면) · 구현: Claude · 리뷰: Codex
> 선행: T1-11 (API), T1-13 (화면 기반)

## 계획 (Claude)

### 목표

장수를 만들고, 예턴 30칸을 빠르게 편집한다. 저장 충돌과 사전 검사 경고를 화면에서 보여 준다.

### 범위

`/w/:worldId/create`, `/w/:worldId/turns`, 메인의 예턴 앞 5칸 미리보기.

### 하지 않는 것

국가 예턴 편집(M2), 기본 방침 설정(M2 D12), 작전 참여 채우기(M2 D2), 역할별 입장(M3 D15).

### 장수 생성

- 이름, 통솔·무력·지력 (합계 165, 각각 15~80). 남은 점수를 실시간 표시, 규칙 위반이면 생성 버튼 비활성 + 이유.
- 초상: M1은 기본 이미지 몇 개 중 선택 또는 없음 (`portraitId` null). 초상 목록 화면은 T1-17·T1-19 뒤.
- `pending` 응답이면 "장수를 만드는 중…" 표시 후 `general.mine`을 다시 조회.

### 예턴 편집 (원작 정보량 + 모던 정리)

```text
┌ 칸 ┬ 실행 예정 시각 ┬ 명령 ────────┬ 인자 ─────┬ 사전 검사 ┐
│ 1  │ 191년 3월 14:03 │ 농지 개간    │           │ ✓         │
│ 2  │ 191년 4월 14:13 │ 출병         │ 복양      │ ⚠ 교전 아님 │
│ …  │                 │              │           │           │
└────┴─────────────────┴──────────────┴───────────┴───────────┘
[선택: 2~5] [명령 넣기 ▾] [당기기] [밀기] [전체·홀수·짝수 칸 선택] [저장]
```

- 여러 칸 선택: 클릭, Shift+클릭 범위, 전체·홀수·짝수(myosam 아이디어). 키보드: 위아래 이동, Space 선택, Enter 명령 넣기.
- 명령 고르기: 분류(내정·군사·인사·개인)별 목록 + 검색. 비용과 오르는 값을 함께 표시(myosam 아이디어).
- 인자가 필요한 명령(출병·이동·모병 등)은 대상 선택 칸을 띄운다. 대상 후보는 지도 데이터에서.
- 사전 검사: 넣은 칸마다 `turns.precheck` 결과를 ✓ 또는 ⚠ + 이유로 표시. 경고여도 저장은 된다 (실행 때 재검사).
- 저장: 편집은 화면에서 모았다가 [저장] 한 번. `STALE`이면 "다른 곳에서 먼저 바뀌었습니다" + 최신 목록 다시 불러오기,
  내 편집은 버리지 않고 다시 적용할지 묻는다.
- 실행 예정 시각은 서버가 준 `nextTurnAt`과 턴 간격으로 계산해 보여 준다 (표시만).

### 검증

| 무엇 | 어떻게 |
| ---- | ------ |
| 생성 | Playwright: 합계 초과 시 버튼 비활성 + 이유, 정상 생성 → 메인 |
| 편집 | Playwright: 2~5칸 선택 → 농지 개간 → 저장 → 새로고침 후 유지 |
| 당기기·밀기 | Playwright: 밀기 1 → 1칸 휴식, 뒤로 한 칸씩 |
| 충돌 | Playwright: 탭 두 개에서 저장 → 늦은 탭에 충돌 안내와 다시 불러오기 |
| 키보드 | Playwright: 마우스 없이 3칸 넣고 저장 |
