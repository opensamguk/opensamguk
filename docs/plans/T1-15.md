# T1-15 장수 생성·예턴 편집 화면

> 대기열: T1-15 · AC: AC-M1-06 ~ AC-M1-09 (화면) · 구현: Claude · 리뷰: Codex
> 선행: T1-11 (API), T1-13 (화면 기반)

## 계획 (Claude)

### 목표

장수를 만들고 예턴 30칸을 빠르게 편집한다. 저장 충돌과 사전 검사 경고를 화면에서 보여 준다.

### 범위

`/w/:worldId/create`, `/w/:worldId/turns`, 메인의 예턴 앞 5칸 미리보기.

2026-10-21 소유자 UI 정정(지도와 예턴은 같은 메인 화면) 뒤 범위를 이렇게 고친다. 30칸 편집기는
`apps/web/src/turns/TurnEditor.tsx`의 재사용 부품으로 만든다. 메인 명령 칸에 넣는 일은 T1-16이 한다.
`/w/:worldId/turns`는 같은 편집기를 넓게 쓰는 보조 화면이다. 앞 5칸 읽기 전용 미리보기만으로는 끝내지 않는다.

### 하지 않는 것

국가 예턴 편집(M2), 기본 방침 설정(M2 D12), 작전 참여 채우기(M2 D2), 역할별 입장(M3 D15).

### 장수 생성

- 이름, 통솔·무력·지력 (합계 165, 각각 15~80). 남은 점수를 실시간 표시, 규칙 위반이면 생성 버튼 비활성 + 이유.
- 초상: M1은 기본 이미지 몇 개 중 선택 또는 없음 (`portraitId` null). 초상 목록 화면은 T1-17·T1-19 뒤.
- `pending` 응답이면 "장수를 만드는 중…" 표시 후 `general.mine`을 다시 조회.

### 예턴 편집 (원작 정보량 + 모던 정리)

```text
┌ 칸 ┬ 실행 예정 시각 ┬ 명령 ────────┬ 인자 ─────┬ 사전 검사 ┐
│ 1  │ 191년 3월 14:03 │ 농지 개간    │           │ ✓         │
│ 2  │ 191년 4월 14:13 │ 출병         │ 복양      │ ⚠ 교전 아님 │
│ …  │                 │              │           │           │
└────┴─────────────────┴──────────────┴───────────┴───────────┘
[선택: 2~5] [명령 넣기 ▾] [당기기] [밀기] [전체·홀수·짝수 칸 선택] [저장]
```

- 여러 칸 선택: 클릭, Shift+클릭 범위, 전체·홀수·짝수(myosam 아이디어). 키보드: 위아래 이동, Space 선택, Enter 명령 넣기.
- 명령 고르기: 분류(내정·군사·인사·개인)별 목록 + 검색. 비용과 오르는 값을 함께 표시(myosam 아이디어).
- 인자가 필요한 명령(출병·이동·모병 등)은 대상 선택 칸을 띄운다. 대상 후보는 지도 데이터에서.
- 사전 검사: 넣은 칸마다 `turns.precheck` 결과를 ✓ 또는 ⚠ + 이유로 표시. 경고여도 저장은 된다 (실행 때 재검사).
- 저장: 편집은 화면에서 모았다가 [저장] 한 번. `STALE`이면 "다른 곳에서 먼저 바뀌었습니다" + 최신 목록 다시 불러오기,
  내 편집은 버리지 않고 다시 적용할지 묻는다.
- 실행 예정 시각은 서버가 준 `nextTurnAt`과 턴 간격으로 계산해 보여 준다 (표시만).

### 검증

| 무엇 | 어떻게 |
| ---- | ------ |
| 생성 | Playwright: 합계 초과 시 버튼 비활성 + 이유, 정상 생성 → 메인 |
| 편집 | Playwright: 2~5칸 선택 → 농지 개간 → 저장 → 새로고침 후 유지 |
| 당기기·밀기 | Playwright: 밀기 1 → 1칸 휴식, 뒤로 한 칸씩 |
| 충돌 | Playwright: 탭 두 개에서 저장 → 늦은 탭에 충돌 안내와 다시 불러오기 |
| 키보드 | Playwright: 마우스 없이 3칸 넣고 저장 |

## 구현 기록 (Claude)

- 바꾼 것 (2026-10-21, `apps/web`·`e2e`·이 계획·`phases.md` T1-15 행·백로그 한 줄):
  - `apps/web/src/turns/TurnEditor.tsx`: 재사용 30칸 편집기 `TurnEditor({ worldId, selectedCityKey })`. 칸 표(실행 시기·명령·인자·사전 검사),
    칸 고르기, 명령 고르기, 당기기·밀기·구간 반복, 저장, 충돌 안내, 다시 로그인 안내를 한 부품에 둔다.
  - `turns/useTurnDraft.ts`: 서버 목록(`turns.get`, 10초마다 다시 묻기)과 화면 초안을 나눈다. 초안은 편집 시작 때의
    revision, 편집 목록, 결과 30칸을 갖고 탭의 sessionStorage(`계정 ID + 월드 ID` 키)에 둔다. [저장]은 `turns.set` 한 번이다.
    `STALE`이면 받은 최신 30칸을 캐시에 넣고 내 편집 목록을 보관한 채 다시 적용할지 묻는다.
  - `turns/draft.ts`: 편집 계산. 서버와 같은 `@opensamguk/shared`의 `editArray`로 넣기·밀기·당기기·반복을 계산한다
    (웹 의존성에 `@opensamguk/shared` 추가). 흩어진 칸 넣기는 이어진 구간마다 `put`으로 나눈다.
  - `turns/CommandPicker.tsx`·`args.ts`: `commands.list`의 분류·이름 검색과 `argsSchema`로 만든 인자 칸.
    대상 도시·국가는 `world.map`에서 고른다. 지도에서 고른 도시는 대상 도시 기본값과 [지도에서 고른 도시 쓰기] 버튼으로만 쓴다.
  - `turns/schedule.ts`: 칸마다 실행 연월과 시각. 시각은 `home.get.nextTurnAt + 칸 번호 × 턴 간격`, 연월은 장수 `nextTurnTick`과
    `world.summary`의 현재 연월·tick 길이로 센다. 월드가 멈춰 `nextTurnAt`이 null이면 시각은 비운다.
  - `turns/TurnsPage.tsx`: `/w/:worldId/turns`. 같은 편집기와 최근 실행 결과 칸(`home.get.recentLogs`, 실패는 실패 이유 그대로).
  - `general/CreateGeneralPage.tsx`·`createForm.ts`: `/w/:worldId/create`. 이름, 통솔·무력·지력(남은 점수 실시간), 초상(기본 이미지 또는
    초상 6개 중 하나), 이미 장수가 있을 때 안내, `pending`이면 만드는 중이라고 알리고 `general.mine`을 1.5초마다 다시 묻는다.
  - `router.tsx`: `create`·`turns` 두 주소의 화면만 바꿨다 (다른 주소는 T1-16).
  - `e2e/game.ts`(월드·장수·API·턴 창 도우미), `e2e/turns.spec.ts` 12개.
- 예턴 편집 조작 (UI 지침에 넣을 문구):
  - 칸을 누르면 그 칸을 고르거나 풀고 Shift를 누른 채 누르면 마지막으로 누른 칸부터 범위를 더한다. 전체·홀수 칸·짝수 칸·선택 해제 버튼이 있다.
  - 키보드: 표에 초점을 두고 위아래 화살표로 옮긴다. Shift+화살표는 범위를 더하고 Space는 고르거나 푼다. Enter는 명령 찾기 칸으로 간다.
    명령 찾기에서 Enter를 누르면 첫 결과를 고른다. 인자가 없으면 바로 고른 칸에 넣고 표로 돌아온다. 인자가 있으면 첫 인자 칸으로 간다.
  - 넣기·당기기·밀기·반복은 화면 초안만 바꾼다. [저장]을 눌러야 서버에 간다. 바뀐 칸에는 바뀜 표시가 붙고 위에 저장하지 않은 편집 수가 보인다.
  - 사전 검사는 칸마다 가능, 또는 경고와 그 이유로 보인다. 경고가 있어도 저장되며 실행할 때 엔진이 다시 검사한다.
  - 다른 탭 저장이나 턴 실행으로 서버 목록이 먼저 바뀌면 저장 때 다른 곳에서 먼저 바뀌었다는 안내와 최신 목록을 보여 준다.
    그리고 [내 편집 다시 적용]과 [내 편집 버리기] 중 고르게 한다. 다시 적용하면 최신 목록에 같은 편집을 같은 순서로 적용한다. 사용자는 확인한 뒤 다시 저장한다.
  - 저장 중 로그인이 풀리면 [다시 로그인] 링크를 보여 준다. 저장하지 않은 편집은 탭에 남아 같은 계정으로 다시 로그인하면 이어서 저장한다.
  - 못 쓰는 버튼(고른 칸이 없을 때 넣기, 바꾼 칸이 없을 때 저장, 이어지지 않은 구간의 반복)은 점선으로 두고 누르면 이유를 보여 준다.
- 계획과 달라진 점과 이유:
  - 메인 앞 5칸 미리보기 대신 재사용 편집기를 만들었다. 소유자 UI 정정과 총괄 결정(T1-16이 메인 배치와 결합을 맡음) 때문이다.
  - 명령 비용과 오르는 값은 보여 주지 않는다. `commands.list`가 key·이름·분류·인자 형식만 준다. 병종은 번호로 받고(기본값은 내 장수의 병종),
    등용 대상 장수도 번호로 받는다. 능력치 규칙(합계 165, 15~80)은 월드별 규칙을 주는 API가 없어 화면 상수로 두고 최종 판단은 서버가 한다.
    서버 계약 확장이 필요해 [백로그](../product/backlog.md)에 적었다. 현재 AC 범위 밖이라 이번에 서버 카드를 만들지 않았다.
  - 분류 이름은 계획의 인사 대신 서버 분류(`strategy`)를 따라 전략으로 썼다. 임관·건국·거병·하야·등용이 들어 있다.
  - 사전 검사 표시는 기호(✓, ⚠) 대신 가능·경고 글자와 색을 함께 쓴다 (색만으로 알리지 않기, 글쓰기 규칙).
  - 저장하지 않은 초안을 sessionStorage에 둔다. 다시 로그인과 새로고침 뒤에도 편집을 잃지 않게 하려는 것이다. 다른 계정은 키가 달라 보지 못한다.
  - 클릭은 고르기·풀기를 번갈아 하는 방식이다. 넓은 범위는 Shift+클릭과 전체·홀수·짝수 버튼으로 고른다.
  - 화면은 `turns.edit`를 쓰지 않는다. 편집을 모아 한 번에 저장한다는 계획대로 `turns.set`만 부른다.
