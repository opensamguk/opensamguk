## 계획 (Claude)

### 목표

지금 병종 판 `basic`은 성벽과 보병·궁병·기병 세 종류뿐이다(T1-03 가정 A7). 사용자가 2026-11-01 병종을 다양하게 만들고 전투 특수 효과까지 넣도록 정했다. 원작의 계략 병종인 귀병 계열은 빼고 그 자리에 창극병 계열을 둔다. 원작 병종과 사료에 나오는 부대를 함께 넣는다. 사료 근거가 없는 원작 이름은 그대로 두되 창작이라고 적는다. 지역 조건은 원작의 8지역 대신 州로 정한다. 사용자는 이 범위를 모두 구현하라고 했다.

새 병종 판 `expanded`를 만든다. 새 월드에만 쓰며 기존 월드와 `basic` 판, 재생, 해시는 바꾸지 않는다.

### 계열과 상성

| 번호 | 계열 | 원작 |
| --- | --- | --- |
| 0 | 성벽 | 그대로 |
| 1 | 보병 | 그대로 |
| 2 | 궁병 | 그대로 |
| 3 | 기병 | 그대로 |
| 4 | 창극병 | 원작 귀병(4) 자리. 번호만 같고 내용은 새로 정한다 |
| 5 | 차병 | 원작 그대로 |

원작 보·궁·기는 보병이 궁병을, 궁병이 기병을, 기병이 보병을 이기는 세 고리다(공격 계수 1.2, 받는 계수 0.8). 창극병은 기병을 이기고 궁병에 진다. 보병과 창극병은 서로 1.0이다. 차병은 원작 계수를 그대로 쓰고 귀병(4) 칸은 창극병으로 읽는다.

| 공격 \ 방어 | 보병 | 궁병 | 기병 | 창극병 | 차병 |
| --- | --- | --- | --- | --- | --- |
| 보병 | 1.0 | 1.2 | 0.8 | 1.0 | 1.2 |
| 궁병 | 0.8 | 1.0 | 1.2 | 1.2 | 1.2 |
| 기병 | 1.2 | 0.8 | 1.0 | 0.8 | 1.2 |
| 창극병 | 1.0 | 0.8 | 1.2 | 1.0 | 1.2 |

이 표대로면 궁병이 두 계열을 이기고 기병이 두 계열에 진다. 수치 균형은 아래 균형 검사로 맞춘다. 검사에서 한 계열이 같은 비용 대결에서 다른 계열을 모두 이기면 기본 능력치를 고친다.

### 州 조건

병종 조건은 거점의 州를 읽는다. 지도 자원의 도시 행에 선택 칸 `province`를 더한다. 값은 191년 기준 13州(사례·예·기·연·서·청·형·양·익·량·병·유·교)와 東夷·이민족을 나타내는 작업 기준 값이다. 익주는 남중 조건 때문에 `익주`와 `남중` 두 값으로 나눈다. 남중은 『華陽國志』 南中志의 범위(건녕·운남·영창·월수·장가)를 따른다.

원작 8지역은 이렇게 옮긴다.

| 원작 지역 | 州 |
| --- | --- |
| 중원 | 청주병만 쓰던 지역이라 청·연주로 좁힌다 |
| 하북 | 기·유주 |
| 서북 | 량주와 옹주 삼보 |
| 서촉 | 익주(남중 제외) |
| 남중 | 남중 |
| 초 | 형주. 귀병을 빼서 이 지역 조건을 쓰는 병종은 남지 않는다 |
| 오월 | 양주 |
| 동이 | 쓰지 않는다. 궁기병은 오환·선비, 맥궁병은 고구려 거점으로 정한다 |

SAN10에서 새로 들어온 거점은 지금 대부분 region 1이다. 거점별 州 값은 SAN10 지도 사료 검토(D-054 2항)가 만드는 대응표로 채운다. 통합 지도와 che 지도에는 이 칸을 넣지 않으며 그 지도로 만든 월드는 `basic` 판만 쓴다.

### 병종 조건 검사

병종 판 스키마의 병종 행에 선택 칸 `requirements`를 더한다. 원작 `isCrewTypeAvailable`(`packages/logic/src/world/unitSet.ts:284-396`)의 조건 가운데 아래만 받는다.

| 종류 | 뜻 | 원작 |
| --- | --- | --- |
| `tech` | 국가 기술이 값 이상 | ReqTech |
| `provinces` | 국가가 그 州 도시를 하나 이상 가짐 | ReqRegions |
| `cities` | 국가가 그 도시를 가짐 | ReqCities |
| `citiesWithLevel` | 그 도시를 가지고 규모가 값 이상 | ReqCitiesWithCityLevel |
| `minRelYear` | 시작 연도부터 값 년이 지남 | ReqMinRelYear |
| `research` | 국가 연구 표식이 켜짐 | ReqNationAux can_* |
| `scorched` | 국가가 초토화를 한 번 이상 함 | ReqNationAux did_특성초토화 |
| `chief` | 실행 장수가 수뇌 | ReqChief |
| `impossible` | 모집 불가 | Impossible |

향귀병이 쓰던 ReqHighLevelCities·ReqNotChief는 귀병을 빼서 받지 않는다. 검사는 순수 함수 하나(`packages/rules/src/world/crewRequirements.ts`)로 둔다. 모병·징병(`commands/military.ts`), 부곡 편성(`campaign/preparation.ts`), 도시 수비병(`cityResources/preparation.ts`), 미리보기(`commands/statPreview.ts`), NPC 병종 고르기(`npc/index.ts`, `cityResources/npc.ts`)가 모두 이 함수를 부른다. 실패 문구는 원작처럼 「현재 선택할 수 없는 병종입니다.」에 이유 한 줄을 붙인다. 모병·징병은 원작처럼 실행 때 다시 검사한다.

### 전투 특수 효과

`battle/simulate.ts`는 지금 공격·방어·상성 계수만 쓴다. 병종 행에 선택 칸 `effects`를 더하고 아래 효과를 넣는다. 원작 트리거의 동작을 지금 페이즈 계산 위에 옮긴다. 원작 병종 판에서 이 효과를 가진 병종은 그대로 받는다.

| 효과 | 원작 | 동작 |
| --- | --- | --- |
| `firstVolley` | che_선제사격시도·발동 (`war/triggers/che_선제사격.ts:11-54`) | 첫 페이즈 전에 한 번 더 사격한다. 이 사격에서 상대에게 평소의 2/3 피해를 주고 받는 피해는 0이다. 양쪽 다 가지면 서로 2/3씩 주고받는다. 성벽과 궁병 계열, 정란·벽력거 |
| `guard5` | che_방어력증가5p (`:10-15`) | 수비할 때 받는 피해 1/1.05. 보병 계열 |
| `cavalryClash` | che_기병병종전투 (`:10-20`) | 공격할 때 주는 피해 1.02, 받는 피해 0.97. 수비할 때는 반대. 성벽을 칠 때 주는 피해 0.9. 기병 계열 |
| `wallSafe` | che_성벽부상무효 | 성벽을 칠 때 장수 부상이 없다. 차병 계열 |
| `hold` | che_저지시도·저지 | 수비할 때 (훈련+사기)/400 확률로 한 페이즈를 막고 상대 피해의 0.9를 흡수한다. 목우 |
| `avoid` | che_회피시도·발동 | 매 페이즈 `avoid`% 확률로 받는 피해 1/6. 기존 병종 행의 avoid 값을 쓴다 |
| `pikeWall` | 신규 | 창극병 계열. 기병의 `cavalryClash`를 지운다 |

상성 계수 키는 계열 번호와 병종 id를 함께 받는다. 원작 정란·충차는 백이병(1106)·양마기병(91300)을 병종 id로 따로 적었다(`coefficient`가 지금은 계열 키만 읽는다).

난수 소비 순서가 바뀌면 재생이 깨진다. 효과가 없는 병종만 쓰는 전투는 지금과 같은 순서로 난수를 쓰고 같은 결과를 낸다. 이 성질을 `basic` 판 회귀 시험으로 고정한다. 확률 효과(`hold`, `avoid`)는 효과를 가진 병종일 때만 난수를 더 쓴다.

### 연구 병종

연구 병종 7종(대검병·극병·화시병·원융노병·산저병·상병·화륜차)은 T4-09·T4-10의 연구 명령으로 연다. 두 계획은 준비 턴 기제(T4-07)가 먼저 들어가야 한다. 사용자가 전부 구현하라고 해서 T4-07 → T4-09 → T4-10 순서로 이 작업 뒤에 잇는다. 그 전에는 `research` 조건이 언제나 거짓이라 연구 병종을 고를 수 없다. 음귀병·무희 연구 명령 두 개(`nation_research_ghost`, `nation_research_dancer`)는 귀병을 빼면서 여는 병종이 없어진다. 명령 대응표에서 사용자 결정으로 제외한 명령으로 표시한다.

### 균형 검사

병종 판을 바꾸면 도구 하나(`tools/unitset/balance.ts`)가 같은 비용 병력끼리 모든 쌍을 시드 100개로 싸우게 하고 이긴 비율 표를 낸다. 조건은 둘이다. 같은 계열 기본 병종끼리 상성표 방향과 다르게 이기는 쌍이 없어야 한다. 같은 기술 단계의 병종 가운데 비용 대비 승률이 모든 상대에게 60%를 넘는 병종이 없어야 한다. 이 표는 계획 리뷰와 PR에 붙인다.
