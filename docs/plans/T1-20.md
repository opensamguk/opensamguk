# T1-20 참가할 월드 목록 API

> 대기열: T1-20 · AC: AC-M1-05 (로그인 뒤 이동) · 구현: Codex · 리뷰: Claude
> 선행: T1-10 · T1-14 구현 중 생긴 작업 · 화면 연결: T1-16

## 계획 (Claude)

### 목표

로그인 뒤 돌아갈 주소(`next`)가 없을 때 화면이 첫 RUNNING 월드(`/w/:id`)로 보낼 수 있게, 월드 목록을 준다.
월드 ID가 UUID라 화면이 추측할 수 없다.

### 범위

`apps/server`에 `world.list` query 하나.

- 로그인 필요(`protectedProcedure`). 무인증은 `UNAUTHORIZED`.
- 반환: `{ worlds: Array<{ id: string; name: string; status: WorldStatus }> }`.
- `status`가 `RUNNING`인 월드만, 만든 순서(오래된 것 먼저).
- 입력 없음(`z.void()`).

### 하지 않는 것

로비(인원·설정·참가 신청)는 M2 T2-03. 내 장수가 있는 월드 우선 정렬도 T2-03.

### 검증

| 무엇 | 어떻게 |
| ---- | ------ |
| 목록 | 통합 테스트: PREOPEN·RUNNING·PAUSED 월드 중 RUNNING만, 만든 순서 |
| 권한 | 통합 테스트: 무인증 `UNAUTHORIZED` |
| 비어 있음 | 통합 테스트: RUNNING 월드가 없으면 `worlds: []` |

### 채울 문서

구현하면서 함께 채운다. 리뷰어는 문서도 확인한다.

- 없음 (API 계약은 `AppRouter` 타입).
