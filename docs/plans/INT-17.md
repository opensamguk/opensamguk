# INT-17 기본 계략4종 운영 연결

> AC-INT-17 · 구현 Codex · 리뷰 Claude · 선행 INT-14, INT-15 · 견적 3~4일
> 사용자 지시로 동결한 [통합판 v0.1](./integration-release.md)과 [5능력치](../product/five-stats.md)를 따른다.

## 계획

목표는 기존 화계·파괴·선동·탈취 순수 규칙을 선택 재사용해 새 프로필에 등록한다. five-stats의 공격 점수와 지력 저항, 기존 비용·RNG·피해를 연결한다. 기존 ext/personnel 충돌 플래그를 없애는 우회는 금지하고 필요한 네 명령만 typed 저장/입력/재생 어댑터로 잇는다. 장비·전략8종·특수병종·카드 명령은 제외한다.

수정 범위는 packages/rules/src/commands/ext/stratagem/, packages/rules/src/ruleRegistry.ts, apps/engine/src/, apps/server/src/, e2e/다. 새 기능을 더하지 않는다. 기존 main·v1 기준 SHA와 자원 출처는 통합 기준 문서를 따른다. 세부 코드 경계·API 인증·엔진 단독 상태 변경·시드 RNG·턴 트랜잭션을 지킨다.

검증은 인사/서약과4계략 공존, 실제 DB 실행·비용/실패·타인/제재·중복 입력·재시작, source RNG 검증·archive 재생/해시, UI 명령 목록과 엔진 가능 명령 일치

선행 인수 뒤 착수하고 검증 결과와 구현하지 않은 담당의 리뷰를 같은 문서에 남긴다. 구현자가 스스로 완료로 바꾸지 않는다.

## 구현 기록

2026-10-27 순수 산식·기능 등록, 실제 DB/API·재생, 화면·공존 인수의 세 묶음으로 나눠 착수한다. 각 묶음은 하루 이내이며 AC-INT-17에 연결한다. 네 계략은 별도 저장 조각 없이 기존 typed 효과·개인 예약·엔진 턴 경로를 사용한다. 기존 ext/personnel 충돌은 유지한다. 새 stratagem-basic 기능만 five-stats에 의존하고 공격 점수와 지력 저항을 적용한다. 비용·피해·성장·난수 소비 순서는 유지한다. 아직 운영 인수·독립 리뷰·병합 전이다.

## 검증 결과

2026-10-27 구현하지 않은 담당의 독립 리뷰에서 파괴가 기존 strength 분기를 따라가는 P1을 발견했다. 실제 명령 key를 구별해 화계·파괴는 지력을 쓰도록 고쳤고, 지력80/무력70·난수0.44의 실제 파괴 성공과 지력70/무력100의 실패 반례를 추가했다. 수정본 독립 리뷰를 통과했다. 기존 비용·피해·난수 순서는 유지한다.

집중6파일227건 통과. 실제 PostgreSQL·HTTP1건은 인사·정책·조약을 함께 켠 월드에서 사람 장수를 API로 생성하고 출사한 뒤 네 계략을 예약·실행했다. 미인증·타인·행위자 위조·제재·중복 revision을 거부하고, 재시작·5개월 재생 해시와 다른 월드 보존을 확인했다(2.36초). 실제 격리 PG·API·Vite·Chromium1건은 네 명령 목록·30칸·화계 실행 비용·다음 칸 표시를 통과했다(9초). 화면도 검수했다.

전체 pnpm check는 새 schema 의존성을 시험 fixture에 복사하지 않은4건만 먼저 실패했다. 실제 원본 파일 한 줄을 복사 목록에 추가해 assertion·부정 반례를 유지했고 독립 리뷰와 집중137건을 통과했다. 최종 전체 check는254파일4975건 전부 통과했다(256.41초). 필수 CI·main 병합은 아직 전이므로 AC-INT-17 완료로 기록하지 않는다. 정식 시나리오·새 지도·휘하·전체 한 기수 인수는 INT-12에서 별도로 확인한다.
