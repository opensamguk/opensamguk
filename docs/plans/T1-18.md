# T1-18 독립 에이전트 15분 실제 플레이·완주 데모

> 대기열: T1-18 · AC: AC-M1-21 · 수행: 독립 참가 에이전트 · 확인: 총괄과 반대쪽 리뷰
> 선행: T1-09, T1-14, T1-15, T1-16, T1-17, T1-19, T1-26, T1-27 · 사전 점검 카드: t_0a3237e7

## 계획 (Claude)

### 목표

턴 간격 1분 월드에서 참가자 1명이 장수 생성, 임관, 내정, 모병, 출병, 점령까지 실제 브라우저 화면을 조작해 진행한다.
참가자는 소유자 승인 M1-INDEPENDENT-15MIN-20261022(2026-10-22)에 따라 사람 1명 대신 독립 에이전트 1명이다. 이 에이전트는 T1-26·T1-27 구현자, 이 계획 작성자, 시험 증거 작성자와 분리한다. 가속 전 실제 플레이는 최소 15분이다.
이어 가속 모드로 그 판의 종료까지 가고 종료 화면에 승자와 연도가 나온다 (AC-M1-21, A17·D-024).

### 사전 점검에서 확인한 빈 곳

main `77723bf`의 사전 점검(CI [39741923516](https://github.com/peppone-choi/opensamguk/actions/runs/39741923516), 산출물 `T1-18-main77723bf-preflight.zip`)에서 기술 회귀는 통과했지만 데모 뒷부분을 할 경로가 없었다.
엔진은 종료를 판정하지 않고 사람이 플레이한 같은 DB 월드를 가속하는 운영 명령이 없으며 승자·종료 결과를 읽는 API와 화면도 없다.
이 빈 곳을 두 작업으로 나눴다. 백엔드는 [T1-26](./T1-26.md)(Codex), 화면은 [T1-27](./T1-27.md)(Claude)이다. 둘 다 병합돼야 데모를 시작한다.
NPC 전용 `pnpm sim`이나 새 NPC 판으로 사람 판의 종료를 대신하지 않는다.

### 종료 규칙 (D-024)

소유자가 승인 기록 GAME-END-POLICY-20261022(2026-10-22 20:06 KST)로 아래 세 가지를 정했다. 정본은 [D-024](../product/decisions.md#d-024-m1-완주-데모의-참가자와-기수-종료-규칙을-정한다-2026-10-22)다. 같은 결정을 다시 묻지 않는다.

| 번호 | 정한 것 | 답과 근거 |
| ---- | ------- | --------- |
| Q1 | A17. 기수는 천하통일이나 월드에 정한 종료 연도에 끝난다 | 승인. T1-26의 `--end-year` 명시 생성 계약을 그대로 쓴다. 기존 `endYear = null` 월드는 통일로만 끝난다 |
| Q2 | 데모 월드의 종료 연도 | 300년. 이 시험 월드의 생성 인자일 뿐 운영 기본값이나 제품 상수가 아니다. 1030은 191년에 시작하고 AC-M1-17의 10시드는 300년까지 통일 0건이었다. 실제 DB 가속에 걸리는 시간은 T1-26 구현 기록의 처리량으로 본다 |
| Q3 | 종료 연도로 끝났을 때 승자 | 승자 없음(`END_YEAR`, 승자 `null`). 300년 12월 정산 전에 통일하면 실제로 통일한 국가가 승자다(`UNIFIED`). 도시 수 같은 다른 기준은 넣지 않는다 |

사전 점검의 300년은 NPC 시뮬레이터 기본값(AC-M1-17 증거용)을 빌린 합성 경계였다. 승인된 300년은 이 시험 월드에 따로 준 값이며 시뮬레이터 상수에서 읽지 않는다.

### 진행

1. 기준 소스를 정한다. T1-26·T1-27이 들어간 최신 main의 정확한 SHA와 그 SHA의 필수 CI 통과를 기록한다. `77723bf`를 그대로 쓰지 않는다.
2. 사전 점검 체크리스트의 전용 개발 환경 명령으로 일회용 DB를 띄운다. 기존 운영 DB·공유 DB·다른 담당의 DB는 쓰지 않는다.
3. `pnpm world:create --scenario 1030 --map che --seed <시드> --turn-term 1 --end-year 300 --name <이름>`, `pnpm world:start --world <ID>`, `pnpm dev`.
4. 가입·로그인은 녹화 전에 끝낸다. 녹화는 월드 선택부터 한다. 실제 이메일·비밀번호·쿠키·토큰과 DevTools 저장소는 녹화하지 않는다.
5. 화면에서 장수 생성, 임관, 내정, 모병, 출병, 점령을 한다. 각 단계의 턴 결과를 메인 기록에서 확인한다.
6. 점령 확인 뒤 `pnpm world:accelerate --world <ID>`. 위쪽 띠에 가속 진행 중이 보이는지 확인한다. 필요하면 `world:pause`·`world:resume`으로 멈췄다 이어 간다.
7. 엔진이 월드를 끝내면 `pnpm world:status --world <ID>`로 `ENDED`와 결과를 확인한다. 브라우저를 새로고침해 결과 칸의 끝난 이유, 승자(또는 승자 없음), 종료 연월을 녹화한다.

### 체크리스트

참가 에이전트가 채운다. 영상 시각과 관측한 값을 단계마다 적는다. 가속 전 실제 플레이 구간의 시작·끝 영상 시각으로 15분 이상임을 보인다.

| 단계 | 확인할 것 |
| ---- | --------- |
| 월드 | 같은 `worldId`, 턴 간격 1분, `world:status`의 `endYear`가 300 |
| 장수 생성 | 참가 에이전트가 화면 입력란을 직접 조작해 이름·능력치·초상 입력, 합계 규칙 |
| 임관 | 예턴 입력, 실행 뒤 소속 국가 표시 |
| 내정 | 실행 결과와 도시 수치 변화 |
| 모병 | 병력 변화 |
| 출병·점령 | 전투 기록과 도시 소유 변화 |
| 가속 | `world:accelerate` 실행, 같은 월드에서 연월이 빠르게 넘어감, 사람 장수 기록이 이어짐 |
| 종료 | `world:status`의 `ENDED`, 결과 칸의 이유·승자·연월이 서로 같음, 새로고침 뒤에도 같음. `END_YEAR`면 300년 12월·승자 없음, `UNIFIED`면 통일한 국가가 승자 |

### 증거 형식

녹화 파일명과 SHA-256, 참가 에이전트 식별(구현·증거 작성자와 다름), 가속 전 실제 플레이 시간, 채운 체크리스트, 기준 소스 SHA와 필수 CI 링크, `worldId`·시드·종료 연도 300과 그 결정 근거(D-024), `world:status` 출력(비밀값 없음).
자동 E2E·단위 시험, 화면을 거치지 않는 API 요청, NPC 수, 시뮬레이터 결과, 합성 경계 탐침, CI 실행 시간은 실제 플레이 15분이나 이 AC의 증거로 세지 않는다. 가속 시간도 15분에 넣지 않는다.
독립 참가 에이전트의 실제 브라우저 녹화와 체크리스트를 확인한 뒤에만 AC-M1-21을 바꾼다. M1-INDEPENDENT-15MIN-20261022와 D-024의 승인은 시험 성공이나 AC 완료가 아니다.

### 하지 않는 것

데모를 쉽게 하려고 종료 연도를 D-024의 300년에서 바꾸거나, 운영 명령으로 상태를 직접 `ENDED`로 바꾸거나, 수치를 고치지 않는다.
최신 소유자 지시의 전체 명령 MVP(AC-M1-14 전체 명령)는 별도 관문이다. 이 데모로 그 조건을 대신하지 않는다.
