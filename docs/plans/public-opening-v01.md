# 통합판 v0.1 공개 오픈 준비

> 2026-10-28 사용자 요청으로 공개 준비를 별도 실행 목표로 등록했다. 금요일 공개 준비 구현, 토요일 전체 검사, 다음 주 누구나 가입하는 공개 오픈을 목표로 한다. 목표일은 인수조건 면제나 완료 보장이 아니다.

## 범위와 일정

통합판의 게임 범위는 [동결 계획](./integration-release.md)을 유지한다. AC-INT의 유효15개는 실제132개월 완주·복원·재생과 독립 인수 뒤 PR #264, main `fe065223`에서 완료했다. 이번 실행은 공개 준비의 남은 구현을2026-10-30까지 끝내고10-31에 최종 후보의 전체 검사·복원·가입 리허설을 실행하는 목표다. 변경별 검사는 그 전에 진행한다. 다음 주는11-02~11-08이며 공개 날짜를 확정했다는 뜻은 아니다.

사용자는 다음 주 오픈이 초대 테스트가 아니라 누구나 가입하는 공개 오픈임을 확인했다. 이전 요청에서 보류했던 메일·약관·공개 배포의 준비를 다시 범위에 넣는다. 군현·지속 행군·5자원·피로·카드·실시간/격자 전투·v1 전체1,000명·원작90명령과 새 공개 초상은 이 요청으로 되살리지 않는다. 공개 권한과 실제 배포·리허설 완료는 구분한다. 기존 사용자 데이터와 월드를 보존하며 새 비용·계정 비밀값·운영 초기화를 임의로 만들지 않는다.

통합판의 완료율은15개 AC 중 구현·검증·독립 리뷰·main 병합이 있는 항목의 비율로 유지한다. 공개 준비 항목을 이 분자에 더하지 않으며 두 목록은 서로의 완료 증거를 대신하지 않는다.

사용자는 담당 이름과 기존 대기열 선행 때문에 멈추지 말고 결정이 필요 없는 공개 준비를 구현·검증·독립 리뷰·보호 병합까지 진행하도록 승인했다. 서버·도메인·메일 서비스와 운영자·문의 이메일은 미정이다. 비용·외부 계정 접근·약관 본문·보존안·실제 공개 실행은 승인받은 것으로 기록하지 않는다.

### 운영 후보와 첫 메일 묶음

2026-10-28 공식 가격표 기준으로 DigitalOcean 기본4vCPU·8GiB·160GiB는월$48, 작은2vCPU·4GiB·80GiB는월$24다. 첫 안은 큰 사양으로 부하를 측정하는 것이며 수용량을 보장하지 않는다. 세금·외부 백업·도메인 비용은 별도다. [공식 가격](https://www.digitalocean.com/pricing/droplets)

도메인은 Cloudflare Registrar의 등록/갱신 원가 정책을 후보로 둔다. 실제 이름의 등록 가능 여부와 등록·갱신 가격은 구매 전에 확인한다. 도메인 이름·구매·계정 선택은 미정이다. [공식 안내](https://domains.cloudflare.com/)

메일 후보는 Resend의 HTTPS API다. 무료는월3,000건/하루100건, Pro는월$20/50,000건이며 공개 첫날에는 무료 일 한도가 가입을 막을 수 있다. 서버$48와 Pro의 기본 합계는월$68이고 추가 비용은 별도다. [공식 가격](https://resend.com/pricing)

DigitalOcean은 기본 SMTP25·465·587을 막으므로 HTTPS를 먼저 준비한다. 이번 묶음은 `MAIL_TRANSPORT=resend`를 명시했을 때만 고정된 공식 HTTPS 주소로 발송한다. 키는 `MAIL_API_KEY_FILE`에서만 읽고 발신 주소는 `MAIL_FROM`으로 받는다. 운영 capture와 미설정/잘못된 키 파일은 시작을 거부한다. 발신 도메인 인증·연락처·사용자 키가 없으면 활성화하지 않는다. 자동 재시도 없이10초 안에 실패를 돌려주고 공급자 본문·주소·토큰·키를 오류나 로그에 남기지 않는다. 로컬 HTTP 시험의 목적지 주입은 직접 생성자 인자로만 허용하고 운영 환경변수로 목적지를 바꾸는 경로는 만들지 않는다. [SMTP 제한](https://docs.digitalocean.com/support/why-is-smtp-blocked/), [Resend 전송 계약](https://resend.com/docs/api-reference/emails/send-email)

## 남은 범위 대조

기존 AC-M3-16은 AC-M3-01~15 전부를 공개 선행으로 요구한다. 그중 AC-M3-12~15의 관직 주재 보정·추천 예턴·역사 인물 역할 입장·월단평은 통합판 AC의 완료 분모에 없다. 이번 오픈 일정만으로 이 네 조건을 완료·취소하거나 게임 동결 범위를 확대하지 않는다. 공개 관문과 v0.1 범위의 관계는 실제 구현 상태를 대조한 뒤 명시적으로 정한다. 이 대조 전에는 공개 관문을 모두 통과했다고 기록하지 않는다.

## 검증과 리뷰

공개 준비 전체는 미완료다. PR #262의 계정 기반에는 실제 전체 검사와 독립 리뷰가 있지만 인증/동의 차단·탈퇴·운영 연결을 대신하지 않는다. 앞선 공개 build의 잘못된 실행 환경과 지도 준비30초 초과 실패 기록도 보존했다. 지도는 원래30초 그대로 전체 재실행에서 준비5.913초·8건 통과와 자기 DB 삭제를 확인했으나 최초 초과의 원인은 미확정이다. 각 작업의 최종 코드와 실제 검증은 구현하지 않은 담당에게 독립 리뷰받는다. 사람의 수락이나 공개 운영 결과를 대신 기록하지 않는다.

2026-10-27 문서의 독립 리뷰에서 관리자 작업 번호를 T3-05·06으로 바로잡고 기존 AC의 독립 에이전트 리허설과 사용자 수락을 구분했다. 수정 뒤 추가 지적 없이 문서 리뷰를 통과했다. 이 증거는 공개 준비 계획의 검토이며 공개 관문 인수나 배포 결과는 아니다.
