# 통합판 v0.1 공개 오픈 준비

> 2026-10-27 사용자 요청. 금요일 통합판 완료, 토요일 전체 검사, 다음 주 누구나 가입하는 공개 오픈을 목표로 한다. 목표일은 인수조건 면제나 완료 보장이 아니다.

## 범위와 일정

통합판의 게임 범위는 [동결 계획](./integration-release.md)을 유지한다. 2026-10-30까지 AC-INT의 구현·실제 검증·독립 리뷰·main 병합과 정식 한 기수 완주를 목표로 한다. 전체 회귀는 변경마다 먼저 실행하고 10-31은 최종 전체 검사·복원·가입 리허설과 발견된 결함 수정에 쓴다. 다음 주는11-02~11-08이며 공개 날짜를 확정했다는 뜻은 아니다.

사용자는 다음 주 오픈이 초대 테스트가 아니라 누구나 가입하는 공개 오픈임을 확인했다. 이전 요청에서 보류했던 메일·약관·공개 배포의 준비를 다시 범위에 넣는다. 군현·지속 행군·5자원·피로·카드·실시간/격자 전투·v1 전체1,000명·원작90명령과 새 공개 초상은 이 요청으로 되살리지 않는다. 공개 권한과 실제 배포·리허설 완료는 구분한다. 기존 사용자 데이터와 월드를 보존하며 새 비용·계정 비밀값·운영 초기화를 임의로 만들지 않는다.

통합판의 완료율은15개 AC 중 구현·검증·독립 리뷰·main 병합이 있는 항목의 비율로 유지한다. 공개 준비 항목을 이 분자에 더하지 않으며 두 목록은 서로의 완료 증거를 대신하지 않는다.

## 공개 준비 대조표

기존 [인수조건](../product/acceptance-criteria.md#m3)과 각 상세 계획을 사용한다. 아래는 착수 시점의 미완료 범위이며 구현이 있다는 이유만으로 AC를 통과시키지 않는다.

| 작업과 AC | 해야 할 일과 검증 | 묶음 |
| --- | --- | --- |
| T3-01~03, AC-M3-01·02 | 메일 인증·일회용30분 재설정·실제 수신·버전 동의·탈퇴/익명화·가입 화면을 연결한다. 서비스와 발신 도메인·운영자/문서 본문은 실제 설정과 맞춘다 | 서버/메일2일, 동의/탈퇴2일, 화면1~2일 |
| T3-04, AC-M3-03 | 최종 AppRouter의 세션·CSRF·요청 제한·제재·타인·입력 오류를 실제 HTTP/PG로 대조한다. 새 메일·휘하 API를 누락하지 않는다 | 1일 |
| T3-05·06, AC-M3-04·05 | 관리자 월드/계정 조작·감사·다중계정 자료의 구현과 권한을 대조하고 부족한 경로를 구현한다 | API/감사2일, 화면1~2일, 반례1일 |

| T2-15, AC-M2-08·09·10 | 운영 Compose/HTTPS/배포·이전 이미지 복귀·매일 백업·별도 DB 복원·오류 알림을 구현하고 실제 절차대로 검증한다 | 배포2일, 복원/복귀1~2일, 알림1일 |

표의 일수는 작업을5작업일 이하의 검증 가능한 묶음으로 나눈 견적이다. 이 일수를 합쳐 위 마감까지 모두 끝난다고 약속한 것은 아니다. 앞선 구현은 재사용하며 미완료와 실제 결함부터 처리한다. 계정 접근이나 사용자 결정이 필요하면 먼저 구현·시험·설정 후보·인수 자료를 준비해 필요한 입력만 요청한다.

## 남은 범위 대조

기존 AC-M3-16은 AC-M3-01~15 전부를 공개 선행으로 요구한다. 그중 AC-M3-12~15의 관직 주재 보정·추천 예턴·역사 인물 역할 입장·월단평은 통합판 AC의 완료 분모에 없다. 이번 오픈 일정만으로 이 네 조건을 완료·취소하거나 게임 동결 범위를 확대하지 않는다. 공개 관문과 v0.1 범위의 관계는 실제 구현 상태를 대조한 뒤 명시적으로 정한다. 이 대조 전에는 공개 관문을 모두 통과했다고 기록하지 않는다.

## 검증과 리뷰

공개 준비를 완료했다고 판정할 증거는 아직 모으지 않았다. main에 메일 인증·동의·탈퇴의 모델/실행 경로가 없고 운영 배포 문서에도 미완료 절차가 남아 있음을 확인했다. 통합판을 먼저 완성하면서 외부 계정에 의존하지 않는 준비를 진행한다. 각 작업의 최종 코드와 실제 검증은 구현하지 않은 담당에게 독립 리뷰받는다. 사람의 수락이나 공개 운영 결과를 대신 기록하지 않는다.

2026-10-27 문서의 독립 리뷰에서 관리자 작업 번호를 T3-05·06으로 바로잡고 기존 AC의 독립 에이전트 리허설과 사용자 수락을 구분했다. 수정 뒤 추가 지적 없이 문서 리뷰를 통과했다. 이 증거는 공개 준비 계획의 검토이며 공개 관문 인수나 배포 결과는 아니다.
