## 계획 (Claude)

### 목표

[글쓰기 규칙](../writing-style.md)의 S1 패턴을 기계로 잡는다. T1-23·T1-24가 고친 결과를 이 검사로 확인한다.

### 범위

`tools/lint-text/`와 루트 스크립트 `pnpm lint:text`.

- 대상: `docs/**/*.md`, `AGENTS.md`, `README.md`, `apps/web/src`의 문자열·JSX 텍스트, `packages/rules/src`와 `apps/server/src`의 한국어 문자열
- 코드 블록, 인라인 코드, URL, 표의 경로 칸은 건너뛴다.
- `private/`(git 제외, 비공개 자료)는 검사하지 않는다.
- 검사 항목(원본 ID): 이모지(C-5), 이중 피동 "되어지"(A-8), "가지고 있다"(A-7), 결산어 문서당 3회 초과(D-1), 의의 과장 문구(D-2), 열거 도입구(D-3), 연결어미 뒤 쉼표(C-11), 콜론 부제 헤딩 반복(C-10), 따옴표 강조 문서당 5회 이상(J-2) <!-- lint-text-ignore A-7 A-8 -->
- 출력: `파일:줄 [ID] 걸린 표현`. 기본은 경고만 내고 `--strict`면 1건이라도 있으면 실패한다.
- 예외: 줄 끝 `<!-- lint-text-ignore ID -->`, 코드에는 `// lint-text-ignore ID`

### 하지 않는 것

윤문(고치기) 자동화, S2 패턴 전부. S2는 사람과 리뷰가 본다. `pnpm check` 연결은 T1-23·T1-24가 끝난 뒤 한다(지금 넣으면 기존 글 때문에 실패한다).

### 검증

| 무엇 | 어떻게 |
| ---- | ------ |
| 패턴 | 단위 테스트: 항목마다 걸리는 예문 1개, 안 걸리는 예문 1개 (원본의 사람 글 예외 포함) |
| 건너뛰기 | 단위 테스트: 코드 블록·인라인 코드·URL 안의 표현은 안 걸림 |
| 실제 저장소 | `pnpm lint:text` 결과 건수를 구현 기록에 남긴다 (T1-23·T1-24의 출발점) |

- 재리뷰(t_a91a329e, `961e6cd`) R2b 수정, 칸반 t_e0026dd5:
  - 문제: 목록 표지를 한 번만 떼고 표지 뒤 첫 내용의 들여쓰기를 다시 보지 않았다. 그래서 목록 안 인용의 펜스(`- > ` 뒤 펜스), 한 줄에 겹친 목록 안의 펜스(`- - ` 뒤 펜스), 표지 뒤 5칸 이상 띄운 들여쓴 코드가 글로 걸렸다.
  - `maskMarkdown()`의 블록 판정을 컨테이너 스택으로 바꿨다. 줄마다 열린 인용과 목록 항목을 바깥부터 맞춘다. 남은 자리에서는 새 인용과 목록 항목을 겹친 만큼 모두 연다. 그 뒤 가장 안쪽의 첫 내용을 펜스, 들여쓴 코드, 문단 순으로 판정한다. 인용과 목록이 어떤 순서로 겹쳐도 같은 경로를 탄다. 예문별 예외는 두지 않았다.
  - 같이 맞춘 CommonMark 규칙: 목록 항목의 칸은 바깥 컨테이너의 내용 시작점부터 센다(인용 표지 앞 공백이 줄마다 달라도 된다). 표지 뒤가 5칸 이상이면 1칸 뒤에서 내용이 시작하고 나머지는 들여쓴 코드다. 빈 채로 열린 항목은 빈 줄에서 끝난다. 문단 바로 아래의 `-` 줄은 제목 밑줄이다. 문단 안에서는 빈 항목과 1이 아닌 번호 목록이 새 항목을 열지 못한다. 표지가 빠진 이어쓰기 줄에서는 바깥 컨테이너가 새 항목을 연다.
  - 이미 열린 인용은 표지 앞이 4칸 이상이어도 이어진다고 본다. CommonMark 명세와 markdown-it이 다르게 읽는 곳이다. 코드로 보고 가리는 쪽보다 글로 보고 검사하는 쪽을 골랐다.

  - markdown-it(CommonMark)과 대조: 인용·목록 표지, 펜스, 들여쓴 줄, 제목, 구분선, 빈 줄을 무작위로 1~8줄 엮은 문서 12만 개(탭 없는 것 6만, 탭 섞은 것 6만)에서 코드 밖 문장 수를 비교했다. 우리가 markdown-it보다 더 가리는 경우는 0건이다. 남은 차이는 탭 없는 쪽 25건, 탭 섞은 쪽 61건이고 모두 우리가 더 검사하는 쪽이다. 이중 인용 안의 게으른 이어쓰기, 탭 뒤 인용 표지처럼 markdown-it이 명세와 달리 읽는 갈래다. 대조 스크립트는 작업 메모라 커밋하지 않았다.
