# T2-06 직책·인사·발령 응답 화면

> 대기열: T2-06 · AC: AC-M2-05, AC-M2-16 (화면) · 구현: Claude · 리뷰: Codex
> 선행: T2-05 (API)

## 계획 (Claude)

### 목표

군주는 인사부에서 임명·해임을, 직책자는 자기 국가 예턴을, 사람 장수는 발령 제안에 답한다.

### 범위

`apps/web`: `/w/:id/nation/personnel`(인사부), `/w/:id/nation/turns`(국가 예턴), 메인의 발령 알림 상자, 위쪽 띠 메뉴 `국가`.

### 화면

- **인사부:** 소속 장수 표(이름·직책·도시·공헌·사람/NPC). 직책 높은 순으로 놓는다. 군주에게만 직책 바꾸기 칸이 열린다. 다른 사람에게는 `DisabledReason`으로 서버가 준 이유(`군주만 임명할 수 있습니다`)를 보인다.
- **국가 예턴:** T1-15 예턴 편집 부품을 재사용. 직책 탭(군주·참모·수뇌…), 내 칸만 편집 가능, 남의 칸은 읽기 전용. 국가 예턴 권한이 없는 장수에게는 서버가 준 이유를 보인다.
- **발령 제안:** 메인 위쪽에 눈에 띄는 상자를 둔다. 문구는 `공손찬이 북평으로 발령했습니다 · 남은 기한 1개월, 넘기면 수락`이고 [수락] [거절] 버튼이 붙는다. 거절 버튼 옆에 공헌이 얼마나 줄어드는지(−10%와 실제 값) 안내한다.
- 권한은 서버가 준 값(`appoint`, `edit`, `respond`)으로만 판단해 버튼을 그린다. 화면이 권한을 추측하지 않는다.

v1과 다르게 정한 것:

- v1 발령 대상은 현이다. 새 게임은 94도시라 도시로 바꿔 읽는다.
- v1은 거절하면 충성과 명망이 줄었다 (`requests.ts:75`). 새 규칙은 공헌 −10%다 (T2-05).
- v1의 취소됨(발령이 무효가 되어 벌점 없이 끝남, `requests.ts:16`)은 새 `SUPERSEDED`에 해당한다. 메인 상자는 PENDING만 그리므로 끝난 상태 칩을 두지 않는다.
- v1은 받은 요청을 서신함 탭과 조정 화면에서 보였다. 새 화면은 메인 위쪽 상자 하나로 모은다 (방치되는 장수가 바로 보게, D11).

v1에는 있으나 범위 밖:

- 내린 발령 현황 (대상과 현, 응답 기한, 상태, `CourtParts.tsx:51-78`)
- 포상 미리보기와 창고별 차감 추정 (`CourtParts.tsx:161-231`)
- 봉록 (`CourtParts.tsx:235-239`)
- 조정 결정의 부대 탈퇴 지시와 현 포기 (`CourtScreen.tsx:30-34`). 천도는 국가 예턴 명령으로 들어간다 (T1-08).
- 지방 관직·속관·추천·중앙 관직·봉신 탭 (`web/game/components/offices/OfficesScreen.tsx:24-30`)
- 서신함 요청 탭과 정치 동의 요청 (`web/game/components/mail/MailRequestsPane.tsx:21-36`)
- 인물 표 거르기, 초성 찾기, 능력 열 (`web/game/components/people/PeopleFilterBar.tsx:11-80`)
- 모바일 결정 목록 (`CourtParts.tsx:350-388`)
