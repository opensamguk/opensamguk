# T2-06 직책·인사·발령 응답 화면

> 대기열: T2-06 · AC: AC-M2-05, AC-M2-16 (화면) · 구현: Claude · 리뷰: Codex
> 선행: T2-05 (API)

## 계획 (Claude)

### 목표

군주는 인사부에서 임명·해임을, 직책자는 자기 국가 예턴을, 사람 장수는 발령 제안에 답한다.

### 범위

`apps/web`: `/w/:id/nation/personnel`(인사부), `/w/:id/nation/turns`(국가 예턴), 메인의 발령 알림 상자, 위쪽 띠 메뉴 "국가".

### 화면

- **인사부:** 소속 장수 표(이름·직책·도시·공헌·사람/NPC). 군주에게만 직책 바꾸기 칸이 열리고 다른 사람에게는 `DisabledReason`("군주만 임명할 수 있습니다").
- **국가 예턴:** T1-15 예턴 편집 부품을 재사용. 직책 탭(군주·참모·수뇌…), 내 칸만 편집 가능, 남의 칸은 읽기 전용.
- **발령 제안:** 메인 위쪽에 눈에 띄는 상자: "공손찬이 북평으로 발령했습니다 · 남은 기한 1개월 [수락] [거절]". 거절 버튼은 "공헌 −10%" 안내를 함께.
- 권한은 서버가 준 값(`canAppoint` 등)으로만 판단해 버튼을 그린다. 화면이 권한을 추측하지 않는다.

### 검증

| 무엇 | 어떻게 |
| ---- | ------ |
| 임명 | Playwright: 군주로 로그인 → 수뇌 임명 → 수뇌 계정에서 국가 예턴 편집 가능 |
| 권한 | Playwright: 일반 장수 → 인사 칸 잠김과 이유 |
| 발령 | Playwright: 제안 상자 → 수락 → 위치 바뀜 / 거절 → 안내 문구 뒤 상자 사라짐 |
