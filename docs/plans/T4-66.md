## 1. 목표

AC-M1-14의 이 명령 행(`scout_talent`)이 대응표 11단계 증거를 모두 갖는다. 켠 월드에서 장수가 금을 내고 인재를 찾는다. 찾으면 재야 NPC 장수가 새로 생겨 다음 차례부터 지금 NPC 판단으로 움직인다. 새 장수는 같은 트랜잭션에 장수 행과 예턴 30칸으로 저장되고 재시작과 12개월 재생에서 같은 상태 해시를 낸다. 끈 월드와 기본 37개는 바뀌지 않는다.

### 4.3 확률

- `max = S1의 상한`, `npc = scoutedGenerals.ids.length`, `gen = 장수 수 − npc`
- `current = trunc(gen + npc / 2)`, `main = (max(max − current, 0) / max)^6`
- `p = npc < 50 ? max(main, 1 / (npc / 3 + 1)) : max(main, 1 / max)`

NPC 수가 0이면 `p = 1`이다(원작과 같다). `max`가 0 이하면 `p = 0`이다.

### 4.4 RNG 소비 순서

1. `rng.next() < p`이면 발견. 못 찾으면 끝(합계 1회).
2. 나이 `rng.int(20, 25)`
3. 사망까지 `rng.int(10, 50)`
4. 이름: S2 (가)면 아직 월드에 없는 풀 장수를 `rng.int(0, n − 1)`로 하나, (다)면 소비 없음
5. 친밀도 `rng.int(1, 150)`
6. 능력치 유형 `pickWeighted(rng, [['무', 6], ['지', 6], ['무지', 3]])`
7. 주 능력치 감소 `rng.int(0, 10)`
8. 낮은 능력치 증가 `rng.int(0, 5)`
9. 도시 `rng.int(0, 도시 수 − 1)`. 도시는 `cityKey` 오름차순
10. 턴 위치 `rng.int(0, TICKS_PER_MONTH − 1)`

S2 (가)에서 남은 풀 장수가 없으면 (다)로 넘어가고 4의 소비가 없다. 원작의 이름 중복 반복 뽑기는 S2 (가)가 월드에 없는 장수만 고르므로 필요 없다. (다)의 이름은 `인재{n}`이고 `n`은 `ids.length + 1`이다. 같은 이름이 이미 있으면 `n`을 하나씩 올린다.
