# T2-17 플레이어 가이드 9개

> 대기열: T2-17 · AC: AC-M2-11 (가이드 부분) · 구현: Claude · 리뷰: Codex
> 선행: T2-16 · 관련: [user/](../user/index.md), 참고: core2026 `docs/user/`, [myosam 도움말 구성](../product/idea-harvest.md#b-myosam묘섭-위키)

## 계획 (Claude)

### 목표

지인 테스트 참가자가 혼자 읽고 첫 장수를 만들어 예턴을 넣을 수 있는 플레이어 가이드 9개를 쓴다 (AC-M2-11).

### 범위

`docs/user/` 9개 뼈대를 실제 규칙으로 채운다. 화면 안 "도움말" 링크가 이 문서를 가리킨다.

### 하지 않는 것

원작 게시판 근거 문서(sources.md, 제외), 전략 공략, 영상.

### 결정

- **읽는 순서는 myosam 방식**: 기초(index) → 초급(장수와 도시, 시간과 턴) → 중급(전쟁, 지도와 보급, 재정과 외교, 국가 운영) → 참고(용어 사전, 명령과 실행 시기). 각 문서 끝에 "다음은 …" 링크.
- **규칙 근거는 코드다.** 수치·조건은 `packages/rules`와 `balance.ts`, 명령은 생성 문서(T2-16)를 기준으로 쓰고 문서마다 근거 파일을 맨 아래 한 줄로 남긴다.
- 원작과 다른 점(조약서, 작전판, 기본 방침, 발령 응답, 교역)은 원작 경험자가 헷갈리지 않게 "원작과 다른 점" 상자로 따로 표시.
- 처음 온 사람의 말로 쓴다. 은어는 용어 사전으로 링크.
- 화면 캡처는 넣지 않는다 (M2에서는 화면이 계속 바뀜). 화면 이름과 메뉴 위치를 글로 적는다.

경로는 v1 저장소(`opensamguk-v1` `bc05362`) 기준이다. v1 사용자 문서는 규칙이 달라(휘하·縣·순) 내용을 옮기지 않고 구성과 쓰는 방식만 가져온다. 수치와 조건은 위 결정대로 우리 코드에서 쓴다.
