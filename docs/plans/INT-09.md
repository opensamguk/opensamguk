# INT-09 부곡 전투·기존 정산·점령·재생

> AC-INT-09 · 구현 Codex · 리뷰 Claude · 선행 INT-04, INT-06, INT-15 · 견적 4~5일
> 사용자 지시로 동결한 [통합판 v0.1](./integration-release.md)과 [5능력치](../product/five-stats.md)를 따른다.

## 계획

목표는 부곡을 병력 정본으로 삼아 기존 모병·훈련·이동·출병·귀환을 어댑터로 연결한다. 실제 지휘관 통솔/무력 보정·도시/관문 점령·월 군량·멸망·재생을 통합한다. 같은 부대의 비용을 General.crew와 부곡에서 이중 청구하지 않는다.

수정 범위는 packages/rules/src/battle/, packages/rules/src/monthly/, packages/rules/src/commands/, apps/engine/src/다. 새 기능을 더하지 않는다. 기존 main·v1 기준 SHA와 자원 출처는 통합 기준 문서를 따른다. 세부 코드 경계·API 인증·엔진 단독 상태 변경·시드 RNG·턴 트랜잭션을 지킨다.

검증은 통솔/무력 0·50·100, 지휘관 교체·분할 상한 우회·중복 실행, 트랜잭션 실패/리스 상실/재시작, 두 월드 격리·모든 월 해시·최종 상태 일치

선행 인수 뒤 착수하고 검증 결과와 구현하지 않은 담당의 리뷰를 같은 문서에 남긴다. 구현자가 스스로 완료로 바꾸지 않는다.

## 구현 기록

2026-10-27 INT-06의 관계·부곡 저장 계약 뒤 순수 어댑터부터 착수한다. 준비 명령, 이동/귀환과 전투, 월 정산·멸망·재생과 실제 PG/HTTP 검증의 세 묶음으로 나누며 각각1~2일을 잡는다. 선행 기능을 운영에 등록하거나 AC를 완료한 상태는 아니다.

첫 묶음은 모병·징병의 기존 비용·인구/민심·훈련 희석, 실제 지휘관의 전체 병력 상한, 훈련·사기진작, 소집해제를 부곡 병력 정본에 적용한다. 군량·장수 능력치·위치를 부곡에 복제하지 않는다. NPC와 사람의 첫 모병은 자기 지휘 부곡을 만들며 기존 General.crew와 동시에 병력을 저장하지 않는다. 집중 단위8건과 rules 타입·ESLint를 통과했다. 구현하지 않은 담당은 이 순수 어댑터에 추가 결함이 없다고 독립 리뷰를 승인했다. 이동·전투·정산 어댑터와 실제 검증이 남았으며 운영 명령 등록은 하지 않았다.

이동 어댑터는 기존 명령이 검증한 도착 거점을 그대로 쓰고 함께 있던 NPC 부장만 이동한다. 사람 휘하의 위치·예약, 떨어진 부장과 빈 부곡은 바꾸지 않는다. 집중 단위5건과 rules 타입·ESLint를 통과했고 구현하지 않은 담당의 독립 리뷰를 받았다.

교전 어댑터는 실제 지휘관의 통솔·무력을 한 번 적용하고 두 부곡의 피해를 함께 반영한다. 교전별 군량은 소유자의 기존 쌀에서 한 번 차감한다. 성벽은 실제 도시의 벽·방어·기술과 기존 병종1000을 쓰며 장수 보정을 받지 않는다. 0·50·100 경계와 무관 스탯, 군량 공유·피해·벽 교전의 집중 단위10건, rules 타입·ESLint를 통과했다. 구현하지 않은 담당은 추가 결함 없이 독립 리뷰를 승인했다.

## 리뷰

준비·이동·교전 순수 어댑터만 독립 리뷰를 통과했다. 출병 권한·전쟁·인접·집결·교전 순서·점령, 운영 명령·월 정산·엔진 저장·재생 연결과 실제 PG/HTTP 인수는 남았다. 이 기록은 AC 완료나 런타임 통과 증거가 아니다.

출병 명령 어댑터는 같은 거점의 자기 부곡, 실제 수비 지휘관의 거점·등장 시점, 기존 보호·전쟁·보급·인접·병종 검사를 적용한다. 수비·벽 교전과 점령·천도·멸망을 연결했다. 리뷰에서 성벽0의 기존 군량 소비 누락과 지휘관별 BattleLog 키 중복을 지적받아 고쳤다. 벽0도 점령 직전 군량을 소비하고 같은 수비 지휘관의 교전은 한 보고로 합친다. 출병7건·교전5건 집중 검사를 통과했다. 실제 DB의 보고 저장 회귀와 엔진 연결은 남았다.

월 정산은 campaign-v1에서 실제 지휘관 거점의 보급 단절 손실을 부곡 훈련·사기에 적용하고 국력에 소유 부곡 병력을 한 번 합산한다. 기존 월급·세입·쌀을 유지하며 새 유지비를 만들지 않는다. 집중3건, 기존 출병/정산 회귀를 포함한22건, 재생·인사 회귀를 포함한24건과 rules 타입·ESLint를 통과했다. 구현하지 않은 담당은 출병의 두 수정과 월 정산 순수 묶음을 추가 결함 없이 독립 승인했다. 운영 등록·저장·API·실제 기수 인수를 완료한 기록은 아니다.

명령 연결부는 기존 준비·이동·귀환·거병을 부곡 정본으로 실행한다. 기존 계략의 부상 난수를 추가 소비 없이 실제 지휘 부곡 피해에 적용한다. 사람 휘하가 있거나 상관에게 속한 장수는 관계 해제 없이 소속을 바꾸지 못하며 NPC 하위 관계·소유 병력은 보존한다. 휘하 NPC의 군사 행동은 상관의 부곡 명령을 따른다. 독립 리뷰의 교역 예약 사전검사 보존과 비활성 명령 오류 구분 지적을 고쳤다. 실제 교역 정의·꺼진 명령 반례를 포함한7건과 rules 타입·ESLint를 통과했고 수정본 독립 승인을 받았다. 운영 기능 등록과 실제 API/엔진 인수는 남았다.

NPC 선택기는 전달받은 실제 resolver로 명령을 검사한다. campaign-v1에서 부곡의 병력·훈련·사기, 실제 지휘관의 전체 병력 상한과 소유자의 군량을 쓰며 기존 월드는 기존 경로를 따른다. 새 NPC3건은 병력 복제 없이 모병·훈련·사기·출병·점령, 휘하 NPC의 독립 군사 행동 거부와 분할 상한을 확인한다. 기존 NPC·직책·프리셋93건, 새 NPC를 포함한51건, rules 타입·ESLint를 통과했다. 구현하지 않은 담당은 세 파일의 독립 리뷰를 승인했다. 운영 등록·실제 PG·전체 기수 인수는 남았다.
