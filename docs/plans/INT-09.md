## 계획

수정 범위는 packages/rules/src/battle/, packages/rules/src/monthly/, packages/rules/src/commands/, apps/engine/src/다. 새 기능을 더하지 않는다. 기존 main·v1 기준 SHA와 자원 출처는 통합 기준 문서를 따른다. 세부 코드 경계·API 인증·엔진 단독 상태 변경·시드 RNG·턴 트랜잭션을 지킨다.

검증은 통솔/무력 0·50·100, 지휘관 교체·분할 상한 우회·중복 실행, 트랜잭션 실패/리스 상실/재시작, 두 월드 격리·모든 월 해시·최종 상태 일치

## 구현 기록

## 리뷰

준비·이동·교전 순수 어댑터만 독립 리뷰를 통과했다. 출병 권한·전쟁·인접·집결·교전 순서·점령, 운영 명령·월 정산·엔진 저장·재생 연결과 실제 PG/HTTP 인수는 남았다. 이 기록은 AC 완료나 런타임 통과 증거가 아니다.

출병 명령 어댑터는 같은 거점의 자기 부곡, 실제 수비 지휘관의 거점·등장 시점, 기존 보호·전쟁·보급·인접·병종 검사를 적용한다. 수비·벽 교전과 점령·천도·멸망을 연결했다. 리뷰에서 성벽0의 기존 군량 소비 누락과 지휘관별 BattleLog 키 중복을 지적받아 고쳤다. 벽0도 점령 직전 군량을 소비하고 같은 수비 지휘관의 교전은 한 보고로 합친다. 출병7건·교전5건 집중 검사를 통과했다. 실제 DB의 보고 저장 회귀와 엔진 연결은 남았다.

월 정산은 campaign-v1에서 실제 지휘관 거점의 보급 단절 손실을 부곡 훈련·사기에 적용하고 국력에 소유 부곡 병력을 한 번 합산한다. 기존 월급·세입·쌀을 유지하며 새 유지비를 만들지 않는다. 집중3건, 기존 출병/정산 회귀를 포함한22건, 재생·인사 회귀를 포함한24건과 rules 타입·ESLint를 통과했다. 구현하지 않은 담당은 출병의 두 수정과 월 정산 순수 묶음을 추가 결함 없이 독립 승인했다. 운영 등록·저장·API·실제 기수 인수를 완료한 기록은 아니다.

명령 연결부는 기존 준비·이동·귀환·거병을 부곡 정본으로 실행한다. 기존 계략의 부상 난수를 추가 소비 없이 실제 지휘 부곡 피해에 적용한다. 사람 휘하가 있거나 상관에게 속한 장수는 관계 해제 없이 소속을 바꾸지 못하며 NPC 하위 관계·소유 병력은 보존한다. 휘하 NPC의 군사 행동은 상관의 부곡 명령을 따른다. 독립 리뷰의 교역 예약 사전검사 보존과 비활성 명령 오류 구분 지적을 고쳤다. 실제 교역 정의·꺼진 명령 반례를 포함한7건과 rules 타입·ESLint를 통과했고 수정본 독립 승인을 받았다. 운영 기능 등록과 실제 API/엔진 인수는 남았다.
