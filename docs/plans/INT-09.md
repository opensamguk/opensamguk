# INT-09 부곡 전투·기존 정산·점령·재생

> AC-INT-09 · 구현 Codex · 리뷰 Claude · 선행 INT-04, INT-06, INT-15 · 견적 4~5일
> 사용자 지시로 동결한 [통합판 v0.1](./integration-release.md)과 [5능력치](../product/five-stats.md)를 따른다.

## 계획

목표는 부곡을 병력 정본으로 삼아 기존 모병·훈련·이동·출병·귀환을 어댑터로 연결한다. 실제 지휘관 통솔/무력 보정·도시/관문 점령·월 군량·멸망·재생을 통합한다. 같은 부대의 비용을 General.crew와 부곡에서 이중 청구하지 않는다.

수정 범위는 packages/rules/src/battle/, packages/rules/src/monthly/, packages/rules/src/commands/, apps/engine/src/다. 새 기능을 더하지 않는다. 기존 main·v1 기준 SHA와 자원 출처는 통합 기준 문서를 따른다. 세부 코드 경계·API 인증·엔진 단독 상태 변경·시드 RNG·턴 트랜잭션을 지킨다.

검증은 통솔/무력 0·50·100, 지휘관 교체·분할 상한 우회·중복 실행, 트랜잭션 실패/리스 상실/재시작, 두 월드 격리·모든 월 해시·최종 상태 일치

선행 인수 뒤 착수하고 검증 결과와 구현하지 않은 담당의 리뷰를 같은 문서에 남긴다. 구현자가 스스로 완료로 바꾸지 않는다.

아직 착수하지 않았다.
