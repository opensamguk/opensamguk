# INT-10 운영 지도 화면

> AC-INT-10 · 구현 Claude · 리뷰 Codex · 선행 INT-02, INT-03 · 견적 2일
> 사용자 지시로 동결한 [통합판 v0.1](./integration-release.md)과 [5능력치](../product/five-stats.md)를 따른다.

## 계획

목표는 실제 GIS·기존 도트 아이콘·국가색·도시/관문 선택·확대를 운영 API에 연결한다. 실제 좌표와 게임 배치를 따로 표시하지 않는다. 항구는 시설, 전장은 표시로 다룬다. 새 지리 그림을 생성하지 않는다.

수정 범위는 apps/web/src/, e2e/, docs/user/다. 새 기능을 더하지 않는다. 기존 main·v1 기준 SHA와 자원 출처는 통합 기준 문서를 따른다. 세부 코드 경계·API 인증·엔진 단독 상태 변경·시드 RNG·턴 트랜잭션을 지킨다.

검증은 실제 API E2E, 375px 핵심 조작·키보드 목록·줌/선택·판 불일치·공개 정보 경계, 공개 빌드 자산 검사

선행 인수 뒤 착수하고 검증 결과와 구현하지 않은 담당의 리뷰를 같은 문서에 남긴다. 구현자가 스스로 완료로 바꾸지 않는다.

## 구현 기록

2026-10-27 사용자 담당 인계에 따라 Codex가 착수한다. API의 고정 지도 표시·기존 GIS/도트 자산 연결, 확대/이동/키보드 거점 선택, 실제 정식191년 API·375px·공개 자산 검증의 세 묶음이다. 각각 하루 이내이며 AC-INT-10에 연결한다. 운영 자료의 판·GIS 원본 해시·거점 대응이 다르면 위치를 추정하지 않고 다시 불러오도록 안내한다. 기존 월드는 기존 지도를 유지한다.

## 리뷰

구현하지 않은 담당이 실제 GIS·기존 도트, 공개 정보 필드와 이미지 허용 목록, 타임랩스와 PNG 내보내기, 모바일·키보드 조작을 독립 검토했다. 수로 경유 순서, 판/좌표 불일치의 내보내기 차단, 과거 프레임의 미기록 거점 표시, 작은 화면의 가로 넘침을 고쳤다. 키보드 검사는 ArrowRight 전후 viewBox 좌표의 실제 변화를 확인하도록 보강했다.

최종 집중5파일144건과 실제 정식191년 API의 Chromium1건이 통과했다. 후자는491명·21국 월드에 사람 장수를 입력 원장으로 생성하고61거점·80표식·이미지5종 디코딩·확대/키보드·375px/44px 조작·지연 공개 지도를 확인한다. 공개 Chromium4건과 공개 빌드의102파일·이미지6종·외부 초상0개 검사도 통과했다. 실제 Chromium에서 발견한 가로 넘침은 공통 레이아웃의 축소 가능한 grid 열과 좁은 화면의 헤더 줄바꿈으로 수정했다. 전체 검사·필수 CI·병합 전이므로 AC는 미완료다.

## 병합 뒤 인수 근거

위 집중·정식 API·공개 빌드 검증 뒤 전체 check5,049건과 실제 Chromium190건이 통과했다. 기존 알림2건은 통과 근거에서 제외했다. 구현하지 않은 담당이 실제 GIS/도트·운영 지도 계약·공개 정보 경계·화면 조작과 실행 증거를 독립 인수했다. [PR #253](https://github.com/opensamguk/opensamguk/pull/253)은 필수 CI40514922155와 보호 대기열40518302055의7개 검사를 모두 통과해 main `4c9114ce3e3f25a905ec4eed56021a849502051d`에 병합됐다. 지도 UI의 AC만 마감하며 휘하·부곡 조작과 정식 한 기수는 INT-11/12에서 인수한다.
