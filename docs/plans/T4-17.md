### 접근

1. 선행 확인: T4-03 1단계와 각 기능 작업의 규칙 PR이 main에 있다. 아직 병합되지 않은 기능은 이번 등록에서 빼고 같은 ID로 다음 등록 PR을 연다(쟁점 Z3).
2. 대응표 도구가 정해진 factory를 읽게 한다(쟁점 Z1). 등록 전에 넣어야 `pnpm check`가 막히지 않는다.
3. 실제 시험 파일 대조를 넣는다(쟁점 Z2).
4. 명령·조각·관계를 등록한다. `ext/registry.test.ts`의 관계 대조가 통과해야 한다.
5. 기능 작업에서 조각 등록 전이라 미뤄진 실행 성공 단위 시험을 돌린다([T4-07](./T4-07.md) 쟁점 Z2).
6. 순수 재생 보존 시험과 엔진 통합 시험 X1~X14를 쓴다. T4-03 2단계 시험을 같은 PR에서 돌린다.
7. 끈 월드 골든과 기본 37개 대조를 확인하고 대응표 증거를 채운다.

- 순수 재생: `replay.test.ts`에 `strategyCooldown` 조각이 든 상태에서 장수 턴(계략)과 국가 턴(백성동원)이 섞인 12개월 재생을 두고 매달 `ext`가 사라지지 않으며 해시가 두 번 돌려도 같은지 본다(T4-02 2.4.5).
- 권한: 일반 명령은 기존 `turns.set`·`turns.edit`·`turns.precheck`·`commands.list`의 다섯 범주 시험에 확장 key 사례를 더한다(T4-03 2단계 A). 국가 명령의 저장 권한은 T4-50이다.
- 국가 명령은 엔진이 읽는 국가 칸을 시험이 직접 넣는다. T4-50이 먼저 병합되면 HTTP로 넣는 시험을 더한다.

### 상대 영역에 필요한 것

- T4-03(Codex): 2단계 시험의 조건이 조각이 있는 일반 확장 명령이다. 이 작업의 조각은 국가 명령(전략, 국호·국기)에만 있다. 일반 명령 HTTP(X1)와 국가 명령 조각 저장(X3, X7~X10)을 합쳐 2단계로 받아 줄지 확인이 필요하다(쟁점 Z4).

- T4-48(Codex): 해산 시험(X6)은 `isWandering`과 `wander` 조각 병합 뒤다.
- T4-04(Claude): 화면 E2E는 이 등록 뒤 켠 월드에서 돈다.
