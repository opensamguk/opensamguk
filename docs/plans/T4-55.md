## 계획 (Claude)

### 목표

AC-P2-10 (나): 변경권이 생기는 조건. 이 작업이 끝나면 U-04에서 정한 조건이 맞는 국가에 [T4-16](./T4-16.md)의 변경권 조각 `nationIdentity` 칸이 생기고 그 국가의 군주가 국호나 국기를 한 번 바꿀 수 있다. 조건이 맞지 않는 국가와 확장을 끈 월드에는 변경권이 생기지 않는다. 같은 시드면 같은 시점에 같은 국가에 생긴다.

### 범위

| 파일 | 내용 |
| ---- | ---- |
| 새 파일 `packages/rules/src/commands/ext/nationIdentity/grant.ts` | 변경권을 주는 순수 함수 |
| `ext/nationIdentity/slice.ts` (T4-16 소유, 이 작업이 이어서 고침) | U-04에 따라 `create`가 초기 변경권을 주거나 조각에 부여 이력 칸을 더한다 |
| 새 파일 `ext/nationIdentity/grant.test.ts` | 부여 시험 |
| 공용 확장 훅을 부르는 한 줄 | U-04가 건국 때 부여나 월간 판정을 고르면 필요하다. 훅의 위치와 소유는 쟁점 Z1 |

### 하지 않는 것

- 변경 명령 자체(T4-16).
- 국가 등급 상승 규칙의 도입. U-04가 (가)를 고르면 필요하지만 핵심 규칙 추가라 별도 작업과 승인이 먼저다(쟁점 Z2).
- 무작위 건국(UQ-3)과 무작위 수도 이전 사용권(MQ-4). 원작에서 무작위 건국도 국기 변경권을 준다. UQ-3이 무작위 건국을 넣기로 하면 그 작업이 이 함수를 부른다.

### 기술 계약 초안 (U-04 뒤 확정)

#### A. 부여 함수

```ts
// ext/nationIdentity/grant.ts
export function grantRights(value: NationIdentityState, nationId: number, rights: readonly IdentityRight[]): void; // 칸을 true로
export function initialRights(context: ExtInitContext): NationIdentityState; // (다)·(라): 시작 국가마다 { rename: true, flag: true }
export function foundingRights(): readonly IdentityRight[]; // (가)·(나): ['flag'], (다): ['rename', 'flag']
export function monthlyRights(view: WorldView, value: DeepReadonly<NationIdentityState>): Record<string, IdentityRight[]>; // (나): 문턱을 처음 넘은 국가
```

- 모두 순수 함수다. 난수를 쓰지 않는다.
- 이미 `true`인 칸에 다시 주면 그대로 `true`다(원작처럼 쌓이지 않는다).
- (나)의 한 번만 판정을 위해 조각 값에 선택 칸 `grantedAt7?: true`를 더한다. 이 칸이 없는 기존 저장값도 새 `validate`를 통과하므로 T4-16 조각을 이미 저장한 월드가 깨지지 않는다.

#### B. 부여 시점

| 시점 | 쓰는 안 | 방법 |
| ---- | ------- | ---- |
| 월드 생성 | (다), (라) | T4-16 조각의 `create(context)`가 `initialRights(context)`를 낸다. T4-03이 생성 때 `createExtState`를 부르므로 따로 연결할 곳이 없다 |
| 건국·거병 직후 | (가), (나), (다) | 명령 실행 뒤 공용 확장 훅(쟁점 Z1)이 실행 전후 국가 목록을 비교해 새 국가에 `foundingRights()`를 준다. 건국 파일(`personnel.ts`)은 고치지 않는다 |
| 월간 정산 | (가), (나) | 월간 공용 확장 훅이 `monthlyRights`를 적용한다 |

- 확장을 끈 월드는 조각이 없으므로 어느 훅도 아무것도 하지 않는다.
- 확장을 켰더라도 국호·국기 변경 명령을 켜지 않은 월드는 관계 행이 없어 조각이 없다.

#### C. 기록

부여는 국가 기록에 `국호·국기 변경권을 얻었습니다.` 같은 한 줄을 남길지 U-04와 함께 정한다. 원작은 등급 상승 기록에 묻어 따로 남기지 않는다.
