# INT-26 원작 정보 대조표

> [INT-26](./INT-26.md)의 부록. 결정 [D-085](../product/decisions.md).

2026-11-13 원작 core2026 화면 53장면과 명령 인자 화면을 opensamguk 배포 커밋 `2d54c23d`의 화면·응답·규칙과 줄마다 대조했다. 각 줄은 다른 검증자가 코드로 반증을 시도한 뒤 남은 것이다. `메인 카드` 묶음은 반증 검증 전이다.

- `규칙`: 규칙·상태·DB에는 값이 있고 응답에 없다. 응답만 넓힌다.
- `없음`: 규칙에 개념이 없다. 규칙부터 넣는다.
- `제외`: 결정 기록에 근거가 있어 일부러 뺀 것. 근거를 적고 사용자 확인 전까지 두지 않는다.
- 응답에 이미 있는 값(`응답`)은 INT-25 PR 3에서 화면만 고친다. 여기에는 싣지 않는다.
