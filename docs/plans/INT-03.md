# INT-03 실제 지도·거점·연결 검수

> AC-INT-03 · 구현 Codex · 리뷰 Claude · 선행 INT-02 · 견적 3~4일
> 사용자 지시로 동결한 [통합판 v0.1](./integration-release.md)과 [5능력치](../product/five-stats.md)를 따른다.

## 계획

목표는 53도시·8관문·6항구 시설·13전장 표시를 고정한다. GIS와 도트 표식을 재사용하고 거점 좌표를 한 방식으로 다룬다. 항구/전장 표시를 통과하느라 빈 이동 턴을 추가하지 않는다. 육수로·필수 관문과 우회를 검토한다.

수정 범위는 tools/map-data/, resources/, packages/rules/src/world/, apps/web/src/mapEditor/다. 새 기능을 더하지 않는다. 기존 main·v1 기준 SHA와 자원 출처는 통합 기준 문서를 따른다. 세부 코드 경계·API 인증·엔진 단독 상태 변경·시드 RNG·턴 트랜잭션을 지킨다.

검증은 장안↔낙양·한중↔성도·양양↔강릉의 필수 길목, 양평 도시/관문 구분, 단절·차단·강·항구 귀속, 같은 입력의 운영 그래프·해시 일치

선행 인수 뒤 착수하고 검증 결과와 구현하지 않은 담당의 리뷰를 같은 문서에 남긴다. 구현자가 스스로 완료로 바꾸지 않는다.

## 구현 기록

2026-10-27 운영 지도 계약 PR248 위에서 자원 생성·출처/대응표, 명시적 육수로·필수 길목 검증, 편집 초안 왕복과 운영 연결 확인의 세 묶음으로 나눠 착수한다. 각 묶음은 하루 이내이며 AC-INT-03에 연결한다. 기존 Natural Earth GIS와 80표식 좌표를 재사용한다. 기존 도시의 경제 값은 ID로 보존하고 새 도시의 게임 수치는 별도 명시한다. 항구·전장은 운영 앵커를 만들지 않는다. 연결은 가까운 거점을 자동 연결하지 않고 고정한 경로만 사용한다. 기존 이름과 새 이름의 대응을 남겨 191년 시나리오를 이름 추정으로 배치하지 않는다.

## 리뷰

구현하지 않은 담당이 자료·생성기·좌표/해시·기존 경제 보존·항구 귀속을 독립 검토했다. 출처 고지에 새 산출물과 core2026 MIT의 대응을 덧붙이라는 지적을 반영했다. 80표식·61앵커·81경로를 확인했고 잘못된 ID 결합이나 명백한 바다 직선을 발견하지 못했다. 새 게임 연결을 역사 도로망의 복원으로 주장하지 않는다.

집중7건이 통과했다. 장안↔낙양·한중↔성도의 필수 검사는 지정한 최단 회랑의 관문이며 모든 장거리 우회를 금지한다는 뜻이 아니다. 부분 회랑의 길목 차단과 전체 판의 명시적 무관·상용 우회를 각각 검사한다. 양양↔강릉은 장판 표식을 그리되 한 번 이동하며 항구와 전장은 전략 앵커가 아니다. 정식191년 시나리오의 생성·운영 화면 연결·전체 인수와 CI·병합은 남아 있다.

## 병합 뒤 인수 근거

53도시·8관문·6항구 시설·13전장 표시의80표식,61앵커와81경로를 정식 운영 자원에 연결했다. 실제 좌표와 게임 조정 좌표는 같은 position 모델을 쓴다. GIS 원본 해시·기존 경제/ID·명시적 길목/우회/단절·항구 귀속과 한 번 이동 검사를 통과했고 정식491명 DB 생성과 실제 지도 화면에서도 연결을 확인했다. [PR #250](https://github.com/opensamguk/opensamguk/pull/250)은 필수 CI와 보호 대기열40503662995를 통과해 main `6406af8135a8b8dbfa3edbb0ed117c5d839e3b43`에 병합됐다. 구현하지 않은 담당은 최종 자료·코드·실행 증거와 이 AC의 범위를 대조해 마감을 승인했다. 역사 도로망 전체를 복원했다고 주장하지 않는다.
