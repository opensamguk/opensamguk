## 계획 (Claude)

### 목표

AC-M1-14의 이 명령 몫이다. 원작 `nation:che_감축`에 대응하는 확장 국가 명령 `nation_shrink`가 켠 월드에서 연속 예약으로 실행되어 증축했던 수도의 규모를 1 내리고 인구·내정·수비·성벽의 현재값과 최대를 줄이며 국고에 일부를 돌려준다. 지도 원래 규모보다 작게는 줄이지 못한다. 성공 1건과 대표 실패 1건 단위 시험이 있고 같은 입력이면 결과가 같다. HTTP 이후 단계 증거는 T4-50·T4-51 뒤 같은 ID 아래에서 받는다.

`capitalScale.ts`는 T4-73 소유다. 감축에 필요한 상수(`SHRINK_BASE`, `SHRINK_POP_FLOOR`)도 T4-73이 그 파일에 둔다. T4-74 PR이 그 파일을 고쳐야 하면 T4-73 리뷰를 다시 받는다.

### 하지 않는 것

- 증축(T4-73), 준비 턴 기제(T4-07), 직책 권한 표(T2-05), 화면(T4-51, 인자가 없어 목록 표시만), NPC 판단(C11).
- 지도 자료를 명령 문맥으로 넘기는 경로. 원래 규모는 조각에서 읽는다.

### 3. 기술 계약 초안 (Codex 계획 기술 검토 전)

#### 3.1 정의

| key | name | category | target | args |
| --- | ---- | -------- | ------ | ---- |
| `nation_shrink` | 감축 | `nation` | `nation` | `noArgs` |

증축과 같이 `defineCommand`로 `{ kind: 'world' }` 효과를 낸다. key와 target은 이 파일에 글자 그대로 적는다([T4-73 §2.5](./T4-73.md#25-등록-모양)).

#### 3.2 검사 순서

| 순서 | 조건 | code | 이유 |
| ---- | ---- | ---- | ---- |
| 1 | `defineCommand` 국가 명령 검사 | `NO_ACTOR`, `BAD_ARGS`, `NOT_NATION`, `NOT_RULER` | T2-05 뒤에는 권한 표 |
| 2 | [T4-73 §2.1](./T4-73.md#21-공통-검사-capitalscalecheckview-actor) 공통 검사 | `NOT_OWN_CITY`, `NO_SUPPLY`, `BAD_STATE` | 같은 문구 |
| 3 | 수도 규모 4 이하 | `BAD_STATE` | 더 감축할 수 없습니다. |
| 4 | 수도 규모가 `capital_scale.origin[수도]` 이하 | `BAD_STATE` | 원래 규모보다 작게 줄일 수 없습니다. |

4번에서 `origin`에 수도 키가 없으면 조각이 깨진 것이다. 조각 `validate`를 통과한 상태에서는 생기지 않으므로 예외로 둔다(쟁점 R1).

#### 3.3 실행

`change(state, actor)`가 아래를 바꾼다. RNG는 쓰지 않는다.

1. 수도 `level -= 1`.
2. 현재값: `population = max(population − POP_STEP, SHRINK_POP_FLOOR)`, `agriculture`·`commerce`·`security = max(값 − DEVEL_STEP, 0)`, `defence`·`wall = max(값 − WALL_STEP, 0)`.
3. 최대값: `populationMax −= POP_STEP`, 내정 셋 `−= DEVEL_STEP`, 수비·성벽 `−= WALL_STEP`.
4. 국가 `gold += 환급`, `rice += 환급`.
5. `capital_scale.changes[국가] += 1`.
6. T4-73 C5 (가)면 행위자 `experience += 30`, `dedication += 30`.

2와 3 뒤 현재값이 최대를 넘지 않는다는 불변식을 시험으로 고정한다. 현재값이 최대보다 2,000 넘게 낮았던 칸은 2에서 같은 양을 빼므로 최대와의 차이가 그대로다. 원작과 같다.

#### 3.4 준비 턴

증축과 같다([T4-73 §4.4](./T4-73.md#44-준비-턴)). 원작에서는 증축과 감축이 같은 `capset` 번호를 쓰므로 증축 직후 감축을 이어 예약해도 번호가 바뀌어 처음부터 센다. T4-07이 이 뜻을 받는지는 T4-73 쟁점 R2와 같다.
