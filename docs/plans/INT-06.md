# INT-06 휘하·부곡 DB·API·응답

> AC-INT-06 · 구현 Codex · 리뷰 Claude · 선행 INT-02, INT-05 · 견적 3~4일
> 사용자 지시로 동결한 [통합판 v0.1](./integration-release.md)과 [5능력치](../product/five-stats.md)를 따른다.

## 계획

목표는 상하 관계·명망·부곡·실제 지휘관을 저장하고 제안·수락·거절·해제·편성·지휘를 입력 원장과 엔진으로 처리한다. NPC 서약의 매력 확률·500금·대상별 월 1회, 사람 동의 보호는 five-stats 문서대로 한다. 군량/피로/창고 체계를 새로 만들지 않는다.

수정 범위는 packages/db/prisma/, packages/rules/src/campaign/, apps/engine/src/, apps/server/src/routers/다. 새 기능을 더하지 않는다. 기존 main·v1 기준 SHA와 자원 출처는 통합 기준 문서를 따른다. 세부 코드 경계·API 인증·엔진 단독 상태 변경·시드 RNG·턴 트랜잭션을 지킨다.

검증은 실제 PostgreSQL에서 중복·동시 서약·순환·타월드/타국·타인 조작·제재·거절 비용·재시도·재시작, 같은 병력 이중 배치 금지

선행 인수 뒤 착수하고 검증 결과와 구현하지 않은 담당의 리뷰를 같은 문서에 남긴다. 구현자가 스스로 완료로 바꾸지 않는다.

## 구현 기록

아직 착수하지 않았다.
