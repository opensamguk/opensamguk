## 계획

목표는 상하 관계·명망·부곡·실제 지휘관을 저장하고 제안·수락·거절·해제·편성·지휘를 입력 원장과 엔진으로 처리한다. NPC 서약의 매력 확률·500금·대상별 월 1회, 사람 동의 보호는 five-stats 문서대로 한다. 군량/피로/창고 체계를 새로 만들지 않는다.

수정 범위는 packages/db/prisma/, packages/rules/src/campaign/, apps/engine/src/, apps/server/src/routers/다. 새 기능을 더하지 않는다. 기존 main·v1 기준 SHA와 자원 출처는 통합 기준 문서를 따른다. 세부 코드 경계·API 인증·엔진 단독 상태 변경·시드 RNG·턴 트랜잭션을 지킨다.

검증은 실제 PostgreSQL에서 중복·동시 서약·순환·타월드/타국·타인 조작·제재·거절 비용·재시도·재시작, 같은 병력 이중 배치 금지

선행 인수 뒤 착수하고 검증 결과와 구현하지 않은 담당의 리뷰를 같은 문서에 남긴다. 구현자가 스스로 완료로 바꾸지 않는다.

2026-10-27 관계/부곡 상태와 불변 원장 연결, 제안/응답과 엔진·API, 실제 비용/권한/재시작 검증의 세 묶음으로 나눠 착수한다. 각 묶음은1~2일이며 AC-INT-06에 연결한다. typed CampaignState를 origin3/archive3의 campaign-v1에 연결하며 기존 ext 저장에 임의 자료를 넣지 않는다. NPC 시도는 같은 시드·게임 월·행위자·대상으로 재현하고 유효한 거절도500금을 쓴다. 사람 제안은 확률·NPC 비용을 적용하지 않고 대상 본인이 응답한다. 국가는 개인 관계와 다른 경계이며 멸망 뒤 무소속 관계와 병력을 보존한다. DB/API·명령 어댑터와 검증을 마치기 전에는 운영 기능을 켜지 않는다.

## 리뷰

2026-10-27 첫 규칙 묶음은 관계·부곡 상태 검증, 사람 제안/응답/해제, NPC 서약의 순수 전이를 구현했다. 관계와 서약 테스트 2파일33개, rules 타입 검사와 대상 ESLint를 통과했다. 구현하지 않은 담당의 독립 리뷰에서 이 묶음의 수정 요청은 없었다. DB·API·입력 원장·부곡 명령과 실제 PostgreSQL 인수는 아직 연결하지 않았으며 AC-INT-06은 미완료다.

다음 저장·원장 묶음은 적용 기록의 비용·응답·시드 RNG를 재계산하고 World.campaignState에 형식1 관계/부곡을 저장한다. 기존 월드는NULL로 유지하고 기능 의존·시드·판을 DB CHECK로 검사한다. 엔진의 같은 World 잠금·펜싱 트랜잭션에서 이전 JSON과 대조해 저장하며 General.crew 중복 병력은 거부한다. 아직 기능 등록과 운영 API·명령 어댑터는 연결하지 않았다.

독립 리뷰는 typed 상태와 별도 결과의 revision 불일치, PG 시험의 지도 저장 누락을 지적했다. 두 경로를 수정하고 추가 지적 없이 코드 리뷰를 통과했다. 전이→재생→CAS 회귀를 포함한 관련6파일107건, rules/engine/server 타입·대상 ESLint·format 검사를 통과했다. 실제 PostgreSQL4건은 기존NULL·정식491명 원본 값과 지도 JSON 저장·연결 재생성·턴 후반 롤백·두 월드 보존·동시 CAS 하나만 성공·DB CHECK 거부를 확인했다. 이 저장 검사는 엔진/리스 실행·API 인수나 한 기수 완주를 대신하지 않는다.

부곡 입력의 순수 전이는 빈 부곡 편성·지휘 변경·빈 부곡 해산을 구현했다. 병력은 기존 모병/징병·소집해제 명령에서 처리하며 편성 입력이 병력·군량을 만들거나 버리지 않는다. 본인/직속 NPC 부장, 실제 지휘 병력 전체 상한과 사람·타인 부곡 조작 거부를 검사한다. 독립 리뷰에서 떨어진 병력을 지휘 변경으로 옮길 수 있던 경로를 지적해 병력 있는 부곡은 기존·새 지휘관 모두 소유자와 같은 거점이어야 하도록 수정했다. 최종10건과 타입·ESLint가 통과했고 수정본의 독립 리뷰도 통과했다. API와 군사 명령 연결은 남아 있다.

재생 연결은 새 프로필의 최초 인물 출처·시드와 원생성 unitSet의 군사 병종 허용 목록을 보존한다. 사람 장수 생성은 해당 general.create 입력 sequence를 출처로 추가한다. 관계·편성 입력의 결과와 tick을 재계산해 비용·응답·부곡 번호·병종 위조를 거부한다. 신규4건과 기존 편성·원장·재생·인사 회귀를 포함한46건, rules 타입·ESLint를 통과했고 구현하지 않은 담당은 여섯 파일의 독립 리뷰를 승인했다. 운영 registry에는 아직 등록하지 않았으며 초기화·로드·턴/월 저장·API의 실제 통합 검증은 남아 있다.
