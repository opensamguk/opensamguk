#### 4.4 계산

- `refund = floor(population / 5 × Π_{f∈농업·상업·치안} ((f − fMax × 0.5)/fMax + 0.8))`, `fMax ≤ 0`인 항은 건너뛴다. `max(0, ·)`.
- 감소 `reduce(cur, max, ratio) = max ≤ 0 ? max(0, round(cur × ratio)) : max(round(max × 0.1), round(cur × ratio))`. S2 (나)면 결과를 `min(cur, ·)`로 한 번 더 자른다.
- 인구·농업·상업·치안·수비는 `reduce(·, ·, 0.2)`, 성벽은 `reduce(wall, wallMax, 0.5)`다. 원작 성벽 식 `max(round(wallMax × 0.1), round(wall × 0.5))`와 같은 모양이므로 S2 (나)의 `min(cur, ·)`도 성벽에 똑같이 적용한다. 성벽 0·최대 1,000이면 (가)는 100으로 오르고 (나)는 0에 머문다. 민심은 `max(50, trust)`.

손 계산 예 (인구 300,000/500,000, 농업 6,000/10,000, 상업 5,000/10,000, 치안 5,000/10,000): 60,000 × 0.9 × 0.8 × 0.8 = 34,560이 금·쌀에 각각 들어간다.

#### 4.5 실행

`change(state, actor, args)`가 아래 순서로 바꾼다. RNG는 쓰지 않는다.

1. 환급량을 실행 전 값으로 계산한다.
2. 대상 도시 `nationId = null`, 내정·인구·성벽·민심을 §4.4로.
3. 국가 `gold += refund`, `rice += refund`.
4. `lockUntilTick[국가] = (actor.tick ?? 0) + 24 × TICKS_PER_MONTH` (안 (가), S3).
5. 대상 `level >= 8`이면 `specialScorch[국가] = (specialScorch[국가] ?? 0) + 1`.
6. S6 (가)면 행위자 `experience = max(0, round(experience × 0.9 + 15))`, `dedication += 15`. 같은 국가의 다른 장수 가운데 `officerLevel >= 5`는 `experience = round(experience × 0.9)`.
7. `refreshSupply(state)`(`supply.ts:4-20`).

대상 도시에 있던 장수는 움직이지 않는다. 원작과 같다. 그 장수의 다음 턴은 공백지에서 시작한다.
