# INT-18 도시 금·쌀·수비병과 부곡 배속

2026-10-29 사용자가 도시 공용 병력과 권한자 배속을 선택했다. 이어 도시 병력이 수비병이라고 정정했고 도시별 금·쌀·병사 보유를 요청했다. 수비에 참전하지 않는 예비병 안은 이 정정으로 폐기한다. 함락 뒤 남은 병력을 승자에게 넘기지 않는 조건은 유지한다. 이 문서는 추가 범위의 구현 계획이며 기존 INT-01~17의 완료 증거를 대체하지 않는다.

## 기존 구현과 달라지는 부분

고정 v1 `bc053629710711d4c5dfa50683bae78f4baeca95`의 일반 부곡 편성도 개인 병력·군량을 차감한다. 별도 도시 원장은 v2 샌드박스 전용이며 일반 부곡 배속 경로와 연결돼 있지 않다. 그 비용·상한·자원 종류를 그대로 가져오지 않는다.

## 지킬 계약

새 기능 표시 `city-resources-v1`을 원생성에 고정한다. 기존 `campaign-v1`과 발령 동행을 고친 `campaign-assignment-v2`의 뜻은 바꾸지 않는다. 진행 중인 월드에 새 표시나 자원을 덧씌우지 않으며 기존 원장·월 해시·재생을 보존한다.

도시 금·쌀·수비병은 도시별 원장 한 곳을 정본으로 삼는다. 병력은 병종별 수량과 훈련·사기를 보관하고 같은 인원을 General.crew나 부곡에 복사하지 않는다. 도시 병사 총수는 병종별 합계의 조회값이다. 기존 개인 금·쌀과 국고도 보존하며 입출금 없이 같은 금액을 도시에 더하지 않는다. 금·쌀·병사 외 철·목재·말·휴대 군량·피로는 추가하지 않는다.

권한자는 기존 국가 지휘 역할인 군주·참모·수뇌에 한정한 명시적 배속 권한으로 검사한다. 자국 도시의 병력을 같은 도시에 집결한 자국 부곡에 배속한다. 도시 수량 감소와 부곡 수량 증가를 한 트랜잭션에서 처리하고 병종·실제 지휘관 전체 상한을 확인한다. 사람의 소유자·지휘관·휘하 관계·예약 30칸을 배속으로 바꾸지 않는다. API 접수와 엔진 적용 때 세션·제재·소속·직책·위치·잔여 수량을 각각 검사한다.

도시 병사는 도시 수비에 자동으로 참여한다. 부곡에 배속한 인원은 도시 수비에서 제외한다. 성벽·방어 수치와 병사 수는 구분하며 전투 손실은 도시 원장에 한 번 반영한다. 가상의 인물이나 임의 5능력치를 만들어 수비 지휘관으로 넣지 않는다. 아래 전투 계약을 순수 규칙 리뷰로 고정한 뒤 구현한다. 함락 뒤 남은 수비병은 해산하며 승자 병력으로 이전하지 않는다.

모집·배속·도시 훈련·도시 사기·수비·부곡 출병이 NPC에서도 연결돼야 한다. 도시 모집만 반복하고 빈 부곡으로 끝나는 상태를 통과로 세지 않는다. 사람의 조작과 같은 비용·권한·상한 함수를 쓰며 별도 무상 충원을 넣지 않는다.

## INT-18A 구현 계약

### 원장·초기화·점령

`WorldState.cityResources`는 `{version:1, cities: Record<cityKey,{gold,rice,garrison}>}` 한 조각이다. `garrison`은 병종별 `{crewType,troops,train,atmos}` 배열이며 병종 중복을 거부하고 병종 번호로 정렬한다. 도시 키는 실제 월드의 모든 도시·관문과 정확히 대응한다. 도시 총병력을 포함한 수량과 금·쌀은 0~2,147,483,647 정수, 훈련·사기는 0~100 정수다. 잘못된 값·누락을 0으로 대체하지 않는다. 모든 계산을 검증한 뒤 적용하고 범위 초과는 실패·롤백한다.

새 판 생성에서 모든 도시 금·쌀은 명시적으로 0, 수비병은 빈 배열로 시작한다. 기존 국고·개인 자원을 복사해 초기 자원으로 만들지 않는다. 기능 표시가 없는 판에는 이 조각을 추가하지 않는다. DB는 새 nullable `World.cityResourcesState` JSON을 추가해 한 번만 저장하며 City나 CampaignState에 같은 수량을 두지 않는다. 원생성·복제·load/persist·월 정산·해시·재생 모두 이 조각을 운반한다. World 잠금과 이전 JSON CAS를 캠페인·도시·장수 저장과 같은 트랜잭션에서 적용한다.

함락 시 남은 도시 병사는 해산해 0으로 만들고 승자 부곡이나 도시 병력으로 넘기지 않는다. 해산 인원은 민간 인구로 돌아가되 기존 populationMax까지만 더하며 상한 밖 인원도 기록에 남긴다. 금·쌀은 같은 도시 원장에 남고 도시 소유 변경에 따라 새 소유국의 도시 자원이 된다. 장수나 국고에 전리품을 더하지 않는다. 멸망·중립화 경로에서도 도시 참조와 원장의 일치를 검사한다.

### 기존 세수·급여 총액의 보존

자원 종류와 수확 월은 기존대로 금 1·7월, 쌀 4·10월이다. 국가별 경제 도시를 도시 키 순서로 읽고 각 원래 세수의 반올림 전 값을 `w_i`, 합을 `W`라 한다. 국가 세수 `G=round(W)`, 활동 장수 수 `n`, 기존 급여율 `r`에 대해 개인 지급액은 기존과 같은 `p=floor(round(G*r)/n)`이며 n=0이면 p=0이다. 급여 총액 `S=p*n`, 도시 적립 총액 `R=G-S`다. 국가·개인의 기존 잔액은 이 계산의 초기값이나 나눗셈 대상이 아니다.

각 도시에 `floor(R*w_i/W)`를 우선 배분하고 남은 정수는 도시 키 오름차순으로 한 단위씩 준다. W=0이면 G·S·R은 모두0이다. 관문은 세수·적립 대상에서 뺀다. 새 판의 개인 급여는 원본과 정확히 같고 도시 적립 합계는 원본의 국고 증가분과 정확히 같아야 한다. 새 국고 증가분은0이다. 무장0명·세수0·소수 반올림·동률·소유 변화·정수 경계를 고정 시험한다.

### 모집·훈련·배속과 수비

모병·징병은 현재 자기 국가 거점의 장수가 기존 개인 예약 한 칸으로 실행한다. 기존 병종·인구·민심·매력 비용 산식을 쓰고 금은 도시 원장에서 차감한다. 병력은 도시의 해당 병종에만 더하며 부곡을 생성하거나 직접 충원하지 않는다. 새 병사의 훈련·사기는 기존 모집과 같은0이다. 같은 병종의 기존 병력과 합치면 기존 훈련·사기를 수량 가중 평균해 버림한다. 도시 전체 병력에 가상의 장수 통솔 상한을 적용하지 않는다. 부곡 배속 때는 실제 지휘관 전체 통솔 상한을 반드시 적용한다.

기존 훈련·사기 명령에 새 판 전용 도시 병종 대상 인자를 추가한다. 자기 국가의 현재 거점 장수가 개인 예약 한 칸을 쓰고 도시 금에서 기존 DRILL_COST를 차감한다. 훈련·사기 증가량은 훈련을 실행한 실제 장수의 기존 drillGain 산식이다. 실제 지휘관을 바꾸거나 없는 장수 능력치를 만들지 않는다. 부곡 대상 명령은 기존 동작·개인 지갑을 유지한다.

병력 배속은 군주·참모·수뇌(기존 직책5~12)의 명시적 국가 권한으로 실행한다. 국가의 어느 자기 도시든 대상으로 삼을 수 있지만 대상 부곡 소유자·실제 지휘관은 모두 그 도시에 집결한 자국 인물이어야 한다. 같은 병종 도시 병력을 빼고 대상 부곡에 더하며 훈련·사기는 수량 가중 평균한다. 도시 병력 N 중 M을 부곡 B에 배속할 때 N-M명과 도시 훈련·사기는 그대로 남긴다. M=N이면 빈 병종 행을 지운다. 부곡 훈련은 `floor((B*부곡훈련+M*도시훈련)/(B+M))`이고 사기도 같은 식이다. B=0이면 도시 훈련·사기를 그대로 받는다. 부족한 N·병종 불일치·범위 초과는 양쪽 모두 불변으로 실패한다. 금·쌀·인구·사람의 예약은 바꾸지 않는다. 사람의 즉시 입력은 별도 `city.resources` InputEvent로 접수하고 기존 계정별 중복 키와 단일 적용 경계를 사용한다. NPC는 같은 순수 배속 함수를 호출하는 국가 예약 명령을 골라 실행한다. 무상 자동 충원은 하지 않는다.

수비 순서는 기존 부곡 수비의 순서, 도시 수비병의 병종 번호 순서, 성벽 순서다. 각 공격 부곡은 남은 수비를 이 순서대로 상대한다. 도시 수비병에는 기존 부곡의 훈련20 선발 문턱을 적용하지 않는다. 사기가 있는 병사는 훈련0이어도 실제 병종·도시 소유국 기술·city.defence로 simulateBattle에 들어간다. 수비 측 장수 보정은 생략한다. 성벽은 기존1000 병종·성벽 수치로 별도 교전하며 도시 병사를 다시 세지 않는다.

도시 교전 전에 기존 `ceil(병력*BATTLE_RICE_PER_CREW)`만큼 도시 쌀을 한 번 차감하고 기존 기아 사기 감소를 적용한다. 도시 수비에 부곡 소유자의 쌀을 함께 차감하지 않는다. 도시 수비병의 사기가0이면 교전 불능으로 패주 처리해 해산·민간 복귀를 기록한다. 이를 보이지 않는 병력0으로 덮거나 사기를100으로 올리지 않는다. 성벽이 남거나 사기가 있는 생존 수비병/부곡이 남으면 점령할 수 없다. 함락 시 잔여 병력의 비승계·민간 복귀도 같은 함수로 처리한다.

조회는 기존 cityInfo의 자국/현재 거점 상세 가시성을 따른다. 공개 지도·타임랩스에 도시 금·쌀·수비병을 덧붙이지 않는다. NPC는 도시 금·인구·수비병과 훈련·사기를 보고 모집 또는 도시 준비를 고르고 국가 권한자는 집결한 부곡에 한정 수량을 배속한다. 배속 완료 뒤 기존 부곡 훈련·사기·출병을 이어 간다. 도시 적립이 없는 첫 수확 전에는 무상 병력을 만들지 않는다.

NPC의 빈 부곡 편성은 개인 예약 한 칸의 `form_unit`으로 처리한다. 같은 병종의 빈 부곡을 중복 생성하지 않으며 병력·자원·다른 사람 예약을 만들지 않는다. 모집 명령은 여전히 도시 병사만 늘린다. NPC는 기존 준비 기준인 병력2000·훈련60·사기70을 사용해 도시 준비와 부곡 준비를 고른다. `nation_city_allocate`는 새 판의 국가 예약 한 칸으로 같은 배속 함수를 실행한다. 기존 판의 직책 명령 표와 사람의 30칸은 바꾸지 않는다. 사람의 즉시 배속은 별도 입력으로 접수한다.
