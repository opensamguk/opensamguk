## 0. 이 문서의 위치

## 계획 (Claude)

### 목표

자기 장수와 같은 국가 장수의 특기를 메인에서 본다. 이름 옆에 내정·전투 분류가 글자로 붙고 설명(이 월드에서 실제로 들어가는 효과)을 읽을 수 있다. 특기 효과를 켜지 않은 월드나 효과 범위 밖 특기는 그렇다고 밝히고 효과를 지어 보이지 않는다. 특기가 없으면 `없음`이다.

### 범위

| 구분 | 파일 | 담당 → 리뷰 |
| ---- | ---- | ----------- |
| 새 파일 | `apps/web/src/general/Traits.tsx`(`TraitBadge`, `TraitDetail`), `general/Traits.module.css`, `general/traits.test.tsx` | Claude → Codex |
| 고치는 파일 | `apps/web/src/main/GeneralInfo.tsx`(장수 정보 칸에 특기 한 줄, 58~75줄 `InfoGrid` 항목), `main/NationInfo.tsx`(소속 장수 표에 특기 열 하나, 187~190줄 `generalColumns`) | Claude → Codex |
| E2E | 새 `e2e/traits.spec.ts`, `e2e/traitsSeed.ts` | Claude → Codex |

`apps/server`, `packages/*`, 경로·메뉴는 고치지 않는다.

### 하지 않는 것

- 특기 효과 계산, 특기 목록 화면, 다른 국가 장수의 특기 보기(서버가 보내지 않는다).
- 특기 초기화 명령의 인자·표시(T4-57·T4-58), 도시 정보의 주둔 장수 표에 특기 넣기(쟁점 T26-Q2).
- 성격 표시 변경. 성격은 지금처럼 표시하지 않는다.

## 2. 화면 계약

### 2.1 장수 정보 칸

- 항목 이름 `특기`, 값은 `TraitBadge`. 예: `경작` 뒤에 `Tag` `내정`. 전투 특기면 `전투`.
- 값을 누르거나 초점을 두고 Enter를 누르면 같은 칸 아래에 `TraitDetail`이 펼쳐져 `description`을 한 줄로 보인다. 다시 누르면 접힌다. 마우스 올림만으로 여는 툴팁은 쓰지 않는다(키보드와 터치).
- `active: false`면 이름 옆에 `Tag` `효과 꺼짐`을 붙이고 설명 자리에 `이 월드에서는 특기 효과를 쓰지 않습니다.`를 쓴다.
- 효과 범위 밖 특기(T4-25 TT-2)면 서버 `description`이 정한 문구를 그대로 쓴다. 화면이 따로 판단하지 않는다.
- `trait: null`이면 `없음`.

### 2.2 국가 정보 칸 소속 장수 표

- 열 `특기`. 값은 `TraitBadge`의 짧은 꼴(이름과 분류 글자 한 자, 예: `경작 (내)`). 정렬은 이름.
- 표에서는 설명을 펼치지 않는다. `title` 속성에도 넣지 않는다. 설명은 장수 정보 칸에서만 본다.
- 공개 범위 밖 장수(서버가 `trait` 칸을 주지 않음)는 —와 지금 표의 이유 표시 방식을 따른다.

### 2.3 접근성

- 분류는 색이 아니라 글자로 밝힌다.
- 펼침 단추는 `aria-expanded`와 `aria-controls`를 쓴다.

### 3.2 Chromium E2E (`e2e/traits.spec.ts`, `pnpm e2e`)

실제 `pnpm dev`와 `_test` PostgreSQL. 준비(`traitsSeed.ts`)는 T2-26 `saveInitialWorld`의 `ruleFeatures: ['traits']`로 월드 T를, 규칙 기능 없이 월드 O를 만든다(T4-25 §2.2). 각 월드에 사람 장수 A를 만들고 준비 스크립트가 DB에서 A의 `special`을 `경작`으로 바꾼다. 화면 응답을 짓는 것이 아니라 DB 준비이며 새 장수가 특기를 얻는 규칙(TT-5)이 없어서다. 같은 국가에 시나리오 전투 특기 장수 하나를 둔다. 턴 실행은 `TurnLoop`를 직접 돌린다.

| ID | 시험 | 기대 |
| -- | ---- | ---- |
| E1 | T 메인 | 장수 정보에 `경작` `내정`. 펼치면 서버 설명 |
| E2 | T 국가 정보 | 소속 장수 표에 A와 전투 특기 장수의 특기 열 |
| E3 | T에서 효과 반영 | A가 농지 개간을 실행한 뒤 개인 기록의 결과 수치가 같은 상태를 순수 함수로 돌린 값(준비 스크립트가 계산)과 같다. 특기 없는 대조 장수와 다르다 |
| E4 | O 메인 | `경작`과 `효과 꺼짐`. 같은 농지 개간 결과가 특기 없는 대조와 같은 계산이다 |
| E5 | 다른 국가 | 다른 국가 계정으로 A의 국가 정보를 열면 특기 열이 — |
| E6 | 특기 없는 장수 | `없음` |
| E7 | 키보드 | Tab으로 특기 값에 가서 Enter로 펼침 |
