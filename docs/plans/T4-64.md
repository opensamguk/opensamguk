## 1. 목표

AC-M1-14의 이 명령 행(`travel`)이 대응표 11단계 증거를 모두 갖는다. 켠 월드의 장수가 견문하면 시드로 정해지는 사건 하나를 겪고 경험을 얻으며 사건에 따라 금·쌀이 늘거나 줄고 다칠 수 있다. 같은 시드면 같은 사건이다. 끈 월드와 기본 37개는 바뀌지 않는다.

### 4.2 RNG 소비 순서

1. `pickWeighted(rng, TRAVEL_EVENTS)`. `rng.next()` 한 번.
2. 고른 줄에 가벼운 부상이 있으면 `rng.int(10, 20)`.
3. 고른 줄에 큰 부상이 있으면 `rng.int(20, 50)`. 13번 줄은 2와 3을 차례로 쓴다.

이미 부상 80 이상이어도 2·3의 난수는 소비한다. `Math.random()`과 현재 시각은 쓰지 않는다.

### 4.3 효과

| 순서 | 효과 | 조건 |
| ---- | ---- | ---- |
| 1 | `general experience add` 30 또는 60 | 항상 |
| 2 | `general gold add 300` 또는 `rice add 300` | 얻는 줄 |
| 3 | `general gold add −min(200, gold)` 또는 `rice add −min(200, rice)` | 잃는 줄 |
| 4 | `general injury set min(80, injury + d)` | 다치는 줄, 지금 부상 < 80일 때만(S2 (나)) |

13번 줄은 4를 두 난수를 더한 값으로 한 번만 낸다. 효과 목록 순서는 골든으로 고정한다.

### 4.4 사건표와 기록 문장

문장은 원작을 옮기지 않고 새로 썼다. 금액 자리는 실제로 바뀐 양이다. 장수 로그 `logs` 한 줄이며 보고·국가 기록은 없다.
