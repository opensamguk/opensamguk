수정 범위는 apps/web/src/general/, apps/web/src/personnel/, apps/web/src/turns/, apps/web/src/battleSim/, e2e/, docs/user/다. 새 기능을 더하지 않는다. 기존 main·v1 기준 SHA와 자원 출처는 통합 기준 문서를 따른다. 세부 코드 경계·API 인증·엔진 단독 상태 변경·시드 RNG·턴 트랜잭션을 지킨다.

검증은 실제 API의 생성→영입→편성→지휘→기존 이동→전투, 타인 예약 보호·오래된 revision·NPC 중복 입력·재접속·잘못된 입력·모바일 핵심 흐름

## 구현 기록

2026-10-28 남은 연결을 주둔 표·통합판 도움말·단일 교전 지휘관 미리보기의 세 묶음으로 대조했다. 각 묶음은1일 이내이며 AC-INT-11을 따른다. 기존 시뮬레이터의 구형 결과와 Worker 경계를 보존하면서 통합판에서만 통솔·무력 보정을 명시적으로 입력하고 엔진과 같은 계산부를 사용한다. 다른 세 능력치·성벽 지휘관을 임의로 채우거나 전체 출병 예측을 추가하지 않는다.

2026-10-27 사용자 담당 인계에 따라 Codex가 구현한다. 생성 화면의 월드별5값·설명, 메인의 개인 휘하·동의·편성/지휘, 실제API·모바일·예턴 초안 보호 검증의 세 묶음으로 나눈다. 각각1~2일이며 AC-INT-11에 연결한다. 기존3스탯 월드의 생성 계약과30칸 예약은 유지한다. 서버의 확정 결과를 표시하고 사람의 수락을 화면이나 시험이 대신 기록하지 않는다.

## 리뷰

서버의 월드별 생성 규칙으로 기존3값과 신규5값·275 합계를 구분하고 정본의 시작 유형을 연결했다. 메인 장수 정보의 정치·매력과 개인 휘하·명망·NPC 비용/확률/월 제한·사람 본인 응답·부곡 편성/지휘/해산·잔여 금/쌀을 표시한다. 요청은 사용자·월드별 같은 번호로 접수와 완료를 구분하고 새로고침 뒤에도 확정 결과를 조회한다. 개인 예턴 초안과 다른 사람의30칸 예약을 바꾸지 않는다.

구현하지 않은 담당은 NPC 금 부족 사전 안내 누락을 지적했다. NPC에만500금 부족 차단과 이유를 표시하고 무료 사람 제안은 유지한 수정본을 승인했다. web/server 타입과 생성 폼5건, 정식191년21국·491명의 실제 PostgreSQL·HTTP·Chromium1건이 통과했다. 화면 검사는 두 사람의5값 생성/임관, 본인 수락·NPC 영입, 부장 지휘 빈 편성·접수 중 재접속·지휘 변경, 타인 예약·미저장 초안 보존,375px 가로 넘침 없음과44px 버튼을24.4초에 확인했다. 병력이 있는 부곡의 준비/이동/전투와 한 기수 인수, 전체 회귀·CI·병합은 남아 있어 AC는 미완료다.

군사 예약 연결에서 unitId를 구형 명령 스키마로 거부하던 결함을 고쳤다. 월드별 명령 스키마로 예약·편집·사전검사를 처리하고 실제 부장과 부곡의 훈련·사기로 상승량을 계산한다. 독립 리뷰에서 꺼진 확장 명령의 오류 응답 회귀를 지적받아 기존 구분을 복구했다. 집중21건과 정식491명 실제 PG·HTTP33건이 통과했으며 수정본 독립 승인도 받았다. 최신 화면 회귀와 실제 이동/전투 인수는 남았다.

단일 교전 미리보기에는 통합판의 지휘관 통솔·무력을 직접 입력하는 경로를 연결했다. 엔진과 같은 두 능력치 계산부를 쓰며 구형 요청·결과와 성벽의 무보정 계약을 유지한다. 다른 세 능력치나 상대의 비공개 값을 채우지 않는다. 실제 Chromium7건은0·50·100과101 오류, 장수/성벽 Worker 결과, 재실행·실패 복구·취소, 예턴 초안 보존과375px/44px을 통과했다. 새 선택칸의19px 높이는 기존44px 스타일로 고쳤다. 구현하지 않은 담당이 계산부·요청 경계·UI·시험과 수정본을 독립 승인했다.

최신 로컬 전체 `pnpm check`는276파일5,169건을 통과했다. 공개 빌드·자산 검사는102파일·승인 이미지6개·외부 초상0개, 공개 Chromium은4건 모두 통과했다. 이 기록은 단일 교전과 도움말 연결의 증거다. 정식 사람 장수의 직접 점령·한 기수, 최신 전체 PostgreSQL/Chromium과 필수 CI·보호 병합 및 최종 독립 인수는 계속 확인하며 AC는 미완료다.

후속 CI에서 장수 생성 뒤 메인 이동이 누락되는 경합을 조사했다. 실제 생성 응답을 보류하고 실제 `general.mine` 재조회가 먼저 생성값을 읽게 한 반례는 수정 전 기존5초 URL 단언에서 실패했다. 유효한 요청을 보내기 직전에 부모 화면에 생성 시작을 기록해 폼이 먼저 사라져도 이동을 유지한다. 처음부터 장수가 있는 경우의 안내와 서버 권한·1.5초 폴링은 유지했다. 수정 뒤 같은 반례와 정식491명 전체 조작1건이 통과했고 두 파일의 최종 코드 독립 리뷰도 받았다. 총120초·URL5초 제한은 바꾸지 않았다. 리뷰에서 지적한 실패 정리 Promise·route/listener 해제를 보완했으며 정리 수정본 재실행과 최종 전체 회귀·CI는 계속 확인한다.

## 병합 뒤 인수 근거

## 2026-10-28 국가 표 조회 보완
