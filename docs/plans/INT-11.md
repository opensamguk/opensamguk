# INT-11 5능력치·휘하·부곡 조작 화면

> AC-INT-11 · 구현 Claude · 리뷰 Codex · 선행 INT-06, INT-09, INT-10, INT-17 · 견적 3~4일
> 사용자 지시로 동결한 [통합판 v0.1](./integration-release.md)과 [5능력치](../product/five-stats.md)를 따른다.

## 계획

목표는 5능력치 생성·역할·효과 미리보기와 휘하/명망·제안/응답·부곡 편성/지휘·잔여 자원을 연결한다. 기존 30칸 예약과 작전판을 유지한다. 비용·호응 확률·상한·실패 이유를 접수 전에 표시한다.

수정 범위는 apps/web/src/general/, apps/web/src/personnel/, apps/web/src/turns/, apps/web/src/battleSim/, e2e/, docs/user/다. 새 기능을 더하지 않는다. 기존 main·v1 기준 SHA와 자원 출처는 통합 기준 문서를 따른다. 세부 코드 경계·API 인증·엔진 단독 상태 변경·시드 RNG·턴 트랜잭션을 지킨다.

검증은 실제 API의 생성→영입→편성→지휘→기존 이동→전투, 타인 예약 보호·오래된 revision·NPC 중복 입력·재접속·잘못된 입력·모바일 핵심 흐름

선행 인수 뒤 착수하고 검증 결과와 구현하지 않은 담당의 리뷰를 같은 문서에 남긴다. 구현자가 스스로 완료로 바꾸지 않는다.
