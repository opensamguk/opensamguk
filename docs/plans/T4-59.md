## 1. 목표

AC-M1-14의 이 명령 행(`gift`)이 대응표 11단계 증거를 모두 갖는다. 켠 월드에서 장수가 같은 국가 장수에게 자기 금이나 쌀을 넘기고 경험·공헌을 얻는다. 본인, 다른 국가 장수, 재야 대상은 실패한다. 끈 월드와 기본 37개는 바뀌지 않는다.

### 4.2 정의

| key | name | category | target | args |
| --- | ---- | -------- | ------ | ---- |
| `gift` | 증여 | `personal` | `general` | `z.strictObject({ generalId: positive, resource: z.enum(['gold', 'rice']), amount: z.number().int().min(1).max(10_000) })` (S1 (나)) |

인자 이름은 `nation_reward`(`nation.ts:7`)와 같게 둔다. 원작 분류는 `국가`지만 장수 자기 자원을 쓰므로 `donate`와 같은 `personal`로 둔다. 확정은 Codex 검토가 한다. 대상 `generalId`는 명령 인자일 뿐이며 행위자는 서버가 세션에서 정한다(AGENTS §7).

### 4.3 검사 순서와 실패

| 순서 | 조건 | code | 문구 |
| ---- | ---- | ---- | ---- |
| 1 | 장수 없음 | `NO_ACTOR` | 장수가 없습니다. |
| 2 | 대상이 자기 자신 | `BAD_TARGET` | 자기 자신에게는 증여할 수 없습니다. |
| 3 | 재야이거나 국가 없음 | `NOT_NATION` | 국가에 소속되어야 합니다. |
| 4 | 현재 도시가 자기 국가 도시 아님 | `NOT_OWN_CITY` | 자기 국가 도시에서만 가능합니다. |
| 5 | 현재 도시 보급 끊김 | `NO_SUPPLY` | 보급이 끊긴 도시입니다. |
| 6 | 대상이 없거나 다른 국가·재야 | `BAD_TARGET` | 같은 국가 장수에게만 증여할 수 있습니다. |
| 7 | 넘길 양 0 (S3 (나)) | `NO_GOLD` 또는 `NO_RICE` | 증여할 금이 없습니다. / 증여할 쌀이 없습니다. |

순서는 원작(본인 → 재야 → 도시 → 보급 → 대상 → 자원)을 따른다. 3~5는 `ownCity`를 부른다. 6에서 없는 장수와 다른 국가 장수의 문구를 하나로 둬 사전 검사가 다른 국가의 장수 번호를 가리는 데 쓰이지 않게 한다.

### 4.4 계산과 효과

- `keep = resource === 'gold' ? 0 : 500` (S2 (가))
- `amount = min(args.amount, max(0, 보유 − keep))` (S4 (가))

효과는 필드 변경만이며 순서를 골든으로 고정한다. RNG는 쓰지 않는다.

| 순서 | 효과 |
| ---- | ---- |
| 1 | `{ kind: 'general', id: actor, field: resource, op: 'add', value: −amount }` |
| 2 | `{ kind: 'general', id: 대상, field: resource, op: 'add', value: amount }` |
| 3 | `{ kind: 'general', id: actor, field: 'experience', op: 'add', value: 70 }` |
| 4 | `{ kind: 'general', id: actor, field: 'dedication', op: 'add', value: 100 }` |

### 4.5 로그·보고

| 경우 | `logs` (행위 장수) | `reports` (대상 장수) |
| ---- | ------------------ | --------------------- |
| 성공 | `증여: {대상 이름}에게 금 {amount}` (쌀이면 쌀) | `{행위 장수 이름}에게서 금 {amount} 받음` |

요청보다 적게 넘긴 경우에도 실제로 넘긴 양을 적는다. 국가 기록은 없다.
