## 계획 (Claude)

### 목표

메인, 지도, 예턴 편집(T1-15), 도시 정보, 국가 정보, 기록이 실제 데이터로 동작한다 (AC-M1-19).

### 화면별 내용

| 화면 | 보여 줄 것 | API |
| ---- | ---------- | --- |
| 메인 | 장수(능력치·금·쌀·병력·훈련·사기·경험·공헌·위치·소속·직책), 현재 도시 요약, 국가 요약, 다음 턴까지 남은 시간, 예턴 앞 5칸, 최근 로그 10줄 | `home.get` |
| 지도 | 94도시 SVG, 소유국 색, 연결선, 보급 끊김 표시, 내 위치 강조, 도시 클릭 → 도시 정보 | `world.map` |
| 도시 정보 | 수치와 최대치 막대, 주둔 장수(공개 범위 안에서) | `city.get` |
| 국가 정보 | 국고·군량·세율·기술(소속만), 소속 장수 표, 소유 도시 표. 관리 필요 항목 노랑·빨강 강조(myosam 아이디어) | `nation.get` |
| 기록 | 탭 3개: 내 장수 로그 · 국가 역사 · 월드 정세. 더 보기 | `records.*` |
| 첫 화면 `/` | 로그인했고 `next`가 없으면 첫 RUNNING 월드(`/w/:id`)로 보낸다. 없으면 "열린 월드가 없습니다" (T1-14에서 넘어온 일) | `world.list` |

### 결정

- 남은 시간은 서버의 `nextTurnAt`에서 1초마다 화면만 줄인다. 0이 되면 `home.get`을 다시 조회 (M2 SSE 전까지).
- 공개 범위 때문에 빠진 필드는 "—"로 표시하고 이유 툴팁(예: "다른 국가 정보").
- 국가색 대비가 낮으면 글자색을 자동으로 바꾼다 (지도 이름표 가독성).
- NPC 장수는 이름 앞 표시와 별도 색 (myosam 아이디어).
- 표는 정렬 가능, 숫자 오른쪽 정렬.

### 소유자 UI 정정 (2026-10-21)

위 화면별 표는 화면을 주소마다 나눈 원래 계획이며 기록으로 둔다. 현재 기준은 [D-020](../product/decisions.md#d-020-메인-한-화면에서-지도와-예턴을-함께-다룬다-2026-10-21)과 [UI 지침 §2](../frontend-ui-guidelines.md#2-메인-작업-화면-m1)다.

- 원작 대조: 레퍼런스 R1 core2026 `MainView.vue`(`df6c926`)의 `layout-desktop`은 10열 격자다. 1행 지도(1~7열)와 명령 목록(8~10열, 1~2행), 2행 도시 정보, 3행 국가(1~5열)·장수(6~10열), 그 아래 기록(장수 동향·개인 기록 2열, 중원 정세 전체 폭)이다.
  명령 목록은 `CommandListPanel` → `ReservedCommandEditor`로 예약·당김·반복을 같은 화면에서 한다.
- 현재 소스(`eedd815`) 대비 바꾼 것: 빈 5패널 격자와 왼쪽 장수 요약 띠를 없애고 메인을 R1 배치로 다시 짰다. 지도 도시 선택은 주소의 `?city=`만 바꿔 같은 화면의 도시 정보 칸을 바꾼다.
  국가 상세 표와 기록 더 보기도 메인 안에서 연다. `/map`, `/city/:key`, `/nation/:id`, `/records`는 같은 부품을 쓰는 보조 화면으로 남겼다.
- 유지한 것: T1-12 조회 API·공개 범위, T1-13 토큰·공통 부품, T1-14 로그인 가드, `/create`·`/turns` 경로(T1-15 소유).
- 편집기 연결 계약(총괄 확정): T1-15가 `apps/web/src/turns/TurnEditor.tsx`의 `TurnEditor({ worldId, selectedCityKey })`를 만든다. T1-16은 그 편집기를 메인 명령 칸에 끼운다.
  `selectedCityKey`는 지도에서 고른 `city.key`이며 대상 고르기 힌트일 뿐이다. 메인은 지도 선택·재조회 때 편집기를 다시 만들지 않는다.
- 검증 기준도 바뀌었다: 주소 6개가 열리는 것이 아니라, 같은 메인에서 지도 선택·30칸 입력·저장·충돌 안내·도시 변경과 재조회 뒤 초안 유지·턴 결과를 실제 DB·HTTP·Chromium으로 본다.
