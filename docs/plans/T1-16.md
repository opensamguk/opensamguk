# T1-16 핵심 화면 6개 연결

> 대기열: T1-16 · AC: AC-M1-19 · 구현: Claude · 리뷰: Codex
> 선행: T1-12 (조회 API), T1-13 (화면 기반), T1-20 (월드 목록)

## 계획 (Claude)

### 목표

메인, 지도, 예턴 편집(T1-15), 도시 정보, 국가 정보, 기록이 실제 데이터로 동작한다 (AC-M1-19).

### 화면별 내용

| 화면 | 보여 줄 것 | API |
| ---- | ---------- | --- |
| 메인 | 장수(능력치·금·쌀·병력·훈련·사기·경험·공헌·위치·소속·직책), 현재 도시 요약, 국가 요약, 다음 턴까지 남은 시간, 예턴 앞 5칸, 최근 로그 10줄 | `home.get` |
| 지도 | 94도시 SVG, 소유국 색, 연결선, 보급 끊김 표시, 내 위치 강조, 도시 클릭 → 도시 정보 | `world.map` |
| 도시 정보 | 수치와 최대치 막대, 주둔 장수(공개 범위 안에서) | `city.get` |
| 국가 정보 | 국고·군량·세율·기술(소속만), 소속 장수 표, 소유 도시 표. 관리 필요 항목 노랑·빨강 강조(myosam 아이디어) | `nation.get` |
| 기록 | 탭 3개: 내 장수 로그 · 국가 역사 · 월드 정세. 더 보기 | `records.*` |
| 첫 화면 `/` | 로그인했고 `next`가 없으면 첫 RUNNING 월드(`/w/:id`)로 보낸다. 없으면 "열린 월드가 없습니다" (T1-14에서 넘어온 일) | `world.list` |

### 결정

- 남은 시간은 서버의 `nextTurnAt`에서 1초마다 화면만 줄인다. 0이 되면 `home.get`을 다시 조회 (M2 SSE 전까지).
- 공개 범위 때문에 빠진 필드는 "—"로 표시하고 이유 툴팁(예: "다른 국가 정보").
- 국가색 대비가 낮으면 글자색을 자동으로 바꾼다 (지도 이름표 가독성).
- NPC 장수는 이름 앞 표시와 별도 색 (myosam 아이디어).
- 표는 정렬 가능, 숫자 오른쪽 정렬.

### 소유자 UI 정정 (2026-10-21)

위 화면별 표는 화면을 주소마다 나눈 원래 계획이며 기록으로 둔다. 현재 기준은 [D-020](../product/decisions.md#d-020-메인-한-화면에서-지도와-예턴을-함께-다룬다-2026-10-21)과 [UI 지침 §2](../frontend-ui-guidelines.md#2-메인-작업-화면-m1)다.

- 원작 대조: 레퍼런스 R1 core2026 `MainView.vue`(`df6c926`)의 `layout-desktop`은 10열 격자다. 1행 지도(1~7열)와 명령 목록(8~10열, 1~2행), 2행 도시 정보, 3행 국가(1~5열)·장수(6~10열), 그 아래 기록(장수 동향·개인 기록 2열, 중원 정세 전체 폭)이다.
  명령 목록은 `CommandListPanel` → `ReservedCommandEditor`로 예약·당김·반복을 같은 화면에서 한다.
- 현재 소스(`eedd815`) 대비 바꾼 것: 빈 5패널 격자와 왼쪽 장수 요약 띠를 없애고 메인을 R1 배치로 다시 짰다. 지도 도시 선택은 주소의 `?city=`만 바꿔 같은 화면의 도시 정보 칸을 바꾼다.
  국가 상세 표와 기록 더 보기도 메인 안에서 연다. `/map`, `/city/:key`, `/nation/:id`, `/records`는 같은 부품을 쓰는 보조 화면으로 남겼다.
- 유지한 것: T1-12 조회 API·공개 범위, T1-13 토큰·공통 부품, T1-14 로그인 가드, `/create`·`/turns` 경로(T1-15 소유).
- 편집기 연결 계약(총괄 확정): T1-15가 `apps/web/src/turns/TurnEditor.tsx`의 `TurnEditor({ worldId, selectedCityKey })`를 만든다. T1-16은 그 편집기를 메인 명령 칸에 끼운다.
  `selectedCityKey`는 지도에서 고른 `city.key`이며 대상 고르기 힌트일 뿐이다. 메인은 지도 선택·재조회 때 편집기를 다시 만들지 않는다.
- 검증 기준도 바뀌었다: 주소 6개가 열리는 것이 아니라, 같은 메인에서 지도 선택·30칸 입력·저장·충돌 안내·도시 변경과 재조회 뒤 초안 유지·턴 결과를 실제 DB·HTTP·Chromium으로 본다.

## 구현 기록 (Claude)

- 담당: `opensamguk-frontend-implement`, 카드 `t_1290c125`, 브랜치 `wt/t_1290c125`. 시작 기준 `eedd815`, 진행 중 `176330f`(T1-11 병합)로 맞췄다. 상태: 진행중. 편집기 결합 전이라 리뷰로 넘기지 않는다.
- 바꾼 것:
  - 메인 작업 화면 `apps/web/src/pages/MainPage.tsx`: R1 배치 10열 격자. 칸 부품은 `apps/web/src/main/`(`WorldMap`, `CityInfo`, `NationInfo`, `GeneralInfo`, `CommandPanel`, `Records`, `Panel`).
  - 위쪽 띠 `apps/web/src/layout/GameLayout.tsx`: 월드 이름·현재 연월·다음 턴 카운트다운. 0초에 `home.get`·`world.summary`·기록을 다시 받는다. 같은 시각이 다시 오면 5·10·20·30초 뒤 네 번만 더 묻는다 (`apps/web/src/game/countdown.ts`).
  - `/`는 첫 RUNNING 월드로 보낸다(`router.tsx`의 `beforeLoad`). 없으면 열린 월드가 없다는 안내.
  - 보조 화면 `apps/web/src/pages/WorldPages.tsx`(지도·도시·국가·기록). 공통 부품 `DataTable`(머리글 정렬)·`Tag`·`LoadingState`.
  - 시험: 단위 `apps/web/src/game/game.test.tsx`(시계 주입 카운트다운·0초 재조회·백오프 상한, 기록 연월, 오류 재시도), `apps/web/src/main/main.test.tsx`(지도 연결선·접근 이름·선택, 표 정렬, 관리 표시, 예약 시각).
    E2E `e2e/main.spec.ts`: 엔진 CLI로 턴 1분 월드를 만들어 실제 엔진이 턴·월간 정산을 처리하는 상태에서 메인 배치(지도 오른쪽 명령 목록), 94도시·소유국 색·연결선·보급·내 위치, 적 도시 선택 시 같은 문서 유지와 서버 응답에 수치 없음,
    국가 표 정렬, 0초 재조회 뒤 새 시각과 엔진이 쓴 개인 기록, 월간 정산 뒤 국가 기록·중원 정세, 생성 API로 만든 재야 장수, 장수 없음, 없는 월드, 보조 주소를 본다. 스크린샷 9장.
- 계획과 달라진 점과 이유:
  - 소유자 UI 정정으로 별도 주소 중심 배치를 메인 한 화면으로 바꿨다 (위 절, D-020).
  - AppRouter 타입에서 `city.get`·`nation.get`·`home.get`의 상세 필드가 빠진다. 서버의 `cityInfo`·`nationInfo`가 공개 모양과 상세 모양을 함께 반환해 반환 타입 추론이 공개 모양 하나로 줄기 때문이다.
    화면은 T1-12 계약의 상세 필드를 `apps/web/src/game/types.ts`에 적는다. 실제로 받은 필드가 있는지로 가른다. 서버 수정은 하지 않았다(Codex 소유).
  - NPC 표시는 응답에 NPC 여부가 없어 넣지 않았다. 기록의 연월은 `world.summary`의 현재 연월·tick·tick 길이로 화면에서 붙인다(서버 값만 사용).
  - 시험 계정의 국가 소속 화면을 보려고 `e2e/world.ts`가 시나리오 소속 장수 하나에 계정을 DB로 붙인다. 빙의에 해당하는 API가 없어서다. 생성 API 경로는 따로 시험한다.
  - 기록 입력은 strict라 tRPC `infiniteQueryOptions`가 덧붙이는 `direction`을 거부한다. 화면은 커서만 넣어 직접 부르고 쿼리 키는 같은 procedure 아래에 둔다 (`main/Records.tsx`).
  - 공백지는 늘 보급이 없으므로 보급 끊김은 국가 도시에만 표시한다. 시나리오 소속 장수는 직책 0으로 시작해 소속이 있으면 0도 일반으로 보인다.
- 남은 것: T1-15 `TurnEditor`를 메인 명령 칸에 끼운다. 그다음 같은 메인에서 30칸 입력·저장·STALE·지도 선택과 재조회 뒤 초안 유지·턴 결과를 E2E로 본다. 그 전에는 AC-M1-19를 통과로 쓰지 않는다.
- 검증 결과: 로컬 `pnpm install`·`check`·`e2e`는 공용 검증 자원 대기(exit 75)로 시작하지 못했다. 로컬에서는 Prettier, ESLint(`apps/web/src`, `e2e`), `pnpm lint:text`만 통과했다.
  GitHub CI 39546565983(head `5ead468`, [PR #48](https://github.com/peppone-choi/opensamguk/pull/48) 초안)에서 `pnpm check`(단위 63파일), 웹 빌드, 실제 PostgreSQL 통합 10파일, Chromium E2E 37개가 통과했다.
  스크린샷 9장은 같은 소스에 업로드 단계만 더한 탐침 `qa/t1-16-screens` 실행 39546569011의 산출물이다(병합하지 않음). 첫 실행에서 기록 칸이 tRPC 무한 조회의 `direction` 때문에 400을 받은 것을 스크린샷으로 찾아 고쳤다.
