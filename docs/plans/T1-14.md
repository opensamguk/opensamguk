# T1-14 로그인·가입 화면

> 대기열: T1-14 · AC: AC-M1-05 (화면) · 구현: Claude · 리뷰: Codex
> 선행: T1-10 (API), T1-13 (화면 기반)

## 계획 (Claude)

### 목표

T1-10의 계정 API로 가입·로그인·로그아웃을 화면에서 한다. 이 화면까지 끝나야 AC-M1-05가 사용자 기준으로 끝난다.

### 범위

`apps/web`의 `/login`, `/signup`, 위쪽 띠의 로그아웃, 로그인 가드가 `auth.me`를 쓰도록 연결.

### 하지 않는 것

이메일 인증·비밀번호 재설정·약관 동의(M3 T3-03).

### 결정

- 입력 검사는 화면에서도 하되(이메일 형식, 비밀번호 10~128자) 최종 판단은 서버 응답.
- 오류 표시: `UNAUTHORIZED` → "이메일 또는 비밀번호가 맞지 않습니다", `CONFLICT` → "이미 가입된 이메일입니다", 네트워크 → 다시 시도 버튼.
- 성공하면 `next` 주소로, 없으면 월드 목록이 생기기 전까지 첫 RUNNING 월드(`/w/:id`)로.
- 비밀번호 칸은 `autocomplete="current-password"`/`"new-password"`, 보이기 토글.
- 제출 중에는 버튼을 막고 진행 표시.

### 검증

| 무엇 | 어떻게 |
| ---- | ------ |
| 흐름 | Playwright: 가입 → 메인 이동 → 로그아웃 → 로그인 → 메인 |
| 오류 | Playwright: 틀린 비밀번호, 중복 이메일 메시지 |
| 가드 | Playwright: 로그아웃 상태에서 `/w/1` → 로그인 → 원래 주소로 복귀 |
| 키보드 | Playwright: Tab·Enter만으로 로그인 |
