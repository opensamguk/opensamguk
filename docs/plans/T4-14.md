## 계획 (Claude)

### 목표

AC-P2-08 (가): 강행은 원작 근거의 거리 안 도시로 한 턴에 이동한다. 이 작업은 명령 정의와 단위 시험 몫이다. 등록과 엔진 시험은 T4-17, 일반 명령 저장·사전 검사 연결은 T4-03, 인자 화면은 T4-04다. 방랑 국가(AC-P2-08 (나))는 T4-48이며 이 작업의 완료로 세지 않는다(명세 §6.1).

### 명령 key

`forced_march`(대응표 원본 `general:che_강행`, 대상 `general`, AC `AC-P2-08`).

### 범위

| 파일 | 내용 |
| ---- | ---- |
| 새 파일 `packages/rules/src/commands/ext/forcedMarch/forced_march.ts` | 명령 정의 하나 |
| 새 파일 `ext/forcedMarch/index.ts` | `forcedMarchCommands` 배열 |
| 새 파일 `ext/forcedMarch/forced_march.test.ts` | 성공·대표 실패와 반례 |
| `resources/NOTICE.md` | 원작 출처 한 줄 |

손대지 않는 파일은 `ext/registry.ts`, `ext/state.ts`, `ext/stratagem/`(거리 함수 import만), `commands/military.ts`, `registry.ts`, `types.ts`, `effects.ts`, `src/index.ts`, 엔진·서버·화면이다. 상태 조각이 필요 없다.

### 하지 않는 것

- 방랑 군주가 강행하면 국가 장수 전원이 함께 옮기는 원작 동작. 우리에게 방랑 국가가 없고 그 표식은 T4-48이 정한다. T4-48이 그 동작을 더할지 정한다(상대 영역).
- 아이템 추첨(원작 `tryApplyUniqueLottery`). 장비 범위 U-06 밖이다.
- 운영 등록(T4-17), 저장·재생(T4-03), 화면(T4-04).

### 원작 동작

| 항목 | 원작 |
| ---- | ---- |
| 제약 순서 | 같은 도시 아님 → 거리 3 이내 → 금 ≥ `develCost × 5` → 쌀 ≥ 0 |
| 거리 | 연결선 너비 우선 칸 수. 소유와 상관없다 |
| 국가 조건 | 없다. 재야도 쓸 수 있고 다른 국가 도시로도 갈 수 있다 |
| 비용 | 금 `develCost × 5`(시작 해 100), 쌀 0 |
| 효과 | 현재 도시 = 대상, 훈련 = max(20, 훈련 − 5), 사기 = max(20, 사기 − 5), 경험 + 100, 통솔 경험 + 1 |
| 방랑 군주 | 관직 12이고 국가 규모 0이면 국가 장수 전원도 대상 도시로 |
| 난수 | 아이템 추첨만 |
| 기록 | 장수 행동 기록 `{도시}로 강행했습니다.` |

훈련·사기 식은 20 미만인 값을 20으로 올린다. 병력이 없는 장수(훈련 0, 사기 0)가 강행하면 훈련·사기가 20이 된다.

### C10 수치 분리표

#### 단위가 같아 원작 값을 그대로 옮길 수 있는 값

| 값 | 원작 | 우리 쪽에서 같은 이유 |
| -- | ---- | --------------------- |
| 거리 | 3칸 | 우리 지도 연결(`connections`)이 원작 지도를 옮긴 것이다 |
| 훈련·사기 감소 | 5, 하한 20 | 우리 훈련·사기도 0~100이다 |
| 경험 | 100 | T4-05 S0과 같은 근거 |
| 쌀 비용 | 0 | |

#### 환산이나 의미 결정이 필요한 값

| ID | 원작 | 우리 쪽 사정 |
| -- | ---- | ------------ |
| K1 금 비용 | `develCost × 5`, 해마다 오른다 | 우리는 해마다 오르는 비용이 없다(T4-05 K1과 같다) |
| K2 대상 소유 | 다른 국가 도시로도 간다 | 우리 이동은 국가 소속 장수가 다른 국가 도시로 가지 못하게 한다(`military.ts:79-81`). 강행만 허용하면 출병 없이 적 도시에 들어간다 |
| K3 훈련·사기 하한 | 20 미만 값을 20으로 올린다 | 강행이 훈련·사기를 올리는 경우가 생긴다 |

### 기술 계약 초안 (Codex 계획 기술 검토 전)

| key | name | category | target | args |
| --- | ---- | -------- | ------ | ---- |
| `forced_march` | 강행 | `military` | `general` | `z.strictObject({ cityKey: positive })` |

`defineCommand`(`support.ts:27-59`)로 만든다. 장수 위치를 바꿔야 하므로 world 효과가 필요하고 이 명령에는 국가 명령 검사가 없다. 대응표 도구가 읽을 수 있게 `key`와 대상을 글자 그대로 둔다(T4-17 쟁점).

검사 순서와 실패:

| 순서 | 조건 | code | 문구 |
| ---- | ---- | ---- | ---- |
| 1 | 장수 없음 | `NO_ACTOR` | 장수가 없습니다. (`defineCommand`) |
| 2 | 인자 오류 | `BAD_ARGS` | 명령 인자가 잘못되었습니다. (`defineCommand`) |
| 3 | 대상 도시 없음 | `BAD_TARGET` | 도시가 없습니다. |
| 4 | 대상이 현재 도시 | `BAD_TARGET` | 같은 도시입니다. |
| 5 | 거리 3 초과 | `NOT_ADJACENT` | 세 칸 안의 도시로만 강행할 수 있습니다. |
| 6 | FM2 (나): 국가 소속이고 대상이 다른 국가 도시 | `NOT_OWN_CITY` | 다른 국가 도시에는 출병해야 합니다. |
| 7 | 금 < 100 | `NO_GOLD` | 금이 부족합니다. |

- 3과 6의 문구는 이동(`military.ts:76`, `:80`)과 같다.
- 거리는 `stratagemDistance`(`ext/stratagem/base.ts:43-60`)를 import해 쓴다. 3 이하만 허용하므로 5칸 탐색 상한과 99는 결과에 영향이 없다. 같은 너비 우선 탐색을 두 번 쓰지 않으려는 선택이다. 거리 함수를 공용 위치로 옮길지는 G-03에서 정한다.
- 원작 쌀 0 조건은 우리 쌀이 0 미만이 되지 않으므로 검사로 두지 않는다.

효과(`change`):

| 순서 | 바뀌는 것 |
| ---- | --------- |
| 1 | 장수 `cityKey` = 대상 |
| 2 | 금 − 100 |
| 3 | FM3 (나): 훈련이 20 초과면 `max(20, 훈련 − 5)`, 사기도 같은 식 |
| 4 | 경험 + 100 |

- 난수를 쓰지 않는다.
- 로그 `{도시} 강행`. 이동 로그(`military.ts:86`)와 같은 꼴이다. 국가 기록은 없다.
