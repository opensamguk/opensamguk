# T2-10 메시지·공지 화면, 실시간 갱신

> 대기열: T2-10 · AC: AC-M2-04, AC-M2-07 (화면) · 구현: Claude · 리뷰: Codex
> 선행: T2-09 (API)

## 계획 (Claude)

### 목표

메시지를 범위별로 읽고 쓰며 내 턴 결과·새 메시지·월간 정산이 새로고침 없이 2초 안에 화면에 반영된다.

### 범위

- `apps/web/src/realtime/useWorldEvents.ts`: SSE 연결 → 알림 종류별로 TanStack Query 무효화
- 메시지 패널 (메인 오른쪽 접이식 + `/w/:id/messages` 전체 화면), 위쪽 띠 안 읽음 배지
- 국가 공지 팝업 (바뀐 뒤 첫 접속 1회)
- T1-16의 "남은 시간 0초에 다시 조회" 임시 방식을 SSE로 대체

### 하지 않는 것

알림 소리·브라우저 알림(M3 웹 푸시), 메시지 검색.

### 결정

| 알림 | 다시 조회할 것 |
| ---- | -------------- |
| `turn.result` | `home.get`, `turns.get`, `records.general` |
| `message.new` | `message.list`(해당 범위), `message.unread` |
| `monthly.done` | `world.summary`, `home.get`, `world.map` |
| `offer.new`, `treaty.new` | 발령 상자, 외교실 |
| `notice.updated` | 국가 공지 |

- 연결 상태를 위쪽 띠에 작게 표시 (연결됨 · 다시 잇는 중). 끊긴 동안에도 화면은 쓸 수 있다.
- 메시지 탭: 개인 · 국가 · 외교(권한 있을 때만) · 전체. 탭마다 안 읽음 수.
- 보내기 실패(도배 제한 등)는 입력칸 아래에 이유 표시, 입력 내용은 지우지 않는다.

### 검증

| 무엇 | 어떻게 |
| ---- | ------ |
| 실시간 | Playwright: 두 브라우저(사용자 A·B) → A가 보낸 개인 메시지가 B 화면에 2초 안에, 새로고침 없이 |
| 턴 결과 | Playwright: manual 시계로 턴 진행 → 메인 최근 기록이 2초 안에 갱신 |
| 범위 | Playwright: 외교 탭은 군주·참모에게만 |
| 공지 | Playwright: 공지 수정 → 소속 장수 다음 접속 시 팝업 1회 |
| 재연결 | Vitest: 가짜 EventSource로 끊김·재연결 → 전체 재조회 1회 |
