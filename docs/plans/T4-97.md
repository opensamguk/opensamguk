### 런타임 동등성 (AC-P2-35, T4-98)

위 띠·메뉴·예턴 상태·도시에서 명령 고르기는 공통 `apps/web` 하나이며 런타임을 보고 기능·권한·저장 동작을 나누는 분기가 없다. 메뉴 배치는 화면 폭으로만 바뀐다. 저장 상태는 기존 편집기 초안과 기존 `turns.*`·`world.summary`·`home.get`·`world.map` 계약에서만 오며 새 query·API·규칙 판정은 없다. 실시간 갱신은 기존 SSE 계약을 그대로 쓰고 Cloudflare가 같은 갱신 계약을 주는지는 T4-98에서 대조한다.

`e2e/t4-97-game-ui.spec.ts`는 PG 고정물(`saveInitialWorld`·Prisma 조회)로 준비하고 DB를 확인하므로 opensamguk판 증거다. Cloudflare판(Worker·DO·D1)은 아직 연결과 실제 검증 전이며 이 시험을 Cloudflare 완료 증거로 쓰지 않는다. 같은 화면 장면을 Cloudflare에서 실행하려면 브라우저 조작은 그대로 두고 준비·저장 확인만 Worker·D1 쪽으로 바꾼 시험이 필요하다. AC-P2-34는 [런타임 기능 동등성](../architecture/runtime-parity.md)대로 양쪽 실제 실행 전에는 완료가 아니다.
