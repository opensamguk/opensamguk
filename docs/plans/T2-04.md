# T2-04 로비 화면

> 대기열: T2-04 · AC: AC-M2-02 (화면) · 구현: Claude · 리뷰: Codex
> 선행: T2-03 (API)

## 계획 (Claude)

### 목표

로그인 뒤 로비에서 월드 목록(상태·시나리오·턴 간격·인원·시작일)을 보고 참가한다 (AC-M2-02).

### 범위

`apps/web`: `/lobby` 주소, 로그인 성공 뒤 이동 대상을 `/lobby`로 변경 (T1-14의 첫 RUNNING 월드로 보내기를 대신함), 위쪽 띠에 `로비` 링크.

### 하지 않는 것

월드 만들기(M3), 월드 상세 페이지(카드 안 요약으로 충분).

### 화면

```text
┌ 공지 (lobby.notices, 최신 1개 펼침) ─────────────────────────┐
├ 월드 카드 ────────────────────────────────────────────────────┤
│ [진행 중] 정규 1월드 · 군웅할거(191) · 193년 4월               │
│ 턴 60분 · 장수 34/— · 시작 10/18                               │
│ 내 장수: 조운 (공손찬)                     [들어가기]          │
├────────────────────────────────────────────────────────────────┤
│ [가오픈] 속성 2월드 · 공백지(180) · 턴 10분 · 장수 3/10        │
│                                            [장수 만들기]       │
└────────────────────────────────────────────────────────────────┘
```

- 상태는 글자와 색을 함께 쓴다 (색만으로 구분하지 않음). 글자는 `진행 중`, `가오픈`, `멈춤`이다.
- 버튼: 내 장수가 있으면 `들어가기`(`/w/:id`), 없으면 `장수 만들기`(`/w/:id/create`). 서버가 만들 수 없는 이유를 주면 그 이유를 `DisabledReason`으로 보인다 (정원이면 `인원이 찼습니다`).
- 로그인 안 한 사람도 목록을 본다. 버튼은 `로그인하고 참가`이고 `/login?next=/lobby`로 간다.
- 월드가 0개면 `EmptyState`, 목록을 못 받으면 `ErrorState`와 다시 시도. 둘을 섞지 않는다.

### v1 근거

v1 로비(G-03)에 붙인다. 경로와 줄은 v1 저장소(`opensamguk-v1`, 비공개, `bc05362`) 기준이다. 요소 목록은 로컬 `private/v1/catalog/06-web-ui.md`의 G-03·G-P07과 `private/v1/backlog/UI.md`의 UI-03·UI-17에 있다.
같은 폴더 파일은 두 번째부터 이름만 적는다. 오른쪽 칸은 [T2-03](./T2-03.md)의 응답 필드다.

v1과 다르게 정한 것:

- v1은 월드 상태와 내 참가 여부를 칩 하나로 합쳤다 (참가 중·마감·모집 중, `lobbyEntry.ts:50-64`). 새 화면은 상태 칩에 월드 상태만 쓰고 내 참가 여부는 버튼이 맡는다.
- v1은 준비 중이거나 점검 중이면 입장을 막았다 (`ServerCard.tsx:74-80`). 새 화면은 `myGeneral`과 `createBlockedReason`만 보고 버튼을 그린다. 멈춤 월드도 내 장수가 있으면 `들어가기`가 열린다.
- 가오픈 월드의 장수 만들기는 서버가 정한다. 지금 `general.create`는 RUNNING 월드만 받는다 (`apps/server/src/routers/general.ts:37`). 위 그림의 가오픈 카드 버튼은 T2-03이 허용할 때만 열린다.

v1에는 있으나 범위 밖:

- 서버 거르기 칩 (`LobbyScreen.tsx:46-58`). ENDED는 기본 숨김으로만 다룬다.
- 기수 칩, 통일 칩, 따라잡기 배속 칩 (`ServerCard.tsx:101-104`)
- 세력 수와 NPC 수 (`ServerCard.tsx:111`)
- 내 장수 초상 (`ServerCard.tsx:117-124`)
- 현황 펼치기의 지도 미리보기·세력 현황·천하 정세 (`ServerCard.tsx:129-145`)
- 공지 고정 표시와 더 보기 (`NoticeBoard.tsx:61,71`)
- 로비 각주 두 줄 (`LobbyScreen.tsx:12-15,72-76`)
