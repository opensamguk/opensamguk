# T2-04 로비 화면

> 대기열: T2-04 · AC: AC-M2-02 (화면) · 구현: Claude · 리뷰: Codex
> 선행: T2-03 (API)

## 계획 (Claude)

### 목표

로그인 뒤 로비에서 월드 목록(상태·시나리오·턴 간격·인원·시작일)을 보고 참가한다 (AC-M2-02).

### 범위

`apps/web`: `/lobby` 주소, 로그인 성공 뒤 이동 대상을 `/lobby`로 변경 (T1-14의 "첫 RUNNING 월드" 대체), 위쪽 띠에 "로비" 링크.

### 하지 않는 것

월드 만들기(M3), 월드 상세 페이지(카드 안 요약으로 충분).

### 화면

```text
┌ 공지 (lobby.notices, 최신 1개 펼침) ─────────────────────────┐
├ 월드 카드 ────────────────────────────────────────────────────┤
│ [진행 중] 정규 1월드 · 군웅할거(191) · 193년 4월               │
│ 턴 60분 · 장수 34/— · 시작 10/18                               │
│ 내 장수: 조운 (공손찬)                     [들어가기]          │
├────────────────────────────────────────────────────────────────┤
│ [가오픈] 속성 2월드 · 공백지(180) · 턴 10분 · 장수 3/10        │
│                                            [장수 만들기]       │
└────────────────────────────────────────────────────────────────┘
```

- 상태는 글자 + 색 (색만으로 구분하지 않음).
- 버튼: 내 장수가 있으면 "들어가기"(`/w/:id`), 없으면 "장수 만들기"(`/w/:id/create`), 정원이 차면 `DisabledReason`("인원이 찼습니다").
- 로그인 안 한 사람도 목록은 보이고, 버튼은 "로그인하고 참가".

### 검증

| 무엇 | 어떻게 |
| ---- | ------ |
| 흐름 | Playwright: 로그인 → `/lobby` → 장수 없는 월드에서 장수 만들기 → 메인 → 로비로 돌아가면 "들어가기" |
| 상태 | Playwright: 상태 3종 카드 표시, ENDED 숨김 |
| 정원 | Playwright: 정원 찬 월드 → 이유 표시 |
| 무인증 | Playwright: 로그아웃 상태 목록 보임, 버튼은 로그인으로 |
