# INT-15 5능력치 내정·모병·NPC 판단

> AC-INT-15 · 구현 Codex · 리뷰 Claude · 선행 INT-14 · 견적 2~3일
> 사용자 지시로 동결한 [통합판 v0.1](./integration-release.md)과 [5능력치](../product/five-stats.md)를 따른다.

## 계획

목표는 five-stats 문서의 내정 가중치·모병 비용·훈련/사기 산식을 새 프로필에만 적용한다. NPC가 정치형은 내정, 무장형은 군사, 매력형은 주민/모병을 실제 효율로 고른다. 미리보기·실행·재생에서 같은 함수를 쓴다. 기존 RNG 소비 순서와 레거시 산식은 보존한다.

수정 범위는 packages/rules/src/commands/, packages/rules/src/npc/, apps/server/src/routers/turns.ts와 apps/web/src/turns/다. 기본 방침은 기존 실행기를 통해 같은 명령 산식을 쓴다. 새 기능을 더하지 않는다. 기존 main·v1 기준 SHA와 자원 출처는 통합 기준 문서를 따른다. 세부 코드 경계·API 인증·엔진 단독 상태 변경·시드 RNG·턴 트랜잭션을 지킨다.

검증은 모든 명령의 0·50·100과 가중 합·비용/상한, 징병 할인 중첩 방지·민심/전방/비용 보존, 역할별 같은 시드 NPC 선택, 빈 예약 방침·미리보기/실행/재생 일치

선행 인수 뒤 착수하고 검증 결과와 구현하지 않은 담당의 리뷰를 같은 문서에 남긴다. 구현자가 스스로 완료로 바꾸지 않는다.

## 구현 기록

2026-10-27 Codex가 첫 구현에 착수했다. 작업은 정본 내정 점수·모병/훈련 공통 함수, NPC 효율 선택, 실제 실행/재생 검증의 세 묶음으로 나눈다. 각 묶음은 하루 이내이며 AC-INT-15에 연결한다. 첫 묶음은 새 기능 판에서만 정치·매력과 정본 가중 점수를 쓰고 기존 비용·RNG 호출·전방/민심·상한을 보존한다. 모병의 검사·차감과 NPC의 예산 계산은 같은 비용 함수를 쓴다. 미리보기에서 쓸 점수·비용 함수도 실행과 공유한다. 기존 프로필은 기존 산식을 그대로 따른다.

## 리뷰

구현하지 않은 Codex 담당이 첫 산식·NPC 선택·미리보기·API 권한과 구형 동작 보존을 검토해 수정할 제품 결함이 없다고 판정했다. 리뷰 담당은 집중11파일58건과 diff 검사를 직접 통과했다. 구현 담당은 새 점수·비용·NPC·미리보기30건 및 rules/server/web 타입 검사를 통과했다. 실제 PostgreSQL·Chromium·전체 check·CI·병합 전이므로 AC 완료로 세지 않는다.

리뷰에서 빈 예약의 기본 방침 실행·재생 증거가 빠졌다고 지적했다. 실제 PostgreSQL 시험에 정치형 내정과 훈련 방침, 직접 넣은 휴식 보존을 추가했다. 이 보완과 화면 E2E의 실행 결과는 별도로 확인한다.

실제 PostgreSQL·HTTP2건이 통과했다. 인증 없는 요청·타인 장수·행위자 위조를 거부하고 반복 미리보기는 상태와 입력을 바꾸지 않는다. 구형 응답은 그대로다. 새 판에서 내정8종·모병/징병·훈련/사기12종을 예약해 비용과 확정 상승량을 실제 엔진과 대조했다. 이어 직접 넣은 휴식과 빈 예약의 내정·훈련 방침을 실행하고15개월을 재생해 재접속 상태의 해시 및 같은 시드 재생 결과가 일치했다. 다른 월드의 초기 상태도 그대로였다.

실제 PostgreSQL·API·Vite를 쓰는 격리 Chromium1건이7.4초에 통과했다. 30칸과 내정 점수90, 모병비923, 훈련10·사기9, 실제 엔진 차감100과 다음 칸 이동을 확인했다. 보완 시험의 독립 리뷰에서 Origin 도우미 오류를 수정했고 재검토를 통과했다. 이 작은 고정물의 결과는 정식491명 한 기수 인수가 아니다. 전체 check는 기존 복구 셸 단위1건이5초를 넘어 실패했으며 시험 대역의 불필요한 외부 프로세스를 줄인 뒤 다시 확인한다.
