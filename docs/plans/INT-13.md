# INT-13 통합 지도 파일 편집기

> AC-INT-13 · 구현 Codex · 리뷰 Claude · 사용자 직접 요청 2026-10-27

## 계획

개발 전용 /dev/campaign-map-editor에서 도시·관문·항구·전장과 경로를 파일로 편집한다. 기존 v2 편집기는 유지한다. 사용자 요청으로 Codex가 화면까지 맡는다.

packages/rules의 자원 편집 공개 모듈에 순수 v3 초안 계약·참조 검증·경로 계산을 둔다. apps/web/src/mapEditor에 캔버스·거점과 경로 폼·되돌리기·JSON 입출력을 만든다. 좌표와 연결은 새로 만든 검토 초안이다. 원작 배경 이미지는 넣지 않는다. 최초 초안에는 선택한 53도시·8관문·6항구·13전장을 싣되 경로는 검토하며 추가한다. 미연결 경고를 숨기지 않는다.

범위는 오프라인 파일 편집과 연결 확인이다. 런타임 자원 게시·월드 생성·기존 이동 연결은 INT-02·03에서 다룬다. 이 초안 형식은 게임에서 즉시 읽는 운영 형식이 아니다.

검증은 잘못된 참조·중복 ID·방향·수로·양의 안전 정수·항구 귀속·경로 없음·정수 누적을 단위 시험하고 Chromium에서 거점 이동·경로 편집·되돌리기·내보내기와 불러오기·잘못된 파일 보존을 실제 조작한다. 공개 빌드에 개발 화면이 남지 않는지 검사한다.

## 구현 기록

개발 전용 경로에 파일 편집기를 추가했다. 53도시·8관문·6항구 시설·13전장 후보를 처음에 싣고 거점 이동·추가·삭제, 항구 귀속, 지형 다각형, 경로 방식·방향·활성 상태를 편집한다. 되돌리기·다시 적용·JSON 왕복과 참고 밑그림을 지원한다. 밑그림은 파일 내보내기에 포함하지 않는다.

좌표는 main 기반 검토 초안이며 새 지형·연결의 완성본이 아니다. 초기 경로는 비웠다. 거점 사이의 연결 구간을 확인한다. 이동 기간·속도는 계산하지 않는다. 운영 DB에 저장하거나 월드를 바꾸지 않는다.

실제 Chromium에서 새 편집기 2건과 기존 v2 회귀 2건을 통과했다. 확대 후 끌기, 방향·수로, 지형 그리기·왕복·손상 파일 보존·도시 삭제와 항구 복구를 확인했다. 공개 빌드·자산 검사도 통과했으며 개발 편집기 경로는 공개 산출물에서 제외한다. 독립 리뷰 전이다.
