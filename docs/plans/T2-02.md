# T2-02 월드 규칙 프리셋 (D5)

> 대기열: T2-02 · AC: AC-M2-03 · 구현: Codex · 리뷰: Claude
> 선행: T2-01 · 관련: [차별화 D5](../product/differentiation.md#d5-월드-규칙-프리셋-기본-포함), FR-WLD-05, FR-NPC-04

## 계획 (Claude)

### 목표

규칙 프리셋 파일 하나로 턴 간격·시작 조건·명령 세트·NPC 설정이 바뀐다 (AC-M2-03).

### 범위

- `resources/preset/*.json` 4종: `regular`(정규), `speed`(속성), `beginner`(초보), `hardcore`(하드코어)
- `packages/rules/src/world/preset.ts`: zod 스키마와 적용 함수
- `world:create --preset <key>` (기존 `--scenario`·`--turn-term`보다 프리셋이 기본값, 명령줄 값이 우선)
- `World.presetKey`, `World.preset`(만들 때의 프리셋 내용 사본)

### 하지 않는 것

프리셋 편집 화면(M3 관리자), 원작 수치 맞추기.

### 결정: 프리셋 항목

| 항목 | 의미 | 출처 |
| ---- | ---- | ---- |
| `turnTermMinutes` | 턴 간격 | A3 |
| `scenario`, `map`, `unitSet` | 리소스 키 | |
| `commands.general`, `commands.nation` | 허용 명령 key 목록 (없으면 전체) | |
| `npc.fillRatio`, `npc.aggression` | NPC 장수 비율, 출병 가중치 | FR-NPC-04 |
| `protection.foundUntilMonths` | 시작 뒤 이 기간 동안 건국 금지 | myosam 초반 보호 |
| `protection.peaceMonths` | 시작 뒤 이 기간 동안 출병·선포 금지 | myosam |
| `protection.maxGeneralsPerNation` | 국가당 사람 장수 상한 (null이면 없음) | myosam |
| `boost.smallWorld` | 사람 장수 수가 적을 때 내정 상승 배수 표 | myosam 인원 보정 |
| `boost.lateJoin` | 시작 뒤 1년마다 새 장수 시작 금·쌀 증가량 | myosam 늦게 온 장수 |
| `features.advisor` | 군사 조언(D3) 기본 켜기 (초보) | D3 |

- **월드는 만들 때의 프리셋 내용을 `World.preset`에 그대로 저장한다.** 나중에 파일을 고쳐도 진행 중인 월드는 바뀌지 않는다 (재생 결정성).
- 명령 허용 목록 밖의 명령은 `turns.precheck`·실행 검사 모두에서 `COMMAND_DISABLED`로 실패한다.

### 검증

| 무엇 | 어떻게 |
| ---- | ------ |
| 스키마 | 단위: 4종 프리셋 파싱, 잘못된 값 거부 |
| 적용 | 통합: `speed`와 `beginner`로 월드 2개 생성 → 턴 간격·보호 기간·명령 목록이 다름 |
| 보호 | 단위: `peaceMonths` 안 출병 실패(`PROTECTED`), 뒤 성공 |
| 고정 | 통합: 월드 생성 뒤 프리셋 파일을 바꿔도 그 월드 동작 그대로 |
