# T2-21 알림 설정 화면

> 대기열: T2-21 · AC: AC-M2-18 (화면) · 구현: Claude · 리뷰: Codex
> 선행: T2-20 (API)

## 계획 (Claude)

### 목표

사용자가 디스코드 웹훅을 등록·해제하고 받을 알림 종류를 고른다.

### 범위

`apps/web`: `/settings/notifications` (계정 설정, 월드와 무관), 위쪽 띠 계정 메뉴에서 이동.

### 화면

- 웹훅 주소 입력 → [시험 보내고 저장]. 성공하면 "등록됨 (…ab12)", 실패하면 디스코드가 돌려준 이유를 쉬운 말로.
- 알림 종류 체크: 예턴 실패 · 공격받음 · 외교 제안 · 예턴 3칸 이하.
- 웹훅 만드는 법을 3단계로 안내 (디스코드 채널 설정 → 연동 → 웹후크).
- 주소는 저장 뒤 다시 보여 주지 않는다 (끝 4자리만).

### 검증

| 무엇 | 어떻게 |
| ---- | ------ |
| 등록 | Playwright(가짜 웹훅 서버): 저장 → 등록됨 표시 |
| 실패 | Playwright: 디스코드가 아닌 주소 → 이유 표시, 저장 안 됨 |
| 종류 | Playwright: 체크 해제 → 새로고침 뒤 유지 |
